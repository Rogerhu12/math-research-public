## 3. 固定原整数列空间的特征零不包含

对任一个 j，假设存在

\[
 x\in\mathbb Q^{217374},\qquad A_{\rm std}x=h_0t_j.
\]

固定整数列 mod31 独立，故存在一个方形子式在31下为单位。
在该子矩阵上求逆说明 x 的每个坐标在 \(\mathbb Z_{31}\) 中：
不能通过给 x 引入 31 分母规避下一步。
约化 mod31 后，由固定列独立性，x 的唯一剩余类就是已保存的 \(x_{0,j}\)。
于是 \(z=(x-x_{0,j})/31\in\mathbb Z_{31}^{217374}\)，且

\[
 A_{\rm std}z\equiv r_{1,j}\pmod {31}.
\]

对原常预基作正常形，右端必须落在完整 \(\operatorname{im}R\)，与第2节已保存的非零不可约余矛盾。
故各目标分别都有

\[
\boxed{h_0t_j\notin\operatorname{im}_{\mathbb Q}A_{\rm std}
\quad(2\le j\le10).}
\]

该证明给出的是真实特征零**固定列空间**排除；不把数值失败当作原理想排除。

还有一个不需新计算的准确推论：仅增加同一个 mod31 kernel 标准补空间中的允许 s 次数也不能修复它。
所有原常预基的 s 幂、加完整 kernel 的所有标准单项式，在 mod31 下整体线性独立；
任意有限子集因此有单位子式。任何落在该无限标准列族的有限有理线性组合，连同 \(x_0\) 的支撑，
都能在一个有限的 mod31 独立列集中套用上一段证明，仍被同一 \(\rho_j\ne0\) 排除。
这里的“同一个标准列族”是严格限定；加入非标准原列会带来 mod31 kernel 初值自由，上一证明即不适用。

## 4. 为什么没有排除全部原来源

若允许改变原 mod31 解为 \(x_0+k\)，其中 \(k\) 是完整原 mod31 kernel 向量，
选择其整数代表 \(\widetilde k\) 后，下一位 residual 会改变为

\[
 r_1-\frac{A\widetilde k}{31}\pmod {31}.
\]

因此未证明这些 kernel 向量的特征零/整数提升之前，不能把本条非包含推广到全部原来源。
同样，660个未选原 N 行的 mod31 生成缩减，不能自动当作固定整数单位缩减。
本条只保存并证明固定标准补空间的障碍。

另一个可区别的后继是允许候选 \(h_0+31g\)、\(\deg g\le23\) 且最高系数固定，
在相同原商中检验全部九式 \(\rho_j+\operatorname{NF}_G(g t_j)=0\)。
这需要新的共同24未知线性系统；本条未计算或预判其结果。
