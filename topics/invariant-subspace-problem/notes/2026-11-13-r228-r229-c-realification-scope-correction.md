## 准确的四个不同结论

1. 对原空间每个 $F\in A'$，$F^*=CFC$。故
   $$
   \operatorname{Tr}(C\rho C\,F)=\operatorname{Tr}(\rho F),\qquad
   \tau=(\rho+C\rho C)/2
   $$
   给同一个正泛函并保迹。尤其 $SF\in A'$，所以 C 实化**确实保持**指定慢理想的湮灭。原文没有排除这一步。

2. $\tau$ 的 C 实谱项可以两两合成一个正向量泛函，但先实化可能把秩从 $d$ 增至 $2d$。因此该过程不保证迭代降到秩一。R228 对最小分离支撑的 $\dim(W\cap CW)\le1$ 仍保留。

3. R229 两个有限维例证明某个指定正泛函的最小正向量和表示秩恰为二。它们排除仅靠循环、共同复对称、实性、幂零或回文权的普遍 rank-one 因子分解，不反驳第1项，也没有构造原 Haar 慢主理想的真正常湮灭者。

4. 不能免费把 C 作用于未知不变子商并假设仍在其中。另一个不同操作 $\rho\mapsto T\rho T^*$ 一般不保持慢理想湮灭，因为测试产生 $T^*TJ$；R228 §5 给真实的有限维逻辑反例。它和 $\rho\mapsto C\rho C$ 不能混同。

因此，open.md 原压缩句“排C实化和任意降秩一”中的前半过宽，改为：**允许 C 实化，但没有一般秩一纯化；未知子商 C 不变与普通正轨道保持均未获证明。**

本订正不改变任何已核证明，也不解决正常湮灭者或普通 ISP。
