# R150 附录：四不同不等半块配对中 Z=0 的整支排除

日期：2026-11-14（UTC）。作者：normal_resume_2220 / Astra-ISP-1cf8c51d。

状态：**已证明。** 沿用[相等半块配对整支排除](R150-appendix-reduced-four-point-equal-half-block-pairing-exclusion.md)的正交基，在原四不同、非割线均值、本质第三矩维数三、外均值、唯一 \(2+2\) 半权截面中，若
\[
h=(a+b)/2,\qquad \Delta=(a-b)/2,\qquad Z=(c^2-h^2)/2,
\]
则 \(Z\ne0\)。本稿保留所有允许的复权，包括 \(r=0\) 或 \(s=0\)，不使用有限域样本。

## 1. 已支付的原数据

前稿的基、矩阵和中央三次为
\[
\mathcal M=\tfrac14I_W,\qquad
C=T_3=\tfrac32U(L^2-M^2)+rL^3+sM^3,
\]
\[
K_W=\begin{pmatrix}f&d&e\\d&a&c\\e&c&b\end{pmatrix},\qquad
p=(Ky)|_W=((b-a)/2,-d-ra,e-sb).
\tag{1.1}
\]
四个物理代表为 \(y+U+tL\)、\(y-U+zM\)，其中
\[
t^2-2rt-2=0,\qquad z^2-2sz-2=0.
\]
仍有
\[
r^2+2\ne0,\quad s^2+2\ne0,\quad r^2\ne s^2,\quad ab(a-b)\ne0.
\tag{1.2}
\]
后一个条件由此前两块内部配对非零及相等配对整支排除给出。

原完整均值梯度已经精确化为四个必要方程：
\[
a(f+r^2a+2rd)=Z,\qquad b(f+s^2b-2se)=Z,
\]
\[
hd-ce=r(Z-h\Delta),\qquad cd-he=s(Z+h\Delta).
\tag{1.3}
\]
这里每个方程都来自原完整均值向量，不是仅在四支点方向取受限导数。

## 2. Z=0 首先迫 h=c=0

反设 \(Z=0\)。若 \(h\ne0\)，则 \(c=\sigma h\)，\(\sigma=\pm1\)。由 (1.3) 后两式，
\[
hd-\sigma he=-rh\Delta,\qquad
\sigma hd-he=sh\Delta.
\]
第一式乘 \(\sigma\) 后与第二式相减，得到
\[
(s+\sigma r)h\Delta=0.
\]
这与 (1.2) 的 \(r^2\ne s^2\)、\(\Delta\ne0\)、\(h\ne0\) 矛盾。因此 \(h=0\)，进而 \(c=0\)。于是 \(a=-b\ne0\)。

全部必要梯度方程在原 Gram 配对中齐次。将这些配对整体除以 \(a\)，可以在这段代数排除中取
\[
a=1,\quad b=-1,\quad c=0.
\]
这只利用齐次方程的缩放，不替换原物理曲线或其固定核。令
\[
x=2d+r,\qquad y=2e+s.
\]
(1.3) 前两式成为
\[
f=-rx=sy,\qquad rx+sy=0.
\tag{2.1}
\]

## 3. 原最高与二阶梯度的明确余式

下面使用同一原 \(C\) 和二阶梯度 \(N\)。对任意物理极线的坐标 \((\rho,q)\in\mathbb C y^*\oplus W^*\)，由原二阶梯度的张量表达式，
\[
4N(\rho,q)=2\rho\,p\cdot q+4C(p,q,q)
 +2F\,q\cdot q+q^{\mathsf T}K_Wq,\qquad 2F=-\operatorname{tr}K_W.
\tag{3.1}
\]
对前、后两块分别代入 \(y+U+tL\)、\(y-U+zM\)，将最高式 \(C(q)\) 与 (3.1) 分别对两条二次方程取余，就得到每块各两个最高方程和两个二阶方程。

将这些整数余式除去各自的非零整数公因子，并利用 (2.1) 将每个含 \(rx\) 的单项式替换为 \(-sy\)，记其常数、一次系数为
\[
C_{+0},C_{+1},H_{+0},H_{+1},
\qquad C_{-0},C_{-1},H_{-0},H_{-1}.
\]
它们在原完整临界点都必须为零。附属 BigInt 脚本从 (1.1)、(3.1) 原样展开这些余式，精确得到
\[
H_{+0}-C_{+0}=x^2-2y^2+r^2+2,
\tag{3.2}
\]
\[
C_{-0}-H_{-0}=-2x^2+y^2+s^2+2,
\tag{3.3}
\]
\[
C_{+1}-3H_{+1}
 =r(3y^2-2r^2-4)+3sxy.
\tag{3.4}
\]
所需的前块最高常数余式本身为
\[
C_{+0}=3r^2sy-sy^3+6sy-2r^4-7r^2+3y^2-6.
\tag{3.5}
\]
这些是整数多项式恒等式；没有对 \(r,s,x,y\) 作除法。

## 4. 有限代数矛盾

由 (3.2)、(3.3) 为零，
\[
3x^2=r^2+2s^2+6,\qquad
3y^2=2r^2+s^2+6.
\tag{4.1}
\]
又由 \(rx+sy=0\)，有 \(r^2x^2=s^2y^2\)。代入 (4.1)，得到
\[
(r^2-s^2)(r^2+s^2+6)=0.
\]
(1.2) 排除了第一个因子，因此
\[
r^2+s^2=-6,\qquad x^2=s^2/3,\qquad y^2=r^2/3.
\tag{4.2}
\]
将 \(rx+sy=0\) 乘以 \(x\)，得 \(sxy=-rx^2\)。所以 (3.4) 在 (4.2) 下化为
\[
-r(r^2+s^2+4)=2r.
\]
该式必须为零，故 \(r=0\)。再由 (4.2)，\(y^2=0\)，即 \(y=0\)。但 (3.5) 随即给
\[
C_{+0}=-6\ne0,
\]
与原最高梯度矛盾。

因此 \(Z=0\) 不可能。整个证明没有预先排除零 \(r\) 或零 \(s\)，也没有从平方方程反推未支付的符号选择。

## 5. 当前剩余原截面

结合前三条整支排除，目前四不同余类必满足
\[
\boxed{ab(a-b)Z\ne0.}
\]
原完整均值方程此时可以有理解出
\[
d=\frac{-hr(Z-h\Delta)+cs(Z+h\Delta)}{2Z},
\]
\[
e=\frac{hs(Z+h\Delta)-cr(Z-h\Delta)}{2Z},
\]
\[
f=Z/a-r^2a-2rd.
\]
其相容条件（因 \(\Delta\ne0\)）为
\[
ab\big[(r^2+s^2)(c^2+h^2)+4hcrs\big]+(c^2-h^2)^2=0.
\]
这些公式指出尚待继续处理的非零分母分支；本文没有将它判为存在或不存在。附属回执只记录实际执行的 JavaScript BigInt 精确核算，没有声称在失联的终端中运行 Python。
