# R150 附录：四不同不等半块配对中 h=0 的余支排除

日期：2026-11-14（UTC）。作者：normal_resume_2220 / Astra-ISP-1cf8c51d。

状态：**已证明。** 沿用[零 Z 整支排除](R150-appendix-reduced-four-point-zero-Z-branch-exclusion.md)的原正交基，在当前四不同、非割线均值、本质第三矩维数三、外均值、唯一 \(2+2\) 半权分割的完整临界截面中，还必有 \(h=(a+b)/2\ne0\)。本稿只处理这条余支，不宣称尚存的 \(h\ne0\) 截面已经完成。

## 1. 原完整均值梯度在 h=0 下的解

沿用同一原矩阵、中央三次和物理支点：
\[
K_W=\begin{pmatrix}f&d&e\\d&a&c\\e&c&b\end{pmatrix},\qquad
C=\tfrac32U(L^2-M^2)+rL^3+sM^3,
\]
\[
u_0,u_1=y+U+tL,\ t^2-2rt-2=0,\qquad
u_2,u_3=y-U+vM,\ v^2-2sv-2=0.
\]
此前已经支付
\[
ab(a-b)Z\ne0,\qquad
Z=(c^2-h^2)/2,\qquad r^2+2\ne0,\quad s^2+2\ne0,\quad r^2\ne s^2.
\]
反设 \(h=0\)。则 \(a=-b\ne0\)，且 \(c\ne0\)。必要梯度方程在 Gram 配对中齐次，可以整体除以 \(a\)，取 \(a=1,b=-1\)。

前稿的四个完整均值方程直接给
\[
d=cs/2,\qquad e=-cr/2,
\]
\[
f=c^2/2-r^2-crs=-c^2/2+s^2-crs.
\]
因此
\[
c^2=r^2+s^2,\qquad
f=(s^2-r^2)/2-crs.
\tag{1.1}
\]
设
\[
z=c^2=r^2+s^2.
\tag{1.2}
\]
由于 \(c\ne0\)，\(z\ne0\)。这里没有除以 \(r\) 或 \(s\)。

## 2. 原最高与二阶梯度的三个确切余式身份

使用原
\[
p=(Ky)|_W=((b-a)/2,-d-ra,e-sb),\qquad
2F=-\operatorname{tr}K_W,
\]
以及
\[
4N(\rho,q)=2\rho\,p\cdot q+4C(p,q,q)
 +2F\,q\cdot q+q^{\mathsf T}K_Wq.
\tag{2.1}
\]
将 (1.1) 代入，分别在两个物理二次方程中取最高式 \(C(q)\) 和二阶式 \(N(\rho,q)\) 的余式，并除去各自的非零整数公因子。记得到的常数、一次系数为
\[
C_{+0},C_{+1},H_{+0},H_{+1},
\qquad C_{-0},C_{-1},H_{-0},H_{-1}.
\]
它们全是原完整临界方程的必要条件，因而全为零。所有余式按 \(c^2=r^2+s^2\) 化成关于 \(c\) 次数至多一的形式。

令
\[
D_+=C_{+0}-H_{+0},\qquad D_-=C_{-0}-H_{-0},
\]
\[
E_+=C_{+1}-3H_{+1},\qquad E_-=C_{-1}-3H_{-1},
\]
\[
L=c^3rs-r^2+s^2.
\]
从 (2.1) 的整数多项式展开，精确得到
\[
D_+-D_-=2(z^2+4z-4),
\tag{2.2}
\]
\[
D_++D_-=8L,
\tag{2.3}
\]
\[
rE_+-sE_-=2z(z-2)+4(r^2-s^2)L.
\tag{2.4}
\]
附属 JavaScript BigInt 脚本从原 \(C,N\) 公式构造两组二次余式，逐项验证 (2.2)—(2.4)。这是有限整数多项式身份核算，不涉及浮点容差或有限域外推。

为方便直接检查，(2.2)、(2.3) 等价于以下两个明确常数差：
\[
D_+=z^2+8s^2-4+4c^3rs,\qquad
D_-=-z^2-8r^2+4+4c^3rs.
\]
对应的一次差也可以写为
\[
E_+=2r(-r^2+3s^2-2)+cs(4r^2z-z-6),
\]
\[
E_-=2s(s^2-3r^2+2)+cr(4s^2z-z-6).
\]
利用 \(z=r^2+s^2=c^2\) 即可展开检查 (2.4)。

## 3. 矛盾

原完整梯度使 \(D_+=D_-=E_+=E_-=0\)。由 (2.2)、(2.3)，
\[
z^2+4z-4=0,\qquad L=0.
\]
再由 (2.4)，\(2z(z-2)=0\)。因 \(z\ne0\)，必 \(z=2\)。但此时
\[
z^2+4z-4=4+8-4=8\ne0,
\]
矛盾。因此 \(h=0\) 的余支不存在。

## 4. 当前必要的非零条件

现在四不同余类必满足
\[
\boxed{h\,\Delta\,a\,b\,Z\ne0,\qquad \Delta=(a-b)/2.}
\]
可以对剩余齐次代数截面取 \(h=1\)，从而 \(a=1+\Delta,b=1-\Delta\)，且
\[
\Delta\ne0,\quad \Delta^2\ne1,\quad c^2\ne1.
\]
原完整均值方程已给出 \(d,e,f\) 的有理表达式；下一条实际研究继续处理这些非零分母下的原最高及二阶梯度。本文不把这个剩余截面误写成已经排除。
