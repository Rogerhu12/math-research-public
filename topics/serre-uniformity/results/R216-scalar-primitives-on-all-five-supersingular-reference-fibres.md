# R216：五个超奇异参考纤维中的真实标量原函数

**状态：已证明并已精确实算。** 本文的计算对象是 R194 的同一第三类微分 $\eta_B$。覆盖范围是所有所需 Hecke 靶所在的五个超奇异参考纤维，不是整条模曲线的全部 QC 剩余盘。代码保存 $4079$ 个普通项链标号及 $21$ 个真正椭圆标号的标量原函数，并明确保留二十个 CM4 极点的对数项。

## 1. 准确对象、标记和单位 chart

使用 R206 的五个真实参考模型，剩余 $j$ 为 $9,10,44,0,1728$。每个模型包含同一个 R80 域中的真实 $41$ 挠基及标准 Weil 根；层标号仍是 R102 的 $820$ 个非分裂项链。对 $j=0$ 使用 $A-A_*$ 为 stack 参数，其他参考使用 $B-B_*$。R205 的 Gauss–Manin 函数为
$$a=-\frac{\Delta'}{12\Delta},\qquad
\beta=\frac{9BA'-6AB'}{2\Delta},\qquad \Delta=4A^3+27B^2.$$

其中 $\beta(0)$ 均为单位。用 R205 的清极点截面和必要时另一个实际有理清极点截面，递推
$$W'=\beta\frac{V_3(W)G_v}{Wv}-2aW.\tag{216.1}$$
每次求逆前逐点确认 $Wv$ 为单位；新 $G_v$ 在原 $820$ 行逐项验证，不由单点局部拟合。

三个非椭圆参考的所有标号均为普通点。$j=0$ 参考有 $819$ 个普通标号及一个有效阶三稳定子标号；$j=1728$ 参考有 $800$ 个普通标号及二十个有效阶二稳定子标号。因此普通标签总数为
$$3\cdot820+819+800=4079.$$
在两个椭圆 $j$ 纤维中，普通标签分别三三、两两表示相同的粗模点；不能把 $4079$ 宣称成互不相同的几何圆盘。保留标签正是实际 Hecke 迹需要的计数。

旧参考截面 $f_0$ 在其中少数点上非单位不造成缺口，因为 (216.1) 和以下标量计算根本不除以 $f_0$。真正 raw 全坐标在模47为零的 $21$ 个标号只交给 R208 的粗模框架，不在 stack raw 零向量上求逆。

## 2. 同一第三类微分的普通盘原函数

R194 已给
$$\eta_B=\frac{s(W)}{q(W)}\,\beta(t)dt,$$
其中 $s\in H^0(3L)$、$q\in H^0(2L)$ 的系数已准确保存至 $47^3$。其唯一真实有限极点是 $Z_{-4}$，留数为一；其余极点为尖点，留数为负一。上述普通剩余盘与这些支撑都不交。

若 $q(W(0))$ 为单位，直接作整级数除法得到
$$\eta_B=(c_0+c_1t+c_2t^2+\cdots)dt,$$
并保存
$$F(t)=c_0t+\tfrac12c_1t^2+\tfrac13c_2t^3\pmod{47^4},\qquad t\in47R_2.\tag{216.2}$$
这里 $c_i$ 只需模 $47^3$。对所有 $n\ge4$，
$$v_{47}(t^n/n)\ge n-v_{47}(n)\ge4,$$
所以更高积分项不影响模 $47^4$ 的值。两个端点的 tiny 积分就是 $F(t_1)-F(t_0)$，不会引入一个未经校准的积分常数。

## 3. 可去分母零点不需损失47进精度

R194 的分母还含已经被分子消去的 $K_f$、$E_{-B}$ 支撑。若 $q_0\equiv s_0\equiv0\pmod{47}$，不能直接反演 $q_0$。本次实际遇到的这些点均有 $q_1\not\equiv0\pmod{47}$。

写 $q(t)=\sum q_it^i$、$s(t)=\sum s_it^i$。真实商 $c(t)=s(t)/q(t)$ 在这些盘上整且正则，因为 R194 已在整模型中消去对应非极点除子。令 $N=5$，用五个系数方程
$$\sum_{k=0}^4 q_{i+1-k}\,\widetilde c_k=s_{i+1},\qquad 0\le i\le4,\tag{216.3}$$
其中负下标项取零。矩阵模47为下三角、对角元为单位 $q_1$，故它在 $R_2$ 上可逆。

省略的真实尾只在最后一个方程产生 $q_0c_5$。矩阵只有一个可能非零的上副对角线，且其项都等于 $q_0\in47R_2$；其逆矩阵第 $(i,j)$ 项在 $j>i$ 时被 $47^{j-i}$ 整除。因此
$$\widetilde c_i-c_i\in47^{5-i}R_2,\qquad i=0,1,2.\tag{216.4}$$
这已经给三项所需的 $47^3$ 精度。证明可将矩阵写成单位下三角可逆矩阵加 $q_0$ 乘上移矩阵；Neumann 展开中，从第 $i$ 行走到更高的第 $j$ 列至少使用 $j-i$ 次上移，每次带一个47因子。

程序解完 (216.3) 后，又核对被省略的常数项方程 $q_0\widetilde c_0=s_0\pmod{47^3}$。全过程只反演单位矩阵，未除以47；因此没有把损失的一位精度藏在后续对数中。

## 4. 真正椭圆盘与未删除的对数项

R208 提供真正的 coarse weight-two 值。对 CM4，固定 $A=1,B=t$、$u=t^2$、$W_{\rm raw}=tW_c(u)$，所以
$$\eta_B=-\frac{3}{2(4+27u)}\frac{s(W_c(u))}{q(W_c(u))}\,du.\tag{216.5}$$
这二十个点都是真极点。程序确认 $q(0)=0$、$q'(0)$ 为单位，并逐点得到
$$\boxed{\eta_B=\left(\frac1u+d_0+d_1u+O(u^2)\right)du.}\tag{216.6}$$
留数一是 R194 的准确留数，并由实际系数重新核准。因此原函数必须写为
$$\log u+d_0u+\tfrac12d_1u^2+\cdots.$$
对于 $u\in47^2R_2$，其正则部分模 $47^4$ 只需 $d_0u$。但 $\log(u_1/u_0)$ 的单位部仍须保留；若 $u_i$ 有正47估值，就需要相应的额外输入精度。原函数 atlas 没有将此项删去，也没有声明模 $47^4$ 的任意 raw 非零值足以求它的四位对数。

对 CM3，固定 $B=1,A=t$、$u=t^3$，有
$$\eta_B=\frac{3}{2(4u+27)}\frac{s(W_c(u))}{q(W_c(u))}\,du.\tag{216.7}$$
这里分母常数是单位，没有对数项。保存其前三个整被积系数，并检查 Frobenius 下降。由于实际 $u\in47^3R_2$，常数被积系数已给出模 $47^4$ 所需的全部变化。

若 CM4 的新模型用 $A=-1,B=t$，直接用 invariant 参数 $u=B^2/A^3=-t^2$ 代入 (216.6)。无需猜测 homothety 的四阶导数；微分和标量原函数在模型同构下不变。

## 5. 实际同源端点的独立 tiny 比较

从 R145 同一个 family0 的 $54$ 个物理参数出发，对每条 $2$、$3$ 同源实际提升其小次数核到两个端点。二阶核满足
$$r^3+r+32+t=0,$$
三阶核满足
$$3r^4+6r^2+12(32+t)r-1=0.$$
给定原始 R131 核，两个单位 Newton 步已使误差进入 $47^4$。使用准确 Vélu 公式求出端点模型，再由 R206 的实际同构和 $41$ 挠基传输确定参考参数及项链。

每条分支按 (216.2) 计算原函数差，最后对相同的 $54$ 个标号求和。这里不再额外乘 $1/\ell$：真实同源对微分的尺度已经通过实际模型参数和端点变化包含在积分中。该独立端点算法与 R197 先构造全局迹微分再积分的算法不同；完整证书核对三个既有值
$$890368,\qquad463561,\qquad924161\pmod{47^4}.$$
