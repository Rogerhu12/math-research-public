# 独立审查：固定物理尾的分段射击与 M8/M12 Cartesian 重放

2026-11-09，Astra-visible-flex-950f9f73 / independent_audit。
审查者未参与尾形优化、非线性求解或射击分段实现。

## 范围与结论

**分段坐标、动量端口和 raw node 映射核查通过。** 对相同实际
weighted metric、纯基波切口高度幅度 $a=0.0003$，独立全深度重放
确认 M8 到 M12 的有限维缺陷明显下降。下述极值仍为有限径向及
角向采样；平面二阶径向导数使用四阶有限差分。这些数据不构成
无限尾、严格连续极值、完整 C² 闭曲面或全时 reach 证书。

## 数值分段没有改变物理度量

每个原 profile 分成两段。独立审稿程序不导入提交的 subdivision
函数，而是从实际物理 profile 重新构造 $x\mapsto a+hx$，只将
$dr/dx$、$d\log w/dx$ 乘 $h$。每个原 cell 内的 $\mu$ 相同；
动量只在原 cell 的外端除 $2^{2.75}$，内部所有端口比例为 1。
原 cell 的 profiles 及各半段按外到内存储、内到外积分，顺序与
检查点吻合。180 个 stage 的 `rawNode=[0,18,\ldots,180]` 及
11 个 `rawStates` 均逐值核对。

深处线性图用当前 cell 的 $\mu$ 传播，在进入最后一个已表示
cell 时改变一次动量单位；切口 jet 将 node 0 已改单位的动量
乘回 $2^{2.75}$。这些单位转换相互一致。原始 warm checkpoint
在原 cell 内重新积分而不是插入额外动量换算，也符合相同系统。

M8 与 M12 输入检查点所有参数逐项比较，仅 `modes`、
`initialCheckpoint`、`traceFile` 不同；二者 `cutHeight` 补零后
完全相同，物理构造源码哈希相同。二者 physicalDepth=10、
shootingParts=2、每半段 32 RK 步、angular quadrature=256、
linearFar=32、linearSteps=256，因而本次是冻结几何的角模态加密。

注意 `normalizedFullDefect` 含当前 profile 的 $dr/dx$，因此
每个原 profile 分两段会将该显示量除 2。跨分段数比较应使用
物理 `fullDarboux`，或本审稿同时保存的
`normalizedFullDefectRawProfile`；不能把坐标改变量当作收敛。

131 倍，实际最大曲率变化约 $4.22\times10^{-8}$。
M12 的 Cartesian 二阶张量已接近平面有限差分误差层，不能继续
将该显示量当作精确 PDE 残差。另一个 $a=0.0001$ 检查中，差分
步长 $5\times10^{-5}$ 减半后，最坏张量量从 $2.65\times10^{-9}$
增至 $6.29\times10^{-9}$，而相应曲率只变化约 $5.9\times10^{-9}$；
这支持该误差层诊断，不支持严格曲率包络。

两份重放都检查了全部 179 个 stage 接缝。M12 的位置误差
$7.86\times10^{-17}$，经向一阶误差 $1.67\times10^{-16}$，
角向一阶除半径后 $2.59\times10^{-16}$；混合二阶除半径后
$3.31\times10^{-16}$，角向二阶除半径平方后
$1.70\times10^{-15}$。径向二阶为 $3.31\times10^{-9}$，亦在
差分误差层。高度平均值由实际积分增量沿尾累积，未在接缝
重新拟合刚体或竖直平移。有限精度接缝小仍不等于精确 C² 拼接。
