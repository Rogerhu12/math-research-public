## 1. 明确固定背景定义

对 $0\le n<160$，采用 `2026-11-09-db6f-tail-finite-source-calibrations.json` 中的 160 个校准系数作为**精确二进实数几何常数**，不要求它们恰为某个隐含方程的精确根。该表 SHA256 为

`bcfaba00aec62290b5b29432836c9e76ef6cf0d582b06c046677b0f8688ca9f4`。

生成器 `db6f-tail-freeze-background.py` 核对了六份实际 checkpoint 的全部有限源校准参数相同，涵盖旧 q=.02 的 32/64/128 步、宏观 M8 的 32/64 步及 M12/parts4/64 步。`calibrationSteps=512` 始终固定，几何精度加密不重新选择这些系数。表内系数按 `Fraction` 核实全部属于 $[1/2,2]$。

从 $n=160$ 起继续使用已审无限源的精确解析定义和校准根盒，不用有限浮点表代替无限源。`oldCut`、`epsilonScale` 按原精确归一化公式派生；全局物理径向乘子 $\alpha$ 按原真积分宽度条件定义。这些对象须与表内的局部源校准系数区分。

以下保留实际参数盒：orientation $+1$、$R=64$、源指数 $11/4$、$\eta$ 指数 $3/2$、protectCell $160$、$w_{cut}=1/2$、curvatureBound $6$；无 flat override 或 literal rejoin。物理宽度 $W=r_{cut}-a_c$ 严格处于 $(0,1/2)$。

## 2. 只需包围 cell 0

在第 0 cell 的每个源段上写

$$r_x=A(x)+\alpha B(x),$$

$$A=|r_{o,x}|j_0(1-\chi)
  +\chi\frac{|w_x|}{6(1+w^2)^{3/2}},
\qquad B=\chi\frac{|r_{o,x}|}{1+w^2}\,\omega(x).$$

这里 $\omega$ 是冻结的正径向权重，$\chi,j_0$ 是原保护端函数。定义九段积分之和

$$A_0=\int A\,dx,\quad B_0=\int B\,dx,
\quad A_{H,0}=\int wA\,dx,\quad B_{H,0}=\int wB\,dx.$$

其余有限 cells 的 cap 均不超过 $1/49$。已审 raw 源界 $w_n\le1280\,2^{-7n/4}$ 在 $n\ge160$ 也小于 $1/49$。故第 0 cell 之外的全部背景高度贡献不超过 $W/49$。

所有径向长度项非负，而且 $\alpha>0$。原宽度条件因此给 $\alpha B_0\le W$。所以全尾高度总变差满足

$$H_{rot}\le\frac W{49}+A_{H,0}+\alpha B_{H,0}
\le\frac1{98}+A_{H,0}+\frac12\frac{B_{H,0}}{B_0}.
\tag{1}$$

这故意把第 0 cell 的部分宽度重复计入，以避免认证其它 159 个有限 cells 的积分或数值 $\alpha$。只要对九段的三个积分给可靠上下界，就可以得到所需高度包络。

## 3. 区间程序为何构成真包围

`db6f-tail-background-height-interval.py` 从冻结的几何参数和第 0 cell 的精确二进系数 $1.426600691200502$ 出发，重建 source、cap、valley 修改、cut-preserving 恢复和正径向权重的公式。它没有读取已有 Gauss 积分值作为证据。旧 bookkeeping 文件只提供冻结校准系数，并作为输入哈希记录。

每个 $x\in[0,1]$ 被分为 4096 个闭有理区间。所有代数运算复用向外舍入区间类；smoothstep 用单调端点界，cap 的不同分支做覆盖 hull。被积函数区间乘子区间长度，再以成对向外加法求和，给出 Riemann 意义的严格积分包围。包含临界点、cap 分支边界或 $w_x=0$ 的子区间也保留，未假定区间内固定符号。

指数包围使用 $y=x/2^k$，并在选取 k 后再以精确二进缩放检查 $|y|\le1/8$。对 $e^y$ 取 18 次 Taylor 多项式，余项绝对值由

$$\frac87\frac{(1/8)^{19}}{19!}$$

控制，然后在非负区间上平方 k 次。对数先用二进 `frexp` 归到 $m\in[1,2]$，令 $z=(m-1)/(m+1)$，使用 32 项

$$\log m=2\sum_{j=0}^{31}\frac{z^{2j+1}}{2j+1}+R,
\qquad |R|\le\frac{2(1/3)^{65}}{65(1-1/9)}.$$

这些截断误差是显式有理数；常数 $\log2$ 用同一公式包围。除不可信的缩放初猜外，不依赖平台 `exp/log` 的最后一位正确性。程序检查 width、protectCell、源盒、cap 正性、无覆盖和无 rejoin 等前提，不会对不在该类中的输入静默输出全尾结论。

## 5. 与精确 metric 验证的边界
