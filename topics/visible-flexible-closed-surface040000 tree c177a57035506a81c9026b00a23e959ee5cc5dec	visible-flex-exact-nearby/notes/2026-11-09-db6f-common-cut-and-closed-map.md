# 用精确共同端迹定义一个真正 C² 的有限闭图

2026-11-09，root / Astra-visible-flex-db6f0b0e。完整构造与区间实现，待未参与者独审。本文处理实际有限近似的公共空间接缝，不声称它已是精确等距解或已满足全部 README 指标。

## 1. 输入对象与精确定义

前缀 $B(u,\psi)$ 是 `db6f-root-flat17-coupled-m8f16.json` 指定的有限 Fourier、共享二阶 jet Hermite 图。$0\le u\le S_0$，高度均值由保存增量的精确和定义。其目标辅助角为
$$\theta=\Theta(u,\psi)=\psi-e(u)\sin(3\psi)/3.$$
在端点 $e=e'=e''=0$；整个域 $\Theta_\psi>0$。

显式尾的扰动 $V(r,\theta)$ 由 `db6f-tail-int2-flat17-m8-q10-n8-s32-manifest.json` 定义：四次 $V_r$ 的精确积分给分段五次 C² 图，使用共享的二阶端 jet。此包原本的旋转背景满足 $h_r=+w$；上尾必须反射**整个**高度，包括 V 的每个高度分量和每阶导数。

固定旋转背景采用已审冻结有限源及无限深源定义；全局径向归一参数是已证唯一正的真积分解。以切口高度常数 $H_c$ 定义上尾
$$T(r,\theta)=\bigl(r e^{i\theta}+V_h(r,\theta),\ H_c+\int_r^c w(\rho)d\rho-V_z(r,\theta)\bigr).$$
尾包的外端半径与精确 binary $c=0.6$ 相等，此等式在当前包中已按 Fraction 检查；后续包也须核查。其内端通过同一扰动两 jet 的 R6 五次多项式延伸到原 cuff $a_c$，在 $a_c$ 的扰动及前两阶径向导数严格为零。整个无限背景在 cuff 有 $w=w_r=0$ 的 C² 平连接。

取 $H_c$ 使 $T(c,\theta)$ 的均值高度与 $B(S_0,\psi)$ 的精确均值相同。这个选择只改变刚体竖直定位；不会修改 g。前缀与尾的其余端迹仍有小差，下面精确补齐。

## 2. 同一材料弧长及所需端 jet

精确桥证书给 $L_*$、完整前缀材料长度 $S_*$ 及 $\lambda=S_0/S_*$。在真正材料坐标 s 中使用 $u=\lambda s$。端点径向导数由目标 metric 给出
$$k=\frac{dr}{ds}=-\frac1{\sqrt{1+w_c^2}},\qquad
k_2=\frac{d^2r}{ds^2}=-\frac{w_cw_{r,c}}{(1+w_c^2)^2},$$
其中 $w_c=1/2$、$w_{r,c}=-7w_c/c$ 精确成立。

因为端点辅助角与材料角的两阶差全部为零，要让一个 u 图在真正材料坐标中与 T 接上，其端迹应为
$$Y_0(\psi)=T(c,\psi),$$
$$Y_1(\psi)=\frac{k}{\lambda}T_r(c,\psi),$$
$$Y_2(\psi)=\frac{k^2T_{rr}(c,\psi)+k_2T_r(c,\psi)}{\lambda^2}.$$
令 $\Delta_j=Y_j-\partial_u^j B(S_0,\psi)$。高度均值的 $\Delta_0$ 按上述定位恒等于零，不能把两次独立舍入后的均值相减来定义这个零。

尾平面复 Fourier 模为 $1+3j$，柱坐标 R、T 的系数由
$$R_j=C_{1+3j}+C_{1-3j},\qquad T_j=C_{1+3j}-C_{1-3j}$$
转换。当前尾需柱坐标最高32模；前缀原16模在余下模上精确补零。这没有丢掉尾的高频端迹。

## 3. 精确五次公共端迹修正

在原前缀网格选 $b<S_0$，令 $W=S_0-b$。当前选择 $W\simeq.14826$，是数值表示的修正区宽度，不改变目标 g。对 $u\le b$ 令 $C=0$；对 $b\le u\le S_0$，令 $t=(u-b)/W$ 并取
$$C=(10t^3-15t^4+6t^5)\Delta_0
 +W(-4t^3+7t^4-3t^5)\Delta_1
 +W^2(t^3/2-t^4+t^5/2)\Delta_2.$$
每个标量基函数在 t=0 连同前两阶导数为零，在 t=1 给规定的对应二 jet。因此 $\widetilde B=B+C$ 在整个前缀为 C²；其末端两 jet 正好是 $Y_0,Y_1,Y_2$。

由角函数的逐点相等，纯角及混合二阶导数也自动匹配。这一步支付完整 Cartesian 两阶 jet，不仅是高度或第一基本形式。

系数的精确定义允许有理运算与已夹根 $L_*$。程序 `db6f-root-common-cut.py` 不把这些实系数独立舍入成新的几何常数，而是向外包围该共同定义。tail 端值按原四次导数积分公式累加；一、二阶 tail 端导数是保存的精确 binary 常数。每个前缀 span 上将 C 通过有理仿射换元展开后，加到原 Hermite 系数包围中。数学图本身仍由上述精确公式定义。

## 4. 闭曲面与全相位族

上前缀在真实材料坐标表示为
$$\widetilde F_+(s,\theta)=\widetilde B(\lambda s,\Theta(\lambda s,\cdot)^{-1}(\theta)).$$
把它与 T、其 R6 圆领和 cuff 平圆盘按相同材料角连接。下半部是 z=0 镜像。入口的精确 R13 条件保持，因为修正支撑远离入口，故中间镜像接口也是 C²。

在上平圆盘内按 R16 加三个固定凸起；它们全部位于半径 .11 内，实际 cuff 半径 $a_c\in(.14,.15)$ 仍留有平环邻域。R16 的证明只用该包含关系，矩常数与凸起自身曲率不依赖外围盘恰好等于有理 .15。两盘中心邻域保持平坦，极点用普通平面坐标正则。

所得参数面由两个盘和其间环带组成，拓扑为 $S^2$。它是一个精确定义的 C² 映射；浸入/嵌入与 reach 须另用各块的连续几何界支付，不由拓扑直接推断。

活动环带使用 $F_\alpha=R_\alpha F_0(s,\theta-\alpha)$，两带标记帽保持不动。圆领的全部两 jet 轴对称，所以每个相位仍为同一个全局 C² 映射，且随相位在 C² 拓扑连续。可用 $\alpha\in[0,2\pi/3]$，其中含见证相位 $\pi/3$。目标 g 在活动带为固定旋转 metric，帽上取固定诱导 metric；误差与几何界按已审全相位引理传递。
