## 2. 准确物理数据约定

原 JSON 的共享 `(a-a0,a_s,a_ss)` jets、原始段长、固定相位、K、cut 的 r/w/wr 和本次实际 T，均解释为解析得到的 binary64 的准确有理数。原始椭圆仍准确为 `A=7/5,B=1/2`，

\[
a_0=\frac{2A}{\pi}E(1-B^2/A^2)
\]

由已推的 `balanced-moments-taylor-01` 准确包围，不取浮点 `Candidate.a0` 作定义。派生相位、长度和积分同样保持准确解析量，不取区间中点定义它们。

转向 ramp 的设计常数准确为
\(e=2/25,1-e=23/25,e/2=1/25\)。不能把源码里分别舍入的 `.08,.92,.04` 当作互不关联的准确常数，否则会在人为的微小接口差中破坏本来准确的 ramp 恒等式。

每个 Hermite 段用准确长度 L 和共享两端 jets 定义五次多项式。设

\[
c_0=j_{0,0},\ c_1=Lj_{0,1},\ c_2=L^2j_{0,2}/2,
\quad d=j_{1,0}-c_0-c_1-c_2,
\]

\[
v=Lj_{1,1}-c_1-2c_2,\quad z=L^2j_{1,2}-2c_2.
\]

则后三系数为 `10d-4v+z/2,-15d+7v-z,6d-3v+z/2`，半径为 \(a_0+\sum c_j\tau^j\)。源码逐项验证全部相邻原始 Hermite jets 完全相同。初始圆柱之后的第一条初 jet 是 `(0,0,0)`，最后 Hermite 的末加速度准确为零。

后续 phase 段使用同一个共享末 phase；从 Hermite 开始时以
\(\phi_0=\operatorname{atan2}(a_s,\sqrt{1-a_s^2})\) 确定相位，正平方根选定所需分支。turn 上

\[
\phi=\phi_0+(\phi_1-\phi_0)I(\tau)/(1-e),\qquad
L=|\phi_1-\phi_0|/[K(1-e)],
\]

\[
I(\tau)=\begin{cases}
\tau^3/e^2-\tau^4/(2e^3),&0\le\tau\le e,\\
\tau-e/2,&e\le\tau\le1-e,\\
1-e-(1-\tau)^3/e^2+(1-\tau)^4/(2e^3),&1-e\le\tau\le1.
\end{cases}
\]

brake 为 \(\phi=\phi_0+(\phi_1-\phi_0)\tau^2\)，coast 为常相位。位置和两物理导数准确由

\[
a=a_{\rm left}+L\int_0^\tau\sin\phi(t)dt,
\quad a_s=\sin\phi,\quad a_{ss}=\cos\phi\,\phi_\tau/L
\]

定义。最后补偿 coast 的长度由下一 brake 的准确积分解出，保证 brake 末半径等于原 cut 半径。cut phase 与 brake 长取

\[
\phi_1=-\operatorname{atan2}(1,w),\quad
\phi_{s,1}=-w_r/(1+w^2)^{3/2},\quad
L=2(\phi_1-\phi_0)/\phi_{s,1}.
\]

因此准确末 jet 为

\[
(a,a_s,a_{ss})=\left(r,-(1+w^2)^{-1/2},-ww_r/(1+w^2)^2\right).
\]

Hermite 的共享 jets、turn 两端零 phase 一导、coast 零 phase 一导及 brake 初端零 phase 一导逐一给出 C² 接合。所有累计起点共享同一个准确定义。此处无需 C³ 假设。

## 3. 有限多项式包围与余项

每条解析 phase 支式独立处理，尤其 turn 的 `e,1-e` 两个内部支点。将支段 \([l,r]\) 写成 \(\tau=(l+r)/2+(r-l)y/2\)，\(|y|\le1\)，再写 \(\phi=\phi_c+\Delta(y)\)。\(\Delta\) 常数项在代数上准确为零。若 \(D=\sum_{j\ge1}|\Delta_j|\)，则 \(|\Delta|\le D\)。

使用 24 阶 sin/cos Taylor 多项式。实轴上 sin/cos 每阶导数绝对值至多 1，因此每一点的严格余项不超过

\[
R=D^{25}/25!.
\]

所有系数运算和中心 sin/cos 由 70 位定向区间计算包围。对称单项式积分准确使用 \(\int_{-1}^1y^{2j}dy=2/(2j+1)\)。归一化完整支段积分额外误差为 \((r-l)R\)；从左端到任一点的半径误差为 \(L(r-l)R\)。这两项及全部有限系数均保存在包内，后续限制到更小盒时仍须保留。

Hermite 的半径和两导直接作 Bernstein 凸包。phase 和其一导也先转 Bernstein，再应用区间 sin/cos 给出物理一、二导。半径多项式 Bernstein 凸包加上上述显式误差。因此第一节的全域范围和正性是连续证明。

## 4. 每一段均校准的准确径向 clock

浮点评估 reference profile 所得到的 90 个二进制计算端点全部是保存的原生场节点；恢复后的运行逐个检查这一点。它们仅用作准确有理的**计算坐标**，不拿它们的差冒充物理解析长度。

在端点 \(x_j,x_{j+1}\)、宽 \(h=x_{j+1}-x_j\) 上，令

\[
t=(x-x_j)/h,\qquad
S(x)=s_j+ht+(L-h)W(t),\qquad W(t)=10t^3-15t^4+6t^5.
\]

全部 89 段都采用这个式子。W 的端点值是 0、1，一、二阶端点导数均为 0，所以每个接缝准确有相同的 S、`S_x=1,S_xx=0`。因此 S 全局 C²。又

\[
J=1+(L/h-1)30t^2(1-t)^2,\qquad
0\le30t^2(1-t)^2\le15/8.
\]

逐段准确 L 区间直接给出第一节的正 J 范围，故 S 是到完整准确物理区间的 C² 微分同胚。它不改变固定 \(ds^2+a(s)^2du^2\)。

原 native 三次场仍由原节点/值/真 first-x jets 定义，保持 C¹；采用该 S 和原既定移动角 chart 后，在固定材料 u 上积分 R119 的 skew frame ODE，即定义此包对应的有限 X。它与旧浮点 clock 所定义的 X 略有差别。单段长度差很小不是两者所有几何读数的严格转移证明，本记录没有作这种替代。
