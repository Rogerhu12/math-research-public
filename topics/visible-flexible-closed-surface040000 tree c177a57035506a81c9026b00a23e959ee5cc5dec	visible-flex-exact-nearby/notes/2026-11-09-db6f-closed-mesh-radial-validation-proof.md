# 有向三角网格的径向嵌入门

作者：`/root/independent_geometry`，2026-11-09。root 已独立审查设计中的条件引理，以下补齐顶点步骤与球面积公式；具体区间实现和输出仍须另审。

## 命题

给定一个有限、连通、有向的闭三角二维流形 $K$。每个顶点有空间位置 $v\ne0$，每个面的三个有序顶点为 $a,b,c$。假设对全部面有

$$\Delta=\det(a,b,c)>0,\qquad a\cdot b>0,\quad b\cdot c>0,\quad c\cdot a>0.$$

令 $\Omega(a,b,c)$ 是该面的径向投影的有向球面积。若

$$2\pi<\sum_{\text{faces}}\Omega<6\pi,$$

则分片线性空间图 $K\to\mathbb R^3$ 为嵌入，且其径向投影到 $S^2$ 为保向同胚。

## 1. 各层的正局部度

行列式严格为正说明面所在的平面不通过原点，且按给定面方向，平面法向和面内每个点的位置向量的内积均正。因此径向投影在面内部是保向局部微分同胚。

沿共享有向边 $a,b$，另一面的边方向必须是 $b,a$。若两面的第三顶点分别为 $c,d$，则

$$\det(a,b,c)>0,\qquad\det(a,b,d)<0.$$

故两个第三顶点的径向像落在由 $a,b$ 张成的大圆的两侧。两面投影在边邻域恰好提供两个半邻域，所以这里仍是保向局部同胚。

考虑顶点 $v$。其 link 是一个环，循环相邻顶点记作 $v_1,\ldots,v_m$。每条邻边有 $v\cdot v_i>0$，故整个足够小的星形邻域的径向像位于以 $v/|v|$ 为中心的开半球内。用这个半球的中心投影坐标把 $v$ 的像移到平面原点，其他邻点给非零平面射线 $z_i$。

每个相邻面满足正行列式，等价于平面中 $\det(z_i,z_{i+1})>0$。于是依正向从 $z_i$ 到 $z_{i+1}$ 的角增量唯一地落在 $(0,\pi)$。由于 link 闭合，全部角增量的和为 $2\pi k$，其中整数 $k\ge1$。

各相邻三角扇均覆盖其对应的小扇区。取半径小于所有有限个邻边像的距离及所有扇区外边界距离，投影在这个小圆盘周围的覆盖数就是上述 $k$。因此顶点也有正整数局部度；$k>1$ 恰是可能的分支情形。这里没有从“全局度为一”直接跳过顶点局部度的核验。

## 2. 每面球面积的代数公式

把三个向量归一化为单位向量。径向三角形采用小于 $\pi$ 的短大圆边。Girard 公式把面积写为三个内角之和减 $\pi$；将球面余弦律代入角的半角恒等式，得到

$$
\tan\frac\Omega2=
\frac{\det(a,b,c)}{
|a||b||c|+(a\cdot b)|c|+(b\cdot c)|a|+(c\cdot a)|b|}.
$$

也可写作半角的复数相位：$e^{i\Omega/2}$ 是 $D+i\Delta$ 的单位化，其中 $D$ 为上式分母。当前 $D>0$、$\Delta>0$，选择正的小面积支，故

$$\Omega=2\arctan(\Delta/D).$$

这正是程序使用的公式。逐面球面积积分的和等于径向映射的全局整数度乘 $4\pi$；面边界的球面积为零，不影响积分。

## 3. 度一推出嵌入

面积假设使全局度落在 $(1/2,3/2)$，故等于 1。第一节证明了所有点的局部度均为正整数。对于任意目标点，全局度等于它的有限原像的局部度之和；因此只能有一个原像，且局部度只能为 1。分支和多个原像都被排除。

径向映射是紧空间到 Hausdorff 空间的连续双射，故为同胚。若两个不同空间图点在 $\mathbb R^3$ 中相同，则它们的径向像也相同，矛盾。因此原分片线性图也为嵌入。

## 4. 不调用反三角函数的严格区间门

对 $q\ge0$，

$$q-q^3/3\le\arctan q\le q.$$

右式由导数比较直接得到；左式之差的导数为 $q^4/(1+q^2)\ge0$，且在零处差为零。故每面只需包围 $q=\Delta/D$，就有

$$2(q-q^3/3)\le\Omega\le2q.$$

区间四则运算、平方根及向外舍入由已审后端完成；所有面上下端点再以 Fraction 精确相加，不依靠浮点求和的默认舍入。利用 $3<\pi<22/7$，程序验证更易比较的充分条件

$$L>44/7,\qquad U<18,$$

即可保证 $2\pi<\sum\Omega<6\pi$。

拓扑侧由独立读出的 PLY 面表支付：无重复面，每边恰两面且反向，每个顶点的半边旋转为唯一一个环，无孤立顶点，面邻接图连通。Euler 特征数 2 另外核对，作为该闭球面网格的冗余结构检查。

这些门认证的是文件中精确二进顶点构成的 PL 曲面。它们不改变也不扩张原连续 $C^2$ 图的 metric、reach 或 G5 结论。
