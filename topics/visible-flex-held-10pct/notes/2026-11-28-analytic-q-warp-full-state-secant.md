## 初猜的完整定义

新增入口是
[`q_warp_secant_predictor.py`](../scripts/resume_20261128/analytic/q_warp_secant_predictor.py)。
它只接受原 `portable_prefix_continue.py` 真实返回、全部原 solver / RMS /
physical BC / 全 metric 门通过、raw / physical 文件 SHA 均一致的两个同 M 输入。
本次原参数为 M=8、角网格256、实际 mean/audit512，q 与 warp-reference 同步变化。

设两输入为 $q_l<q_r$，目标为 $q_*>q_r$，
$\beta=(q_*-q_r)/(q_r-q_l)$。在共同的原计算坐标 $t,\psi$ 上，用各自
**实际保存的完整 cubic PPoly** 求全部 $3M+1=25$ 状态分量，而后取

$$Y_*(t)=Y_r(t)+\beta\bigl(Y_r(t)-Y_l(t)\bigr).$$

这只是原未知坐标中的初猜。不同 q / warp 下的材料角与物理径向坐标不同，
本式不声称把旧物理曲面逐点保持；也没有把割线解释成已经等距的图。
目标 RHS、Frenet 根、背景、角图及后续审计全部使用真实目标 $q_*=\mathrm{warp}_*$。

原 $p_0$ 保持加性 $\delta$ 语义：

$$p_{*,0}=p_{r,0}+\beta(p_{r,0}-p_{l,0}).$$

对高阶支撑系数先还原实际物理值 $c_i=p_i\,\mathrm{pscale}_i$，
取 $c_*=c_r+\beta(c_r-c_l)$，再除以目标原构造器的
$\mathrm{pscale}_{*,j}=\max(q_*^{j+1},10^{-9})$。没有只外推末端 H，
也没有冻结或删除任何状态或控制。

预测后沿原 adaptive restart 的规则，用目标实际 $s(t,p_{*,0})$ 和
$(T_u\text{ 或 }T_d)/2$ 截止长度，加完整入口差乘
$\max(0,1-s/s_c)^3$。这是对初猜的原入口补齐，所有原方程仍留在下一次 BVP。
平均高度不是原独立未知量；它继续由原完整物理审计以声明的512节点重建。
