# 原 native 六处二幂投影优化：字节相同但实测未提速，保留原核

本条只记录 2026-11-28 的实际工程比较，不重开已接受 M12 尾的数学结论。正在运行的 M16/M24 原 native 二进制均未改动；候选在独立仓外目录编译。

## 两个独立候选与实际输入

只改原 C++ 的六处角平均 `/nq`：Newton moment 投影、Newton Gram、literal Jacobian Gram、其右端、`dN` 和 flux。保每一项原分子乘法顺序和原求和顺序。仅 long-double 模式、配置 `N` 与 `nq` 都为正二幂时使用精确可表示的 `1/nq` 乘法；其余情况保原除法，binary64 callback 路径也不动。编译仍使用原 `-O2 -fno-fast-math -ffp-contract=off -fexcess-precision=standard -frounding-math`。

V1 每个分子另检查 `isfinite`；V2 只保配置层检查，所有原分支、Newton、literal-J、最终输出有限性与审计门仍在。V2 在原有限数值域中对应相同二进制指数缩放，不改变原非线性方程。

输入是本会话真正接受的 M12/N256 尾的末次完整 native Jacobian 输入，原包仍为 `ccba27ff6af8686f24197591e9314fedf96f15ebfdb431971a5616ad573f296c`。选五个真实段：首段 0、最深段 1151、原 minA 最小段 80、原 minD 最小段 22、冻结半径/背景斜率差商选出的高曲率区域段 813。最后一个只是选择压力区域的差商，值约 7.99492，不是连续曲率证书。每个候选都与保留的同输入原输出逐字节比对，并交替重跑原核作近邻计时；没有改造假输入。

## 真实结果

所有比较均覆盖完整生产 binary64 state、完整 Jacobian、三个 root 计数及四个非计时数值诊断；只排除每段最后八字节 `kernel_seconds`。生产 CLI 不输出可选 canonical 80-bit 缓冲，因此本条不声称比过那些未保存字节。

| 候选 | 五段重复数 | 原核 CPU 合计 | 候选 CPU 合计 | 候选/原核 | 完整非计时字节 |
|---|---:|---:|---:|---:|---|
| V1，逐项 finite guard | 3 | 2.267185 s | 2.709243 s | 1.194981 | 全部相同 |
| V2，只配置 guard | 5 | 4.176496 s | 4.613505 s | 1.10463532 | 全部相同 |

另用真实旧 M12/N192（`nq=64`）首/深两段检验非二幂 N fallback，两版都与原保存输出完整相同。该输入对应之前的 FFT 审计配置错误，这里只取当时确实完整返回的 native 分段输入/输出作除法 fallback 工程比较，绝不把那次尾请求记成接受。

V1 还实际重放了一次全部 **1152 段完整 J**：比较的非计时总字节数为 **6064216**，全相同，SHA 为 `60ac45e1736ba2ade555c265d6c25c5ddc58f437ba844d4de01d18bd528b9667`；本次 wall=210.214783 s、CPU=187.894898 s。原旧整批是在不同并发/负载下运行，不能把整批 wall 直接当配对速度比。V2 五段已经没有提速，故未重复付其全 1152 段重放。

## 执行决定

V1 比配对原核 CPU 慢约 19.50%，V2 慢约 10.46%。当前证据不足以称为提速；**活 M24 与后继幅度请求继续原核**。候选、完整输入/输出和计时详情留在仓外，Git 仅保再现源码与本条小记录。此比较没有增加 full-H、outer coupling、闭图、全局 metric/reach 或共同度量收敛结论。
