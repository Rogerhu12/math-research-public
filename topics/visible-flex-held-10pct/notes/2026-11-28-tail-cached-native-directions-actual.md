# 独立缓存 native 完整方向：五个真实段的实际比较

独立候选已编译并实际执行，当前生产 `frozen_flow_batch`、E/full-H 源和请求均未改。候选 builder 保留原 C++ 的 root、RHS、full-J、flow、协议、守卫原文，只在 Engine 中追加缓存方向方法及独立 C handle 入口。它未接入接受链，没有新非线性尾或闭图接受。

## 缓存的实际内容和复用

对一个固定原冻结段，缓存构造用同一 long-double RK4 状态轨迹和原 point-root，并在每个 RK 点保存完整 Q、完整 L（含零模）及 **literal B** 的原 checked Cholesky 下三角。state/Q/L/factor 在内存中保持原 80 位有效数字，没有中途 binary64 舍入。缓存输入以独立 handle 持有，不能改成另一状态；任何新 Newton 状态需要重新构造。

apply 接受完整 2M×b 初始方向，保全部 2M+2 输出分量。它由缓存完整 Q/L 重建原角节点行，再付原 branch checks；不重做 point-root 或 factor。其方向式是同日 `tail-literal-jvp-structure` 的完整式，Π、零模、mean 和原 Fourier 投影均保留。固定源下的 opaque handle 不是全批持久服务；当前全 1152 段的矩阵自由 solver 尚未接成。

## 真实输入及两种比较不可混淆

使用已接受 M16/N256/.5 的末 fresh J 中第 0、22、80、813、1151 段，**原 state、系数、角表、RK/cusp 网格全部不改**。每段先运行候选库中未改动的原 full-J 方法，要求其完整 binary64 state/J 与此前保留的 production 输出逐字节相同；五段均相同。缓存构造的 state 也与它逐字节相同，root calls/updates 相同。每段的完整方向测试包括全模非零单方向、18 个着色方向、32 列单位阵，以及单方向再次复用；复用两次的 canonical80 输出字节完全相同，apply 的 root calls/updates 不增加。

随后把缓存 native80 方向输出与原 full-J 的 native80 矩阵乘方向作比较。**两者不声称逐字节相同**：方向法先按线性性收集再积分，原 full-J 法先形成完整矩阵再乘，各有限浮点加法顺序不同。首次严格逐分量相对检查在 1e-12 门停止，没有保存完整行数据；随后另一个独立记录入口保留五段的全部比较及失败标志，没有把该门改称通过。

| 方向 | 最大逐分量 `abs(error)/(abs(J) abs(v))` | 最大全局同尺度差 | 最大绝对差 |

| 全模单方向（及再次复用） | 2.52022765702e-18 | 4.05337628173e-19 | 1.39698386192e-9 |
| 18 个着色方向 | 3.06287451195e-4 | 1.03655604684e-18 | 1.39698386192e-9 |

大逐分量相对差出现在极小交叉项。例：第 813 段单位阵的行 0、列 29，原 full-J 为 −2.6359728864610279201e-41，缓存方向为 −2.6377720497628032328e-41；第 1151 段着色方向一个分量约 2.91e-42。第 22 段部分单位列也有约 4.29e-15 的差，对其约 5.99e-7 的交叉条目形成 7.16e-9 相对差。因此 `all_strict_comparisons_passed=false` 保留为真记录，不能拿全局尺度小就声称所有逐项检查过门。后继即使仅生产初猜，仍须以完整原残差核验；最终接受一定回到原 full-J/height-J/audit。

## 实测成本：M16 未得到全求解提速

以下是五段此次实际 kernel 时间之和，受当前并行负载影响，不能外推为高 M 保证。

| 实际工作 | 五段 kernel 秒数 |
| --- | ---: |
| 原完整 full-J | 3.050047925 |
| 构造全部 RK 缓存 | 1.316125650 |
| 第一次完整单方向 apply | 0.166993916 |
| 18 色一起 apply | 1.206702943 |
| 全 32 列一起 apply | 2.655317327 |
| 同一单方向再 apply | 0.283475883 |

单次 apply 比原 full-J 便宜，但结合此前 18 色 P 的 60 次完整 A 乘积，**当前 M16 路线没有实证全求解速度收益**。该实现已避开每次 root/B factor 重算，却仍为每次方向重建全部角行与 literal partials。每个普通 16 步段的 Q/L/三角factor/state 缓存为 191008 B，68-RHS 段为 202912 B；本探针真实峰值 RSS 51768 KiB。缓存 byte 数不含各 handle 重复的角表/冻结系数，不能按它单独估全批峰值。

高 M 全批若继续此路，必须先共享只读角表并控制全 RK factor 缓存，再实测迭代数和完整方向成本。当前没有 M80 输入或运行结论，没有把一次局部方向核验当作全高度 J 的返回。
