# R14. 闭合转角确定平均斜率，非特征Darboux方程补齐高度二jet

会话 `literature_mechanisms`。这是 R12 的条件补充，不是闭合曲面的存在定理，也不把有限 Fourier 截断或采样残差升级为精确接口。主会话 `Astra-held10-f00f08c9-20261117` 已逐式独立复核角速导数、允许区间凸性、曲率符号、Darboux分母及误差条件数。

## 命题

固定 `r0>0`，令 `u in R/LZ`。两张参数曲面

`X_j(r,u)=(Y_j(r,u),z_j(r,u))`，`Y_j in R²`，`j=1,2`，

在接口 `r=r0` 的各自一侧为 C² 并具有连续二 jet 到接口。两边 r 采用同一方向。假设其精确第一基本形式在接口附近为

`g_j=E_j(r) dr²+r² du²`。

E_j 在各自一侧足够光滑以使用经典 Gauss 方程，并且 E_j、E_j' 连续到接口，满足共同值

`E_1(r0)=E_2(r0)=E0>0`，`E_1'(r0)=E_2'(r0)=E0'`。

例如 E_j 在各自一侧 C² 即足够。只要求这些公共接口值；两侧度量的更高径向导数不必相同。若原问题已有同一个光滑物理 g，这些条件自动满足。

进一步假设：

1. 经一次固定竖直平移，两侧的完整高度迹相同：`z_j(r0,u)=zeta(u)`。
2. 两侧径向高度斜率的非均值相同：`(z_j)_r(r0,u)=c_j+eta(u)`，其中 eta 周期、均值为零，c_j 为常数。
3. 两侧水平投影的 Gram 矩阵 `h_j=g_j-dz_j⊗dz_j` 在整条接口上正定。
4. 经必要的固定平面反射后，`epsilon=sign det((Y_j)_r,(Y_j)_u)` 相同，而且两条真实闭合水平曲线 `u -> Y_j(r0,u)` 的单位切向量有相同 turning number n。它们不必是平面简单闭曲线；若均连续来自标准正向圆并保持正则闭合，则 n=1。
5. 存在同一个符号 `sigma in {+1,-1}`，使两侧在整个角周期都有

   `sigma Q_j(u)>0`，其中 `Q_j=E0 zeta''+r0(c_j+eta)`。

则 `c_1=c_2`，两侧完整高度二 jet 相同。再由 R12，存在一个固定平面欧氏等距变换，使两侧完整 Cartesian 二 jet 沿整条接口相同。若两侧本已同平面取向，则该变换只需旋转和平移。

这里第五条是实质条件：不是仅在一个角点非零，也不是仅分别存在不相同的符号。在 upper 分支的典型情形为两侧 Q 全部严格负。

## 1. 水平度量及有向切向角速

以下各量都在 r=r0 上，暂写 r=r0、E=E0、`p=c+eta(u)`。令

`v=zeta'(u)`，`a=zeta''(u)`，`G=r²-v²`，

`h_rr=E-p²`，`h_ru=-p v`，`h_uu=G`，

`d=det h=E G-r²p²`。

正定等价于 G>0 且 d>0。给定 v、a、p，R12 的有向平面曲率公式给切向角速 `omega=|Y_u| kappa`：

`omega = epsilon [G G_r-2G(h_ru)_u+h_ru G_u]/(2 sqrt(d) G)`。

这里

`G_r=2r-2v p_u`，`(h_ru)_u=-p_u v-p a`，`G_u=-2v a`。

p_u 的项严格抵消，分子化为 `2r G+2r² p a`，所以

`omega(c,u)=epsilon r/sqrt(d) * [1+r p a/G]`.                 (1)

特别地，omega 不需要先知道 z_rr，也不依赖 E'。当 zeta 常数时，(1) 成为 `omega=epsilon/sqrt(E-p²)`，与圆的直接计算一致。

## 2. 允许均值区间的凸性

对于每个固定 u，d>0 的允许均值集合是开区间

`-eta(u)-sqrt(E G)/r < c < -eta(u)+sqrt(E G)/r`。

整圈允许集合为这些区间的交，因此是凸开区间。等价地，d 关于 c 是严格凹二次式；若 c1、c2 都使 d>0，则两者之间全部 c 也使 d>0，且

`d((1-t)c1+t c2,u) >= (1-t)d(c1,u)+t d(c2,u)>0`。

同样，`Q(c,u)=E a+r(c+eta)` 关于 c 仿射。若两个端点 Q 都在同一严格符号支上，则整个连接区间保留该符号。由紧致性，还存在这个连接区间上统一的正 d 下界和正 |Q| 下界。

因此下节的求导与积分可以在 c1 到 c2 的整个区间内合法进行，没有跨越投影退化点或非特征分支。

## 3. 总转角严格单调，所以 mean 斜率唯一

对 (1) 求 c 导数，利用 `d_c=-2r²p`：

`partial_c omega`

`=epsilon r [r a/(G sqrt(d))+(1+r p a/G)r²p/d^(3/2)]`

`=epsilon r/d^(3/2) [r a(d+r²p²)/G+r²p]`

`=epsilon r²(E a+r p)/d^(3/2)`

`=epsilon r² Q/d^(3/2)`.                                   (2)

因此在上述允许区间中，`I(c)=integral_0^L omega(c,u) du` 严格单调，导数符号为 epsilon*sigma。

对每条实际 C² 正则闭合水平曲线，单位切向量 `T_j=Y_{j,u}/|Y_{j,u}|` 是圆到圆的 C¹ 映射。把其角度在 [0,L] 连续提升，有

`I(c_j)=angle(T_j(L))-angle(T_j(0))=2 pi n`。

这里用的是真实周期闭合及相同 turning number；有限尾的数值 holonomy 残差不能被忽略。严格单调性与相等端值迫使 `c1=c2`。

于是 z、z_r 沿整条接口相同，其已有的切向导数 z_u、z_uu、z_ru 也相同。还剩 z_rr。

## 4. Darboux 方程唯一补齐 z_rr

对 `g=E(r)dr²+r²du²`，接口处的非零 Christoffel 项为

`Gamma^r_rr=E'/(2E)`，`Gamma^r_uu=-r/E`，

`Gamma^u_ru=Gamma^u_ur=1/r`。

内蕴 Gauss 曲率为 `K=E'/(2r E²)`。这可由弧长坐标 ds=sqrt(E)dr 及 K=-a_ss/a 直接得到。两侧共有 E0、E0'，因此 K 的接口值相同。

令

`A=z_rr-E' z_r/(2E)`，

`B=z_ru-z_u/r`，

`C=z_uu+r z_r/E=Q/E`。

高度函数的协变 Hessian 是 `Hess_g z=n_z II`。又有 `n_z²=det(g-dz⊗dz)/det g=d/(E r²)`。Gauss 方程遂给

`A C-B²=K d`.                                               (3)

第五条保证 C≠0，所以 (3) 唯一确定

`z_rr = E' z_r/(2E) + [(z_ru-z_u/r)²+K d]/(z_uu+r z_r/E)`.   (4)

右端全部量已经在两侧相同，故 z_rr 相同。这只使用边界二 jet 与两侧 Gauss 方程的连续极限，没有要求跨接口三 jet 相同。

两侧高度二 jet、度量一 jet 此时全部相同，且 h 正定，R12 给一个固定平面等距变换后完整 Cartesian 二 jet 相同。命题得证。

## 5. 可计算的均值误差条件数

本节只量化上面的标量转角条件，不省略实际度量/高度残差。设比较的两个 c 之间已经验证 G>0、d>0，且整个角周期 `|Q|>=q_*>0` 并保持同号。由于 `G<=r²`、`d<=E r²`，由 (2)

`|I'(c)| >= L r² q_* /(E r²)^(3/2) = L q_* /(E^(3/2) r) =: m_* >0`。

如果同一个 zeta、eta 与 E 所定义的转角积分在两个 c 处满足

`|I(c_j)-2 pi n|<=nu_j`，

则中值定理给

`|c1-c2| <= (nu1+nu2)/m_*`。

若两侧只是近似同一 zeta/eta/g，还必须先把这些误差通过 (1) 的分母正下界传播为转角积分误差，再使用本式。不能把采样转角或者点态 metric 小直接代入连续上界。随后 (4) 的 |C| 下界及 R12 的显式误差链可用于补齐二 jet 误差预算。

## 6. 使用范围

- 该结果说明，在精确极限与指定正则符号支中，完整高度迹及非均值斜率匹配并没有留下一个独立、任意的 mean 斜率自由度；周期闭合已经固定它。
- z_rr 由 Gauss 方程确定的前提是接口 C=Q/E≠0。若接口 Q 穿零、两侧 Q 符号不同，或者候选均值之间越过退化投影，此证明失效，不能从中推出不存在。
- 这里的条件只施加在被比较的接口及均值插值区间。尾内部其它位置 A 或相应二形分量过零的问题仍由其自己的构造处理；本局部定理没有给全尾的非特征性结论。
- 真实的有限数值联立仍应记录 mean、全部模、二 jet 和 holonomy 残差。上述精确唯一性不能消除浮点误差，也不能替代同 g 加密、无限尾存在、完整闭合、reach、握持区或 10% 变化比例。
