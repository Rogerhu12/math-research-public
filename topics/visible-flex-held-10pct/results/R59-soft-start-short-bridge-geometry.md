# R59：新软启动 ShortBridge 的严格参考几何与完整二阶扰动窗口

**状态：已证明并已执行参考桥的区间积分及有理数检查。对当前非旋转场的结论是条件性的；尚未审核该场的完整扰动。**

本结果只覆盖 R55 新软启动之后、当前外 cut 之前的 ShortBridge。桥仍使用曲率参数 \(4\)、peak fraction \(1/5\) 和当前 q060 port 的真实 cut 参数，不改前缀的物理目标度量，也不把旋转参考桥的曲率当成实际非旋转曲率。R58 另行处理首 valley 参数 \(4.625\) 的真实尾部背景。

这里补上的是 R55 宽设计盒留下的短桥几何预算：只要实际完整场相对一个明确的旋转参考桥支付四项条件，就有全桥的半径、支撑和实际主曲率界，并自动得到与尾部相接的绝对高度窗口。完整等距、真实尾匹配、全部接缝及帽标记仍须各自支付。

## 1. 实际 cut 与精确辅助参考

输入来自当前 q060 port，文件 SHA-256 为

    aa482f3bbd9506b90e307df72a7890f02f933338a4b3dec230f90b10765b09a5

其中三个 binary64 数值作为精确有理数读取：

\[
R=\frac{5404319552844595}{18014398509481984},\quad
w=\frac{2882303761517127}{36028797018963968},\quad
w_r=-\frac{4203359652212477}{2251799813685248}.
\tag{1}
\]

它们分别约为 \(0.3,0.08,-1.866666666666673\)。定义

\[
p_t=\operatorname{atan2}(1,w),\qquad
p=p_t+\frac15\left(\frac\pi2-p_t\right),\qquad
\epsilon=p-p_t,\qquad
p_s=\frac{w_r}{(1+w^2)^{3/2}},
\tag{2}
\]
\[
L_1=\frac{3p}{8},\qquad L_3=\frac{2\epsilon}{-p_s}.
\tag{3}
\]

桥的转角依次为

\[
\phi_1(t)=p(3t^2-2t^3),\qquad
\phi_2=p,\qquad
\phi_3(t)=p-\epsilon t^2,\qquad 0\le t\le1.
\tag{4}
\]

第一、三段的弧长分别为 \(L_1,L_3\)。令
\(I_j=\int_0^1\sin\phi_j(t)\,dt\)，中段长度定义为真实积分

\[
L_2=\frac{1-R-L_1I_1-L_3I_3}{\sin p}>0.
\tag{5}
\]

于是总长 \(L=L_1+L_2+L_3\)。以 \(\xi\in[0,L]\) 为这条参考桥的弧长，定义

\[
a(\xi)=1-\int_0^\xi\sin\phi(\zeta)\,d\zeta,\qquad
h(\xi)=\int_0^\xi\cos\phi(\zeta)\,d\zeta,
\tag{6}
\]
\[
\Xi(\xi,\theta)
  =\big(a(\xi)\cos\theta,\ a(\xi)\sin\theta,\ z_0+h(\xi)\big),
\qquad \frac7{20}\le z_0\le\frac{51}{100}.
\tag{7}
\]

这里 \(a(0)=1,a(L)=R\) 是精确恒等式，且 \(0\le\phi<\pi/2\)。参考度量与向外单位法线为

\[
g_0=d\xi^2+a^2d\theta^2,\qquad
n_0=(\cos\phi\cos\theta,\cos\phi\sin\theta,\sin\phi).
\tag{8}
\]

转角及其一阶导数在内部接点连续，所以 \(\Xi\) 是 \(C^2\) 图。首段
\(\max|\phi'|=4\)，末段 \(\max|\phi'|=|p_s|<2\)。参考的两主曲率绝对值为

\[
|\phi'|,\qquad \frac{\cos\phi}{a},
\]

因此全桥 \(\max|\kappa_i(\Xi)|\le4\)，后者还用了 \(a\ge R>1/4\)。

### 1.1 参考桥与实际数值 profile 的关系

原 ShortBridge 源以 64 点 Gauss–Legendre 公式计算归一化及查询积分；式 (5)–(6) 使用真实积分。因此本证明不把两者未经验证地称为同一个目标度量。

实际完整图先按一个确定的端点保持 \(C^2\) 重参数化拉回 \([0,L]\times S^1\)，再写成

\[
F=\Xi+V.
\tag{9}
\]

例如可用整段的正仿射径向重参数化。实际图的源积分误差、与精确参考的长度差、非旋转模式、完整 exact lift、唯一高度均值以及该重参数化的全部导数，都包含在 \(V\) 中。参考度量 \(g_0\) 只用于测量几何扰动，不能替代任务中的实际固定 \(g\)。

角坐标 \(\theta\) 是材料角。如果实际数据采用自适应计算角 \(\psi\)，必须使用真实角图的逆映射和完整链式法则，或把参考图也拉到完全相同的计算角中。不能将 \(\psi\) 默认为 \(\theta\)。

\(z_0\) 取实际桥入口已有的唯一高度基准，例如该真实入口截面的既定正权均值。它是要验证的实际量；不得为了通过 (7) 而另行平移某一段。所有界均在共同的 core 高度原点下陈述。

## 3. 实际完整场的四项条件

对式 (9) 的 \(V\) 定义参考单位第一导数范数

\[
\eta_1^2=
|V_\xi|^2+\frac{|V_\theta|^2}{a^2},
\tag{15}
\]

以及参考协变 Hessian 的三个向量分量

\[
H_{00}=V_{\xi\xi},\qquad
H_{01}=\frac{V_{\xi\theta}-(a'/a)V_\theta}{a},\qquad
H_{11}=\frac{V_{\theta\theta}+aa'V_\xi}{a^2},
\tag{16}
\]
\[
\eta_2^2=|H_{00}|^2+2|H_{01}|^2+|H_{11}|^2.
\tag{17}
\]

这些均须在整个 \((\xi,\theta)\) 桥上包围，包含每个径向区间内部、全部角度、全部均值和 lift；只验证节点不够。这里不需要全图 \(C^3\)。

**条件窗口。** 若

\[
z_0\in[.35,.51],\qquad
\|V\|_\infty\le\frac{13}{100},\qquad
\|\eta_1\|_\infty\le\frac3{25},\qquad
\|\eta_2\|_\infty\le\frac{11}{2},
\tag{18}
\]

则实际完整桥满足

\[
|F|<\frac{67}{50}=1.34,\qquad
F\cdot n>\frac{32353}{360100}>.087,\qquad
\max_i|\kappa_i(F)|\le\frac{47505}{3872}<12.3.
\tag{19}
\]

### 3.1 半径与支撑证明

半径由 \(|F|\le|\Xi|+|V|\) 立即得到。取参考的正交单位切向架，两个实际切向量的误差平方和不超过 \(\eta_1^2\)。其叉积 \(N\) 与参考单位法线之差满足 R23 同一恒等估计

\[
|N-n_0|\le\sqrt2\,\eta_1+\frac{\eta_1^2}{2}.
\]

用 \(\sqrt2<99/70\) 与 \(\eta_1\le3/25\)，右端不超过
\(\gamma=774/4375<1\)。所以面积非零，且与参考一致的单位法线满足

\[
|n-n_0|\le\frac{2\gamma}{1-\gamma}=\frac{1548}{3601}.
\tag{20}
\]

故

\[
F\cdot n
\ge\Xi\cdot n_0-|\Xi|\,|n-n_0|-|V|
>
\frac{37}{50}-\frac{121}{100}\frac{1548}{3601}-\frac{13}{100}
=\frac{32353}{360100}.
\tag{21}
\]

### 3.2 实际主曲率证明

式 (15) 给出实际切向微分的最小奇异值至少 \(1-\eta_1\)，这里奇异值均以参考单位架测量。对任意参考单位切向量 \(v\)，以 \(g_0\) 的联络作 Cartesian 协变二阶导数，

\[
\nabla^2_{g_0}F(v,v)
=\mathrm{II}_0(v,v)n_0+\nabla^2_{g_0}V(v,v).
\]

实际法线内积的绝对值至多 \(4+\eta_2\)。除以实际第一基本形式下界 \((1-\eta_1)^2\)，便得实际法曲率及两主曲率绝对值的界。证书保守地将参考常数 \(4\) 放宽到 \(4001/1000\)：

\[
\max_i|\kappa_i(F)|
\le\frac{4001/1000+11/2}{(1-3/25)^2}
=\frac{47505}{3872}<\frac{123}{10}.
\tag{22}
\]

这一步使用实际第一、二基本形式的关系，没有假定实际 metric 已等于 \(g_0\)。若未来实际误差落在不同矩形窗口，也可直接使用上述一般公式重新支付几何门，而无须改变图或目标度量。

### 3.3 较锐单位法线估计与适合全角系数界的备选窗口

下面只改进解析扰动引理，不改变第 2 节的参考桥、已执行积分源或输出。

令 \(A_0:\mathbb R^2\to\mathbb R^3\) 的两列为参考单位切向架，
实际两切向量组成 \(A=A_0+E\)，其中 \(\|E\|_{\rm op}\le\eta_1<1\)。
实际单位法线 \(n\) 满足 \(A^Tn=0\)，所以

\[
|A_0^Tn|=|E^Tn|\le\eta_1.
\]

从 \(A_0\) 沿 \(A_0+tE\) 连续选取法线；每个 \(t\in[0,1]\)
的最小奇异值至少 \(1-t\eta_1>0\)。若法线与 \(n_0\) 的夹角曾达到
\(\pi/2\)，就会有 \(|A_0^Tn|=1\)，与上界矛盾。因此 \(n\cdot n_0>0\)，并且

\[
|n-n_0|^2
=\frac{2\{1-(n\cdot n_0)^2\}}{1+n\cdot n_0}
\le2\eta_1^2.
\tag{22a}
\]

这给出比 (20) 更锐的 \(|n-n_0|\le\sqrt2\,\eta_1\)。
特别地，以下更宽的矩形也是同一实际桥的充分条件：

\[
z_0\in[.35,.51],\qquad
\|V\|_\infty\le.13,\qquad
\|\eta_1\|_\infty\le\frac15,\qquad
\|\eta_2\|_\infty\le\frac{19}{5}.
\tag{22b}
\]

它仍给出 \(|F|<1.34\) 和第 4 节的 cut 高度范围，并有

\[
F\cdot n>
\frac{37}{50}-\frac{121}{100}\frac{99}{350}-\frac{13}{100}
=\frac{9371}{35000}>.087,
\tag{22c}
\]
\[
\max_i|\kappa_i(F)|
\le\frac{4001/1000+19/5}{(1-1/5)^2}
=\frac{7801}{640}<12.3.
\tag{22d}
\]

这里用了 \(\sqrt2<99/70\)。新增的三项有理比较已用 Python
Fraction 单独实际执行并通过；没有重跑或修改参考桥的区间积分。
原窗口 (18) 与备选窗口 (22b) 各自有效，不可把两者中较松的每个坐标
任意混合使用。备选窗口尤其适合直接从实际 quintic 系数的 Bernstein
包围推全角 Fourier 系数绝对值和，从而避免另做大量连续角盒。

## 4. 自动获得尾 cut 的绝对高度窗口

式 (7)、(14)、(18) 在桥末端给出逐点界

\[
\frac{6001}{10000}
<
F_z(L,\theta)
<
\frac{10213}{10000}.
\tag{23}
\]

因此，同一实际图上的任何归一化正权均值也在该开区间内，包括选定材料角或计算角下的真实均值，及已固定的正权离散均值规则。后续必须继续使用既定的同一均值规则，不能据此重新选取高度常数。

式 (23) 将后尾所需的 cut 高度 \(z_c\) 压入

\[
.6001<z_c<1.0213\subset[.2,1.24].
\tag{24}
\]

这比先前条件尾部窗口更紧。R58 的当前 \(4.625\) 背景真实高度与曲率证明仍独立必要；式 (24) 不继承旧 \(3.125\) 背景的数值结论，也不自动匹配任何真实尾 DN 或完整 cut 二阶数据。

在 R55 宽设计盒 \(r\le11/10\) 内，首周期长
\(r(160219/346275)<.51\)。如果实际图已经支付该周期的完整单位经向 metric、core 高度为零且沿用同一个高度重建，则其入口均值的上界 \(z_0<.51\) 还可直接由路径长度得到。下界 \(z_0\ge.35\) 仍须对实际图验证。若 metric 仅近似，必须加入实际误差带，不能把等式 \(|F_s|=1\) 当成已知。

## 5. 与全闭几何预算的衔接及范围

R55 宽盒、此桥、R58 后尾及帽段若共同在同一原点下支付全图
\(|F|<1.34\)、正支撑 \(>.087\)、\(\max|\kappa_i|\le12.3\)，并完成全部公共 \(C^2\) 接缝，才可调用 R1 的闭 \(S^2\) 正支撑法向偏移论证。随后按 R54 插入全长至多 \(.01\) 的短柱，得到原已登记的 \(D\le2.69\) 等组合预算。本结果不单独宣布整图嵌入、全图 reach 或任务完成。

若相位作用只是本段的整体旋转及材料角平移，(18)–(22) 对全部相位一并成立；完整族如含其他修改，则须另付相应扰动。最终为了固定握持片施加的公共刚体归一化保持直径和 reach；半径与支撑的参考原点应随该刚体变换移动，不能把平移后的欧氏坐标原点继续当作未移动。

尚未支付的实际内容包括：新非旋转场的 (18)、第一周期其余部分的实际全角曲率与支撑、真实尾及唯一完整 cut 数据、帽标记的非全等量、全域 relative-operator metric 及细层比较。本结果没有把已见小幅数值入口或尚未运行的后续圆化当作这些证书。
