## 新增结论

- [R1：偏心双圆领的精确相位组装与全相位点对判据](results/R1-eccentric-collar-phase-bearing.md) — 已证明（条件组装）。环带与帽的假设尚未实例化，不是本题完成。

- [R2：二、三角模混合产生横向中心漂移的精确局部环带](results/R2-mixed-modes-local-eccentric-drift.md) — 已证明真实局部解析等距嵌入及中心二/三阶系数；无圆领闭合、无闭曲面。

- [R3：准确半带的同轴相位闭族与定量充分条件](results/R3-mirrored-halfband-phase-family.md) — 已证明条件组装、全时间几何归结和完整像集支持见证；明确预算给held/D≥.3043，但满足条件的半带尚未求出。

- [R4：reach 限制下的端口长度与平盘高度必要界](results/R4-reach-limited-port-length.md) — 已证明准确等距连接的转向长度界，严格排除 L=.75 的强椭圆方案；实际核心法球另给 B/C 的末盘必要高度。没有排除全部 B/C，也没有证明其存在。

- [R5：四个偶多项式模式的完整二阶周期条件](results/R5-four-mode-periodic-obstruction.md) — 已证明当前四维 poly4 空间中的独立三矩圆通过两完整周期条件，当且仅当 11 个几何系数全零；附 36 个精确有理行列式证书。未证明基面可实现或高阶可积。

- [R6：非平面中央曲线的半转镜合与相位闭族](results/R6-nonplanar-halfturn-phase-assembly.md) — 已证明完整二 jet 的半转组装及非凸投影域的 Hausdorff 见证；公开 R44 准确鞍带满足入口对称性。所需圆领连接和完整嵌入尚未取得。

- [R7：九个周期几何系数与任意有限多项式 profile](results/R7-nine-coefficients-and-polynomial-profiles.md) — 已证明额外几何恒等式将实际系数降到九个；任意有限次数、双端至少三阶消失的独立多项式三矩圆通过完整周期条件 iff 九系数全零。未排除一般全平端光滑 profile。

- [R8：全平端光滑 profile 的局部方程与双重端点根](results/R8-flat-profile-period-equation.md) — 已证明完整Volterra周期条件可化为显式四阶二次方程；真实支撑两端必须是C的至少双根，故C恒零或为两实双根的四次式。非零profile和实际几何实现仍未构造。

- [R9：闭空间曲线的准确 rectifying 平度量核](results/R9-rectifying-flat-core.md) — 已直接证明隐式材料坐标、准确平度量、闭角、完整二jet/唯一非零主曲率及半转对称。中央空间曲线能给实际小嵌入环带；指定宽度的全局reach与圆领闭合尚无证书。

- [R10：指数倾斜准确闭合的对称带状基底](results/R10-exponential-tilt-exact-closure.md) — 已证明唯一轴向闭合倾斜、水平/渐近周期及全角正则代数判据；闭合正则浸入不等于嵌入、九系数零或有限可弯族。

- [R11：R44 静态核心与完整C6像的相位幅度上界](results/R11-ruled-core-amplitude-limits.md) — 已证明原核心自身相位Hausdorff比≤.04627；若完整像保C6则比≤sin(π/12)<.3。没有把核心上界外推给任意过渡，局部曲率上界也未排除全部reach目标。

- [R12：ψ 扭曲的准确闭合负曲率核心](results/R12-warped-ruled-core.md) — 已证明自由三瓣扭曲、准确闭合、全角正则判据、完整材料二jet及固定负K度量；连续曲率/填充投影脚本已备，实际幅度与核心嵌入待Actions，圆领连接和闭面仍未实现。

- [R13：内部二重退化下真实的局部 C∞ 复相位开启](results/R13-local-smooth-complex-phase-opening.md) — 已用加权Green/Euler压缩证明跨内点的真实光滑解，左实右复且虚部全平；给出使完整局部Volterra条件成立的三矩常数。尚未实现全局右尾、双端紧支撑、三总矩或实际几何系数。

- [R14：法弦近远点对分解与有限宽准确核心嵌入](results/R14-normal-ribbon-embedding-certificate.md) — 已证明近弧曲率法弦界、完整参数片覆盖的中心曲线reach下界及有限宽法向核心嵌入准则；实际u=.8/1候选将由Actions认证，未覆盖圆领或完整闭面reach。

- [R15：两端零 jet 与满秩 B 下三复总矩自动成立](results/R15-global-endpoint-moments.md) — 已证明完整区间Q=0加两端q/q′/q″零及满秩B，自动给完整O=0与三复总矩零；允许C3且分段C4，另给准确残差传递。没有把局部R13或截断射击当作满足前提的全局解。

- [R16：C2 零延拓、四阶外尾条件与四参数全区方程](results/R16-C2-endpoint-profile-equation.md) — 已证明四阶 profile 外尾足以给 C2 场，简单端根满足 W=−8C′/7，及其完整四参数化。全区非多项式 profile、真实系数几何实现和有限等距族均未构造。

- [R17：旋转参考的线性平端相容性与固定圆领零 trace](results/R17-revolution-linear-flat-port-compatibility.md) — 已证明单调平端的高角模 Robin 条件、零 trace 唯一性和有限阶二jet；未弯 R128 小幅方向不能提供该参考所需的高角模 trace。只限旋转基点线性问题，不排除强非旋转有限分支。

- [R18：四阶简单根外尾的真实解析存在与唯一相位](results/R18-analytic-fourth-order-outer-germs.md) — 已用非共振 Fuchs/Euler 解析收缩证明每个非零复首项对应唯一解析外尾，仅公共幅相自由；不是全区 profile 或实际曲面族。

- [R19：C4 外尾相位唯一性与非负 D 的正 C 分支排除](results/R19-C4-outer-tail-rigidity-and-D-sign.md) — 已将解析外尾唯一性推广到任意非零四阶首项的 C4 输入，并用不除 L 的积分恒等式排除 C>0、D≥0 的双端归零。不是一般曲面刚性定理。

- [R20：实际几何 D 恒零与八系数限制](results/R20-geometric-D-zero-identity.md) — 已证明全 profile 坐标上的点态恒等式及仿射不变性；R13 固定 D=−8 不可几何实现。结合 R19 严格排除内部 C 不变号的简单端根四阶分支，未排除其他机制。

- [R21：D=0、C恒零的有限光滑 profile 刚性](results/R21-zero-C-profile-rigidity.md) — 已对全局 C3、有限分片 C4、双端 q/q′零证明：非零解只能落在全部八个几何系数同时零的算子分支。保留零算子例外，不外推内部变号 C。

- [R22：D=0 变号根处真实的局部 C4 相位开启](results/R22-D0-sign-changing-local-phase.md) — 显式八坐标满足 D0，实解析基底及 x^(9/2) 非线性复分支均由收缩证明；没有闭曲线几何实现、全区外尾匹配或有限等距族。

- [R23：ψ-warp 准确核心的非零 linking 封口障碍](results/R23-warped-core-linking-obstruction.md) — 已证正则Jordan投影下framing为+3，禁止同一嵌入annulus接开放平圆领；两个已认证基线适用。没有否定核心本身或其他零framing机制。

- [R24：空间星核的高度奇偶与平圆领 framing 障碍](results/R24-space-star-height-parity-framing.md) — 当前奇正弦高度类的framing为3的奇数倍，不能嵌入annulus封平圆领；偶余弦高度类严格framing0，但完整连接与定量几何尚缺。

- [R25：偶高度外尖出口的reach与投影余量必要界](results/R25-cosine-core-outward-port-budget.md) — 已证完整闭面从向外出口转回前必须占用额外投影距离；p=w时化为两条准确线性高度约束。D下界必要排除与D上预算的保守设计严格分开，未证明封口存在。

- [R26：通用D0简单根的真实局部C4相位开启](results/R26-generic-D0-simple-root-phase-opening.md) — 已将R22推广为W/C′∈(−9/4,−5/4)及显式非退化jet的开条件；两次Fuchs收缩证明实际解析基底与复分支。实际几何尚未通过该比值条件，全局外尾匹配仍缺。

- [R27：D0方程在L简单零点的C3续解唯一性](results/R27-simple-L-zero-C3-phase-rigidity.md) — 不预设接点四阶导数，先由无log发散强制相容式，再用全负Euler谱无权收缩证明全部共享C3 jet的续解自动解析；实支不能在简单L零点启新相位。高阶/全平退化尚待处理。
