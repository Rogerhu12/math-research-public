# 真正保持端点的有限桥控制：固定 frame、准确 omega 与可变高阶函数

日期：2026-11-14。本稿为 R68 的有效桥方程提供一个具体有限参数域。没有运行真实候选、几何 ODE、profile 积分或优化；配套 helper 只做小型 Fraction/链式恒等式开发核对。来源审查代理已独立逐式和静态审核正文、端点/倒行及前三导数实现。

## 1. 固定真实 k 和长度，改变 h

取已经定义好的、长度 $\ell>0$ 的一个平滑桥 primitive。局部 $t=s/\ell\in[0,1]$，沿用已经采用的严格单调、两端全部导数为零的开关

$$S(t)=\frac1{1+\exp\{1/t-1/(1-t)\}}\quad(0<t<1),
\qquad S(0)=0,\ S(1)=1.$$

原始控制是

$$k_*(S)=k_0+\Delta k S,\qquad
b_*(S)=b_0(1-S)+b_1S+\eta S(1-S)>0,$$

$$h_*=(2b_*)^{-1},\qquad
\omega_*(S)=\omega_0+\Delta k\int_0^S b_*(v)\,dv.$$

其中 $b=1/(2h)$，因而真实相容式为 $\omega_s=k_s b$。长度和 $k$ 全程保持不变；只改变 $b$。

固定有限个实多项式

$$F_j(S)=S^2(1-S)^2P_j(2S-1),\qquad j=0,\ldots,m-1,$$

这里 $P_j$ 是 Legendre 多项式；只使用它们是次数不同的实多项式及 $P_j(-x)=(-1)^jP_j(x)$，不依赖任何数值正交计算。定义

$$b_\beta(S)=b_*(S)+\sum_j\beta_j F_j'(S),\qquad
h_\beta=(2b_\beta)^{-1},\tag{1}$$

$$\boxed{\omega_\beta(S)=\omega_*(S)
+\Delta k\sum_j\beta_jF_j(S).}\tag{2}$$

式 (2) 是从同一个段首 $\omega_0$ 积分得到的真实原函数：

$$\partial_s\omega_\beta
=\Delta k S_s\left(b_*+\sum_j\beta_jF_j'\right)
=(k_*)_s b_\beta.$$

没有在段尾另选常数，也没有以数值重置补齐端点。

## 2. 共同端点条件被准确支付

因为 $F_j(0)=F_j(1)=F_j'(0)=F_j'(1)=0$，(1)–(2) 给出与原始桥完全相同的两端 $k,h,\omega$。再由 $S$ 的全平端 jet，扰动在真实 s 坐标中两端全部导数均为零。故原来与相邻常态的光滑接缝保持。

frame 方程

$$T_s=kN,\qquad N_s=-kT-B,\qquad B_s=N$$

只依赖固定的 $k(s)$ 和真实弧长。因此从同一 frame 入值出发，**整个 frame 曲线**都与原来相同，不只是末 frame 相同；这些 $\beta$ 不需要任何 frame 重新拟合。

必须同时保留一个区别：中心曲线满足 $\alpha_s=h^2T$，所以其真实位移一般会随 $\beta$ 改变。本稿没有把该位移设为不变。若把同一修改后的 P 及其真实倒行用于准确 R45 四块组装，则该结构对任意新的 P 位移仍准确闭合；若原始 frame 仅为数值近似，则仍应计算自然闭合缺陷，不进行置中或 reset。

若一个固定长度连接中的某段本来 k、h 都为常数，可把它写为 $\Delta k=0,b_0=b_1,\eta=0$ 的同一公式。此时 h 可变，而 omega 全程不变。禁止把这些控制直接加到被共同放大 N 的 bulk 上，否则会改变 R67/R68 的次数和最高项前提。

## 3. 正 h、共同物理区间和真正开参数域

令

$$m_* =\min_{0\leq S\leq1}b_*(S)>0,\qquad
K_j\geq\sup_{[0,1]}|F_j'|.$$

在显式开域

$$\sum_j|\beta_j|K_j<m_*\tag{3}$$

中，$b_\beta>0$。例如取右侧 $m_*/2$ 就留出统一余量，获得 h 及所需有限阶导数的共同界，符合 R68 的有界桥族假设。

$K_j$ 可以完全有理地取得：把 $F_j'$ 的有理 power 系数改写成同次数 Bernstein 系数，取其绝对值最大值。因为 Bernstein 基函数在 $[0,1]$ 上非负且和为 1，该值是严格可核的上界。原 $b_*$ 是二次多项式，端点和可能的内部顶点给准确最小值；helper 对冻结二进制参数的精确有理值做这个判断。

共同物理区间还有比扰动范数估计更直接的保护。只要 (3) 成立，

$$\operatorname{sign}(\omega_{\beta,s})=\operatorname{sign}(\Delta k)$$

在段内不变；若 $\Delta k=0$，omega 恒定。omega 两端又与原来准确相同，因此每段 omega 的值域仍是**原来的同一个两端区间**。整个控制词的最小和最大 omega 不变，所以原有正物理条件 $\xi+\omega\geq\delta>0$ 及同一固定 profile 区间都保留，无须另行移动 profile。

h 和 $u=h/(\xi+\omega)$ 的具体范围会变化，须按新控制评价；这里只保证正性、无极点和有界性，没有给 reach 或嵌入结论。

这些方向确实构成有限独立控制：$F_j'$ 的次数依次为 $j+3$，首项非零，因此没有非零常系数线性组合在整个段恒零。端约束没有把它们消成空方向。独立控制不等于其第四响应满秩。

## 4. 准确倒行，不单独重拟合另一半

Legendre 奇偶性给

$$F_j(1-S)=(-1)^jF_j(S),\qquad
F_j'(1-S)=(-1)^{j+1}F_j'(S).$$

倒行保持长度，交换 $k_0,k_1$ 及 $b_0,b_1$，保留 $\eta$，以原段的准确末 omega 为新起点，并取

$$\boxed{\beta_j^{\rm reverse}=(-1)^{j+1}\beta_j.}\tag{4}$$

这样得到的 $k,h,\omega$ 就是原修改后控制的真实时间倒行。特别地，$\Delta k$ 同时变号，(2) 的扰动项仍准确匹配原来的 $\omega(1-S)$。四块几何可共享一份 $\beta$ 并按 (4) 编译，不能把倒行块当作独立优化变量。

## 5. 对有效桥方程的具体作用

对一个由这些控制组成的有限 $\beta$ 向量，所有 frame/scalar 端条件已由第 2 节准确支付，且 bulk 状态、真实周期及同一全局 profile 不变。R68 的必要函数仍为

$$\mathcal C_{\rm eff}(\beta)
=P_2(0,\beta)-D_pP_3(0)A^{-1}M_{\rm bridge}(0,\beta).$$

这些控制真实改变 $h,h_s,\omega$，因而改变 $M_{\rm bridge}$、第四桥积分及其下游历史；没有从端点保持推出这些积分不变。其导数是

$$D_\beta\mathcal C_{\rm eff}
=D_\beta P_2-D_pP_3(0)A^{-1}D_\beta M_{\rm bridge}.\tag{5}$$

式 (5) 中两项必须使用同一个修改后的桥。$D_\beta P_2$ 包括 R67 的真实传播，不只是局部积分。由于 frame 由定义固定，这个模型不会在每个第四评价中另行重拟合 frame，也不会把一个求解误差混成可调方向。

目前还没有求出 $\mathcal C_{\rm eff}=0$ 或证明 (5) 的函数秩。原 R52 数值 profile 已显示第一标准常态门非零，所以后续完整候选还须使用同一个通过所用常态必要门的 profile；本控制族不是修复该已知失败门的捷径。

## 6. helper 的实现身份与已有开发核对

新文件 `scripts/literature_endpoint_preserving_h_controls.py` 提供：

- 用有理递推生成 $F_j$ 及其 Bernstein 界；
- 将固定长度 primitive 装饰成带独立 schema 的受控段，并核准确正 b 充分界；
- 从真实公式评价 $h$ 与 k 的前三 s 导数和 omega，供后续公开 Actions 的矩阵/完整 range 评价器使用；
- 按 (4) 编译受控段的真实倒行。

受控 schema 将原始字段放在 `base` 中，避免旧 movement/helper 默默忽略新的 h 控制。旧程序不能直接把受控段当成普通 ramp；frame 旋转可以复用原 k，而中心线位移和所有 metric/range 数据必须使用新 h。常 h 输入转换到 b 时保留其精确有理倒数，不先舍入一个新 b 来暗改端点 h。

每个受控段记录全部实际字段的 canonical SHA256。评价和倒行入口都先重新计算身份，并从实际字段重核有理正 b 界、所存界及一致的段长；修改控制却保留旧 hash 或旧正性元数据会被拒绝。这个检查只绑定输入定义，不把浮点 jet 评价升级为区间证书。

目前 CLI 仅有 `--toy-only`。toy 用 Fraction 验证前八个 basis 的端点、零 omega 增量和倒行奇偶性，用形式链式法则验证 h 的前三导数，再验证一个人为有理参数盒的正下界及人为 schema 的身份篡改拒绝。没有调用真实候选或评价研究积分。

下一实际控制检查、导数核验或优化必须由本公开仓库 Actions 的新 driver 调用。控制族和 helper 的存在不等于 Ceff、完整第四、有限等距族或主课题几何门已经通过。
