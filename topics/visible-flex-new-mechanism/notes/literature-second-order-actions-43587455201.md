## 3. 投影残差与截断路径的实际限制

零均值投影在连续层面应留下已知的单一分量
$$ (L_XZ-H)_E=-\frac{u^2P(\xi)}{\pi (ds/d\theta)},\qquad
(L_XZ-H)_F=(L_XZ-H)_G=0.$$
非零周期下，投影完整方程误差本就不应消失。当前 JSON 只存总误差，没有存“实测残差减上述显式项”的分量；不能仅凭它把真正周期 forcing 与剩余离散误差完全分开。后续若仍使用 range 恢复器，应增加这一便宜诊断；它不影响当前已经失败的周期检验。

最细 bump 的 $Z$ 峰值仍约 $5.13\times10^7$；端点 jet 外推尚不稳定。$\varepsilon=10^{-5}$ 的投影截断路径最大相对度量误差约 **57.08**。polynomial 两档同一量为 **0.8820 / 0.9308**。这些数都远离本题阈值，不作为 Newton 初值或实际有限弯曲。
