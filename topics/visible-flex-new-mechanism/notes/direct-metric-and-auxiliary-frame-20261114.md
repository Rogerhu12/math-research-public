# 直接重构度量与辅助目标框架的有限空间限制

日期：2026-11-14。root推导。针对首饱和六帽实际试验中大E/F误差，明确一个与课题目标直接等价的诊断及其参数导数。本文没有进行新的几何评价或优化，也没有构造合格连接。

## 1. 精确重构及必要的零均值前提

令角变量为theta，径向变量为t，所有角函数2pi周期。用Pi表示唯一的零均值周期原函数：对于零均值函数f，有

$$\partial_\theta\Pi f=f,\qquad \langle\Pi f\rangle=0.$$

给定单位场T、正函数a(t)及中心高度z(t)，设

$$|T|=1,\quad\langle T\rangle=0,\qquad
X(t,\theta)=a(t)\Pi T(t,\theta)+z(t)e_z.$$

角均值为零是本命题的必要前提，不能只因T单位而省略。当前二重旋转及反射对称的u/v表示使T的水平分量在theta加pi后反号、竖直分量为角反射奇函数，从而准确零均值。有限FFT近似仍需另核原函数与均值误差。

写b=z'，定义真实径向切向

$$U=X_t=a'\Pi T+a\Pi T_t+b e_z.$$

于是

$$X_\theta=aT,\quad
E=|U|^2,\quad F/a=U\cdot T=:q,\quad G/a^2=1.$$

只要a、z为C2且T联合C2，这个定义给联合C2的X。所有结论先针对准确Pi与准确中心函数，离散评价不自动继承准确恒等式。

## 2. 两个真实度量残差的准确算子范数

参考度量取g=dt2+a2 dtheta2。在其正交归一基下，实际度量与参考度量的差为

$$M=\begin{pmatrix}e&q\\q&0\end{pmatrix},
\qquad e=E-1.$$

其两个特征值为

$$\lambda_\pm=\frac{e\pm\sqrt{e^2+4q^2}}2,$$

所以准确相对算子误差为

$$\boxed{\eta_g=\frac{|e|+\sqrt{e^2+4q^2}}2.}$$

可用于平方目标的直接残差是

$$r_g=(e,\sqrt2\,q),\qquad
\eta_g\le |r_g|_2\le\sqrt2\,\eta_g.$$

特别地，准确等距到同一个g恰好等价于e=q=0。任意有限采样均方成本很小都不等于全域最大误差很小；课题要求的全域最大算子误差、同g精化及连续覆盖仍须独立执行。

若全域eta_g小于1，则实际度量的两个归一化特征值至少为1−eta_g，故

$$E-q^2>0,\qquad |X_t\times X_\theta|
=a\sqrt{E-q^2}\ge a(1-\eta_g)>0.$$

这只给局部浸入性，不给全局单射、闭合、reach或宏观位移。

## 3. 与原辅助目标V及积分性残差的准确关系

原框架方法另选单位正交场V，满足V垂直T，并令

$$\mathcal R=V_\theta-(aT)_t.$$

若中心定义为b=平均V的竖直分量，且平均V的两个水平分量准确为零，则

$$\Pi\mathcal R=V-b e_z-a'\Pi T-a\Pi T_t,$$

因此

$$\boxed{U-V=-\Pi\mathcal R.}$$

原来的R=0是e=q=0的充分条件；它同时要求真实U落在所选辅助V的表示中。这个附加条件对于有限角向beta空间可能限制可表示的X，不是课题对实际度量另加的完成门。

反过来，若直接条件e=q=0成立，则定义

$$V_*=U=X_t$$

即得单位、与T正交的真实径向方向，并由X的混合偏导交换准确得到

$$\partial_\theta V_*=(aT)_t.$$

这里无需预先证明V*属于原有限beta基。若使用当前由T确定的全局正交标架N0、T叉N0，V*可作为一个圆值角函数表示；当某个边界圈的角绕数为零时，该绕数沿环带保持零，所以存在全局实周期角提升beta*。这种角提升也不必是有限Fourier/椭圆角函数的组合。

对于C2的X，V*=X_t通常只需C1。原辅助标量场所锁住的更高端口jet不能未经核对就当作课题所需的物理位置C2条件。

由此，R55对指定饱和反射、全标量端口jet及有限解析自由列的准确R=0排除，不能自动解释为直接重构X的e=q=0已经被排除。若要转用该定理，必须重新证明V*具有其全部表示与端口假设。本文也未证明当前有限T空间确有直接度量零点。

## 4. 全参数解析导数

以下delta表示任意参数方向，不是尾部径向距离。Pi与角均值为固定线性算子，参数族保持上述准确零均值。允许a与T同时变化，中心一维自由度通过b、z表示。准确有

$$\delta X=(\delta a)\Pi T+a\Pi(\delta T)
+(\delta z)e_z,$$

$$\delta U=(\delta a')\Pi T+a'\Pi(\delta T)
+(\delta a)\Pi T_t+a\Pi(\delta T_t)
+(\delta b)e_z.$$

因此

$$\boxed{\delta e=2U\cdot\delta U,\qquad
\delta q=(\delta U)\cdot T+U\cdot\delta T.}$$

直接残差Jacobian的两行就是delta e和sqrt2 delta q。形状项仍使用上式delta X；没有省略由metric设计引起的delta a、delta a'列。

当前实现若继续借辅助V定义b，必须取

$$\delta b=\langle\delta V_z\rangle,$$

包括V对所有实际参数的完整链式导数。若未来改为独立的一维b控制，则用该控制的准确导数，并保原准确core/尾及单一高度锚。后者属于另一个明确的连续参数化，不可静默混入旧模型身份。
