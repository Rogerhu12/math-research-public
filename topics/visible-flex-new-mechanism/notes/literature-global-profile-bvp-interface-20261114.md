# C2 全区 profile BVP：实现、固定目标精化及验证接口

日期：2026-11-14。脚本 `scripts/literature_global_profile_bvp.py` 已实现；尚未运行研究优化。计算由公开仓库 Actions 执行。

理论边界条件和参数化见 [R16](../results/R16-C2-endpoint-profile-equation.md)；三总矩与完整 Q 的关系见 R15。

## 实际未知量

在整个 [−1,1] 同时求 q=(1−x²)^4P 和四个实参数 (b,c,d,D)。P 的基包含全局 Chebyshev 模式，另加支撑在 |x|<ρ 的 `exp(τ−τ/(1−(x/ρ)²))` 平坦窗口乘 Chebyshev 模式。后者为内部相位开启留出非解析的函数空间，不把整个候选限制成已被 R7 排除的有限多项式。

实部和虚部按固定参考求积的 H2 半范数构成正交单位二维框架。采用 Grassmann 局部坐标及二阶正定矩阵的极分解，既防止零解，也去掉平面内换基冗余。第一初值来自四个偶模式的三矩 circle；默认 b=0.05、d=0.1，避免优化被完全反射对称的初值锁在偶子空间。D 使用两档 −8、1。

归一化质量矩阵由固定 512 点参考求积定义。若试基方向的质量特征值相对最大值不足 1e−12，就在这个数值试空间中去掉该方向；报告完整特征值、保留维数、丢弃维数及前一 profile 投影后的 H2 误差。它不是对无限维算子的核或刚性判断。

## 端点与目标算子

q 的 0–3 阶端点零 jet 由因子严格施加，零延拓为 C3，因而 Y 为 C2。C 的两个根和 W=−8C′/7 用参数化严格施加。默认参数盒 `|b|≤0.4, −0.4≤c≤2` 保证 `1+bx+cx²≥0.2`，所以这一试验内两根简单且内部 C 不为零。

目标使用完整 Q，而非一端局部延拓。Q/((1−x²)^4) 的各双线性微分系数先用 Fraction **精确**除尽端点因子，再作浮点求值；已检查全部 75 个系数除法。避免通过直接相除很小的端点数值制造伪零。

第一阶段同时调 profile 与四参数；其后各频率阶段**冻结同一组四参数和同一残差尺度**，只增大 profile 试空间。这样不同频率不是偷偷改变算子后的另一组问题。ρ、τ 同样固定。

完整 Q 与满秩 B 下的矩条件在精确问题中冗余；实现仍把 M1、M2 的实虚四个量作为数值预条件残差保留，M0 由正交单位框架处理。验证独立计算全部三个复总矩，不因归一化或 R15 而把报告强行置零。

## 验证

每一阶段冻结 profile 系数及算子参数，在 512、1024 点重新求积和评估，输出：

- 缩去已知端点因子的 Q 及原 Q 的 L2/最大残差；
- 直接四阶公式与精确因式算子的逐点差；
- 从**真实右端 1** 积分的三个 J 及完整 O 最大值；
- 三复总矩、H2 实虚 Gram、R15 的残差传递恒等式误差；
- 两端非零第四阶首项、profile 各阶导数增长和系数范数；
- B 的行列式及奇异值；最终 Jacobian 的另一方向差分交叉检查。

参数边界和有限 Grassmann 坐标盒只是本轮搜索范围。一次失败不能排除更大的 profile 空间或其他参数。
