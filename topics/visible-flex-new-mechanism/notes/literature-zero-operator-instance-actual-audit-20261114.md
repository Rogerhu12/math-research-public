## 4. 本具体长圈设计不能充当主课题厚度候选

以下是对已冻结控制定义的直接解析必要排除，不需要新的数值几何。其第一个 bulk 恰为k=0,h=1,omega=0，走N=16384个完整圈。相应片在刚体坐标中为

$$X(s,u)=(s,u\cos s,-u\sin s),\qquad0\le s\le2\pi N.$$

这是标准螺旋片，主曲率绝对值为1/(1+u²)。冻结xi左端的准确binary64有理数严格大于3，故该片u=1/xi<1/3，局部最大曲率大于9/10。任何包含整片的C2闭曲面，其reach≤10/9；同一u的两端相距2πN，故其整面直径D≥2πN。因此

$$\frac{\operatorname{reach}}D<\frac5{9\pi N}<\frac5{27\cdot16384}<1.14\times10^{-5}.$$

这远低于.03，且整体缩放不改变比值。排除仅针对包含本具体长圈片的完整构造；不排R37的其他有限设计，也不否定它作为真实零算子/高阶range研究基底的价值。报告中的约7.20e6球面弧长、1.256e7中心线弧长均没有冒充直径D。
