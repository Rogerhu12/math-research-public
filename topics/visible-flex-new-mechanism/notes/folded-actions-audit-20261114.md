## 1. 两种 BVP 都尚未接近准确等距

两项计算均固定同一个圆参考度量 $ds^2+a(s)^2du^2$，保留开核心与两端圆领。它们锁定的非圆核心不同，不能互相算作同一问题的精化序列。`solver.success=true` 仅表示最小二乘达到 `ftol` 停止条件。

| 指标 | signed，混合曲率核心 $(A,B)=(.25,.2)$ | Cartesian，椭圆核心输入半轴 $(1.4,.5)$ |
|---|---:|---:|
| 初始相对度量算子误差，257×128 样本 | .4542044083 | 2.9450539258 |
| 最终相对度量算子误差，257×128 样本 | .1700405633 | .5798570211 |
| 最终相对度量算子误差，1025×128 样本 | **.1706907801** | **.5859482594** |
| 最终最大主曲率绝对值，1025×128 样本 | 14.8227460441 | 48.4118649260 |
| 最终最小面积密度，1025×128 样本 | .8 | .6587970430 |
| 函数求值数 | 14 | 34 |
| 求解秒数（含报告） | 16.01 | 27.37 |

signed 的实际角闭合均值残差为 $3.9639771\times10^{-4}$，径向 signed-flow 残差最大值为 $.0959549791$。它的局部单位向量约束不等于位置已经诱导目标度量。Cartesian 的目标归一化度量误差在加密采样后约为 $.586$，不能归为近似等距的细化误差。

这里 signed 位置是角向 FFT 原函数；源程序显式减掉角均值，并在偶数网格删掉 Nyquist 原函数项。因而上述 signed 导数/曲率属于其现有离散审计口径，不是连续二阶 jet 证书。非线性角场的别名和 Nyquist 差异仍须另审。这个限制不会使 $.17$ 的度量误差变成达标结果。Cartesian 使用解析三角角基和径向样条二阶导，核心解析椭圆的实际物理半轴为 $(1.1856068508,.4234310181)$；输入 $(1.4,.5)$ 仅指定比例。

Cartesian 最终采样直径下界为 $2.5269105078$。结合采样曲率值，当前有限场的必要 reach 比例尺度 $1/(D_{\rm lower}\kappa_{\rm sample})$ 仅为 $.0081744459$，已经远低于 $.03$；这与 JSON 自带诊断一致。曲率峰在 $(s,u)=(2.759765625,\pi/2)$，位于圆领附近的转换区，而非锁定核心。signed 的包围盒也给 $D\ge 2.4385597507$，与现有曲率样本合用得到约 $.02767$ 的必要尺度，但受前述 FFT 二阶审计限制，不能将它写作严格连续排除证明。

## 2. 圆参考区间结果与非轴输出严格分开

`folded-reference.json` 使用 50 位 Decimal 定向区间、每积分 512 个小区间，证明了该**圆参考加平盘**的母线嵌入条件：

- 最小半径下界 $.8$；半母线注入性裕量下界 $.07776435056$；镜像半侧分离裕量下界 $.7108380551$。
- 圆参考高度在 $[1.7993921393,1.8141362741]$；直径上界 $3.0092652126$。
- 圆参考主曲率上界 $12.8985901088$。本次参考程序的请求阈值为 $12$，故对应布尔值为 `false`；该上界小于 $13$。
- 圆参考固定平盘的直径与全直径比下界为 $.5316912558$。

这些结论均不能传给待求非轴曲面。法线弦给出的 $.7108\ldots$ 是特定镜像点对所给 **reach 上界**，不是下界。该区间记录明确没有证明圆参考 reach 下界，也没有产生非轴等距带或闭合运动族。
