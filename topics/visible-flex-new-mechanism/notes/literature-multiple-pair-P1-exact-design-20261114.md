# 两个不同正长度 pair 的完整 P1：新准确联合检验

日期：2026-11-14。研究依据为 [R89](../results/R89-affine-covariance-and-positive-multiple-pair-P1.md)。本稿与新源码均是独立输入，不修改已经完成的单 pair producer、v2 或有理分离回执。新研究目标尚未在本地编译或评价。

## 1. 这次改变的真实机制

固定两个不同状态

$$\mathcal S_0:(H,d)=(1,0),\qquad
\mathcal S_1:(H,d)=(1,1).$$

每个都有 $k=+1,-1$ 两段，并使用同一全局 $f,g$、同一右 collar、同一个 $F=f^2$ 目标。两个 pair 的真实每段长度都为 $N\sqrt2\pi$，相对权重准确为 $(1,1)$；没有负 bulk 长度。两座内部 $M=0$ 真实桥有独立控制，跨 pair 的 $M=0$ 连接成本保留在 $P_0$。

R87 已完整排除了一个特定 profile 上的单状态 P1 匹配，不能给该单状态盲加同类参数。本次改变的是实际二阶 bulk 状态与正权和。完整条件为

$$b_{1,0}+b_{1,1}
+\mathcal B_{\mathcal A_{1,0}}S_0
+\mathcal B_{\mathcal A_{1,1}}S_1=0,
\qquad S_0,S_1\in\mathcal W.$$

其中两个模式和全部 $\xi$ 共享同组真实控制参数；它不是分别拟合两个模式。

## 2. 一次标准编译，原式真实仿射输运

入口是 `scripts/literature_multiple_pair_P1_exact.py`。它绑定现有 v2 回执的 152→36 完整第三空间证书、标准原模板 hash、完整五段基准和原式有理代表。

只生成一次标准原式。一般输运使用

$$x=H\xi+d,\quad q_x^{(m)}\mapsto H^{-m}q_\xi^{(m)},\quad
I_x(F)\mapsto H I_\xi(\operatorname{pullback}F).$$

所有颜色、嵌套积分和共同右锚同步输运。第二个状态没有重新选择 profile，也没有重新忽略 scalar 端点类。R89 保证输运后的 36 模板仍各自张成真实 $\mathcal W$。

为了控制表达式大小，实际计算两状态目标时可以对标准基准先用一个有声 word 代表；其差先回到原始式 fresh 验零。后续若产生正关系，仍从**原始基准**构造两座实际控制后的第三算子重新验证。若走分离评价分支，则完全使用原始基准、原始模板和原式右积分，不评价这个 word 代表。

## 3. 不预设 72 列独立

以标准模板索引 $i=0,\ldots,35$ 为外层，先状态 0 再状态 1，生成 72 个原始完整两模式响应列。列号因此为 $2i+j$。

对这 72 列的联合 word 代表作准确有理消元。保留的是原列子集；每条丢列关系都使用同一组系数同时作用于两个模式，随后回到原始双模式表达式，用 fresh 正规化器验证为零。

若最终保留 $r$ 列，这只证明真实响应维数**不超过** $r$。这一上界有全部原式关系支撑，不从不完备代表的独立性推断真实独立性。

先测试总目标是否在该表示 span 中。若找到关系，则构造

$$T_{{\rm rat},j}-\sum_i c_{j,i}T_{j,i}$$

对应的真实两座桥，并将其代回原始常态目标与原始完整第三响应。只有两个全函数都在 fresh 原式验证中为零，才返回 `whole_function_positive_identity_verified=true`。正长度权重仍是 $(1,1)$；有符号的是可达控制环系数，不是 bulk 时长。

## 4. 若 word 层未给正关系，直接评价原式

这时使用与单 pair 证书相同的全局有理输入

$$f=[t(1-t)]^8,\qquad
g=[t(1-t)]^8(1+2t+3t^2+5t^3),\qquad t=\xi-2,$$

支撑在 $[2,3]$，外侧零延拓。所有行和列使用同一对实函数。

状态 $(H,d)$ 的标准坐标区间为 $[2H+d,3H+d]$。同一个 $t$ 多项式正好是输运后的 profile，导数和积分的区间比例由原始有理评价器处理。程序直接评价标准原式在这个输运区间的值，数学上等于 R89 的完整 pullback，而不重新选择输入。人工 toy 已单独核对这两种实现对同一嵌套原式一致。

默认仍取 $t_j=j/49$ 的 48 点，两个模式实虚部共 192 行。只有当真实上界为 $r$、模控制秩恰达 $r$ 且存在非零 $(r+1)$ 阶增广子式时，才返回 `rational_nonmembership_certified=true`。Cramer/cofactor 泛函使用真实有理矩阵定义，模值仅证明其非零。

若模秩不足 $r$，或本次点值没有分离，总结果明确未定。既不把模缺秩当特征零秩上界，也不把有限点模解当全函数正关系。

本次 profile 未先支付三矩。若有真正非零分离子式，可在适用的共同物理区间上使用 R86 的左补偿与光滑化；不由默认 profile 直接宣称所有合法圆失败。
