# 二、三模核心的首次真实 Gauss–Codazzi 延拓

2026-11-14。状态：**数值证据；有边局部环带，不是闭面候选完成**。

与 R2 相同的准确初圈取 $A=.25$、$B=.2$、$a_0=1$，固定
$$a(s)=1+.3s^2,\quad g=ds^2+a(s)^2d\theta^2,\quad 0\le s\le .35.$$
三个计算使用完全相同的物理参数、度量和区间，仅增加材料角 Fourier 网格。DOP853 的 `rtol=2e-11, atol=2e-13, max_step=.005` 相同；径向诊断15个位置。

`scripts/mixed_mode_gc_flow.py` 从解析初圈、完整标架与 $M=0,N=1/\rho$ 出发，同时积分两项 GC、完整三维位置和三个标架向量。没有逐截面重新置中。角导数由全谱一阶微分计算。

准确初始公式为 $C''(0)=(0,-.015,0)$。三次运行自然成功，全部小诊断在 `notes/mixed-mode-gc-20261114/n{64,128,256}.json`，绑定脚本SHA256。径向末端 $C_z\simeq.3470602748235418$。

**实际未解条件：** 末圈的水平半径样本极差约 `.1702646`，并非圆领；两个镜像侧的平均横移相同，不能充当 R1 所需的相对偏心。没有帽、没有闭 $M$、没有整体 $D$、没有全局 reach，也没有 $\delta_{\rm hold}$ 证书。平均中心移动不是像集 Hausdorff 位移。

上表只证明这段有限实际计算的误差随着同一问题的角精化显著下降；有限径向/角样本不是连续误差证书。R2 的解析存在定理给充分小的局部环带，但没有为这里 `.35` 的长度提供严格下界，不能把高精度数值积分当作该范围的严格存在证明。

复现（分别取 N=64,128,256）：
```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/mixed_mode_gc_flow.py \
  --angles 256 --amp2 .25 --amp3 .2 --curvature .6 --end .35 \
  --out notes/mixed-mode-gc-20261114/n256.json
```

继续方向：加入径向奇次项打破上下镜像；直接求完整偏心双圆领 BVP；比较同一准确度量下所有误差，不能将改度量设计序列写成精化。

## 径向不对称的同一准确度量实验

随后把设计改为 $a(s)=1+.3s^2+(.8/6)s^3$，固定 $s\in[-.35,.35]$，左右从同一中央初值积分。**这是新的度量设计，不与上一张表混为一次精化**。在这个新度量内，128/256角节点的最大片采样误差分别为 $1.934829118970401\times10^{-9}$ 和 $2.0051139012389522\times10^{-13}$。

256节点时 $C_y(.35)=-.0008836371484239845$，$C_y(-.35)=-.0006828504067620525$，横向相对中心差 $-.00020078674166193206$。128节点对应差 $-.0002007867416619737$。两侧末圈的水平半径极差仍约`.1663/.1743`，不满足圆领。该数值确认径向奇次项打破了R2的镜像消去，但只获得两个非圆边界之间的中心差，未支付R1假设。
