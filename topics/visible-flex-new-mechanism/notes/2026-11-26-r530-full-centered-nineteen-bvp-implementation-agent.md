## 2. 固定物理母与系数预收

本轮仍用同一个 R578 的 **36 个实际完整块**，窗口 `[4,6]`，微支撑半宽 `2e-6`，共同幅值 `width^(7/4)/256`。六组位置图及正权均由已发表源码评价；没有通过改变微宽、母或幅值解释 refinement。

新源码先用 `Fraction` 做精确稀疏 Laurent 运算。所有除法仅允许关于 h 的单项式负幂。它逐式构造原完整局部 ruling、局部第三源、按原顺序的 B[M,A]、G[M,A]、L[A] 及其真正全导数。最后形成 R586 的整个

\[
q_g^2\bigl(c-B[M,A]+\tfrac12G[M,A]\bigr)
-e_0\bigl[(\gamma L+hD_sL)q_g-hL(q_g)_s\bigr],
\qquad q_g=1+(h\eta-k)^2,
\]

再做精确角平均、按两种加速度分别取系数。不是只把 R0 或第三源的某几个系数预收。

输出的 16 行系数是 R0/Ch/Ck，三个完整中心化历史分量各自的常数/a/b 系数，以及 G[A,A] 的三分量和 L[A]。后一组用于恢复实际固定参数 `nu = nubar - 2*r_center`。精确阶段检查最高项恒等式、四次齐次型、加速度仿射性和位置次数上界。

## 3. 四个有限边值问题和真实未知量

固定参数只取四种 `(H,L)`：

| H | L |
|---|---|
| 1.1 | 3 |
| 1.1 | 5 |
| 1.3 | 3 |
| 1.3 | 5 |

对每个固定 H、L，十九态是

\[
(h,k,\eta,\gamma,\upsilon,A_8,\sigma_+^3,\sigma_-^3).
\]

常数未知参数为 `nubar` 的三分量。中心固定 `h=H, k=eta=gamma=0`、A 的四个偶坐标为零、两侧 sigma 的六坐标为零，共 14 条；末端 A 的八坐标全零，共 22 条。等价的八个原自由控制是初始 `upsilon`、A 的四个奇坐标和三个实际常数参数。没有从“22 等于 19+3”推出存在性或满秩。

正负侧局部 ruling 用实际状态与反射状态分别评价。原 Ch/Ck 的严格号和二乘二行列式必须由当前数值系数满足，否则该 trial 明报失败；不换用外域延拓 ODE。负侧用 `(h,-k,-eta,-gamma,upsilon)`、`J A` 和 `(a,-b)` 评价，随后对 **整个** 第三历史导数取负号。

前三几何态使用可逆 arctan 坐标，使任何有限求解坐标严格满足

\[
0.8<h<3,\qquad |k|<2,\qquad |\eta|<1.
\]

这个盒子连同 `[4,6]` 在原 R530 共同合法域内。其余状态没有以截断替换方程；非有限值或大于已声明数值护栏的速度会停止该 trial 并打印失败原因。
