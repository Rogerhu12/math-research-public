# 曲率交换先恢复池内可行：首轮公开实际结果

本轮修正了上一轮已经确认的过早交换行为，但仍未获得新的合格物理态。一次 SLSQP 连续进行了 73 次主迭代，72 次因当前强制池尚未恢复可行而推迟交换；达到共享 120 次物理评价上限后，最终仍保留原来的 $e407\ldots$ 状态。这个结果不能称为收敛，也不能证明固定度量的可行集为空。下一步须利用本轮已经保存的试探与回调记录定位约束恢复失败，不能继续把停滞归因于每两步重启。

## 4. 分批实现继续有效，但不是几何改善

每次 Jacobian 批最多 18 个径向查询行，即 16 个所属行加共同端点。批内普通二阶 jet 与同状态完整评价最大差为 $3.55\times10^{-15}$。最大单批 Jacobian 返回数组约 189.28 MB，最大选行导数缓存约 54.97 MB，单次约束 Jacobian 约 5.07 MB；没有构造全网十一组的大约束 Jacobian，也没有请求全网完整二阶 Jacobian。

本轮约 1.47 GiB 峰值 RSS 延续了分批实现的内存效果。增加连续迭代没有恢复到早前约 3 GiB 的整网二阶导模式。此事实只评价实现成本和同态一致性，不表示曲率数值改善。

## 5. 下一步的证据需求

本轮已排除“这次仍被两步重启打断”这一实现解释，但没有区分下面几种原因：当前池的严重非线性违反、很小但持续的精度级违反、活动盒/帽高/条带相互限制，或只在试探初期可降曲率而度量恢复失败。

因此下一动作是读取本轮完整历史中的 120 条试探记录和 73 条回调记录，输出每组池内/池外违反数、池内最小行、最接近度量可行的试探与最后试探。这个转换只读既有 JSON，不评价位置、导数、曲率或目标。应据实际残差规模决定可行步限制、约束恢复阶段或表示修正，不能原样追加 120 次评价，也不能用新试探较小的辅助 $\lambda$ 代替合格物理状态。

本记录不增加数学结果编号，不宣布固定 $g$ 无解，不将采样门称为连续嵌入或全曲面 reach 证明。
