## 2. 非局部检查不能由曲率替代

## 3. 连接器使用真实余量

u=.8是较宽裕曲率预算的首选，u=1是幅度较强的备用。连接器不必将整个封口强锁在中央高度+w内：只要真实全高度满足|z|≤Z，同一见证仍给

`δ >= δ_filled - .05`，

`D <= sqrt((D_xy+.10)^2+4Z^2)`。

因此应按实际连接重新支付高度、投影、直径与握持，而不是把当前core-only高度当成不可改变的任务规则。高ψ模式与圆领参考度量可作为设计未知数，最后必须冻结完整g后才做真正精化。

核心嵌入、非局部reach、圆领/闭帽、固定握持及完整同g族均未在本运行中完成。
