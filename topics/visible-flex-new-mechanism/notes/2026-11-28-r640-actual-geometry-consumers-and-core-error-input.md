## P∞误差无需反求材料角

R640给出的2e−5严格核心函数误差，最终可直接在正常角φ上验证。令准确R631曲率半径为ρ*(φ)，则

\[
\Theta(\phi)=\frac1R\int_0^\phi\rho_*(v)\,dv,
\quad e_* =\frac{2}{\pi R^3}\int_0^{\pi/2}\rho_*(v)^3\,dv,
\]

\[
\boxed{\|P_J-P_*\|_\infty=
\sup_{0\le\phi\le\pi/2}
\left|P_J(\Theta(\phi))-
\frac{\rho_*(\phi)^2/R^2-e_*}{2}\right|.}
\]

等式由严格正ρ及D2对称得到，完全避免反求φ(θ)的ODE/逆插值误差。ρ*是R631的显式正根号有理函数；r0/p/q仍由同一准确椭圆支撑积分定义，必须首先向外包围这些常数。

后继严格实现可在φ四分之一圈累计验证Θ和e*积分，并对这个**组合差函数**直接作Taylor/区间包围，避免将P_J与P*各自的巨大范围相减。所用有限P_J的全部系数必须来自实际选定新核心（二进制数可作为准确有理输入），不能另拟一个更好但未嵌入实际连接的多项式。当前的N→2N/Fourier样本不是此严格上界。
