# R30 后续可执行验证：最小接口与尚缺输入

日期：2026-11-14。本文只确定未来验证器的输入契约；没有完整闭面候选已通过，也不新增研究计算。数学充分条件见 [R30](../results/R30-closed-surface-normal-chord-reach-certificate.md)，实际重构曲率见 [R28 曲率补记](orthonormal-frame-curvature-bound-20261114.md)。

## 1. 先冻结哪一个数学曲面

验证入口应是 `FrozenClosedSurface`，而不是点云或一份优化日志。它至少包含全部准确物理参数、核心材料角定义、径向度量定义、各侧 frame 系数、角/径向基底、积分锚点、圆领与圆盘的参数化，以及一份统一的 `physical_definition_sha256`。二进制浮点设计系数应以实际二进制数的准确有理值冻结；提高求积或反解精度不能改这个身份。两侧独立连接器须共享同一准确核心并按同一材料坐标拼接。

R28 的数学位置是连续积分定义的 `X = z_c e_z + a ΠT`，`z_c' = mean(V_z)`；有限 FFT 或 Gauss 输出是该定义的数值求值。验证器要包住前者以及后者的误差，不能把某个求积数组偷偷改成新的曲面。闭面拓扑和所有接缝的准确 C2 匹配应先作为单独输入证书核查；仅各 patch 自身正则还不够。

## 2. 四个最小接口

| 接口 | 必须返回的连续信息 | 失败的含义 |
| --- | --- | --- |
| `chart_enclosure(chart_id, box)` | 同一凸坐标 chart 内的 `X, DX, D2X, n` 包围；实际 shape operator 上界 `K`；正的最小奇异值下界 `m`、上界 `U`、二阶双线性界 `M`；固定坐标缩放与物理身份 | 区间过宽就细分；不得用样本值代替 |
| `common_near_chart(cell_i, cell_j)` | 两个材料子片到同一个凸 chart 的准确转移、包含连接线段的区域、两坐标差的上界 `r_star` | 未找到共同 chart 只表示应走远场或继续细分，不得跳过点对 |
| `far_pair_enclosure(cell_i, cell_j)` | 全部连续点对弦长下界 `d > 0`；两端法向弦绝对值的共同上界 `b`，或分别返回两端上界 | 未分辨的相交区间必须保留；不等于实际自交，也不等于通过 |
| `coverage_certificate()` | 有限材料 atlas、接缝同一点的准确识别、所有未归入近场的片对列表及其递归覆盖关系 | 任何遗漏阻止全局单射与 reach 结论 |

近场只在 `r_star < 2m/M` 且

\[
\frac{(m-Mr_*/2)^2}{K(U^2+UMr_*/3)}\ge\tau
\]

时通过；`M=0`、`K=0` 按 R30 的单独情况处理。远场要求严格 `d>0` 和 `d^2 >= 2 tau b`；若 `d >= 2 tau`，单位法向估计已经足够。材料上不同的点不能因空间上靠近而被并入对角线。

## 3. 从现有 frame pilot 到接口仍缺什么

现有 `frame_collar_bvp.py` 有真实目标正交架、解析角导数、实际位置重构及样本曲率诊断；它尚未提供下列连续验证输入：

1. **准确参数及一维原函数包围。** 椭圆周长和固定材料角反解需带定向误差；`ΠT`、角平均和 `z_c` 的全部角/径向求积需连续包围。误差须沿同一个准确曲面传播，覆盖 B 样条结点、S5 分段点和入口 cutoff 两端。已有密网/双角分辨率一致性是诊断，不能自动变成积分余项上界。
2. **实际二维导数常数。** 需要 `R, R_s, V_s, V_theta, T_theta` 的全 cell 界，以 R28/R30 得实际 `m,U,M,K`；`-a''/a` 是目标度量的高斯曲率，不能代替近似实现面的实际主曲率。若直接包围实际 `DX,D2X`，也必须按实际 Gram 矩阵归一化 shape operator。
3. **完整闭面与跨缝图。** 开放准确核心、两个连接器、两个平圆领和完整帽都要入 atlas。圆盘中心用 Cartesian chart；角周期缝、核心接缝和圆领/盘接缝需有共同光滑图。最终包围须覆盖帽对帽、核心对帽和两连接器之间的全部远场点对。
4. **直径与时间。** 完整曲面直径上界 `D_star` 决定充分目标 `tau = .03 D_star`。只有已严格证明全时间像集都是该完整初始面的刚体像，才能把 reach 和直径归结为一次验证；固定材料握持和 Hausdorff 位移仍另证。

这些输入尚未取得之前，应输出 `incomplete` 并明确缺哪一项，不能输出完整 reach 通过。实际进入二维自适应验证的合理时机，是已有一个完整、固定参数、正确 C2 拼接且连续度量残差有希望达标的候选；当前先保留上述接口，不再为不合格局部核心建立大验证引擎。

## 4. 与端口必要筛的职责区别

`cosine_connector_port_screen.py` 的弦长/支撑转向门针对准确等距目标的单位材料测地线，帮助排除不可能的设计参数。R30 则直接使用实际重构曲面的导数和法向，是完整嵌入/reach 的充分证书。小 C0 度量误差不使一条数值材料径向线自动成为实际测地线，因此不能把端口必要筛通过替代本说明中的实际曲面验证。
