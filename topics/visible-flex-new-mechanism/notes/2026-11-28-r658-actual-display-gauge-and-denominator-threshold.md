## 与同一连续柱的误差传递

令 $d$ 为表中第二列。无需分母假设，R658 对真实已选标尺给出 $|\Delta a_{\rm core}|<e^{-2080-d}$、$|\Delta c_{\rm core}|<e^{-2090-d}$；在 $108\le u\le\alpha_{26}$，共同口的 0 至 3 阶截断差除以 $W$ 小于 $e^{-1000-d}$。在 $u\ge\alpha_{26}$，被截去的真尾本身的同阶余项除以 $W$ 小于 $e^{-1000-d}$。当列未归一但已换到上述真实坐标时，这些都是无条件的有限截断界。

为了给 R658(7) 支付有限列本身的上界，沿用其记号。首 cell 上原准确有限解的两个端值绝对值至多 1，$|y|\le2$。在左端 $p_{\max}/p(a)<(6/5)e^{.001a}<1.4$。中值定理在 cell 某点给 $|y'|\le1/3$，积分 $(py')'=-\epsilon py$ 回到左端得 $|y'(a)|<1.4(1/3+14\epsilon_{\max})<1$。因此 $\|X_{25}(a_{17})\|<1+109^2<e^{10}$。R658 的平衡能量估计给整个数值平尾段 $\|X_{25}\|<e^{1940}$，并给连接段 $\|(y,v)\|<e^{1980}$。相应的 $A$ 积分给体部及 rim 端 $|A_{25}|<e^{1990}$。

对 $u\ge\alpha_{17}$，R658 的逐 cell 界 $e^{64}(a+7)^8e^{5a}Y_n$ 对准确有限柱本身亦成立，$Y_{17}=1$，首项 $<e^{650}$，后来各项递减；真柱亦同。$108\le u\le\alpha_{17}$ 的短段能量放大至多 $e^{109}$，用 $\mu/r<2201$、径向三阶公式及 $1/W<(5/4)e^{327}$，零至三阶除以 $W$ 均 $<e^{700}$。换到实际 display 坐标后，分母扰动乘上的有限尾函数范数至多 $e^{700-d}$。

对 $r\in[.30,.65]$，原 $W>e^{-14}$、$W<3$、$|W'|<e^{12}$。后一粗界可逐源核对。原 sigmoid 阶跃 $s'(t)=s(1-s)(t^{-2}+(1-t)^{-2})$；$0<t\le1/2$ 时 $s\le e^{2-1/t}$，$t^{-2}e^{-1/t}\le4e^{-2}$，故 $s'\le8$，另一半由对称。原最短 core 平滑段长 .03，$t_{\rm core}\le1/3$；代入 $B+G+C$ 的实际导数即可。于是 $C'=\mu C/r-(\mu-1)A/(rW)$、$C''=(\mu-1)W'A/(rW^2)$ 给未缩放有限柱零至二阶 $<e^{2040}$，相同导数上的未缩放截断差 $<e^{-2030}$。在 $5/2\le u\le109$ 的平尾上，由 R658(4)、$Q=-r^\mu u^2y_u/\ell$ 和 $f''=-lQ$ 得相同的更宽界。$\chi$ 的物理一、二阶均 $<e^{20}$：对 sigmoid 再求导至多出现 $t^{-4}e^{-1/t}$ 及其低阶，$x^ke^{-x}\le k!$，区间长度 .1。归一消去的实际第一 core-pair 列不需要相对于原尾进行数值比较。

若某模的**单个**分母条件满足，则 $|a_{25}|>.85$、$|a_\infty|>.8$。R658(7) 可直接输出以下完整齐次 T(P) 输入柱截断分量。这里 $S_j$ 是源中作了齐次 core $A$ 归一及实际 cutoff 的模函数，尚未乘响应坐标。
$$
 \begin{aligned}
 \max_{0\le k\le3}|\partial_r^k(S_{\infty,j}-S_{25,j})|/W&<e^{-2000} &&(108\le u\le\alpha_{26}),\\
 \max_{0\le k\le3}|\partial_r^k S_{\infty,j}|/W&<e^{-2000} &&(u\ge\alpha_{26}),\\
 \max_{0\le k\le2}|\partial_r^k(S_{\infty,j}-S_{25,j})|&<e^{-2000} &&(r_{\rm mouth}\le r\le R).
 \end{aligned}
$$
中式直接包围被有限计算省略的完整真归一尾，端点处的第一式使用有限柱的单侧导数。末式在 $.65$ 外同一第一 core pair 的截断分量恒零。在体部，换标尺后的有限列上界 $e^{2040-d}$、扰动 $e^{-2030-d}$、$d_A=e^{-2080-d}$，所以商差在 cutoff 前 $\le(e^{-2030-d}+e^{-40-2d}/.85)/.8$；乘全部两阶 cutoff 因子后仍 $<e^{-2000}$，因 $d\ge1027$。真尾上直接代入 $e^{700-d},e^{-1000-d},d_A$。角向导数依次乘 $j$ 的相应次幂。

原 forced $j=4$ 的零 $C$ 边界商有独立分母 $C_{h,25}^{\rm force}(R)$。它与表中 $j=4$ 的 $A$ 不同，所用 gain 也取原冻结 264q。实际尾收据报告的 multiplier $-8539.539761495509$ 本身不提供该分母的正下界。附带消费者可以从**同一现有** forced 对象读其两个已付 core $C$ 列，报告该分母所需精度阈值，不重作强迫源或 ODE。强迫列仍按 R658 的源差、$C$ 商、core-back 和原强迫尺度整链传递。此阈值表不授予任一数值积分新的精度资格。
