# R687 一般正交 Darboux 帧的实际全角设计

2026-11-28。采用 R680 已证明的 $\sin\vartheta=.27$ 厚锚点及实际整壳。R683 的直接单位纬圈矩阵和 R685 的固定端点笛卡尔响应均不重播。这个新输入直接在全局 $SO(3)$ 中求体框、径向对数尺度、自由中心斜率，用 [R687](../results/R687-global-darboux-frames-with-quantitative-periodic-immersion-reconstruction.md) 的准确一阶残差、闭合和中心均值约束重建实际 $F$。普通方向的逐圈 holonomy 从显式物理标架保证，并另读真实全环乘积、实际接圈、反射母线倾角积分；积分与节点输出各自保留。

源水平 $\lambda=0$、体参数零准确恢复一般非旋转度量和 R680 真二基。新设计尝试 $.2,.45,.73,1,1$，先用 24 径向区间、8 体谐波，后升至 10 谐波并对终端径向空间加密。每个阶段记录完整实际参数和全部奇异值，阻尼信赖步保全所有自由列。主动光滑保护只删残差及导数同为零的行；实际完整 $F$ 的两级网格几何硬门另行核算。目标到一才允许尝试冻结解析径向 $E=\exp(2\mu_0+2u)$，冻结用的正是实际评价的同一函数；候选须通过独立最大相对误差、闭合、真实端姿长度和完整厚壳门，再在同一 $E$ 上真实加密修正。届时冻结的 $u$ 是固定数据，其余所有自由方向仍保留。

末段分别加密半径、角向及两者，并同时保留连续角导数与奇网 FFT 的实际混叠差、全连续误差估计公式在节点上的读数及直接重建的度量。只有连续 $G,d$ 界时 R687 的 $2B+B^2$ 才是全点误差证书。任何中途结果及少量实际设计节点均不给 README 完成资格。科学执行只在绑定源后的公开 Actions。
