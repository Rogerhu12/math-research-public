## 2. 端点成立，全角失败

合成开发检查实际通过，方向 Jacobian 相对差约 `4.41e−9`、`7.42e−9`，两个准确端点分子都严格为零。

尖点和谷点的独立准确公式分别给 `J=1`、主曲率约 `3.8967241` 和 `4.9531171`；`q_ell` 的区间仅有 `1e−48` 级舍入宽度，准确分子为零。尖点二阶高度约 `−2.54417` 也通过本轮 R25 的必要及保守设计线性界。问题发生在其他角度，不能把两个特殊点的通过当作全角控制。

中央投影半径下界为准确 `23/100`，故中央曲线嵌入；结合正空间曲率，偶反射的零 framing 成立。两项都不能替代整宽单射或厚度。

## 3. 原输出包络数值的缺失前提与修正

原验证 JSON 打印了 `conditional_witness_over_core_D_lower=.33270102536` 并把相应 `.3` 布尔量置真。该打印在这次失败点上缺少前提：投影 padding `w`、高度增量 `w` 和相应整核直径界，使用的是**全宽正 `J` 下固定材料径向路径的 `abs(X_s)=1`**。本点没有这一前提。因此上述数值只保留为未验证的设计公式，不能作为实际整核包络、幅度或闭面位移证据。

已修正后续版本的 `space_star_cosine_verify.py` 报告门：只有整宽正 `J` 通过，才输出实际整核 padding、直径和条件位移比；否则这些字段为 null，相应通过标志为 false，原公式转存到明确的 `unverified_design_budget_formulas`。这项修改不改变准确几何、区间算法、旧输出、源提交或旧文件哈希，也没有为纠正标签重跑旧研究计算。当前正在运行的暖点作业若仍使用旧源版本，审计时同样执行这个前提检查。

中央高度上界 `.150712191265` 本身来自准确三角多项式的区间/弦余项，仍然有效；无效的是不经全宽正则性就把它提升为整核 `+w` 包络。`numerical_material_interface=null` 在本轮是正确的，避免调用未获整宽正 `J` 的材料反解。
