# 11 个周期几何系数的有限基面设计

状态：实现与开发检查；实际优化只在本公开仓库 Actions 运行。此设计尚未产生满足全部周期条件的基面，更没有有限等距族。

## 固定的方程与参数化

使用 R5 的四维 profile 空间。其独立三矩圆通过完整二阶周期条件，当且仅当 11 个几何积分系数全零；因此本次直接求这些系数，不继续把非零周期的投影校正当作解。

基面沿用公开文献的 $X=\alpha+uN$、$\alpha_s=vT$，取
$$r(\theta)=1+a\cos(q\theta),\qquad
\varphi(\theta)=\theta+\frac bq\sin(2q\theta),$$
$$B=\frac{(r\cos\varphi,r\sin\varphi,1)}{\sqrt{1+r^2}},\qquad
v(\theta)=C^{-1}\exp\left(2\sum_{j=1}^{12}c_j\cos(jq\theta)\right).$$
其中 $q=2,3,4$ 分别运行；$a,b,c_j$ 为设计变量。$C$ 在各设计中固定速度的平均尺度，最终验证冻结数值 $C$ 与所有物理参数。

$q$ 重旋转使 $\Lambda_x=\Lambda_y=0$；反射下 $\kappa$ 与 $v$ 为偶函数、$\kappa_\theta$ 为奇函数，故 $\Pi=\int\kappa_\theta/\sqrt v\,d\theta=0$。仍把这几个积分的数值值输出，检查实现。**轴向闭合 $\Lambda_z=0$ 是独立残差，不能通过对位置取零均值原函数冒充满足。** 同理记录计算 $\omega$ 时移除的零模；数学上的零值来自上述反射，而非 FFT 操作本身。

以 $\xi=-1,0,1,2$ 上的低次多项式值提取
$$p_0,p_1,p_2,q_0,q_1,r_0,r_1,s_0,s_1,t_0,t_1.$$
只需 $\kappa,h,\omega$ 及一阶导数，公式来自 `notes/literature-volterra-polynomial-20261114.md`。使用 $\xi=0$ 附近避免旧活动区大 $\xi$ 造成的单项式条件数问题；全部系数同时为零的条件不受渐近坐标平移/缩放影响。另用第四个采样点和所有系数恒等式校验提取，而不靠不适定拟合。

## 有界数值搜索及证据限度

每个种子的系数残差尺度在开始时固定；另对归一化 $|\log\sqrt v|>.8$ 加罚，避免通过严重速度集中压低某一残差。这个罚项不是严格速度比证书，最终必须读实际 min/max。$a\in[.08,.85]$、$b\in[.8,1.55]$、$c_j\in[-.4,.4]$。

初始参数来自原有对称正速度的余弦投影；投影后轴向闭合须重新求解。设计积分用 768 角点，最终同一物理输入在 768/1536/3072 角点复核系数、闭合和多项式恒等式。改变 $q,a,b,c_j$ 是不同设计，不是同一度量上的细化族。

开发检查只验证 11 参数提取/重建的代数往返及常曲率常速几何的恒等式，误差分别为 $1.11\times10^{-16}$ 与零；未在本地运行研究优化。

若轴向闭合仍非零，FFT 原函数画出的只是投影后的周期曲线；其直径与未闭合形式带曲率半径的比仅作诊断，不能解释成实际闭带的 reach 比例。输出显式保存移除的导数均值及这一限制。

即使全部系数残差很小，后续仍须认证积分误差与闭曲线嵌入，再解高阶/非线性固定度量族，并完成闭面、握持、幅度和 reach 的全套条件。程序输出明确保留这些未完成状态。
