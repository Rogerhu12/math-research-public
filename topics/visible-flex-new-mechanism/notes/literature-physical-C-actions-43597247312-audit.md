## 3. 与 profile 匹配的额外区别

由同一份已输出系数作代数评估，在正根处

$$W/C'\approx0.793262646793,$$

在负根处

$$W/C'\approx0.845811741925.$$

两个比值在四档中稳定，但都不同于 R16 四阶外尾所需的 $-8/7$，也不同于 R22 局部实例的 $-55/32$。因此“存在物理实根”本身尚不等于可以安装任一个已知 profile 局部分支。

这四档只是同一个固定基底；它们均给每个采样物理半线恰一个实根，不能由此证明所有基底至多一个根，也不能把所见正 $W/C'$ 比值外推为普遍几何不等式。下一理论问题正是这些根数及比值是否受实际闭曲线几何限制。
