## 3. Jacobian 与 hinge 边界

正半线主平滑残差的独立方向差约 `3.33e−9`，全部平滑观测约 `3.97e−10`。当前 hinge 方向差却约 `.9284`，同时报告有 3 条保护分支在正负方向探针间切换。这个数必须保留；它不能被解释为同一个平滑 Jacobian 的误差，也不能删掉后声称全残差方向处处通过。

运行器先对平滑量作中心列差分，再使用当前 hinge 分支。原始活动边界、分支切换数、光滑部分及截断后的方向差都已分别报告，因此不需重复旧设计来解释该差异。它仍提醒后续严格参数存在性证明不能靠此边界上的普通双边 Jacobian 单独完成。

## 5. 明确剩余条件

正侧候选尚需：以同一准确几何定义包围闭合 tilt 和归一化；证明连续物理半线；为 C 的准确积分系数建立误差界并隔离一个准确简单根；在同一根上控制 W/C′ 与非退化 K。只有这些完成，才可把 R26 的局部存在定理应用到这条具体几何上。

即使该局部门完全认证，R29 的完整有限分片 C4、简单双四阶外尾排除仍然有效。全局紧支撑 profile、总矩、完整闭面和有限连续等距族都没有从本次实验获得。另行推进的解析高频曲线构造也须独立证明其精确闭合、根门及非退化性，不以本次数值成功替代证明。
