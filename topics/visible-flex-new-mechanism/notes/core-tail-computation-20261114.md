# R2 核心到非对称平坦尾：实际 BVP 与回折参考几何

2026-11-14，`/root/mechanism`。全部为**有限数值设计/开发级几何检查**；没有得到精确半带或闭族。

## 1. 已实现的完整问题

`scripts/core_to_tail_bvp.py` 从 `mixed_mode_gc_flow.py` 实际求得 R2 的 $s_0=.15$ 入口。默认固定核心为 $A=.25,B=.2,a(s)=1+.6s^2/2$，入口角数 128。保留完整 $X,X_s,X_{ss}$；随后用五次 Hermite 端口插值加零二 jet 的五次 B-spline/Fourier 自由项，匹配非对称 R128 尾在 $r=.6$ 的完整位置二 jet。尾在 $r\le.34$ 已准确平坦，预定圆领半径 $.3$。

初版实际求的是全部三项相对度量残差：$E-1,\sqrt2F/a,G/a^2-1$，没有除以 $\mathrm{II}_{\theta\theta}$，也没有强制任何法曲率符号。提供有符号 Frenet 角和截面转向速度的独立诊断，但没有把它们当作另外一套已完成的解。

未知包含三分量内部位置、径向半径设计控制、尾两侧角 $A_+,A_-$ 以及尾位置 $C_y,C_z$。尾的材料角为 $\theta-\pi/2$，与 R2 的初始切向角约定一致。不得把末帽平移参数当成已经证明的偏心端口。

端口二 jet 匹配是对同一个数值入口和同一个尾积分评估器的准确 Hermite 身份。它不是精确等距结论，也没有把数值入口误差或积分误差抹为零。

### 圆母面控制

纯多项式 Hermite 位置背景连圆母面的单位速经线也需要额外自由度逼近，故添加准确背景

$$
a'=\cos\beta(s),\qquad z'=\sin\beta(s),
$$

其中 $\beta$ 满足入口实际角度二 jet 和末端 $\beta=\pi$ 的平面端口，另用一个内部角控制满足 $a(L)=.6$。位置由固定的一维积分定义。

`core-tail-unit-circle-control-20261114.json` 取 $A=B=A_+=A_-=0$，真实控制结果 RMS $9.86\times10^{-15}$、细网格 metric $6.58\times10^{-14}$。因此脚本已能表示圆母面的准确极限；非轴残差不能全归因于简单的单位速背景缺失。

解析位置/半径 Jacobian 的独立随机方向差分最大差约 $10^{-10}$。尾的角向一、二导数在差分步长减半时误差约缩小四倍；这些只是代码检查，不替代几何证明。

## 3. 为什么转向内部含特征圆的参考母线

前述普通母面通常在内部保持 $0<\beta<\pi$，环向法曲率 $\sin\beta/a$ 不过零。在这种参考附近优化未必进入退化产生的新非轴分支。因此下一轮选择真正经过 $\beta=0$ 的回折母线，并仍用完整位置度量残差允许其法曲率换号。

先尝试的全局反对称角振荡筛查保存在 `core-tail-folded-reference-scan-20261114.json`：16 个 $(L,\text{wiggle})$ 组合中，一项无闭合根，其余样本母线多有 1—2 处真正折线穿越。这些没有被当作可用种子，也没有进入下一昂贵求解。

改为更受控的三段参考：

1. 从真实入口角 $\beta_0\approx1.48$ 及其实际一、二导数，平滑下降到一个小负值 $\beta_{\min}$；
2. 再平滑上升到 $\pi$，两段连接的角导数至二阶为零；
3. 保持 $\beta=\pi$，形成准确平面径向段，直到半径 $.6$。

两活动段长度比例默认 $.33:.67$；用总活动长度作一维求根，同时满足指定总长和末半径。各段积分分别进行，避免跨分段节点的一次大区间求积误差。全部母面仍准确单位速。

CLI 为 `--background folded --fold-min <负值> --fold-first-fraction .33`。这只是参考几何设计，不把母面自身称为非轴解。

这些数值只是比之前自交种子更合理的输入：它们没有明显曲率预算冲突，但未证明 reach，更不能转移给优化后的非轴几何。
