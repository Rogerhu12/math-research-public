## 2. 为什么直接式只有约 $10^{-8}$ 的一致性

细档的直接物理能量约为

$$E_{\rm phys}=5.1859362793230934\cdot10^{10}
+1.749394027259047\cdot10^{10}i,$$

而 $2T$ 几乎是其负值。二者相加才得到约 $70-61i$ 的第四量。直接各项绝对和约为 `2.1678698794063354e11`；因此直接式与局部式的绝对差约 $10^{-8}$，不是一个新的几何误差或尾项。

两档的 $J_{\rm tot}$ 分别为

$$3.6098739776435215\cdot10^{-15}
-2.582243697030952\cdot10^{-15}i,$$

$$1.2751437669668325\cdot10^{-13}
-5.020715059888684\cdot10^{-14}i.$$

已经完整保留的准确物理端项 $J_{\rm tot}^2/(256l)$ 分别仅为 $10^{-32}$、$10^{-29}$ 量级。它们远小于直接大相消的浮点误差，更远小于已稳定的局部非零量。程序另外分别检查了物理能量与 Sobolev 形式的端项、Sobolev 形式与局部式的端项，没有暗中将三式强制相等。

## 3. 对现有候选的直接含义

冻结几何的第一个 bulk 在原始控制文件中准确写为 $k=0,h=1,\omega=0$、16384 个完整圈。R49/R54 的必要条件因此直接适用：对于同一 profile 圆及固定目标，常段第四 ruling 的纯 $\zeta^4$ 最高系数是 $-\mathcal F/16$。这个最高系数不由合法第二、第三 profile gauge 改变，也不是更改该常段以外的桥就能删除的量。

本次只有数值评价，没有区间包络，因此不把它写成对精确二进制 profile 的严格反证；更不推广为全部 R52 profile 平面的不存在定理。但对下一次计算设计已经足够明确：不应继续把当前冻结数值 profile 当成已经通过常态门的第四候选，原样增加完整第四预算或只调第三 gauge 缺乏依据。
