# R672　同一 86da、1566 维实际场的材料间隙、点态度量与真实主曲率

R643 原工作点 \(q=\mathtt{0d9a753f\ldots e16}\) 的 950 个实际径向节点、256 个输出角和 512 点固定均值给出 \(\widehat\eta_{\max}=2.217909351752879\,10^{-7}\)。原最大值出现在 \((r,\theta)=(0.32888020833333337,1.0799224746714913)\)。相对 \(10^{-6}\) 的**全部剩余误差预算**约为 \(7.782090648247121\,10^{-7}\)。这是旧点的门槛预算。每个新接受态使用自己的完整实际向量、观察及同一 86da 固定度量重新算预算。

## 1　带符号的点值和两个精确门

取 R649 的准确目标弧长 \(ds=\sqrt E\,dr\)。令 \(B=V_0T+U_0n\)，\(w=(b/r)T\)，\(S=Y_s-B\)。在固定目标单位基 \((\partial_s,\partial_\theta/r)\) 下，离解的准确度量误差矩阵为
\[
 M=\begin{pmatrix}d&f\\ f&0\end{pmatrix},\qquad
 d=2B\!\cdot S+S\!\cdot S,\quad f=w\!\cdot S.
\]
原材料具有偶余弦高度和半周对称性，完整角向位置导数为 \(Y_\theta=bT\)，\(b^2+q^2=r^2\)，故右下角准确为零。\(\eta=\|M\|_{\rm op}=(|d|+\sqrt{d^2+4f^2})/2\)。对任意 \(\epsilon>0\)，
\[
 \eta\le\epsilon\quad\Longleftrightarrow\quad
 |d|+f^2/\epsilon\le\epsilon.                                           \tag{1}
\]
这是直接检验 \(\epsilon I\pm M\) 半正定。保持小 \(S\) 的表达避免先对 \(U^2+V^2+P^2\) 和 1 各自取绝对上界，再作差。程序从**现成**节点的 \(S,T,\mathrm{pred},E,b\) 得到有符号 \(\hat d,\hat f\) 的表示误差区间，其中 \(B=\mathrm{pred}/\sqrt E\)。完整连续角向重组在同一材料顶点给 \(d,f\) 的区间。两者的差包含数值相位、原有限 FFT primitive、数值角均值、角点二进制表示和原场不确定性；这个顶点误差只付一次。

设真实顶点与其有符号已付数值之差满足 \(|\delta d|\le a,|\delta f|\le b_1\)。可用 (1)，也可用 Weyl 的 \(\|\delta M\|\le(a+\sqrt{a^2+4b_1^2})/2\)。对于上述真实旧点，若两个分量的**顶点加材料总误差**统一不超过 \((10^{-6}-\widehat\eta_{\max})/\varphi\approx4.81\,10^{-7}\)，\(\varphi=(1+\sqrt5)/2\)，便足以通过度量门。局部带符号 (1) 往往容许更大扰动。旧最终 JSON 中不存在每个角点的带符号阵列或连续导数界；上面没有给它补一个虚构的误差半径。

## 2　不需第四径向导数的实际网格覆盖

对一个标量 \(g\)，在长度 \(h\) 的闭材料段上有 \(g'\in[l,u]\)。记 \(I_1g\) 为两端线性插值。在相对位置 \(t\) 处，
\[
 g-I_1g=h t(1-t)(\overline{g'}_{\rm left}-\overline{g'}_{\rm right}),\qquad
 |g-I_1g|\le h\min\{(u-l)/4,\max(|l|,|u|)/2\}.                         \tag{2}
\]
先对 \(s\) 后对 \(\theta\) 使用 (2)，第二个误差经过端点凸组合，故只需两个误差之和，不假设缺陷对角向带限。分别对 \(d,f\) 使用本材料块上真实的有符号 \(d_s,f_s,d_\theta,f_\theta\) 区间。实际弧宽上界为 \(h_s=(r_{i+1}-r_i)\sqrt{\sup E}\)，角宽 \(h_\theta=2\pi/N\)。若选择直接靠最近网点且只有角连续变化、其余误差可忽略，旧网 \(N=256\) 相应允许的 \(\|M_\theta\|\) 上界约为 \(6.34\,10^{-5}\) 每弧度。一般情形必须用**本地** \(h_s,h_\theta\) 和所有顶点误差。950 个径点不等距，真正最大间隙由已有半径数组逐项比较，点数不能代替它。

径向导数仅用 R649 已需的量。在 \(T,n\) 中，写 \(S=(s_T,s_n)\)，\(\dot s_T,\dot s_n\) 是**平面向量导数** \(S_s\) 的投影，\(h=\phi_s\)。于是
\[
 \begin{split}
 d_s/2={}&((V_0)_s+U_0h)s_T+((U_0)_s-V_0h)s_n
          +(V_0+s_T)\dot s_T+(U_0+s_n)\dot s_n,\\
 f_s={}&(b_s/r-br_s/r^2)s_T+(b/r)(\dot s_T-hs_n).
 \end{split}                                                        \tag{3}
\]
角导数直接取完整 (1) 前两条标量表达式的角 jet；\(S_\theta=(\mathcal H-\langle\mathcal H\rangle)/\sqrt E\)。先对四个真实顶点取凸组合，再付 (2) 的两维余项，将完整区间与直接在整材料块上计算的 \(\eta\) 上界取小。缺失三阶径向输入时，仍可使用只需原高度二阶的直接度量门，真实曲率和 (3) 的径向证书继续开放。

## 3　从真正的有限字典到连续角积分

在每个主体材料段，把固定参考、种子与实际响应的所有投影合并为
\[
 Z=Z_0(r)+\sigma\tanh(V/\sigma)
      -\langle\sigma\tanh(V/\sigma)\rangle_{512}
      +\sum_{j=2,4,\ldots,96}c_j(r)\cos(j\theta),\qquad
 V=\sum_{j=2,4,6,8} v_j(r)\cos(j\theta),\quad\sigma=3/20 .
\]
式中的 \(Z_0\) 含原背景、冻结种子均值、94 项完整独立均值及同一 core 迹的均值校正。实现将固定 512 平均的径向导数并入标量基项，只减一次。实际 1129 个原角坐标、224 个新 compact、96 个新 Gaussian、23 个独立 core，加 94 个均值为 1566；硬 \(\tau=1\) 随原定义恢复。另有原 1130q 参考和冻结 265q 的 4 个 pre-tanh 模、全部旧 bulk 与零核强迫 \(j=4\)，以及最高 96 模的依赖 core 校正。现成数组 `fields,bulk,new_columns,core_radial,new_core_lift,compact_radial_dictionary,analytic_tail_columns`、两套 core 校正和实际接受向量决定各项。强迫项始终在 tanh 之后。用原 split 的 \(W^2\) 或 1 恢复同一 \(E,E_r\)，种子 lambda 图读 \(Wx\)、zeta 图读 \(x/W\)，独立 trial 均值本身不再解根。

对同一组 28 个紧支五次 B 样条，已提供更直接的连续材料输入。读取三组源码字面结点及本对象的原支撑，对真实 24 个角模与新均值的完整 28 系数组先按符号合并。将一个材料间隙在准确十进制和准确 binary64 两套结点的**并集**处分裂。在子段上用 Cox–de Boor 递推得到同一函数在 \(z=(r-l)/(u-l)\) 的准确有理系数。幂基 \(\sum a_kz^k\) 的 Bernstein 系数为 \(b_i=\sum_{k\le i}{i\choose k}a_k/{d\choose k}\)。该子段上取 \(\min b_i,\max b_i\) 包住实际值。依次求导并付真实材料宽度，得零至三阶。先减两个多项式再转换，**同一分量**的十进制/二进制结点及系数实现误差因此有可算的真实导数半径。当前响应也容许按原接受向量的准确 binary64 解释。另一个入口对全部 61 个原五次 bulk 基函数给同样的值与结点移动误差；其外乘 \(\chi[(R-r)/(R-.30)]^{\alpha+2}\)、原 pre-tanh 包络和均值的 core 迹扣除仍须各自支付。这些输出只填入其所属分量。

对其余径向系数，实际端点已有零至二阶可读，源码明确报告所缺三阶。连续证书可使用经证明的整段系数区间，或者用两个实端点的区间凸包加上 (2) 的径向误差（如有二阶上界也可用 \(h^2\sup|g''|/8\)）。七项分别给从前一源实现到后一实现的**全段**增量；每个已供应证据按实际字段键列出所有半径。漏一个字段便不能认证。第三径向列必须同时包含所有四个 \(v_j'''\)、48 个 \(c_j'''\)、均值基项及 \(E''\)。\(Z_0'''\) 的相关部分包括 \(-W''+s_*''+m'''\) 和已定义的固定 512 项 tanh 三阶均值。第三导数对 tanh 是 \(d_1V'''+3d_2V'V''+d_3(V')^3\)，不能用低阶表直接冒充。

## 4　完整整环 primitive、真实曲率和材料边界

对每一实际角扇区 \(\theta=\theta_i+h z\)，\(0\le z\le1\)，求源组合的左端正规化 jet 至 \(k=m-1\)，以及整个扇区上的第 \(m\) 项（含真实余项）；\(1\le m\le12\)。余项的系数可在该区间中随 \(z\) 改变。由于 \(z^m\ge0\)，带符号区间和正积分核共同给出
\[
 I_i\supset\int_0^1 f_i,\qquad J_i\supset\int_0^1 (1-z)f_i,\qquad
 I_i=\sum_k C_{ik}/(k+1),\quad J_i=\sum_k C_{ik}/((k+1)(k+2)).
\]
取 \(\bar f=N^{-1}\sum I_i\)，\(P_0=0, P_{i+1}=P_i+h(I_i-\bar f)\)。零均值周期 primitive 在左端为
\[
 (\Pi f)_i=P_i-N^{-1}\sum_j[P_j+h(J_j-\bar f/2)].
\]
整个扇区再加上对 \(f-\bar f\) 的局部不定积分区间；同一公式对两项平面分量分别成立。这样直接从原谱函数求真正的积分，保留非线性 tanh、平方根、倒数和旋转框架产生的所有角频率。\(\langle\cdot\rangle_{512}\) 仅在冻结高度的原定义处使用。对 turning、\(G\) 和位置 primitive 的积分是连续角均值。

先用 R649 的真实局部式构造 \(a-1,R\)，有三阶时也构造 \(R_r\)。实际 \(F=\langle a-1\rangle\)、\(A=1+F\)，其中 \(a-1=(2n+n^2-(u^2-1))/(u(N+u))\)，\(n=q^2/[b(r+b)]+r^2pt/b^3\)。取 \(\Pi a,\Pi R,\Pi R_r\)，再为 \(\mathcal H,\mathcal H_r\) 的**全局平面分量**逐阶积分，保留 \(G,G_r\) 和旋转框架的两项。得到 \(S=\Pi\mathcal H/\sqrt E\)、\(S_s=\Pi\mathcal H_r/E-E'\Pi\mathcal H/(2E^2)\)。真实根式需要 \(b,u,N,A>0\)；程序保留各块 \(b/r,u,N,A\) 下界。原点数据中的三个最小值 \(0.9999999288188445,0.9997549965174861,0.9996462401163664\) 只是各自样本观察。

将整块实际 \(S,S_s\)、高度与同一固定 \(E\) 的 jet 送入已发表 R649，即得到真实正交切基中形算子的两个特征值区间，不除竖直法向。若整块 \(\eta\le\epsilon<1\)，实际 Gram 的最小特征值至少 \(1-\epsilon\)，故 \(\max|\kappa_i|\le\|\mathrm{II}_{\text{目标单位基}}\|/(1-\epsilon)\) 是另一个直接充分界。\(1/\tau\) 比较仍是曲率分量，完整 reach 还依赖全局正图和高度门。

覆盖器核对同一目标、响应、原径向及角网、每个径向边号及其全部周期扇区；真实 tail 只接受相同 R643 收据沿 R648 再到 R650 的已付散列链，原七行未闭标记一并传递。\(r_{\rm last}\) 与 \(R\) 间的竖直 collar 必须另用正则坐标给出**整段**界，R653 的边界极限不能给这段自动填值。两帽、竖接、反射面与全时运动仍按原几何证书衔接。这次没有重建旧 ODE、根、Jacobian 或 FFT，也没有创建独立科学工作流。
