# C2 曲面允许的四阶外尾：完整边界条件与四参数全局 BVP

日期：2026-11-14。状态：以下正则性和端点主阶关系为完整推导；尚未构造完整 profile。目标是将 R13 的内部相位自由度接入课题允许的 C2 路线，不把 C∞ 当作额外完成条件。

## 1. 从公开 Y 公式核对 C2 零延拓

来源：Mohammad Ghomi、Hongda Qiu、Matteo Raffaelli、Yuetong Zhang，*Nonrigidity of smooth tight surfaces*，2026-11-12，§2.3 Proposition 2.1、式 (5)，[公开原文](https://arxiv.org/html/2611.17269v1)。原文以紧支撑 C∞ profile 陈述；下面的有限正则性结论由同一公式直接计算，不归给原文一个未陈述的 C2 定理。

令 h=√v、w=v−κu、ξ=h/u−ω。在避开 u=0 的固定紧活动带上，写

$$Y_\phi=U(s,u)\phi(\xi)+V(s,u)\phi'(\xi),$$
$$U=uB,\qquad V=-\frac{uT+wB}{2h}.$$

U、V、ξ 都是光滑函数。对任意两个坐标方向 i、j，有

$$\partial_iY=U_i\phi+(U\xi_i+V_i)\phi'+V\xi_i\phi'',$$

$$\begin{aligned}
\partial_{ij}Y={}&U_{ij}\phi
+(U_i\xi_j+U_j\xi_i+U\xi_{ij}+V_{ij})\phi'\\
&+(U\xi_i\xi_j+V_i\xi_j+V_j\xi_i+V\xi_{ij})\phi''
+V\xi_i\xi_j\phi'''.
\end{aligned}$$

所以 φ∈C3([a,b]) 且 φ、φ′、φ″、φ‴ 在两端均为零，就使 Y 及其全部一、二阶坐标导数在活动边界均为零。将 φ 在外侧置零后属于 C3，将 Y 在外侧置零后属于 C2。若 φ=A t4+O(t5)，则 Y=O(t3)、dY=O(t2)、d²Y=O(t)，明确足够。

原文的无穷小等距恒等式只用 Y 的一阶导数，亦可在活动带直接按该公式验证，再由连续性跨边界延拓。因此这种 profile 给合法的 C2 无穷小弯曲场。它没有自动给连续的有限等距族；后续高阶或 fixed-metric 求解仍须完成。

## 2. 两端有限阶主平衡

考虑 R8 的 Q，假设一个端点有

$$q=A t^m+o(t^m),\qquad A\ne0,\quad m\ge4,$$

且前四阶导数有相应渐近。m=4 时，q 在闭区间为 C4、前三阶端点导数为零且第四阶非零就足够。t 在右端为 b−x，在左端为 x−a。

若 C 在该端点非零，Q 的最低次项为

$$-2A^2 C\,m^2(m-1)^2(m-2)(2m-5)t^{2m-6}.$$

其余项阶次更高，故必须 C=0。这里 A 可以为复数，A²仍非零。

在 C=0 后，令 C′、W 表示端点值。右端的下一最低次项为

$$2A^2m^2(m-1)(m-2)
\{2(m-2)^2C'+(3m-5)W\}\,t^{2m-5}.$$

左端是同一表达式的负号：q′、q‴的符号及 C 的一阶展开同时改变。因此左右两端的零条件相同：

$$\boxed{C=0,\qquad W=-\frac{2(m-2)^2}{3m-5}C'.}$$

特别是四阶外尾给

$$\boxed{C(a)=C(b)=0,\qquad
W(a)=-\frac87C'(a),\quad W(b)=-\frac87C'(b).}\tag{1}$$

本文的简单根分支另要求 C′(a)C′(b)≠0。关系 (1) 本身不证明外尾存在，也不证明可以连接两端。

与 R7 的有限多项式排除没有冲突：本构造拟在外尾只有一个固定复相位，第二个独立实分量在内部以 R13 的全平方式开启。没有假设在同一个外端，f、g 在消去共同首项后都仍有不同的有限首阶。拟求的完整函数也不是有限多项式。

## 3. 归一化后的全部四个自由参数

将两端仿射归一到 [−1,1]，并固定不为零的整体系数尺度 r0=1。取

$$C=(1-x^2)(1+bx+cx^2).$$

两个简单端点条件为 1−b+c≠0、1+b+c≠0。若进一步让 1+bx+cx² 在全区间严格正，则内部没有 C 零点；这是一个便利的候选分支限制，不是必要条件。

因为实际九系数要求 W 的三次系数恰为 C 的四次系数的两倍，(1) 给出 W 的全部形式

$$W=d+\frac{16+30c}{7}x+
\left(\frac{16b}{7}-d\right)x^2-2cx^3.$$

剩余常数 D 仍自由。因此自由参数正是 (b,c,d,D)，对应九系数为

$$\begin{aligned}
p_0&=(152+124c+14D)/21,&p_1&=120b/7-4d,&p_2&=4c,\\
r_0&=1,&r_1&=b-d,\\
s_0&=d,&s_1&=(2c-2+D)/3,\\
t_0&=(62+76c-7D)/42,&t_1&=23b/7-d.
\end{aligned}\tag{2}$$

直接代入可核 C、W、A2=C′−W 和 D=A1+A2′−2B2，故没有额外使用不存在的九系数自由度。

更一般地，给定 C=Σc_jx^j、W=Σw_jx^j 且 w3=2c4，加入 D 后可唯一重建九系数：

$$\begin{aligned}
p_2&=-4c_4,&p_1&=4w_2-8c_3,
&p_0&=2w_1-8c_2/3+2D/3,\\
r_0&=c_0,&r_1&=c_1-w_0,&s_0&=w_0,\\
s_1&=(2c_2+D)/3,&t_0&=(3w_1-2c_2-D)/6,
&t_1&=w_2-c_3.
\end{aligned}$$

这些仍是 profile 层的抽象系数；必须另由真实闭曲线积分实现，才能装回曲面。

## 4. 真正全区边值问题

求四个实参数 (b,c,d,D) 及非零复函数 q，使

$$Q[q]=0\quad(-1<x<1),$$

$$q^{(j)}(-1)=q^{(j)}(1)=0\quad(0\le j\le3),$$

且第四阶端点首项非零；允许内部存在 R13 型非解析全平相位开启。整个 q 的零延拓是 C3，足以产生 C2 场 Y。

依 [R15](../results/R15-global-endpoint-moments.md)，若 B0、B1、B2 满秩，完整 Q 解自动满足三复总矩，并按真实右尾给完整 O=0。数值上仍同时计算矩与 O，且在秩亏或端点条件未精确满足时不删除缺失约束。

齐次缩放 q→zq 不改变方程的零集合。可以固定实部/虚部在 H2 半范数下为正交单位向量，既去掉公共幅相与正交实基变换冗余，也防止求解器缩到 q=0；任何非零且三矩为零的真实解均可作此公共归一化：零复总矩 M0 恰好给两实分量的 H2 等范数与正交；这里没有用一般 GL(2,R) 换基保持 Q=0 的错误假设。

首轮离散化用 q=(1−x²)^4 P(x)，让 P 的试空间包含全局 Chebyshev 多项式及一个支撑在 |x|<ρ 的 C∞ 全平窗口乘 Chebyshev 多项式。窗口为 `exp(τ−τ/(1−(x/ρ)²))`，在外侧恒零；它允许内部非解析相位区，而非强制完整 profile 为多项式。**若退化为纯有限多项式，仍受 R7 排除。** 整个有限试空间都只是全区 BVP 的 collocation 近似；必须记录固定系数下次数加密的残差、profile 导数增长及完整矩，不能把某一阶离散零点当作精确解。

为避免在端点用很小的数相除，Q/((1−x²)^4) 可先按微分算子系数进行精确多项式除法，再评估余下系数。对 (2)，每一项 P^(i)P^(j) 的系数都被 (1−x²)^4 整除：四阶端点主项的消失已由 (1) 固定。这个算子将用 Fraction 作合成恒等式检查，研究求解在公开 Actions 进行。

内外匹配和三总矩现在是一个全区边值问题；不是把局部 J 常数当作已实现的全局积分。即使此 profile BVP 成功，实际系数几何实现和有限等距弯曲仍未完成。
