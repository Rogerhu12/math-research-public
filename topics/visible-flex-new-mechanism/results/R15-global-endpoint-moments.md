# R15：两端零 jet 与满秩 B 下三复总矩自动成立

日期：2026-11-14。本文将全局 profile 的边界条件与 [R8](R8-flat-profile-period-equation.md) 的局部四阶方程精确连接。**结论适用于一个已经在完整区间构造出来的函数；局部解、截断端点及自由给定的局部 J 常数不能代入本定理。**

## 1. 定义与正则性

固定 a<b，系数取 R8 的实际九参数形式。特别地

\[
\begin{aligned}
B_0(x)&=r_0+r_1x-p_0x^2/4,\\
B_1(x)&=s_0+s_1x-p_1x^2/4,\\
B_2(x)&=t_0+t_1x-p_2x^2/4.
\end{aligned}
\tag{1}
\]

设 q∈C4([a,b];C)，并且

\[
q(a)=q'(a)=q''(a)=q(b)=q'(b)=q''(b)=0.
\tag{2}
\]

所有平方都不取复共轭。**从真实右端 b 定义**

\[
J_0(x)=\int_x^b(q'')^2,
\quad J_1(x)=\int_x^b y(q'')^2,
\]

\[
J_2(x)=\int_x^b y^2(q'')^2+2\int_x^b(q')^2.
\tag{3}
\]

令总矩向量为 M=(J0(a),J1(a),J2(a))ᵀ。完整算子为 O=A0 q²+A1 q q′+A2(q′)²+Σ B_j J_j，其中各 A 与局部四阶算子 Q 沿用 R8 的明确多项式定义；R8 已逐项证明准确恒等式 Q=O'''。

为覆盖有限阶 C2 曲面 profile，本结果不要求 q 在端点全平。甚至可以减弱为：q∈C3([a,b])，在一个有限分割的每个闭子区间上为 C4，条件 (2) 成立且 Q=0 在各开子区间成立。此时 O'' 连续而 O''' 分段为零，以下证明仍然成立。没有假定 q 的第四导数跨分割点连续。

这只是矩条件所需的正则性。把 profile 转成 C2 曲面时还须检查具体 Y 公式；例如 t^4 外尾的零延拓为 C3，不能称作 C4 或 C∞。

## 2. 全局等价命题

设

\[
\mathsf B=
\begin{pmatrix}
r_0&s_0&t_0\\
r_1&s_1&t_1\\
-p_0/4&-p_1/4&-p_2/4
\end{pmatrix},
\qquad \det\mathsf B\ne0.
\tag{4}
\]

则在条件 (2) 下，下列两件事等价：

- Q[q]=0 在整个区间成立；
- 完整 O[q]=0 且三个复总矩 M=0。

因此，一个满足两端零 jet 的完整 Q 解，在 (4) 下不再需要独立求解六个实总矩方程。反向由 Q=O''' 立即成立。

### 正向证明

在右端 b，(3) 给 J(b)=0，(2) 使 O 中的局部项及其前两阶导数都为零。因此

\[
O(b)=O'(b)=O''(b)=0.
\]

Q=O'''=0 于是给 O≡0。分段 C4 的情形由 O'' 连续，按子区间同样推出结论。

左端 a 的三个 J 值是**总矩 M**，并非人为置零。因 (2)，左端的局部项及前两阶导数仍消失；J′、J″ 在该端也为零。故

\[
\begin{pmatrix}
B_0(a)&B_1(a)&B_2(a)\\
B_0'(a)&B_1'(a)&B_2'(a)\\
B_0''(a)&B_1''(a)&B_2''(a)
\end{pmatrix}M=0.
\tag{5}
\]

记左侧矩阵为 W_B(a)，它准确分解为

\[
W_B(a)=
\begin{pmatrix}1&a&a^2\\0&1&2a\\0&0&2\end{pmatrix}
\mathsf B.
\]

所以 det W_B(a)=2 det B≠0，推出 M=0。这个行列式与选用哪一个左端 a 无关。

若 q 非零，q 的实部 f 与虚部 g 必须实线性独立。否则 q=c h，其中 c≠0 为常复数、h 为实函数，M0=c²∫(h'')²=0 会迫 h''=0，再由端点条件迫 h=0，矛盾。M=0 恰好给 f、g 的三总矩相等及三个交叉矩为零；O[q]=0 同时给完整两个周期通道。

## 3. R13 的精确满秩检查

R13 的系数给

\[
\mathsf B=
\begin{pmatrix}
1&0&5/2\\
0&-4&0\\
-1/2&0&1
\end{pmatrix},\qquad
\det\mathsf B=-9.
\tag{6}
\]

所以若未来把 R13 的局部解接成完整双端零 jet 解，三复总矩就随之成立。但是现有局部常数 `(44/9,3/4,−14/9)` 尚未被证明等于 (3)，故不能现在套用这个推论。

若 B 不满秩，证明仅给 M∈ker B；缺失的总矩约束仍须补上。不能把满秩结论推广到所有九系数组合。

## 4. 残差的精确传递公式

对仍满足 (2) 的任意 q，不必先假设 Q=0。由右端三个零积分常数，精确有

\[
W_B(a)M=
\begin{pmatrix}
-\frac12\int_a^b(s-a)^2Q(s)ds\\
\int_a^b(s-a)Q(s)ds\\
-\int_a^b Q(s)ds
\end{pmatrix}.
\tag{7}
\]

例如第三行来自 O''(a)=−∫Q，第二行再积一次符号转正，第一行再积一次转负。分段 C4、O'' 连续时同样成立。

于是 B 可逆时，(7) 可把完整 Q 残差转成矩误差上界；区间长度记为 L，右向量各分量模长分别不超过 `L³||Q||∞/6`、`L²||Q||∞/2`、`L||Q||∞`。还要乘 W_B(a) 的逆矩阵范数，不能忽视接近秩亏时的放大。

实际数值 BVP 应同时直接积分总矩与 (7) 的右侧作交叉核对。若端点只停在 a+ε、b−ε，或零 jet 仅近似满足，必须保留相应边界项；不能直接使用 (7) 宣布总矩自动消失。

## 5. 对下一全局 BVP 的作用

在满秩 B 分支，可以把主要边值未知量集中于完整区间的 Q=0、两端规定正则性的零 jet，以及非零归一化。三总矩作为独立验证量保留，避免把它们重复计作新的精确约束。

该减少只发生在 profile 层；九系数的真实几何实现、闭合、二阶校正、高阶或有限等距路径，以及闭曲面的嵌入、握持和 reach，均未由这个线性代数步骤解决。

独立复核：根代理已核右端三积分常数、左端 B 基底论证与 R13 的行列式 −9。公式 (7) 是同一三次积分的带残差版本，符号在正文逐项给出。
