# R5：四个偶多项式模式的完整二阶周期条件

**状态：已证明下面的有限维代数结论。** 它把当前四模 polynomial profile 方案的两条函数型周期条件，归结为 11 个几何系数同时为零。未证明存在使这些系数同时为零的基面，未证明二阶解可积成有限等距族。结论不推广到一般 $C^\infty$ 平坦 bump 或更大的多项式空间。

本文续 `literature-volterra-polynomial-20261114.md`，并使用 `literature-second-order-moments-20261114.md` 的三矩与完整二阶 range 公式。所有周期条件均指那一完整算子，未只检查 ruling 能量。

## 1. 归一化与 11 个独立系数

把 profile 区间仿射归一化为 $[-1,1]$，令
$$V=(1-x^2)^4\operatorname{span}_{\mathbb R}\{1,x^2,x^4,x^6\}.$$
归一化前后的三个截断矩按通常变量替换变换；上一篇中的多项式系数恒等关系在此变换下保持。因此仍可把双线性周期算子写成
$$\mathcal O(f,g)=A_0fg+\frac{A_1}{2}(fg'+f'g)+A_2f'g'
+B_0J_0(f,g)+B_1J_1(f,g)+B_2J_2^*(f,g),$$
其中 $J_0=\int_x^1 f''g''$，$J_1=\int_x^1 y f''g''$，$J_2^*=\int_x^1y^2f''g''+2\int_x^1f'g'$。

全部系数可用 11 个实数表示：
$$A_0=-p_1/2-p_2x,\quad A_1=p_0+p_1x+p_2x^2,$$
$$A_2=q_0+q_1x+(t_1-p_1/2)x^2-p_2x^3/2,$$
$$B_0=r_0+r_1x-p_0x^2/4,\quad
B_1=s_0+s_1x-p_1x^2/4,\quad
B_2=t_0+t_1x-p_2x^2/4.$$
这是上一篇中各系数关系的重写，没有增加几何假设。

**命题。** 设 $f,g\in V$ 实线性无关，且其三矩满足
$$J_j(f,f)(-1)=J_j(g,g)(-1),\qquad J_j(f,g)(-1)=0,
\quad j=0,1,2^*.$$
那么
$$\mathcal O(f,f)=\mathcal O(g,g),\qquad\mathcal O(f,g)=0\quad\text{在 }[-1,1]\text{ 上恒成立}$$
当且仅当上面 11 个实数全部为零。

充分性直接。以下给必要性的完整证明。

## 2. 比较最高次数，先消去 $p_2,p_1,t_1$

若 $f,g$ 的次数为 $m,n\ge3$，首项系数为 $a,b\ne0$，直接取每个截断矩的最高幂可知 $\mathcal O(f,g)$ 中 $x^{m+n+1}$ 的系数为
$$abp_2\frac{(m-2)(m-1)(n-2)(n-1)}{4(m+n-1)}.$$
因此交叉条件给 $p_2=0$。

对 $(f,g)$ 作实正交旋转保持所有三矩圆条件及两条周期恒等式。可选一次旋转，使一支的最高项消掉，从而得到不同次数 $M<N$；线性无关保证消掉最高项的支仍非零。

当 $p_2=0$ 时，双线性最高次 $x^{m+n}$ 的系数，除去 $ab$，为
$$p_1\frac{(m-2)(m-1)(n-2)(n-1)}{4(m+n-2)}
-t_1\frac{mn(m-2)(n-2)}{m+n-1}.$$
对角差的最高项只来自次数 $N$ 的支，交叉项则用 $(M,N)$。两方程的系数比不同：固定 $n>1$ 时
$$\frac{(m-1)(n-1)(m+n-1)}{4mn(m+n-2)}$$
严格随 $m$ 增加。其 $m$ 导数的符号，除去正因子，是 $(n-1)(2m+n-2)>0$。故这两方程独立，迫
$$p_1=t_1=0.$$

至此 $A_2$ 与 $B_1$ 至多一次，$B_2$ 为常数。记
$$C(x)=B_0+xB_1+x^2B_2,\qquad W_1(x)=B_1+2xB_2.$$
此时 $C$ 至多二次，$W_1$ 至多一次。

## 3. 两端的有限消失阶给出可靠的两式

再作一次保持所有条件的实正交旋转，可使两支在 $x=1$ 的消失阶不同，记为 $k<\ell$。这里 $k,\ell\in\{4,5,6,7\}$：每个非零元素有因子 $(1-x^2)^4$，剩余是次数至多 3 的 $x^2$ 多项式。由于两支均为偶函数，它们在 $x=-1$ 的消失阶相同。

在右端写 $f=a(1-x)^k+\cdots$、$g=b(1-x)^\ell+\cdots$。对角差的最低阶只来自 $f$，其首项含 $C(1)$，故 $C(1)=0$。在左端，三矩的总差和总交叉量为零，允许把截断积分改成从左端起的负积分；同理 $C(-1)=0$。因此
$$C(x)=c(x^2-1)$$
对某实数 $c$ 成立。

下面只使用两个合法的最低阶方程：对角差中的 $(k,k)$ 项和交叉中的 $(k,\ell)$ 项，**不**另假定 $(\ell,\ell)$ 项必须单独消失。

令 $r=k-1$、$s=\ell-1$。在 $C(1)=0$ 之后，相应最低阶系数给
$$A_2(1)=\frac{r^2}{2r-1}\left(C'(1)-\frac{W_1(1)}{2r}\right),$$
$$A_2(1)=\frac{rs}{r+s-1}\left(C'(1)-\frac{W_1(1)}{r+s}\right).$$
解这两条线性式，得到
$$A_2(1)=\alpha C'(1),\qquad W_1(1)=\beta C'(1),$$
其中
$$\alpha=\frac{rs}{s-r+1},\qquad
\beta=-\frac{2(r+s)(r-1)}{s-r+1}.$$
左端以相同展开也给 $A_2(-1)=\alpha C'(-1)$、$W_1(-1)=\beta C'(-1)$。三者都是一次多项式，因此在整个区间内
$$A_2=\alpha C',\qquad W_1=\beta C'.$$

比较系数，剩余参数只能写成两个实数 $p_0,c$：
$$q_0=r_1=s_0=0,\quad q_1=2\alpha c,\quad r_0=-c,$$
$$s_1=p_0/2+2(1-\beta)c,\qquad
t_0=-p_0/4+(2\beta-1)c.$$

## 4. 一个有限、精确的 $2\times2$ 证书

对于次数为 $m,n$ 的双线性项，在以上参数化下，其最高次 $x^{m+n-1}$ 的系数为 $ab\{P(m,n)p_0+Q(m,n)c\}$，其中
$$\begin{aligned}
P(m,n)={}&\frac{m+n}{2}
+\frac{mn(m-1)(n-1)}{4(m+n-3)}
-\frac{mn(m-1)(n-1)}{2(m+n-2)}\\
&+\frac{mn\{(m-1)(n-1)+2\}}{4(m+n-1)},
\end{aligned}$$
$$Q(m,n)=2\alpha mn
-\frac{2(1-\beta)mn(m-1)(n-1)}{m+n-2}
-\frac{(2\beta-1)mn\{(m-1)(n-1)+2\}}{m+n-1}.$$

再次使用 §2 已取得的次数枢轴 $M<N$。在 $V$ 中它们属于 $\{8,10,12,14\}$。对角差和交叉的最高次分别给矩阵
$$\begin{pmatrix}P(N,N)&Q(N,N)\\P(M,N)&Q(M,N)\end{pmatrix}
\begin{pmatrix}p_0\\c\end{pmatrix}=0.$$

## 5. 供下一轮使用的建设性含义

对于当前四模 polynomial profile 圆路径，先固定一个普通基面再不断调整这四个 profile 系数，不能避开非零的 11 系数周期算子。其精确二阶可解性的基面设计目标已经明确：同时求解
$$p_0=p_1=p_2=q_0=q_1=r_0=r_1=s_0=s_1=t_0=t_1=0,$$
以及原文的基曲线闭合、周期渐近坐标和正速度条件。若能做到，任意满足三矩圆条件的独立 pair 都通过完整二阶周期检验。

这些系数是上一笔记给出的有限几何积分，所以这是实际可用于有限参数 base co-design 的方程组。是否存在具有足够几何厚度、足够低速度对比的基面解，仍待求解；即便二阶成功，高阶可积性和本题的有限幅度比例仍是另外的工作。
