# R86：左侧三矩补偿保持右 Volterra 障碍，并给光滑 profile 圆

日期：2026-11-14。**条件定理，已证明。** 本文不需要新的研究计算。它说明：若某一固定右尾 profile 的真实完整 P1 评价矩阵具有分离子式，则可把该障碍保持到满足全部三个总矩的 $C^\infty$ profile 圆。本文不声称正在运行的有理评价器已经找到该子式。

来源和约定采用 [R39 的三个准确总矩](R39-explicit-moment-circle-and-third-order-range.md)、[R56 的共同右锚分子恢复式](R56-full-variable-range-numerator-calculus-and-finite-fourth-system.md)、[R78 的两种完整 P1 模式](R78-complete-phase-P1-symmetric-square-conditions.md)，以及 [R80 的完整第三仿射类](R80-complete-third-affine-class-and-P1-endpoint-obstruction.md)。平方和极化均为普通复双线性运算，不是 Hermitian 范数。

## 1. 设定与结论

在一个共同正则 profile 坐标区间上固定全部几何系数、共同右 collar 和右原函数

$$I(F)(\xi)=\int_r^\xi F(\eta)\,d\eta.$$

输入可以先为紧支撑 $C^7$ 复 profile $q=f+ig$。 下述光滑化结论以相关有限点值对 $C^6$ 拓扑连续为前提；本次完整 P1 表达式满足这一条件，见第4节。考虑有限个算子表达式，由 profile 的有限阶导数、固定光滑坐标系数、加法、乘法、普通复共轭和 $I$ 有限次生成。几何参数的积分只改变系数，不另引入向左取值的 profile 算子。R56/R78 的本次完整两模式目标及控制响应属于这一类。

假定有 $n$ 个真实控制响应列 $A_1(q),\ldots,A_n(q)$ 和一个目标列 $b(q)$，并在有限个固定查询点上取指定模式的实部或虚部，得到实矩阵

$$A(q)\in\mathbb R^{m\times n},\qquad b(q)\in\mathbb R^m.$$

对本次程序，$n=36$，查询点在 $(2,3)$，原始输入支撑为 $[2,3]$。假设某 $n\times n$ 控制子式和同一组行加另一行后的 $(n+1)\times(n+1)$ 增广子式均非零。于是该 $q$ 上不存在共同实控制系数使全部函数匹配。

**结论。** 只要在全部旧查询点和原右尾支撑的左方还保留一个非空开放区间，就存在一个紧支撑 $C^\infty$ 复 profile $\widehat q=\widehat f+i\widehat g$，使：

1. R39 的三个复总矩全部准确为零；
2. $\widehat f,\widehat g$ 构成非退化的真实三矩相位圆；
3. 同一组查询点、模式及控制列仍有非零控制子式和增广子式，因此该完整函数匹配仍无解；
4. 可进一步统一缩放，使 $\int(\widehat f'')^2=\int(\widehat g'')^2=1$，而不破坏非零子式。

若初始 $q$ 已经光滑，则第 3 项中的全部矩阵值可以完全不变。若初始 $q$ 只有上述有限正则性，先作足够小的光滑逼近，使非零子式保留；随后三矩补偿阶段不再改变任何旧查询值。

本结论是对特定 profile 圆的条件性障碍迁移，不是对所有 profile 圆的排除。

## 2. 右原函数表达式的局部依赖

设两个输入 $q_1,q_2$ 在某个区间 $[a,r]$ 及查询点所需的开放邻域内相同。则任何上述有限表达式在 $[a,r]$ 的内部查询点取值相同。

证明按表达式结构归纳。局部导数、固定系数乘法、普通共轭、加法及乘法显然保持相同。对原函数节点，若其被积函数 $F_1,F_2$ 在 $[a,r]$ 相同，则对 $\xi\ge a$ 有

$$I(F_1)(\xi)-I(F_2)(\xi)=\int_r^\xi(F_1-F_2)(\eta)\,d\eta=0.$$

这也覆盖嵌套原函数。先代入二阶算子，再把其输出作为第三算子的外槽或内槽，仍只是有限次上述操作，故无例外。对固定几何参数作有限积分也保持等式。

因此，在所有查询点及其右方输入不变时，完整控制矩阵与完整目标矩阵逐项不变。这里并非仅保留某个最高 jet、某个局部 forcing 或某个对角三次式；真实右原函数常数也一同保持。

特别地，在查询点左方加入新的 profile 支撑，不会改变这些值。**不能同样声称对左锚恢复或全区间总积分不变；本文只用已明确的共同右锚。**

## 3. 三个左侧 bump 可以支付任意复三矩缺陷

按 R39 的真实定义，记

$$M_0(q)=\int(q'')^2,\qquad M_1(q)=\int \xi(q'')^2,$$

$$M_2(q)=\int\xi^2(q'')^2+2\int(q')^2.\tag{1}$$

所有积分在共同 profile 区间上，或把 profile 零延拓后在整条实线上计算，两者相同。第三式的 $2\int(q')^2$ 必须保留。

在保留的左区间内选三个不同中心 $c_1,c_2,c_3$，再选一个非零、实、偶、$C^\infty$ 紧支撑 bump $\eta$，共同支撑宽度足够小，使三个平移

$$\eta_j(\xi)=\eta(\xi-c_j)$$

互不相交，也与原始 profile 支撑不交。定义

$$a_0=\int(\eta'')^2>0,\qquad
a_2=\int x^2(\eta'')^2+2\int(\eta')^2.$$

由于 $\eta$ 偶，$\int x(\eta'')^2=0$。准确平移公式为

$$\begin{pmatrix}M_0(\eta_j)\\M_1(\eta_j)\\M_2(\eta_j)\end{pmatrix}
=v_j:=\begin{pmatrix}a_0\\a_0c_j\\a_2+a_0c_j^2\end{pmatrix}.\tag{2}$$

将矩阵第三行减去 $(a_2/a_0)$ 倍第一行，得到

$$\det[v_1\ v_2\ v_3]
=a_0^3\prod_{1\le i<j\le3}(c_j-c_i)\ne0.\tag{3}$$

所以对任意已有复 profile $q$，存在唯一 $w_1,w_2,w_3\in\mathbb C$ 满足

$$\sum_{j=1}^3w_jv_j=-\begin{pmatrix}M_0(q)\\M_1(q)\\M_2(q)\end{pmatrix}.\tag{4}$$

每个复数都有复平方根；选择 $z_j\in\mathbb C$ 使 $z_j^2=w_j$，零值时取 $z_j=0$。置

$$\widehat q=q+\sum_{j=1}^3z_j\eta_j.\tag{5}$$

支撑分离，故包括一阶导数项在内的全部交叉积分为零。因此

$$M_\nu(\widehat q)=M_\nu(q)+\sum_jz_j^2M_\nu(\eta_j)=0,
\qquad\nu=0,1,2.\tag{6}$$

没有要求 $w_j$ 为非负实数。若错误地用绝对值平方，任意缺陷补偿将不成立；这里准确使用普通复平方。$z_j$ 的分支只影响所得 profile，且不需随参数连续选择，所以 $w_j=0$ 不是构造奇点。

全部新增支撑在旧查询点左方。由第 2 节，(5) 保持原矩阵和目标的每一个旧查询值，而不仅保持它们的秩。

## 4. 从有限正则的准确证书到真正光滑输入

本次有理评价器使用的零延拓 $q_0$ 属于 $C_c^7([2,3])$。固定一个实、偶、非负、紧支撑光滑 mollifier $\rho$，积分为 1，令

$$q_\varepsilon=\rho_\varepsilon*q_0.$$

则 $q_\varepsilon\in C_c^\infty$，当 $\varepsilon\downarrow0$ 时在 $C^6$ 中收敛于 $q_0$，且支撑包含于 $[2-\varepsilon,3+\varepsilon]$。

为什么这里的子式连续：当前原始第三模板的输入 jet 最高阶不超过 4，二阶算子只再使用至多两个输入导数和右积分，故 R78 的组合点值由有限次 $C^6$ 连续操作给出。固定紧区间上的右积分是连续线性算子；固定有限几何系数有界。目标列也满足相同有限阶界。因此每个矩阵项、控制子式及增广子式均连续依赖 $q$ 的 $C^6$ 范数。

初始两个子式非零，故存在 $\varepsilon_0>0$，使所有 $0<\varepsilon<\varepsilon_0$ 的这两个子式仍非零。这里不需把初始有理泛函的系数强行保持为新矩阵的零泛函：新矩阵仍可用自己的非零控制子式准确定义 Cramer 泛函。非零增广子式已充分给出不相容性。

例如先限制 $\varepsilon<1/32$，可选

$$c_1=5/4,\qquad c_2=3/2,\qquad c_3=7/4,$$

并使 $\eta$ 的共同半宽小于 $1/32$。于是新增支撑全在 $(1,2)$ 内，且与 $q_\varepsilon$ 支撑分离。对该光滑 $q_\varepsilon$ 应用第 3 节，得到光滑 $\widehat q$；补偿准确支付三矩，而第 2 节使已经保留的两子式完全不变。

共同区间的选择顺序是：先选择所需有限路径/系数、有限查询点、光滑逼近与三个有限补偿 bump，再取包含全部支撑并留有开放零 collar 的共同紧区间。仅在 canonical profile 坐标层面，上例可置于 $I\Subset(1,\infty)$。用于某个具体几何实现时，还须确认这个整个区间位于全部真实路径的同一正则物理支，$h>0$ 且 $\xi+\omega$ 统一不为零；本引理不承诺任意预先指定的窄物理带可容所有构造。

本节给的是严格存在性推论，不是一次已执行的光滑 profile 数值拟合，也不指定尚未算出的定量 $\varepsilon_0$。

## 5. 三矩确实给非退化相位圆

写 $\widehat q=\widehat f+i\widehat g$。由 $M_0(\widehat q)=0$ 的实虚部，

$$\int(\widehat f'')^2=\int(\widehat g'')^2=:E,
\qquad\int\widehat f''\widehat g''=0.\tag{7}$$

原右尾非零，而且左补偿没有改变它，所以 $\widehat q\ne0$。如果 $E=0$，两个实紧支撑函数的二阶导数都恒为零，故两个函数都为零，矛盾。因此 $E>0$；$\widehat f,\widehat g$ 在该正定 Gram 型下等长且正交，尤其线性无关。

$M_1=M_2=0$ 同样给各自实二次矩相等和交叉矩为零；第三个交叉矩准确含

$$\int\xi^2\widehat f''\widehat g''+2\int\widehat f'\widehat g'.$$

于是对所有实 $\theta$，

$$\phi_\theta=\cos\theta\,\widehat f+\sin\theta\,\widehat g$$

保持 R39 的三个总矩。该结论不要求 $\widehat f,\widehat g$ 支撑互不相交。

若需归一化，统一取 $\lambda=E^{-1/2}$ 并将两个实 profile 同乘 $\lambda$。三个复零矩保持为零。R78 的目标列及所有第三控制响应列对共同 profile 缩放都是四次齐次，因此每个实评价行的全部 entries 同乘 $\lambda^4$。本次 36 阶控制子式乘 $\lambda^{144}$，37 阶增广子式乘 $\lambda^{148}$，均保持非零。归一化没有引入额外的零子式可能。

## 6. 对当前研究的准确含义

若新的有理评价实际成功，则其非零子式不只反驳一个 universal 桥恒等式；本引理把它提升为**存在一个合法光滑三矩 profile 圆**，在同一个完整第三控制空间中仍不能支付相应完整 P1 条件。三个左侧补偿 bump 不会给控制系数新增可用方向，因为空间仍是同一个完整算子空间；它们只改变输入的左部，右尾测试看不到该改变。

此结论仍不能排除所有三矩圆，也不能排除多个不同 bulk pair 的合并、改变几何机制或其他未被此固定问题覆盖的选择。三矩只支付二阶 ruling 的相应条件；是否有适用的零算子基底、完整三阶相容、第四 ruling、$P_0$、更高阶和收敛仍各有自己的要求。本文不把条件性 profile 障碍升为主课题的闭曲面不存在定理，更没有完成嵌入、reach 和宏观幅度目标。

当前状态是：上述迁移定理已证明，所需实际非零子式尚待新的公开 Actions 回执。
