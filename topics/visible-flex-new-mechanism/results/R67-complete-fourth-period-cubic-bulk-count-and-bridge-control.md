# R67：固定真实控制的完整第四周期是圈数三次函数

日期：2026-11-14。完整准确递推；root 全文核对，repo_sources 独立纸核；未运行新的真实几何、profile 积分或完整目标编译。本文把 R56 的有限分离恢复与已经实际核对的 $27+705$ 三角历史结构用于圈数诊断。下述结论是完整函数层面的代数，不是从几个残差范数拟合一条曲线。

## 1. 同一控制族的含义

固定一个有限有序控制词，包括全部真实平滑连接、全部常态的 $k,h,\omega$、每个常态的整数周期倍数以及同一全局 profile。把每个指定 bulk 的完整圈数共同乘以正整数 $N$。每个 bulk 的真实长度为 $N\ell_i$，其中 $\ell_i$ 已包含该状态的真实 frame 周期与固定整数倍；其他段的控制、长度和端状态均与 $N$ 无关。

完整 frame 圈准确返回 I，且常态 $\omega_s=0$，所以后续连接的 frame/scalar 起始条件不随 $N$ 改变。中心曲线位移可以随 $N$ 改变，不能把 frame 返回当成位移为零；但 R56 的 metric/range 恢复不含空间平移。一个固定的 R45 四块词也可在这个控制族中逐块原样展开，保持真正全局历史，不在任何段重锚。

工作 $\xi$ 区间、profile 与其幅度也保持不变。所有恢复都在同一合法坐标域内；谈参数邻域或渐近时，正的 h 和全部恢复分母须统一远离零。若数值控制只近似满足端条件，则每个 $N$ 都保留其真实缺陷；本稿不进行 reset。整数 $N$ 变化是**改变实体几何和基底度量的新设计**，不是同一几何的加密。只有 quadrature 改变而所有控制及 $N$ 不变才是精化。

数学递推可把 $N$ 形式地看成一个实变量，从而提取多项式系数；这不把非整数或负圈数解释成实际曲面。

## 2. 足够的三角系统与完整第四观察量

记全部第二标量历史为 $b$，全部第三标量历史为 $c$。它们是 R56 某个有限分离表示中的系数向量，允许有冗余。完整恢复有形式

$$b_s=a(s),\qquad c_s=d(s)+B(s)b(s).\tag{1}$$

这里 $a,d,B$ 只依赖真实局部几何控制及其导数；没有 $c$ 反馈，也没有把真实桥删除。首次实际完整编译中维数为 27 和 705，但本证明不依赖这些具体维数。

任一个第四 Fourier 通道的 characteristic 密度，在代入所有历史微分之后都可写成

$$\mathcal O(s,\xi)
=o(s,\xi)+\lambda(s,\xi)b(s)
+Q(s,\xi)[b(s),b(s)]+C(s,\xi)c(s).\tag{2}$$

$Q$ 可按对称双线性形式理解。各系数可为 $\xi$ 函数或有限分离表达式；不要求 profile 基独立。它们不依赖 $N$，在每个常态中为常系数，在桥上按真实局部弧长变化。原始第四 ruling 密度的表示也有相同历史次数。

式 (2) 是 R56 的恢复次数事实：第二场含 $b$ 一次，第三场含 $c$ 一次及 $b$ 一次，第四 forcing 是第二场的平方与第一/第三场的交叉。实际编译的 weighted degree 检查另确认 $\deg b=1,\deg c=2$ 时全部第四观察量次数至多 2。这里不使用“某个数值小”来替代该结构。

## 3. 每个真实桥上的精确递推

写段首历史为

$$b(N)=b_0+Nb_1,\qquad c(N)=c_0+Nc_1+N^2c_2.$$

在任何长度固定的桥内，沿其真实弧长准确满足

$$\begin{array}{lll}
(b_0)_s=a,&(b_1)_s=0,\\
(c_0)_s=d+Bb_0,&(c_1)_s=Bb_1,&(c_2)_s=0.
\end{array}\tag{3}$$

因此桥改变 $b_0,c_0,c_1$，但不改变最高历史 $b_1,c_2$。所有段首值都从前一段原样带入；(3) 没有为当前桥另选积分常数。

把 (2) 分成 $N$ 的三项，桥上的周期累积率准确为

$$\begin{aligned}
(P_0)_s&=o+\lambda b_0+Q[b_0,b_0]+Cc_0,\\
(P_1)_s&=\lambda b_1+2Q[b_0,b_1]+Cc_1,\\
(P_2)_s&=Q[b_1,b_1]+Cc_2,\\
(P_3)_s&=0.
\end{aligned}\tag{4}$$

尤其桥的直接第四作用可以达到 $N^2$。桥时长固定或二阶矩阵成本 O(1)，都不能把 (4) 的第三行删除。

## 4. 每个完整常态 bulk 上的精确递推

在一个长度为 $N\ell$ 的常态上，取 $t\in[0,1]$，真实弧长 $\sigma=N\ell t$。本段的 $a,d,B,o,\lambda,Q,C$ 都为常系数。若上标 in 表示继承的段首值，则

$$\begin{aligned}
b_0(t)&=b_0^{\rm in},\\
b_1(t)&=b_1^{\rm in}+\ell t\,a,\\
c_0(t)&=c_0^{\rm in},\\
c_1(t)&=c_1^{\rm in}+\ell t\{d+Bb_0^{\rm in}\},\\
c_2(t)&=c_2^{\rm in}+\ell t B b_1^{\rm in}
+\frac{\ell^2t^2}{2}Ba.
\end{aligned}\tag{5}$$

这只是 (1) 的准确两次积分，不是大 $N$ 渐近。积分第四观察量时，真实测度是 $ds=N\ell\,dt$，所以本 bulk 的四个函数系数增量是

$$\Delta P_0=0,$$

$$\Delta P_1=\ell\{o+\lambda b_0^{\rm in}
+Q[b_0^{\rm in},b_0^{\rm in}]+Cc_0^{\rm in}\},\tag{6}$$

$$\begin{aligned}
\Delta P_2=\ell\bigg\{&\lambda\left(b_1^{\rm in}+\frac\ell2a\right)
+2Q\left[b_0^{\rm in},b_1^{\rm in}+\frac\ell2a\right]\\
&+C\left(c_1^{\rm in}+\frac\ell2\{d+Bb_0^{\rm in}\}\right)\bigg\},\tag{7}
\end{aligned}$$

$$\begin{aligned}
\Delta P_3=\ell\bigg\{&Q[b_1^{\rm in},b_1^{\rm in}]
+\ell Q[b_1^{\rm in},a]+\frac{\ell^2}{3}Q[a,a]\\
&+C\left(c_2^{\rm in}+\frac\ell2B b_1^{\rm in}
+\frac{\ell^2}{6}Ba\right)\bigg\}.\tag{8}
\end{aligned}$$

这里的 $o,\lambda,Q,C$ 仍是整个 $\xi$ 函数系数，或某个 Fourier 模式的完整有限分离式。不能先逐项取范数后套用这些加法。

## 5. 完整函数三次性与最高项的真实含义

从固定、与 $N$ 无关的初始锚值开始，按真实有限控制词交替应用 (3)、(5)，归纳得所有段的 $b,c$ 分别为 $N$ 的至多一次、二次多项式。由 (4)、(6)–(8)，对每个完整第四通道准确有

$$\boxed{\Pi_4(N,\xi)=P_0(\xi)+NP_1(\xi)
+N^2P_2(\xi)+N^3P_3(\xi).}\tag{9}$$

系数中包括所有真实桥和累计历史；不要求较低阶 range 已经支付，也不要求某个 $N$ 的零算子或 frame 条件已经严格认证。后者是把结果用于弯曲时必须另付的条件。

从 (3)、(5) 可见 $b_1,c_2$ 在桥内不变。因此在固定常态数据和次序后，$P_3$ 只由这些有序 bulk 数据及 (8) 决定，**不依赖桥内部的控制路径**。这句话保留固定桥端状态的前提：若改桥而连带改变下一个 bulk 的 $k,h,\omega$ 或次序，当然也改变 $P_3$。

桥内部控制能改变 $P_2$，既通过 (4) 的直接 $N^2$ 积分，也通过它留下的 $b_0,c_1$ 在后续 bulk 的 (7) 中继续作用。因此不能只调某一桥的本地第四积分而忽略其下游传播。

### 大 N 零二阶构造的一个必要门

假设一个已准确设计的控制族具有固定光滑极限参数 $p_*$，有限 N 修正满足 $p_N=p_*+O(1/N)$；所有桥的长度、控制及所需导数在该参数邻域中有统一界，profile 固定。由 (9) 的光滑参数依赖，

$$\Pi_4(N,\xi)=N^3P_3(p_*,\xi)+O(N^2).\tag{10}$$

所以若 $P_3(p_*,\cdot)$ 不是零函数，则不可能仅靠该有界桥族和 O(1/N) 零二阶修正在任意充分大的 N 上支付第四周期。可以在一个 $P_3$ 非零的点直接应用 (10)，无须假设分离基独立。

这不是对某个单独有限 N 的排除：同一个有限 N 仍可能有不同次数项相消。它也不排除改 bulk、改 profile、使用随 N 增长的新桥、或超出这一固定控制族的构造。

## 6. 怎样把真实桥用于支付条件

若先让同一 profile 和全部有序 bulk 通过 $P_3=0$，下一项是整个函数 $P_2$，而非一个标量范数。对一个端状态保持不变的桥控制变化，(3) 与 (4) 给出直接入口：

1. 积分桥的 $a,B$ 以得到它对 $b_0,c_1$ 的真实改变。
2. 积分 $Q[b_1,b_1]+Cc_2$ 以得到该桥的直接 $P_2$ 改变。
3. 将新的 $b_0,c_1$ 沿后续所有桥和 bulk 继续传播，使用 (7) 累加下游作用。

在同一有限分离表示中，这产生一个到 $P_2(\xi)$ 函数空间的具体控制导数；可再与 frame/scalar 端点、完整二阶矩阵等约束的导数组成共同方程。R56 允许通过真实函数 Gram 核去除冗余，不能把每个分离系数必须为零当成必要条件。

本稿没有宣称这个控制导数满射，也没有把某个有限数值 rank 作为准确存在证据。真正的补偿构造仍须给出端点保持的可用控制、该导数的准确秩或验证 Newton/IFT，以及剩余 $P_1,P_0$ 和全部 ruling 条件。它的用途是把调桥的任务具体化，避免把必要的 $N^2$ 作用误删后寻求不存在的“自动逆片”。

## 7. 数值诊断时不能混淆的量

若以后在公开 Actions 实现 (3)–(8)，应直接传播四个函数系数，或对四个形式 N 值的完整函数作准确节点插值；不得对四个 L2 范数拟合三次式。固定 profile 区间下，$\|\Pi_4(N)\|_{L^2}^2$ 至多六次，L2 本身一般不是多项式。

完整 ruling 在各段的标准局部坐标中至多二次于 N；其平方范数积分在 bulk 还带一个长度 N，因此至多五次。全局 gauge 的 Gram 为一次于 N；先去除真实函数冗余并限定在固定秩区间后，投影后的商范数涉及 Gram 的逆，一般为有理表达式，也不能直接按三次周期规律拟合。

该诊断可将首轮 −4 模式的较小数值区分为 bulk 最高项、桥的 $N^2$ 项和较低项，而不是从两档同时改变 quadrature 的结果猜定某个准确恒等式。任何这样的实际评价仍须在公开 Actions 执行；本稿没有运行它，也没有把固定 N 失败实例改成一个已通过的候选。
