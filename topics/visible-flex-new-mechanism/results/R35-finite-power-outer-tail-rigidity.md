# R35：简单 C 根的任意有限幂次外尾及完整双尾排除

日期：2026-11-14。完整证明，接续 R18、R19、R34；弱积分首项、完整 indicial 多项式和无权唯一性已独立复核。只做精确代数与分析，不运行新的研究数值计算。

**准确假设。** 本稿研究一个已有前三阶同阶渐近的有限幂次外尾。它允许任意实数 $m>3$，包括 $3<m<4$ 的仅 $C^3$ profile，也允许非整数阶。没有预先断言任意简单端根处的 $C^3$ 非零弱解都必具有这种渐近。

## 1. 由弱方程推出指数条件，不假定第四阶渐近

使用内向坐标 $t\ge0$。实际八系数满足

$$L[q]=Aq+2Bq'-2Cq'',\qquad B=C'-W,\qquad
A=2W'-\frac43C'',$$

并取一个简单端根

$$C(t)=ct+O(t^2),\qquad W(t)=w+O(t),\qquad c\ne0.$$

采用 [R34](../results/R34-C3-weak-profile-rigidity-and-two-tail-obstruction.md) 的完整弱式

$$ (Lp)'+ap=0,\qquad
p=q''',\quad a=A'q+(A+2B')q'-2Wq''.\tag{1}$$

设 $q\in C^3([0,\delta])$，且对某个 $\alpha\ne0$、实数 $m>3$，

$$q^{(j)}(t)=\alpha(m)_j t^{m-j}+o(t^{m-j}),
\qquad j=0,1,2,3.\tag{2}$$

这里 $(m)_j=m(m-1)\cdots(m-j+1)$。不假定 $q^{(4)}$ 存在或有同阶渐近。

记 $R=w/c$。由 (2)，

$$L[q]=2c\alpha m(2-m-R)t^{m-1}+o(t^{m-1}),$$

$$p=\alpha m(m-1)(m-2)t^{m-3}+o(t^{m-3}),$$

$$a=-2w\alpha m(m-1)t^{m-2}+o(t^{m-2}).$$

由 $Lp\to0$，将真正的弱式 (1) 从零积分，有 $Lp=-\int_0^t ap\,ds$。比较 $t^{2m-4}$ 的系数得到

$$2c(m-2)(2-m-R)=w(m-1),$$

$$\boxed{\quad R=-\frac{2(m-2)^2}{3m-5}.\quad}\tag{3}$$

即使上述 $L$ 的待定首系数先可能为零，这个积分比较仍然合法；(3) 最终给

$$L[q]=\ell t^{m-1}+o(t^{m-1}),\qquad
\ell=-\frac{2c\alpha m(m-1)(m-2)}{3m-5}\ne0.\tag{4}$$

所以 $L$ 在一个删去零点的邻域不为零，(1) 自动恢复经典四阶 ODE。

函数 $m\mapsto-2(m-2)^2/(3m-5)$ 在 $m>3$ 严格递减，其像为 $(-\infty,-1/2)$。因此一个给定实比值 $R<-1/2$ 至多对应一个允许的有限幂次 $m>3$。

若把 (2) 改成复指数、$\operatorname{Re}m>3$ 的同类逐阶渐近，同一积分比较仍给
$2m^2+(3R-8)m+8-5R=0$。当该实系数二次式有非实根时，必有 $0<R<8/9$，根的实部为 $(8-3R)/4<2$。因此 $\operatorname{Re}m>3$ 的允许指数实际上仍为实数；有限幂次中的对数相位 $t^{i\nu}$ 不能提供额外自由度。

## 2. 完整 indicial 多项式与实际外尾存在

反过来，给定 $m>3$，若端根满足 (3)，则存在一个真实外尾

$$q(t)=\alpha t^m v_1(t),\qquad v_1(0)=1,\tag{5}$$

其中 $v_1$ 为实解析函数；任意非零复幅值 $\alpha$ 都允许。

先核其主算子。对主项 $f=\alpha t^m$，在扰动 $t^r$ 上线性化 $Q$，最低幂次为 $t^{m+r-5}$，系数准确为

$$\boxed{\quad
\ell\,r(r-m)(r+m-4)(r+2m-4),
\quad}\tag{6}$$

其中 $\ell$ 如 (4)。可直接从

$$DQ_f[h]=L[f]h^{(4)}+L[h]f^{(4)}
+2L[f]'h'''+2L[h]'f'''+4Cf'''h'''$$

代入幂次核对。因式 $r-m$ 对应公共幅值变化。

置 $q=t^m v$、$\theta=t\partial_t$，将 $Q$ 除以 $t^{2m-5}$。系数在 $t$ 与 $v,\theta v,\theta^2v,\theta^3v$ 附近解析，最高 Euler 导数系数在 $v=\alpha\ne0$ 处非零，故可正规化为

$$\theta^4v=F(t,v,\theta v,\theta^2v,\theta^3v).$$

$F$ 对四个 $v$ 变量一次齐次。除去公共幅相，令

$$y_1=\frac{\theta v}{v},\qquad
y_2=\frac{\theta^2v}{v},\qquad
y_3=\frac{\theta^3v}{v}.$$

得到实解析三维系统

$$\theta y=J_my+N(t,y),\qquad
N(0,0)=0,\quad D_yN(0,0)=0,$$

$$\operatorname{spec}J_m=\{-m,\,4-2m,\,4-3m\}.\tag{7}$$

这些实部都严格为负。$m=4$ 的重根只给通常的对数矩阵因子，不破坏

$$K_m=\int_0^1\|s^{-J_m}\|\,\frac{ds}{s}<\infty.$$

对解析 $y=O(t)$，积分式

$$y(t)=\int_0^1s^{-J_m-1}N(st,y(st))\,ds\tag{8}$$

在足够小的盘上为收缩，给实际实解析解。由第一条方程的兼容关系
$\theta y_1=y_2-y_1^2$、第二条
$\theta y_2=y_3-y_1y_2$，可恢复

$$v_1(t)=\exp\left(\int_0^t\frac{y_1(s)}s\,ds\right).$$

这使三个 $y_j$ 正好是 $v_1$ 的 Euler 导数比，因而 (5) 真正解原方程，不只是形式幂级数。因为系数实且正规化解唯一，$y$ 和 $v_1$ 为实。

## 3. 已有前三阶渐近的全部弱外尾都只有一个相位

对 §1 的任意解，由 (2) 有 $v\to\alpha$、$\theta^jv\to0$，$1\le j\le3$，所以 $y\to0$。§1 已保证 $L\ne0$，故在删去端点处可使用上述正规系统。

变分常数公式的下端项 $s^{-J_m}y(st)$ 趋零。故任意这种续解都必须满足 (8)，不只解析候选满足。

在连续函数空间的小球中，解析余项有

$$|N(t,y)|\le K(|t|+|y|^2),\qquad
\|D_yN(t,y)\|\le K(|t|+|y|).$$

先缩小球，再缩短区间，使 $KK_m(\delta+2\varepsilon)<1$。于是 (8) 在无权 $C^0$ 球内唯一。§2 的解析解已占据这个唯一解，所以任意满足 (2) 的外尾都有相同的实 $y$。

最后积分 $\theta v/v=y_1$ 并用 $v(0)=\alpha$，强制

$$q(t)=\alpha t^m v_1(t).$$

这证明相位唯一性，也排除了在保持 (2) 的同时偷偷增加一个全平复相位参数。对非整数 $m$，$q$ 本身通常不解析，但除去 $t^m$ 后的 $v_1$ 确为实解析。

由于 $m>3$，$q$ 的前三阶导数均在零点为零。按 R16/R32 对公开场 $Y$ 的完整二阶链式公式，零延拓仍给 $C^2$ 无穷小场。这一正则性事实没有改变完整双端的相位障碍。

## 4. 任意这类有限幂次外尾仍保护最近 C 根

从左端开始，把 $C$ 的符号和 $q$ 的公共复幅值归一，使局部 $c>0$、$\alpha=1$。由 §3，

$$q',q'',q'''>0,\qquad L<0$$

在一个内侧邻域成立；$L$ 的负首项正是 (4)。

在到达最近的内部 $C$ 根以前，$C>0$。R19 的准确恒等式在当前 $D=0$ 弱类中仍成立：

$$Z=L^2q''',\qquad Z'=-2LC(q''')^2.$$

它也可直接由 (1) 求导得到，故不需要先除以 $L$。在上述符号链上，$Z>0$ 且严格增加。任何有限的首次 $L=0$ 或 $q'''=0$ 都与 $Z$ 的正下界矛盾；$q',q''$ 则一直严格增加。在正常点，实 ODE 唯一性继续保持相位。

因此最近的内部 $C$ 根处必有 $L\ne0$，证明与 R19 完全相同。右端使用内向坐标，$C'$、$W$ 同时变号，所以比值 (3) 不变，结论同样成立。

## 5. 双简单有限幂次外尾的完整排除

设实际 $C$ 至多四次，有两个不同的简单外端根 $a<b$。假定 $q\in C^3([a,b])$ 满足完整弱式 (1)，在两端分别满足 (2)，允许两个不同的实指数

$$m_a>3,\qquad m_b>3,$$

以及各自非零复幅值。没有额外的内部正则性或有限分片假设。

每个内部 $C$ 根至少是某一侧最近的根，因为两个简单外端已经占去四次多项式的两个根重数。由 §4，这些内部根处 $L\ne0$。在其余 $C\ne0$ 点，R34 的一般 $C^3$ 弱相位刚性适用。与 R34 的最大实区间论证相同，归一后的 $q$ 必在全区间为实，即整个 profile 恒相位。

因此若还要求第一复总矩

$$\int_a^b(q'')^2\,dx=0,$$

便只可能为零 profile，与任一端非零幅值矛盾。完整的两 profile 三矩圆，以及真正右尾的 $O[q]=0$ 配合满秩尾矩系数矩阵，均含有这条必要条件，故均被排除。

**未覆盖。** 本结论没有证明任意 $C^3$ 外端都属于 (2)。没有有限幂次渐近的端尾、全平端尾、退化的外端 $C$ 根，以及其他有限等距机制仍须另行研究。它也不是一般闭嵌入曲面的刚性定理。
