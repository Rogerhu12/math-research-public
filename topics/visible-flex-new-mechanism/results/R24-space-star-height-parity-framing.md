# R24：空间星核的高度奇偶与平圆领 framing 障碍

日期：2026-11-14。**结论：**当前平面 \(C_3\) 星形投影配任意有限个 \(\sin(3j\phi)\) 高度模式，只要空间曲率处处非零，其准确 R9 rectifying annulus 的中心 framing 是 \(3\) 的奇数倍。因此该嵌入核心不能通过嵌入环带接到开放平圆领。这是拓扑障碍，不取决于优化残差大小，也不否定已经取得的局部浸入、度量和曲率证书。

本结论不排除改换 framing 的核心、改变投影或高度对称性、不同拓扑的组装，更不证明课题整体不存在解。

## 1. 适用对象与 blackboard 架

取
\[
\gamma(\phi)=(r(\phi)\cos\phi,r(\phi)\sin\phi,z(\phi)),\quad
r=1+a\cos3\phi+b\cos6\phi>0,\quad
z=\sum_{j=1}^M H_j\sin(3j\phi).
\]
设 \(\kappa>0\) 全圈成立。由于 \(r>0\)，水平投影为正向光滑 Jordan 径向图，因而 \(\gamma\) 本身嵌入。

写
\[
p=|\gamma'_{xy}|>0,\quad v=|\gamma'|>0,\quad
A=x'y''-y'x'',\quad \Omega=|\gamma'\times\gamma''|>0.
\]
用 \(\Omega\) 表示叉积模，避免与其他笔记的周期多项式 \(W\) 混淆。单位切向为 \(T=\gamma'/v\)，选水平 blackboard 法向
\[
N_{\rm bb}=(y',-x',0)/p,\qquad
M_{\rm bb}=T\times N_{\rm bb}.
\]
这是沿 \(\gamma\) 的一个有向正交法架。Frenet binormal 为
\(B=(\gamma'\times\gamma'')/\Omega\)。

直接展开得到 \(B\) 在这两个法向方向的分量：
\[
\boxed{
F_1=B\cdot N_{\rm bb}=\frac{p z''-p'z'}{\Omega},\qquad
F_2=B\cdot M_{\rm bb}=-\frac{vA}{p\Omega}.
}
\tag{1}
\]
例如第一式的分子是
\(p^2z''-z'(x'x''+y'y'')\) 除以 \(p\)；第二式使用
\((\gamma'\times\gamma'')_{xy}\cdot\gamma'_{xy}=-z'A\)。
由于 \(B\perp T\) 且 \(|B|=1\)，
\[
F=F_1+iF_2:S^1\longrightarrow S^1.
\tag{2}
\]

## 2. 由反射对称和两个端值确定 winding 的奇偶

令 \(P=2\pi/3\)。在本节所有量中：

- \(r,p,v,A,\Omega\) 为 \(\phi\) 的偶函数；
- \(p'\)、\(z''\) 为奇函数，\(z'\) 为偶函数；
- \(F\) 具有周期 \(P\)。

因此
\[
F(-\phi)=-\overline{F(\phi)},\qquad
F(P-\phi)=-\overline{F(\phi)}.
\tag{3}
\]
在 \(\phi=0,P/2=\pi/3\)，有 \(r'=p'=z''=0\)，所以 \(F_1=0\)；由 (1)，\(F_2\) 的符号与 \(A\) 相反。

极坐标曲线的平面曲率分子为
\[
A=r^2+2(r')^2-r r''.
\]
两对称点分别满足
\[
A(0)=(1+a+b)(1+10a+37b)>0,
\]
\[
A(P/2)=(1-a+b)(1-10a+37b).
\tag{4}
\]
故只要 \(1-a+b>0\)、\(1-10a+37b<0\)，就有
\[
F(0)=-i,\qquad F(P/2)=+i.
\tag{5}
\]

在半扇区选连续幅角 \(\alpha\)，使 \(\alpha(0)=-\pi/2\)。那么存在整数 \(n\)，
\[
\alpha(P/2)=\pi/2+2\pi n,\qquad
\alpha(P/2)-\alpha(0)=\pi+2\pi n.
\]
由 (3) 的反射，后一半扇区的幅角增量与前一半相同。具体可在 \([P/2,P]\) 取
\[
\alpha(\phi)=2\alpha(P/2)-\alpha(P-\phi),
\]
其指数恰为 \(F(\phi)\)，且在中点连续。因此
\[
\deg(F|_{\text{一扇区}})
=\frac{\alpha(P)-\alpha(0)}{2\pi}=1+2n.
\]
全圈由三个相同扇区组成，得到
\[
\boxed{\deg F=3(1+2n)\ne0.}
\tag{6}
\]
这里没有根据有限采样猜测 degree，也没有假设恰好等于 \(+3\) 或 \(-3\)；额外高模可能改变奇数 \(1+2n\)，但不能使它成为零而同时保持上述对称性和 \(\kappa>0\)。

## 3. 两个已认证参数组都落在此障碍内

对 \(a=13/20,b=3/25\)：
\[
1-a+b=47/100,\qquad 1-10a+37b=-53/50<0.
\]
对 \(a=3/5,b=9/100\)：
\[
1-a+b=49/100,\qquad 1-10a+37b=-167/100<0.
\]
因此上一轮六模连续证书的两个核心都满足 (4)–(6)。其已证 \(\kappa>0\) 正是定义连续 Frenet framing 所需的条件。结论不依赖六个高度系数的具体值或 SLSQP 的终止标志；同一对称类中继续优化高度系数不能解除此障碍，除非经过 \(\kappa=0\) 或离开这组对称/投影假设。

## 4. 为什么这个 degree 阻止开放平圆领连接

沿嵌入闭曲线取连续非零法向 \(V\)。足够窄的双侧 ribbon 的两条同向平行边界之间的 linking number，等于该法向相对零 framing 的 winding。这里 blackboard framing 是零 framing：水平投影是无交叉 Jordan 曲线，压平高度的同伦保持核心嵌入，blackboard pushoff 随之成为平面曲线的平面平行圈，其 linking number 为零。

也可在一个固定细管中直接验证 winding 贡献：将法向写为
\(\cos\alpha\,N_{\rm bb}+\sin\alpha\,M_{\rm bb}\)，每增加一整圈幅角，两条 ribbon 边界的 linking number 增加一；在圆形核心上可用平面圆盘的有向交点数逐次计数。连续变形及细管同胚保持这个整数。因此这里的两近圈 linking number 是 (6)，至多因选择相反的单圈方向改变总体符号，非零性不变。

R9 在准确材料坐标的中央满足
\[
X_\theta=a_0T,\qquad X_s=B.
\tag{7}
\]
所以它作为曲面内横向的中心 framing 正是 \(B\)。原始 ruling 表达中的 \(B+(\tau/\kappa)T\) 只多了切向分量，不改变法向 framing。由 (6)，任意足够近的两条核心材料圈有非零 linking number。

现在假设存在一个嵌入环带，既包含这个核心子环带，也包含某个开放平圆领。环带参数中的两条平行核心圈可以同时、保持彼此分离地移动到该平圆领中的两条同心圆；嵌入性保证这是空间中一对互不相交曲线的同伦，故 linking number 保持。两条平面同心圆的 linking number 为零，矛盾。

因此
\[
\boxed{\text{当前奇高度星核不能经嵌入 annulus 接到开放平圆领。}}
\tag{8}
\]
只检查局部度量、位置二 jet 或有限点的正常法弦无法发现或解除这一整数障碍。若允许连接区域改变成不同拓扑，必须重新分析；不能把 (8) 扩大为所有闭曲面或所有等距族的不可能性。

## 5. 零 framing 的明确替代：偶高度

若保持同一个 \(r\)，改为
\[
z(\phi)=c+\sum_j H_j\cos(3j\phi),
\tag{9}
\]
则 \(z'\) 为奇函数、\(z''\) 为偶函数，(1) 的两个分量都为偶函数：
\[
F(-\phi)=F(\phi).
\]
只要 \(\kappa>0\)，每个 \(C_3\) 周期的后半条像路精确反向走回前半条，故
\[
\boxed{\deg F=0.}
\tag{10}
\]
这只解除上面的 framing 障碍，不给曲率/reach 预算，也不自动构造封口。

偶高度不再具有原先交换 \(s\) 与 \(-s\) 的 proper 半转对称，不能原样使用 R6 的双半带镜合捷径。仍保留逐侧的镜面对称
\(X(s,-\theta)=\operatorname{diag}(1,-1,1)X(s,\theta)\)；
正负两侧 connector 需要分别求解并与同一个准确中央核心作全二 jet 匹配。若最终取得具有统一角独立度量、两个同轴开放圆领的完整嵌入环带，仍可使用统一相位旋转及固定同轴圆帽；本文没有证明这样的 connector 已经存在。

## 6. 审核范围

本证明是独立解析和拓扑核查；未运行新的几何扫描。另一研究代理已分别复算 (1) 的两分量、(3) 的奇偶、(5) 的端值及 (6) 的奇数 degree 结论。既有六模连续证书继续描述其准确局部核心，但不能继续将这些固定奇高度参数作为平圆领封口的可行候选。
