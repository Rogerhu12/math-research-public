# R674　真实材料接点的移动积分及 R654 第 23 个接受态续接

R654 的真实末态有 15 个物理材料段。四个停留时长在离开静止种子后仍为未知量。固定标准时间网格可跨过窄磨光段。旧工作网的十端为 1.11e−13，同曲线固定细网为 9.69e−7。这个差值已经超过原绝对 1e−8 门。它没有给出连续积分的误差上界，也不能单独归因为某一个接点。这里直接把每个接点放入每一层的积分边界，同时保留原来用于目标函数的全部位置与权重。[原始终态与费用](../notes/2026-11-28-r654-actual23-terminal-and-aligned-continuation.md)

## 移动前缀的完整导数

设材料段物理起点、时长、总长为 S,T,L。段内第 k 个子片标准时间起点及宽度为 a=(S+kT/n)/L 与 b=T/(nL)。n 按实际接受态固定为 max(1,ceil(64T*/L*))，细层逐段加倍。在片上取局部坐标 y∈[0,1]。以 16 个 Gauss 点与两个端点构造次数至多 17 的 Lagrange 基 lᵢ，Wᵢ(y)=∫₀ʸlᵢ。片总权重 wᵢ=Wᵢ(1) 为 Gauss-16 的原权重，两端权重为零，由 Gauss 对 17 次多项式精确直接得到。读数包括所有旧标准时间观测点，工作 1153，细网 2305，以及新积分所需的节点。

对任一物理速率 f，数值前缀为

    I = Σ已完片 bⱼ Σᵢ wᵢ fⱼᵢ + b Σᵢ Wᵢ(y) fᵢ.

求导依次包含全部已完片 bⱼ′Σwᵢfⱼᵢ+bⱼΣwᵢfⱼᵢ′、当前片 b′ΣWᵢfᵢ+bΣWᵢfᵢ′，以及当前上限 b y′Σlᵢ(y)fᵢ。材料节点的 y′=0，固定标准观测位置的 b y′=−a′−yb′。所有 fᵢ′ 都是移动取样点本身的总导数。其中全局扰动的 j 阶空间导数须加 F^(j+1)(x)x′，物理 j 阶速度还含 L^(−j) 的导数。材料节点的基底多项式以固定材料时刻求值，固定观测节点则使用 t=(Lx−S)/T 的全部导数。端点插值使相邻片对同一公共端点给出相同的 f。横跨片边界时，左片末端与右片起点的上限项一致，因而数学离散前缀在该交叉处仍可微。数值实现的长双精度值与 binary64 导数仍有舍入误差。

以这同一算子先积 η，再积八个 A，在正负两侧分别计算原 18 块真系数，最后积六个 ρ。令 E=(8A_t+2A_p,A_p,4A_s,8A_r) 取真实端点，四乘四 Eτ 在当前 q、τ 重建，解 τ_q=−Eτ⁻¹E_q。困难的情形报告未闭。将其代入 h,κ,η、速度、加速度、八个 A、长度与全块系数。六个 ρ 积分核的位移与宽度导数也须右乘 τ_q。取原固定读数行后，用原 R614 两个全局规范的带导数投影、正势与两个 ruling。积分内部的额外节点不改变原最小二乘行数、归一化或 Hermite–Simpson 的 65 个结点。源实际 q,τ 的第一份新 E 与 Eτ 单独保留，新四端校正只动当前四个真实时长。求出新的中心与规范后，才定义这次工作网的第一个完整目标值。

## 连续盒与近活跃高度

对每个材料小区间在有理数上将基底多项式及一阶导数限制到该区间，并转换为 Bernstein 系数，其最小、最大包住连续全区间。对标准时间中点 m、半宽 r 处的模态和，用 Arb 算 F(m),F′(m),F″(m)，其中 F 表示高度余弦或曲率正弦扰动。设 B_j=Σ|cᵢ|ωᵢʲ。任意 |δ|≤r，

    F(m+δ) ∈ F(m)+F′(m)δ+[−1,1]B₂r²/2,
    F′(m+δ) ∈ F′(m)+F″(m)δ+[−1,1]B₃r²/2.

先相加再包 Taylor 主项可保留近极值处的导数抵消。只有输入系数本身精确为零时略过该项。使用原轴向运动基底 h_B,k_B 的已知 η_B。原 η 积分在材料局部 t 坐标的修正速率精确为

    (η−η_B)_t = (T/L)G′/(2h) − (k_B)_t F/(2 h_B h).

按时间次序携带已积修正球，保留每个未闭叶及尚未访问的右侧栈。对源未闭候选只读其原 q,τ 与外包的原前缀球；对源已接受候选直接继承其独立完整五场证书。新候选从头证明所有连续物理盒，完全相同的候选重用其已付前缀或完整证书。原长度、h,κ,η,γ,υ、中心负支、质量行列式与正势的门均保留。已证越界与未闭合有不同记录。

取工作网固定标准时刻已实际观测的近下界局部极小值，用完整隐式 h_q 构成行 N。这里只用独立法向建立试探步。比较无约束完整 Euclidean LM 方向。需要内向时取 N d₀=δ1 的最小范数解，并在 ker N 的正交基 Z 上以完整 JZ 和 −r−Jd₀ 构造阻尼最小二乘。d₀⊥ker N 给出原欧氏惩罚的精确限制。严格提升若耗尽一阶下降，再解同一 JZ 的齐次切步，取带正内向系数且保持负斜率的凸组合。有限个近极值只影响方向；每个新候选依然通过上述连续五场检验、真实四端、全历史及原 actual-delta Armijo。新的局部阻尼从 1e−6、半径 .02 开始。原末态的 1.06e74 阻尼和全部旧费在源账中保留。

绝对工作与固定细读门保持 ruling≤1e−7、十端≤1e−8、反馈与 Hermite–Simpson≤1e−7，以及固定同曲线 η/A/ρ 两层改变≤1e−7。细读冻结最终 q、τ、八个中心和三个规范。离散层之间的一致性仍不是连续四端或全 ruling 的严格证书。R660 的双端固定闭曲面几何障碍仍成立；该必要 BVP 子问题的任何下降不单独解决 README 的存在性目标。
