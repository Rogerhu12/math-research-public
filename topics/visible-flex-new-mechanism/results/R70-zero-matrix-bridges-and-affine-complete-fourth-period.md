# R70：任意端点的准确零矩桥与全部第四周期的仿射圈数降阶

日期：2026-11-14。本文给出真实平滑桥的存在构造，并由 R62/R67 的完整历史恒等式消去所有第四相位周期的最高两次。来源审查代理已独立核对全相位传播；桥存在证明使用已发表 R37 的真实端点可控和八维有限 IFT，不使用未证的任意矩阵几何可达假设。

没有运行新的真实几何或 profile 计算。这里的对象是光滑闭合带的浸入数据；没有闭嵌入曲面、reach、大位移或有限等距族结论。

## 1. 任意端点、任意有限无迹矩阵的桥

**命题。** 给定两端 frame $F_0,F_1\in SO(3)$，两端常值状态 $(k_0,h_0,\omega_0)$、$(k_1,h_1,\omega_1)$，其中 $h_0,h_1>0$，以及任意固定 $M_*\in\mathfrak{sl}_3(\mathbb R)$，存在有限长度的 $C^\infty$ 桥，满足

$$F_s=F\Omega(k),\qquad h>0,\qquad \omega_s=k_s/(2h),$$

两端有指定的开常值 germ、frame 准确匹配，且该桥的完成分部积分后的低导数矩阵积分准确等于 $M_*$。这里不规定中心曲线的空间位移端值。

对固定端数据和矩阵目标的小邻域，可以选择同一个有限辅助整数圈数 K，并使构造按数据光滑依赖，保持 h 正性及所有需要的有限阶统一界。

### 证明：八个真实完整圆及独立于 K 的连接成本

采用 R62 的四个状态

$$(h_j,d_j)=(1,0),(1,1),(1,-1),(2,0).$$

在第 j 个状态安排两个常曲率圆，

$$k_{j,+}=1+\alpha_j+\beta_j,\qquad
k_{j,-}=-1-\alpha_j+\beta_j,$$

并令其常值 $\omega=(d_j+k)/h_j$。每个圆走 K 个**真实完整周期**

$$T(k)=2\pi/\sqrt{1+k^2}.$$

每个完整圆的末 frame 对所有邻近参数都准确回到入 frame；其位移一般不为零，但本命题不约束位移。这一准确周期规则避免了随 K 放大的末端 frame 导数。

令 $\mathbf p=(\alpha_1,\beta_1,\ldots,\alpha_4,\beta_4)$，$B(\mathbf p)$ 是八个圆各走一个完整周期的矩阵和。定义

$$w_j=((1+d_j^2)/(4h_j),d_j/2,h_j/4)^T,$$

$$u_j=(0,1/h_j,-2d_j/h_j^2)^T,\qquad
v_j=(-2,2d_j/h_j,-2(d_j^2-1)/h_j^2)^T.$$

常态矩阵密度为 $w_j\{(k^2-1)u_j+kv_j\}^T$。所以 $B(0)=0$，且令 $T=\sqrt2\pi$，

$$\partial_{\alpha_j}B(0)=4T\,w_ju_j^T,\qquad
\partial_{\beta_j}B(0)=T\,w_jv_j^T. \tag{1}$$

这些八列张成整个无迹矩阵空间。R37 的四本征线证明可原样使用：$u_j,v_j$ 张成 $w_j$ 的零化平面，四条 $w_j$ 的射影代表为

$$(1,0,1),\ (2,2,1),\ (2,-2,1),\ (1,0,4).$$

前三条独立，第四条在它们中三个系数都非零，故同时保持四条本征线的映射只有标量矩阵。等价的有理八列行列式为 $63/2048$，乘 (1) 的非零列尺度仍非零。

现在调用 R37 §4 已证明的真实扩展连接引理，把指定左端状态接入这八个圆、连接相邻圆、并由最后一个圆接到指定右端。中间圆的 frame 可取同一个固定参考 frame；最后桥的目标是实际 $F_1$。每个连接同时准确匹配 frame、k、h、omega，具有开常值端芽，并在参数零点附近光滑选择。

关键是这些连接依赖 $\mathbf p$ 和指定端数据，**不依赖 K**。因为所有长圆已经按真实周期准确返回，连接不需要补偿一个随 K 旋转的末角。

记所有连接的低导数积分和为 $C(\mathbf p)$。它及其有限阶参数导数在固定小邻域有界，与 K 无关。每段两端常值，所有 R7/Volterra 的 s 分部积分端项为零；R20 完成分部积分后的低导数密度给迹零。因此 $B(\mathbf p),C(\mathbf p),M_*$ 都属于同一个八维无迹空间。

整条桥的矩阵是

$$K B(\mathbf p)+C(\mathbf p).$$

定义

$$G(\mathbf p,\varepsilon)=B(\mathbf p)+\varepsilon\{C(\mathbf p)-M_*\}.$$

有 $G(0,0)=0$，且 $D_{\mathbf p}G(0,0)=DB(0)$ 可逆。有限维隐函数定理给光滑 $\mathbf p(\varepsilon)=O(\varepsilon)$。对任意充分大的**有限整数** K，取 $\varepsilon=1/K$，得到

$$K B(\mathbf p(1/K))+C(\mathbf p(1/K))=M_*.$$

这是有限 K 的准确桥，不是把 K 趋无穷的极限当作解。h 正性在小参数邻域保持。端数据和 $M_*$ 作为额外参数，同一 IFT 给所述局部光滑依赖；把 K 固定为一个足够大的整数即可。证毕。

## 2. 同一个真实 omega 与共同物理区间

上述连接不是逐段重置 omega。它沿同一微分方程从真实上一端值连续到达下一端值；每个常段的指定 omega 也由连接准确到达。辅助完整圆上 omega 恒定。

在取定有限 K 和小参数闭邻域后，所有连接与圆上的 omega 有统一有限上下界，h 有统一正上下界。因此对有限多个这种桥，可以在**整个构造完成后**选择同一个紧区间 $I=[l,r]$，使

$$\xi+\omega(s)\geq\delta>0\quad(\xi\in I),\qquad u=h/(\xi+\omega)>0.$$

这不声称能保持任意预先指定的很窄物理区间。选定 I 后，后续所有 profile 均使用同一 I；不得在各段独立平移 profile 或 omega。

本节只保证正则物理支和有限界，没有给任何 reach、全局无自交或宏观厚度。辅助 K 可能很大。

## 3. 真实零矩桥组及准确 R45 单 P

对每个需要的端点连接，取命题中的 $M_*=0$。因此每座桥的完整 second 算子 $\Phi_M$ 对所有同右锚 profiles 都为零；不是只让某一个 profile 的一个 scalar 条件为零。

安排四个 R62 正/负 bulk pair，每个外 bulk 走 N 个真实完整圆。它们之间所有连接均取上述准确零矩桥。起始/结束标量状态取同一个常态；中间连接可取准确 I 末 frame，最后的零矩桥可把末 frame 准确变为 $D=\operatorname{diag}(-1,1,-1)$。

此时单 P 的矩阵为零：每对外 bulk 的完整矩阵准确相消，每座桥自身矩阵也为零。单 P 同时具有真实 D 末 frame 及一致的常值端芽。用 R45 的 P、P、真实倒行 P、真实倒行 P 组装，frame、标量和中心线位移按既有精确恒等闭合，给平滑闭浸入带数据。

这里必须区分两个整数：

- 辅助桥圈数 K：先选定、完成每座桥的准确 IFT 修正并冻结；
- 外 bulk 圈数 N：此后改变的族参数。

K 不能随 N 一起放大，否则这些桥不再是 R67 的固定长度桥，下面的次数账就不适用。

## 4. 全部相位的第二/第三最高历史

固定任意两个光滑右 collar 为零的实 profiles f,g，令

$$\phi_\theta=\cos\theta\,f+\sin\theta\,g.$$

采用指定目标 $g_X+\varepsilon^2\,dY_f\cdot dY_f$ 的 canonical 第二/第三形式恢复。这里先讨论相应 range 表达式，不预先假设左右 collar、三矩圆或较低周期已经全部支付。

按 R62 的真实常态约定，第二/第三 scalar 历史满足

$$W_s=r(f,f)-r(\phi_\theta,\phi_\theta),\qquad
U_s=2r(\phi_\theta,W). \tag{2}$$

分成 N 次数，

$$W=W_0+Nw,\qquad U=U_0+NU_1+N^2v.$$

在固定桥上 w,v 不变。第二最高场为 $-Y_w$，第三最高场为 $-Y_v$。所以桥端更新及直接第四 $N^2$ 项是

$$\Delta W_0=\Phi_M(f,f)-\Phi_M(\phi_\theta,\phi_\theta),$$

$$\Delta U_1=2\Phi_M(\phi_\theta,w),$$

$$\Delta P_2=-\Phi_M(w,w)+2\Phi_M(\phi_\theta,v). \tag{3}$$

每座桥 M=0，因此 (3) 的三项全部为零。从同一个零锚开始，所有 bulk 的入 $W_0,U_1$ 都保持为零。桥内部这些低次量未必逐点为零，$U_0$ 与第四较低次数也未被清除。

## 5. 所有第四周期的三次、二次项准确消失

R62 在常态的完整 drift 分解是

$$R_4=-r(W,W)+2r(\phi_\theta,U)+J(f,\phi_\theta), \tag{4}$$

其中 J 与入 W/U 历史无关。它包括 mixed 恢复产生的局部项，不得删去。

常态 density 的 N 一次项由 (4) 恰为

$$-2r(W_0,w)+2r(\phi_\theta,U_1)=0.$$

乘 bulk 的长度 N 后，这正是其 $P_2$ 增量。因此所有 bulk 与所有桥的 $P_2$ 均为零。J 位于 density 的零次，贡献 $P_1$，并没有随此结论消失。

最高三角流为

$$w_s=d,\quad v_s=2r(\phi_\theta,w),\quad
p_s=-r(w,w)+2r(\phi_\theta,v),$$

其中 $d=r(f,f)-r(\phi_\theta,\phi_\theta)$。对匹配的 $k=+1,-1$ 同 $(h,d_{\rm geometric})$ 常态，真实等长下 $r$ 整体变为 $-r$。上述完整向量场遂整体取反；两个等时段是对任意入最高历史的准确逆流。固定桥不改 w,v，且其 density 至多 N 二次，不产生直接 $P_3$。故每个 pair 的三次周期相消，全词 $P_3=0$。

由 R67 完整第四周期本来至多三次，现得到

$$\boxed{\Pi_4(N,\theta,\xi)=P_0(\theta,\xi)+N P_1(\theta,\xi).} \tag{5}$$

这是所有相位、整个 xi 函数的身份，因而涵盖全部第四 Fourier 模式，而不只纯 $-4$。它不借助采样角度、范数拟合或两档数值相消，也不需要先用较低阶合法性假设将四块替成四倍单 P。
