This is an execution-state specification, not a new mathematical outcome
and not an instruction to run another scientific target. It applies only
if the actual fixed-eta0 correlated mean integral has an unfinished accepted
prefix. A complete target, including one whose gates are false or unknown,
must not be recomputed.

## 1. Immutable admission

A suffix entry must bind the exact original scientific output, its run and
execution receipt, the original scientific source, input manifest and exact
raw/metric identities. It must consume the saved complete decimal balls,
not their midpoints or displayed decimal signs. The mathematical target,
eta0, nu0, alpha, arithmetic precision, primitive convention, source degree
and whole interval stay the same.

If the original document already has complete=true and the final complete
stage, the mathematical target is finished. A failed publication or later
worker timeout requires only administrative recovery.

If all 7296 rows and 6143 joins are accepted but complete=false because the
process stopped before its final saved-ball decisions, the unfinished work
is only those decisions. No intrinsic carrier, source integration, old
prefix row or interface may be evaluated again.

An output without initial_D and the complete waist state has no accepted
scientific starting state. Its accepted-cell count must be zero. New work
then begins at the genuinely unfinished initial state, while all older
completed residual and Green targets remain read-only.

## 3. Exact cursor and one-sided interface state

Let s = completed_common_cells, let r be current_exact_right, and let k
be active_original_row. The original native supplies exact closed rows
[l_i,r_i], original candidate-piece indices and all original knots.

There are only two nonterminal accepted cases:

1. **Inside the first unfinished original row:** k=s and
   l_s <= r < r_s. Its interface_consumed_for_active_row flag belongs to
   this same row. When true, its left interface has already been processed,
   even if r=l_s and no subcell of the row has yet been accepted.
2. **At the end of the last complete original row:** k=s-1 and
   r=r_k=l_s. The saved flag belongs to row k, not row s. The next row's
   left interface has not yet been consumed.

The first suffix cell is [r,r_s] in case 1, subject to the existing local
analytic subdivisions. In case 2 processing starts at row s and its
actual left interface. Previously accepted subcells are not revisited.

The original 6144 candidate pieces are numbered 0 through 6143 and
each true candidate transition advances the index by exactly one.
The source therefore gives the additional exact invariant

completed_mean_interfaces = continuation_state.last_completed_piece.

This distinguishes the two legitimate states at the same original knot:
the old left trace has not yet paid the next atom, while the new right
trace has paid it exactly once. The suffix must verify the invariant
against the immutable candidate partition, not guess a count from a
loop variable or a partially attempted row.

When the original row ends at the current point, its current candidate
piece is the old one-sided piece. A new right-sided piece is used only
after the corresponding mean atom is consumed. The continuous W and Y
are retained, while D, n and m change according to the exact signed
join formula and the saved original raw traces.

All past multipliers and mean atoms enter G and A_D through their saved
current balls. Whole-prefix diagnostics and witnesses likewise have
finite scalar state. Consequently no old private high-order Taylor

definition bytes read-only. It may import the locked original consumer's

not recompute any accepted prefix flow, residual conclusion or old

## 5. Atomic acceptance and trace identity

The current consumer commits its state only in an atomic scalar output.
Its exception handler discards prospective in-memory changes, reads the
last committed document back and truncates any uncommitted private trace
tail to the saved byte count. A killed process leaves the same last
complete output available.

The original worker verifies the hash of exactly the saved accepted
trace prefix. A private file may contain additional bytes from an
interrupted, uncommitted append; those bytes are not scientific state.

A new suffix need not reconstruct or republish the old private trace.
Its receipt should retain two distinct segments:

- the original accepted-prefix byte count, record count and content hash,
  bound to its immutable original scientific output and run;
- the new actual suffix trace's byte count, record count and content hash.

A hash of their metadata is a metadata-chain hash. It is not the content
hash of the concatenated trace, which cannot be manufactured from the
two component hashes. The new complete record count is the sum of the
two accepted segments, with all new interfaces counted exactly once.

Final gates again use the complete scalar output after an actual
save/readback. A suffix's whole-positive flag includes the original
prefix lower bound and original witness history. No small positive
suffix can erase a failed or unknown original prefix.
