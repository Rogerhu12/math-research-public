# First whole BFP19 public entry

This is the first execution entry for the nineteen targets proved in
`results/R147-supplement-complete-target-normalized-nu-forward-column-by-pullback.md`.
It is an input and implementation record, not an actual numerical result.

The new manifest admits all 250 current and 53 historical original files.
Every whole file has its byte count and SHA checked. The original BNC
carrier closure is admitted without treating its failed execution as a
mathematical success. The original successful UACT21 actual and execution
from run `45933303391/1` are admitted with the original whole-file validator.
The original AS input, moving phase and carrier definition are common to
both admitted operator contexts.

The entry restores only the necessary original NP, AS-grid, B-row, IR and
Theta carriers. All original private SHA receipts remain mandatory. The
AS alpha suffix reuses the already restored entire grid and reproduces the
original rotation and source-phase expressions before reproducing the
original exact dyadics. A display-phase midpoint is not substituted. The
historical index and its shard siblings retain their native relative paths.
Old residual, norm, gap, cohomology and BNC observation targets are not run.

The new finite trial has all 512 positive coefficients and their conjugate
negative block. Its floating proposal comes from a periodic inverse
resampling and a positive-block solve; its accuracy is not assumed.
All 2560 coefficients of the exact finite forward B image are retained.
The full 8192-point pullback uses the analytic chain derivative of the
original H24 and K48 maps. Both quadrature and the entire analytic alias
tail enter the bound. Every source coefficient, image coefficient, point,
integrand, true-phase coordinate and signed pairing is saved and read in
full before its dependent target. Large reconstructible arrays remain
private to the Actions job.

The true B-column error includes both complete w-product candidates, the
H-minus-G density error and the true PDE density error. The Theta consumer
uses the entire original 96 by 2240 trial, its full global UACT error, the
full VQ error and every original signed model multiplier. It does not
replace a global error with the low-96 estimate. All 96 signed output
balls and both independent physical density means are retained.

Local validation is limited to AST parsing, descriptor and full-file SHA
checking, original metadata admission and verification that every required
input field exists. It imports no NumPy, FLINT or SciPy and evaluates no
scientific numerical target. Actual success or failure must come from
the new complete public actual and execution files. Even successful BFP19
bounds do not by themselves prove the full homogeneous inverse, the
physical mean/phase/height Schur map, or the exact closed family.
