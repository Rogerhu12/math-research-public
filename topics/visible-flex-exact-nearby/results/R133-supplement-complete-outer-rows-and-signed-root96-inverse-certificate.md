Let \(C_{96}(a_*,b,\kappa_H)=E_e^*P_\ell a_{*,2}\). Append this actual root coordinate to the complete finite relation:
$$
 \mathbb J_c=
 \binom{\mathbb T}{C_{96}}:
 \mathbb R^{289+m_H}\longrightarrow\mathbb R^{289+m_H}.
 \tag{WOB.26}
$$
Reorder \(a_*=E_cc+E_dd\), with \(\dim d=97\), and move the \(C_{96}\) row first. The matrix becomes
$$
 \begin{pmatrix}Id_{96}&0\\ T_c&\mathbb M\end{pmatrix},
 \quad
 T_c=\binom{D_c+\mathscr CGB_c}{W_0^*B_c},\quad

 \begin{pmatrix}
 D_d+\mathscr CGB_d&D_b+\mathscr CGB_b&\mathscr CU_0\\
 W_0^*B_d&W_0^*B_b&0
 \end{pmatrix}.
 \tag{WOB.27}
$$
Thus the signed inverse gates for \(\mathbb J_c\) and W96's \(\mathbb M\) are equivalent. No prescribed low even value has been replaced by a reference complement or a transported coordinate vector.

If the actual square gate holds, \(\mathbb T\) is onto: solve
\(\mathbb J_cz=(r,0)\) for each \(r\). Hence \(\ell=0\), and the kernel of \(\mathbb T\) is exactly 96 dimensional. Its true normalized physical columns are reconstructed from
$$
 z_c=\mathbb J_c^{-1}\binom0{Id_{96}}c,
 \qquad
 a_c=G(B_*a_{*,c}+B_bb_c)+U_0\kappa_c,\qquad

 \tag{WOB.28}
$$
They have \(P_\ell h_{c,2}(r_*)=E_ec\), zero high stable input and the full regular outer condition. Before a strict gate has passed, all \(\ell\) compatibility equations and extra kernel directions remain as in W96/WHS.

For an actual finite matrix enclosure, use inherited weighted Hilbert coordinates. In particular the outer \(b\) coordinate has weights
\(\Lambda_j^{-5/6}\), while the raw root and endpoint coordinates use the normalized \(L^2\) basis; means have weight1. Let
\(\widehat M=W_{\rm out}\mathbb M W_{\rm in}^{-1}\).

\(Id-Q_f\widehat M\) with its signed sum before taking absolute values. If \(E_{ij}\) bounds that complete residual entry, then

 \rho=\left[
  \left(\max_i\sum_jE_{ij}\right)
  \left(\max_j\sum_iE_{ij}\right)\right]^{1/2}<1
 \ \Longrightarrow\
 \|\widehat M^{-1}\|\le\frac{\|Q_f\|}{1-\rho}.

All row/column sums are complete. Means, finite crosses and all actual error enclosures enter before the comparison. No principal sign, interval determinant midpoint or entrywise choice substitutes for (WOB.29).

The entries in (WOB.27) still contain actual \(G,U_0,W_0\). If these are not certified, that version of the test is not yet executable. The following equivalent formulation removes that prerequisite rather than assigning an invented value to \(G\).

## WOB8. A complete residual certificate without first finding the head kernel

Define \(F_0=Id-V_0H\), \(H=A_L+B_{LH}\mathcal P_a\), and use every zero-IVP row from (WOB.24–25). Set
\(B_{d,0}=C_*E_d\), \(B_{c,0}=C_*E_c\). The actual unknowns are
\((a,d,b)\in\mathscr H\oplus\mathbb R^{97}\oplus\mathbb R^{96}\).
Define the complete square operator
$$
 \boxed{\quad
 \mathscr A_c
 \begin{pmatrix}a\\d\\b\end{pmatrix}
 =
 \begin{pmatrix}
 F_0a-B_{d,0}d-B_{b,0}b\\
 \mathscr C_0a+E_dd+D_{b,0}b
 \end{pmatrix}.
 \quad}
 \tag{WOB.30}
$$
Its exact right side, with the prescribed physical \(c\), is
$$
 \begin{pmatrix}
 B_{c,0}c+\mathcal B_0x+f_0\\
 g_0-E_cc-\mathcal D_0x
 \end{pmatrix}.
 \tag{WOB.31}
$$
The first row recovers the true low IVP with root head \(E_cc+E_dd\). The second recovers all193 remaining outer rows. No high boundary equation is duplicated. The same bounded endpoint row is used even before a trial head has a classical trace.

The operator \(\mathscr A_c\) is Fredholm of index zero. Indeed \(V_0H\) is compact on \(\mathscr H\), while every map to or from the additional finite spaces has finite rank. After any fixed identification of the two193-dimensional finite spaces, (WOB.30) is identity plus a compact operator.  \|Id-\mathscr Q\mathscr A_c\|\le\rho_c<1
 \quad\Longrightarrow\quad

 \|\mathscr A_c^{-1}\|\le\frac{\|\mathscr Q\|}{1-\rho_c}.
 \tag{WOB.32}
$$
The residual first proves injectivity; Fredholm index zero then gives surjectivity and the actual two-sided inverse. This criterion remains meaningful when the current coarse mesh test fails. A candidate \(\mathscr Q\) is not assumed to exist with a small residual.

## WOB9. A finite signed implementation and its necessary whole-tail rows

Here is a concrete projection-based realization of (WOB.32). It defines a new validation target; it does not call a failed mesh inverse. Let \(E_N\) be the normalized piecewise-constant embedding, \(P_N=E_NE_N^*\), \(Q_N=Id-P_N\), and put \(K_V=V_0H\). Split the input into
