# R61：全初值解析参考族与端点 Wiener 误差

2026-11-12，visible-exact-astra-f6a2。

**状态：解析验证定理及有限输入格式；实际连续残差仍待计算。**
本结果把 R60 的逐射线参考改成关于整个初值圆周全纯的有限参考族。
这样，初始误差由准确初始函数与参考函数之差给出。最终误差可以
从参考端点的有限 Fourier 系数直接进入 Wiener 范数，不先用有限
真射线取值的 DFT 来估计所有高频。

## 1. 明确定义的有限参考函数

记 \(S_S=\{x\in\mathbb C/(2\pi\mathbb Z):|\operatorname{Im}x|\le S\}\)。
在每个实时间段 \([a_i,b_i]\) 上，定义
\[
 Y_i(t,x)=x/4+U_i(t,x),\qquad q_i(t,x)=e^{L_i(t,x)},       \tag{61.1}
\]
其中 U、L 是时间归一变量
\(u=(t-a_i)/(b_i-a_i)\) 的有限多项式，且各系数是有限实 Fourier
多项式。负频率与正频率共轭，零频为实数。所有保存的实部/虚部
binary64 数或定点整数，均作为**准确有理系数**定义函数。

即便这些系数来自浮点 DFT、不同 dense 段的重参数化或拟合，式
(61.1) 仍是一个准确、可单独检查的参考函数。这里不声称它等于
那些输入节点的准确插值：构造过程的舍入已经进入所选函数本身，
之后必须直接对这个函数验证初值与 ODE 残差。

从不同时间段改用共同 u 时，如果新旧时间端点皆有理，时间差的
比值通常只是有理数，并非二进有理数；若端点含准确的π，则比值
通常也含π。可以保留准确符号系数并作有向求值，也可以明确重新
选择舍入后的有理系数并对新参考函数重新付残差；不得把后一种
选择说成与原 dense 多项式完全相同。

若使用偶数 N 点 DFT 定义实 Fourier 插值，Nyquist 模必须按
\(c_{N/2}\cos(Nx/2)\) 处理，等价于在正负两端各放一半系数。
只保留单边 \(e^{iNx/2}\) 会破坏参考函数在实轴上的实值性质。

对于复 x，q 一般不是实数，但指数表达式保证它处处不为零，且
\[
 q_t/q=L_t,\qquad |q|=e^{\operatorname{Re}L}.             \tag{61.2}
\]
这里 q 是所选参考权，不是已经认证的真实 Jacobian。

## 2. 允许复参考权的统一管定理

固定一个实参数紧区间 I。考虑复标量方程
\[
 Z_t=f(t,Z,p),\qquad p\in I,\quad x\in S_S,             \tag{61.3}
\]
场在所用状态管内关于 Z 全纯，关于 p 二次连续可微；时间方向满足
R60 的局部存在唯一性条件。参考 Y、q 对 x 全纯，在本时间段连续
且分段 \(C^1\)。允许它们依赖 p，但以下估计不通过对 q 求参数导数
来取得真实参数变分。

设 d 连续且严格为正，所有闭圆盘
\(|z-Y(t,x,p)|\le d(t,x,p)\) 都包含在 f 关于状态全纯的开域内，
并给出 \(|f_{zz}|\le B_2(t,x,p)\)。以下 A、B、C 均要求有限。定义
\[
 e_0=Y_t-f(t,Y,p),\qquad e_1=L_t-f_z(t,Y,p).              \tag{61.4}
\]
给出一致预算
\[
 A\ge\int_a^b\sup_{x,p}|e_0/q|\,dt,\qquad
 B\ge\int_a^b\sup_{x,p}|e_1|\,dt,
\]
\[
 C\ge\frac12\int_a^b\sup_{x,p}(B_2|q|)\,dt,\qquad
 r_0\ge\sup_{x,p}|Z(a,x,p)-Y(a,x,p)|/|q(a,x,p)|.         \tag{61.5}
\]
设
\[
 r=r_0+A,\quad \Delta=1-e^BCr,\quad R=e^Br/\Delta.
\]
若 \(\Delta>0\) 且
\[
 \sup_{t,x,p}\frac{|q(t,x,p)|R}{d(t,x,p)}<1,              \tag{61.6}
\]
则真实解对所有 x、p 存在于整段，并且
\[
 |Z(t,x,p)-Y(t,x,p)|\le |q(t,x,p)|R.                     \tag{61.7}
\]
如果初值对 x 全纯，真实解也对 x 全纯；四重角周期由唯一性保持。

### 证明

令 \(w=(Z-Y)/q\)。q 从不为零，所以准确商微分给
\[
 w_t=-e_0/q-e_1w+
 \frac{f(t,Y+qw,p)-f(t,Y,p)-f_z(t,Y,p)qw}{q}.
\]
复 Taylor 余项沿圆盘内线段积分，故
\[
 D^+|w|\le |e_0/q|+|e_1||w|+\tfrac12B_2|q||w|^2.
\]
这与 R60 的标量比较完全相同，且不需要 q 为实数。Bihari 比较
给出 R；严格管条件排除首次离开。局部全纯解由唯一性拼接，产生
全初值条带上的同一个解析族。若场周期为π/2且初值提升满足
\(Z(a,x+2\pi)=Z(a,x)+\pi/2\)，同一关系在整段成立。证毕。

## 3. 域、时间方向与初始误差

如果现有场证书只覆盖物理 \(|\operatorname{Im}\theta|\le\Sigma\)，
那么必须在**整个时间段与初值条带**核对
\[
 |\operatorname{Im}Y(t,x,p)|+d(t,x,p)\le\Sigma.           \tag{61.8}
\]
实轴上的 Y 值或有限复采样不足以支付此项。有限实 Fourier 参考的
虚部可用实轴对称性与导数范数估计，也可用有向复区间直接包络。
还须使用同一径向/参数对象的真实根与正则场，不能混用 rounded 图。

若实际 branch 的保存时间递减，先取正向变量 s，写 t=b−s，并把
场和参考导数同时乘以−1；积分用正时间长度。二者须使用同一时间
方向；同步变号后 e0/e1 的绝对值不变，可以复用其已有模长界。

转向端点若是准确 \(\pm\pi/2\)，须用这个准确数定义参考时间端点，
或者另付保存的 binary64 时间与它的差。不能只因为浮点 cos 值
接近零，就把两种端点当作完全相同。

若初值是准确 dyadic \(H(x)/4\)，则
\[
 E_0(x)=H(x)-4Y(a,x)
\]
是有限周期 Fourier 多项式，线性提升 x 完全抵消。设
\(0<m_0\le\inf_{S_S}|q(a,x)|\)，可取
\[
 r_0:=\frac{\|E_0\|_{A_S}}{4m_0}.                       \tag{61.9}
\]
右侧每个系数差按准确有理数/有向复模求值。这里没有实网格半距
费用，因为参考族已在全初值条带上定义；并非把中心射线视作整个
网格单元的准确解。

## 4. 分段和两腿的 Fourier 跳跃

在相邻时间段或两条腿的连接处，设
\[
 J_i(x)=Y_i(b_i,x)-Y_{i+1}(a_{i+1},x).
\]
J 是有限周期 Fourier 多项式。若上一段的误差界为
\(Q_{i,+}R_i\)，其中 \(Q_{i,+}\ge\sup|q_i(b_i,x)|\)，而
\(0<m_{i+1,-}\le\inf|q_{i+1}(a_{i+1},x)|\)，则下一段取
\[
 r_{0,i+1}\ge
 \frac{Q_{i,+}R_i+\|J_i\|_{A_S}}{m_{i+1,-}}.             \tag{61.10}
\]
若保留 x 相关的区间而非统一极值，可使用同一逐点不等式得到更紧
预算。真实解始终以同一初值 x 标记，不在第二腿另作未经验证的
角反函数。两个归一时间方向必须按第3节处理。

有限 reference 的连接误差包括重参数化、系数舍入及 DOP853 原始
跳跃的全部效果，因为这里直接比较最终所选的两个准确多项式。
不能在使用新 Fourier 参考时只复制旧单节点 jump 的数值上界。

## 5. 端点误差直接进入 Wiener 范数

记全部时间段完成后，外条带上真实端点误差满足
\[
 \sup_{S_S}|Z_b-Y_b|\le\varepsilon_\theta.
\]
令准确旋转位移为 \(\omega=2\pi\alpha\)，H 是当前固定的准确
共轭候选，定义
\[
 E(x)=4Z_b(x)-H(x+\omega),\qquad
 E_{\rm ref}(x)=4Y_b(x)-H(x+\omega).                    \tag{61.11}
\]
若旋转 α 为 R48 的明确二次无理数，其相位
\(e^{ik\omega}\) 用有向代数数、π和三角函数计算。E_ref 是有限
Fourier 多项式（包含实际常数项）；其系数由保存的参考端点与
H 的平移系数直接相减。线性提升的常数 −ω 必须保留。

对于 \(0\le s<S\)，有
\[
 \boxed{\quad
 \|E\|_{A_s}\le\|E_{\rm ref}\|_{A_s}
 +4\varepsilon_\theta\coth\frac{S-s}{2}.
 \quad}                                                \tag{61.12}
\]
证明：解析周期误差 \(D=4(Z_b-Y_b)\) 的 Fourier 系数满足
\(|\widehat D_k|\le4\varepsilon_\theta e^{-S|k|}\)。乘以
\(e^{s|k|}\) 后求和，得到
\(1+2e^{-(S-s)}/(1-e^{-(S-s)})=\coth((S-s)/2)\)。与有限
E_ref 作三角不等式即得结论。这个尾费覆盖了真实流的全部无限
Fourier 模；不是声称真实误差在参考截止频率以上为零。

同一外条带误差还给任意更小条带上的普通角导数估计
\[
 \sup_{S_s}|\partial_x^j(Z_b-Y_b)|
 \le j!\varepsilon_\theta/(S-s)^j.                     \tag{61.13}
\]
用于接 R31 时须再核实际 H/返回组成域与全部 Newton 中间线。

## 6. 参数变分仍需真实场输入

对每条真实解，以复参考权 q 除准确变分方程，R60 的参数估计仍成立：
将其中每个正 q 换成 |q|，并令
\(D=B+2CR\)、\(P_1\ge\int\sup|f_p/q|\)、
\(P_{12}\ge\int\sup|f_{zp}|\)、\(P_2\ge\int\sup|f_{pp}/q|\)。
例如
\[
 |Z_p|/|q|\le e^D(|Z_p(a)|/|q(a)|+P_1)=T,
\]
\[
 |Z_{pp}|/|q|\le e^D(|Z_{pp}(a)|/|q(a)|+2CT^2+2P_{12}T+P_2).
                                                               \tag{61.14}
\]
若初值独立于 p，\(J_p\) 的 R60 公式同样成立。没有把参考 q 对 p
的导数当作真实 Jacobian 参数导数。

真实场采用 \(r=t_*(p)\sin\tau\) 时，波项可写成带
\(\cos^2\tau\) 的正则形式。仍须把 t′、t″、固定 r 与固定 τ 的
区别以及 \(Q(s,p)\) 的全部链式项计入 fp/fpp。R58 的证书不能
自动认证这里每一个场参数系数。

## 7. 实际验证需要提交的有限输入

实际应用应冻结：同一 affine 对象/根/参数范围；各段准确时间端点；
U、L 的全部有理 Fourier–时间系数；准确初始 H 与旋转；每段
复像、非零分母、连续 e0/e1 和 B2 的有向预算；全部跳跃与参数源。

系数可以在任意算法中生成，但验证器必须以这些冻结系数为定义，
完整包括无限 primitive 和真实目标 E 的误差。径向 spline 的
不同真实 span 不可未经预算合并成一个解析片。对每段使用区间
Taylor、带余项的多项式运算或其他严格方法都可，单点 residual
探针和有限阶 ODE 公式不够。

本结果降低了有限射线覆盖整个初值条带的成本，却没有支付任何
尚未计算的连续残差。精确闭曲面的全频逆、真帽、非线性收敛及
本题全部几何比例仍须继续完成。
