# R149 ASQ2. The actual selected far trace and the common height origin

**Proved as a representation of the selected nonlinear branch and its
linearization on the stated domain.** The normalized nonmean far height
in [ASQ](R149-supplement-actualsquare-phase-amplitude-and-single-world-height.md)
is determined by the physical inner curvature. It does not introduce a
free finite amplitude or an extra mean condition. Its complete
differential feeds the core at the actual cut. This identifies which
exterior realization belongs to the selected core/phase problem; it does
not supply the inverse of the resulting feedback.

## Actual value graph

Take the original reflected physical cut $L=9/10$. Let
$\Psi(Q)=(B_Q,C_Q)$ be the complete moving-to-physical angle conversion
and $\gamma(Q)=P_{\perp,\theta}(C_Q-\widehat C)$.
Use the original real-even mean-free value domain of
[SCAP.3](R133-supplement-actual-selected-cap-and-complete-height-feedback-absorption.md),
including both its Wiener and $H^{8193}$ bounds. By
[SHL.3](R119-supplement-L2-response-of-the-actual-selected-tail-and-physical-readouts.md)
the actual selected solution satisfies
$$
 B_0w_\gamma=0,\qquad {\cal F}_\gamma(w_\gamma)=0,\qquad
 f_B=F_Bw_\gamma,\quad F_Bw=w(0)/s_B .
$$
In particular the far height is the endpoint value of the selected
exterior, with its actual 94-step seed, second parameter and first
principal response. By [S.8–10](R119-supplement-nonlinear-far-boundary-straightening-and-complete-graph-Nash.md)
the collar lift has zero boundary value and precisely the required
nonmean derivative. The selected state therefore has this same trace
and its true slope. Its mean slope is given by the same holonomy root.
At the inner endpoint $C_{\ne0}(L)$ is supplied by $\gamma$;
the actual odd $B(L)$ and $C_0(L)$ must match the core. In particular
no scalar endpoint coordinate arising from $F_B$ is available to solve
a curvature mean equation. The B-section scale is fixed on this branch.
A separately varied scale would require
$\dot f_B=(\dot y_B-f_B\dot s_B)/s_B$.

## Exact differential and the square interface

At fixed admitted base write $V_\gamma=Dw_\gamma$ in its original
domain, $G h=P_{\perp,\theta}D C_Q[h]$, and $T=F_BV_\gamma G$.
The cut variation $h$ contains its actual mean and angle correction;
the projection acts on the physical output. If the cut chart varies
explicitly with a parameter or independent source, include its full
variation $g_{\rm dir}$, giving
$$
 \dot f_B=T h+F_B V_\gamma g_{\rm dir}+s_f.
$$
Here $s_f$ denotes an independently prescribed additive far-height
perturbation when that larger forced problem is considered. In the
tangent to the selected unforced graph $s_f=0$. This extension is a
forced perturbation of the trace identification, not a claim that the
selected tail solves arbitrary interior forcing.

To see the row count before any unverified inverse, allow an independent
nonmean $y$ in a complete core equation $A h+B y=f$. Append the genuine
graph equation $y-Th=e$ with $e=F_BV_\gamma g_{\rm dir}+s_f$. Eliminating
$y$ gives $(A+BT)h=f-Be$. The substitution $y'=y-Th$ and subtraction
of $B$ times the second row are bounded triangular changes in the
qualified spaces whenever the named core trace is qualified.
They recover $y$ for every RHS of this graph equation. Thus the
far-height **function and its whole function-valued graph equation**
either both appear or are both eliminated. The fixed selected
realization has exactly the low, root, nonmean-phase and two scalar
slots counted in ASQ when the one absolute placement is free.
The same substitution is made in every signed body, jump, boundary and
world readout that depends on the far trace. In particular, the strict
parameter and source inherit their own trace contributions. Composition
must precede a positive inverse gate unless that gate already encloses
the composed graph. One must not append a second copy of $BT$ to an
operator already built with the selected derivative.

Specifically SCAP.13 at the inner end reads
$\mathcal P_{\rm sel}=\mathcal K_*+\mathcal L_*F_BV_\gamma$.
Its small additive bound applies to the original physical cap and
ordered 97 rows, and to CPA's corresponding weighted comparison as
proved there. It does not bound an arbitrary WOB inverse times $BT$,
the whole high action, or a general world receiver. SHL does not give a
surjective solution operator for arbitrary exterior PDE sources.
Such sources require their own graph solution and are not erased by
the preceding forced *trace* identity.

## Which height condition consumes a constant

S's same-section construction gives a single continuous joined
mean-height profile by integrating the original slopes and matching
the endpoint values. The exact difference of the values on two joined
pieces at that section is invariant under a common translation.
There is no remaining *relative* height origin. For the joined object
[SHT.2, SHT.19](R119-supplement-C1-physical-height-of-the-actual-selected-tail.md)
prove the independent fact $Z(\lambda)=Z(\lambda_0)+
(\lambda-\lambda_0){\bf1}$. Consequently one prescribed absolute
mean with $T_0{\bf1}=1$ fixes the common origin uniquely. Equivalently
one can first fix that common origin in the cap's world frame and
retain the actual predicted absolute core mean as an output. An
*additional prescribed* height in this latter convention is a
compatibility equation. The simultaneous transformation of both sides
is essential; shifting just one side would destroy the join.

For any two such physical means $T_1,T_0$, the span
$(T_1-T_0)Z$ has zero translation column and derivative
$(T_1-T_0)D Z$ with the actual endpoint/test variations if they move.
S explicitly keeps this span and reference height as geometric
outputs. If a further geometric problem prescribes a target span,
its residual and all endpoint contributions remain. The vector
counterpart in [GVC](R119-supplement-C1-global-vector-response-of-the-actual-selected-tail.md)
uses one fixed world orientation and one placement. A varying world
frame or position has its original derivative; it is not an independent
translation for each endpoint. Thus the ASQ scalar count is valid for
one absolute prescription and does not absorb a relative height,
second prescribed position, or fourth Robin equation. The final
same-world matching, geometric bounds, true cut entry and inverse
gates must still be established for a closed family.
