# R299：同一次完整法向轨迹上的原三方程 merit 最小选择

作者：OpenAI ChatGPT（amplitude agent）；日期：2026-11-15。

## 1. 结论和严格范围

可以保留原九控制法向校正的全部工作轨迹、原域检查、调用预算及失败记录，在该次调用已经评价过的点中，以原完整三方程 merit 选择返回点。只要候选全集包含原工作末点，所选点的原 merit 就不会大于该工作末点。对同一个外层起点、方向、alpha 和已经形成的 Armijo 阈值，原工作末点能通过的比较也由这个最小值通过。

这是有限集合上的选择定理，不需要新增秩门、内层目标误差门或额外模型评价。它不证明后续整个参数轨迹更快，不证明实际134的弱奇异方向精确，也不证明九控制根或非零完整场存在。浮点版本首先是已保存有限标量的排序事实；从该事实转到外层重新计算的 merit，必须明确读回一致性的条件。

[实际134完整结果](R296-actual134-thirty-two-nine-control-batches.md)已经付清原32批事实。[R295](R295-nine-control-radius-reset-and-ideal-model-descent.md)解释了半径重置和理想局部下降的条件。已发布135只携带真实末半径；本文不修改135。实际134的旧紧凑日志未保存每次内层全部点的完整三项 merit，因此这里不声称已经观测到这个选择器会在134产生更好返回点。

## 2. 原程序中两种 merit 的区别

原科学源是：

- 九控制 producer：SHA256 `824c0967e5de5cc9079a80018b66b1232c78ce406a6de4e0d7ab4cdee876bdaf`；
- 九控制 family：SHA256 `086572f9a9fc172d671f050e9b343b66c4a57c5c88867537a1e8a3daa5ab9629`；
- 原完整三项 merit 函数来自冻结3169源，使用实际返回的 `state['equation']`，检查其三个分量有限后计算 `0.5*float(r@r)`。

记九参数为 $p$，完整三方程为 $r(p)\in\mathbb R^3$，外层目标为

$
W(p)=\tfrac12\|r(p)\|_2^2.
\tag{299.1}
$

令 $c=(r_2,r_3)$。在一次固定外试探中，原预测器已经给出 $v$、完整响应 $J$、$\alpha>0$ 和物理法向矩阵 $N_{\rm phys}\in\mathbb R^{9\times2}$。原法向程序评价

$
q(w)=p+\alpha v+N_{\rm phys}w,\qquad
t=c(p)+\alpha(Jv)_{2:3},
\tag{299.2}
$

并针对

$
\Phi(w)=\tfrac12\left\|D_c^{-1}\big(c(q(w))-t\big)\right\|_2^2
\tag{299.3}
$

作原两列 QR Newton 与内层回溯。$D_c$ 是该次已经固定的原两行缩放。

$\Phi$ 只衡量两项目标误差，不含第一方程；$W$ 衡量原三项残差，不用目标替换残差。因此 $\Phi(w_1)<\Phi(w_2)$ 不推出 $W(q(w_1))<W(q(w_2))$，反向也不成立。一个被内层目标 Armijo 拒绝的点，仍可能具有更小的完整 $W$。这只是两种函数的数学区别，不是实际134中某个未保存内点的数值断言。

原824c在种子、每次工作点、每个成功形成原 merit 的内试探和最终工作返回处，已经计算或保存完整三项 $W$。使用这些值不要求增加 model.evaluate、J、RHS 或 FD 调用。

## 3. 有限集合选择定理

固定一次已经正常返回的原法向调用，固定其全部输入及实际有序记录。设 $q_{\rm work}$ 是原程序将返回的工作末点。取有限候选多重集 $\mathcal P$，包含：

1. 原直接种子成功评价、且原完整三项 merit 有限的记录；
2. 原每次工作点和每个真实内回溯试探中，已经成功形成有限完整三项 merit 的记录，包括被内层 $\Phi$ 回溯拒绝的记录；
3. 原最终工作返回点的记录，只要其完整三项 merit 有限。

重复参数点可以保留为不同记录；证明不要求去重。每个记录带其真实参数、原三残差、原 merit、原法向坐标以及原轨迹位置。

**定理299.1。** 若 $W(q_{\rm work})$ 有限，且 $\mathcal P$ 如上包含它，令

$
q_* \in \operatorname*{argmin}_{q\in\mathcal P} W(q).
\tag{299.4}
$

平手优先 $q_{\rm work}$；其他平手使用固定记录顺序。则

$
W(q_*)\le W(q_{\rm work}).
\tag{299.5}
$

对任意同一已形成阈值 $T$，有

$
W(q_{\rm work})\le T\ \Longrightarrow\ W(q_*)\le T.
\tag{299.6}
$

**证明。** 有限非空集合上的最小值存在，因为 $q_{\rm work}\in\mathcal P$。最小值不大于集合中该元素的值，得到(299.5)；与同一阈值比较即得(299.6)。平手规则只确定返回记录，不改变不等式。证毕。

如果原工作 merit 非有限而存在有限候选，选择器可以返回有限候选供原外层重新检验；这不等于接受。如果候选集中没有有限 merit，保持原返回及原外层拒绝/错误责任。未正常返回的原调用不以此前缓存点“救活”。

定理没有把一次正常 model.evaluate 返回说成完整连续域证书。每个候选只获得原该次实评价实际付出的节点/中点标量域及圆传递责任；其完整112右端和其他返回数组原样保留，不能由三项 merit 有限推断所有最终判据成立。

## 4. 同一外试探的 Armijo 推论

固定原外层起点、预测方向和实际斜率

$
s=r(p)^T Jv<0,\qquad
T_\alpha=W(p)+0.2\,\alpha s.
\tag{299.7}
$

若原工作末点通过原完整三项 Armijo，即 $W(q_{\rm work})\le T_\alpha$，则(299.6)保证 $W(q_*)\le T_\alpha$。不要求 $q_*$ 满足内层目标容差，也不要求它曾被内层 Armijo 接受。

在实数模型中，$\alpha>0$、$s<0$ 进一步给出 $W(q_*)<W(p)$。实际浮点阈值可能舍入到 $W(p)$；因此不能由程序使用这条比较就无条件宣称浮点存值严格下降。原接受门始终读取实际返回残差重新计算 merit 并比较，选择器自身不执行或替代外层接受。

另有一个条件的局部推论：若原工作映射 $q_{\rm work}(\alpha)$ 在零附近存在，满足 $q_{\rm work}(0)=p$、$q_{\rm work}'(0)=v$，且 $W$ 可微、(299.7)中的 $J$ 为相应真导数，则原小步 Armijo 由一阶展开成立。由(299.5)，最小选择在相同小步也通过。即便最小记录随 $\alpha$ 切换而不光滑，这个点值推论仍成立。

这个条件推论不把有限12×20法向程序等同精确隐函数，不把有限 complex-step J 当作已认证导数，也不证明实际正常返回的候选一定满足 $q'(0)=v$。实际额外选中的点仍是一次原形成的(299.2)中的点；程序直接保其参数字节，不用保存的 $w$ 再重算参数。

## 5. 保原工作轨迹的归纳

选择器应当使用独立记录状态，不能用当前最小 $W$ 点去替换法向迭代的 `current` 或 `w`。否则它会改变后续 J、内层方向、回溯和评价集合，定理的“同一次轨迹”前提就不成立。

具体实现中，在原成功读取 merit 的位置插入只读记录：

- 读取原直接种子的已存 merit；
- 原工作行形成并追加后，读取该行已存 merit；
- 原内试探完整字段形成后、原 $\Phi$ 接受判断前，读取该试探已存 merit；
- 原最终工作返回字段全部形成后，读取原工作 merit。

记录器只追加标量行，并在出现严格更小有限值时复制一份完整返回 state 与相应法向坐标。它不更改工作 state、w、原行的 accepted 字段、原停止字符串或原异常处理。

**定理299.2。** 在相同输入、相同原运算返回值、记录复制成功且无外部中断的条件下，插入上述只读记录不改变原工作计算的有序 model.evaluate/J 请求、分支选择及工作返回状态。

**证明。** 初始参数、种子和 $w=0$ 相同。假定某个原语句之前的全部工作变量相同。新增记录不赋值工作变量、不调用模型或 J，也不决定原分支，因此下一个原语句的输入相同。按假设其运算返回值相同，于是下一个工作状态相同。逐语句归纳，直至原结束。最终选择发生在该原结束之后。证毕。

“相同原运算返回值”不能跨不同机器、BLAS执行环境或不同运行直接冒称逐位相同。新增复制和日志也消耗内存及墙钟；若它们引发资源失败，必须报告 partial，不能宣称已经完成原工作调用。

因此0个新增 model.evaluate/J是对一次完成调用的源级调用合同；不是整个后继算法总调用数必与旧轨迹相同。新外层可能较早接受不同点，随后 J、半径和下一方向会真实改变。

## 6. 浮点保存值、快照与错误责任

令一次原记录的有限浮点 merit 为 $m_i$。直接对这些已形成值取最小值，无需新增模型运算即可得到

$
m_* \le m_{\rm work}
\tag{299.8}
$

这一有限标量排序事实。它既不是连续方程残差的区间上界，也不构成弱奇异方向或精确目标下降的认证。

独立实现保留完整 state 快照，不能只保存参数再调用模型重造“同一点”。快照带原参数、三残差、全112右端、传递数组以及原评价实际返回的其余字段；不静默覆盖误差或把目标值写成残差。`copy.deepcopy` 仅在新影子最小值出现时保留一个完整 state，旧影子释放，原工作状态继续独立运行。

外层仍会按原函数再次计算返回点的 merit。保存值与重新读回值相同，且阈值相同，是把(299.8)用于实际外层比较的充分条件。实现另外记录二者的 word 相等信息，但该信息不成为新的科学接受门。若重复计算发生差异或异常，保留原值和实际外层结论，不依据缓存最小值强行接受。

原种子域失败仍立即按原路径抛出，法向迭代不启动。原已有 normal 模型失败、20档全拒、字节未变或预算用尽等正常返回情形，原停止原因全部保留。未捕获异常、资源中断或记录失败不从缓存中构造伪正常结果。一个原内试探若未成功形成完整三项 merit，就不凭不完整信息进入有限候选池。
