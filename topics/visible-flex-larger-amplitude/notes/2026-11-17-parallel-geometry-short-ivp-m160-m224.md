# 真 .995 零补到 M160/M224：短 IVP、显式小步与角向 Gram

日期：2026-11-17。维护：`parallel-geometry-amplification`。

**状态：局部有限 IVP 的数值证据。M224 末端 Gram 降至 `1.132456e−6`，
仍超 `1e−6`。没有整段 BVP、与 M112 prefix 的 C² 接合或完成标准声明。**

## 1. 固定对象与默认大步失败

固定真 .995 的全部 M112 系数，零补到 M160、M224；固定原 N2048 完整
Frenet RHS、原 core 的 `rho`、同一 inward scalar，并只积分到 .997。
末端所有 Gram 用有限系数的字面 `F_s,F_φ` 在 8192 角读取。
本次不重算 Schur 分解，也不重新选择终端行。

默认 DOP853 自动首步在两种 M、两组容差下均在第一个**未接受步的内部
stage**触发 Q/W/H 域错误。最后有效积分状态仍为 .995；这不是后续 IVP
不存在的证据。该失败记录完整保留，没有夹断根号或修改 RHS。

为消除这一具体首步风险，显式设 `first_step=max_step=.002/64`。
四次积分均真正到达 .997；随后再把显式步长减半到 `.002/128` 核对。

## 2. 端点与步长对照

两组容差固定为 `rtol/atol=1e−12/1e−15`、`1e−13/1e−16`。
在每个显式步长下两组结果逐字相同，因为步长上限控制了轨道；**不把
这种相同当作独立积分收敛验证**。以下另列真正的半步长比较。

| 末端读数 | M160 | M224 |
|---|---:|---:|
| `.002/64` 的 Gram op | 2.13187714362e−6 | 1.13245601754e−6 |
| `.002/128` 的 Gram op | 2.13187714679e−6 | 1.13245602135e−6 |
| 两步长末系数最大差 | 6.66134e−16 | 8.88178e−16 |
| 两步长 Gram 差 | 3.17608e−15 | 3.80462e−15 |
| 末端最小采样 Q | .03766928358 | .03766932098 |
| 末端最小采样 W | .00020656233 | .00012833857 |
| 末端最小采样 H | .00020193852 | .00012371474 |

两者最坏角均约 `.434883553366`。M224 半步长的归一化 Gram 三项为
`rr=−7.97649e−10`、`cross=6.94235e−8`、`angular=−1.12819711e−6`；
主导项仍为角向误差。M160 没有改善原 M112 短 IVP 的约 `2.11128e−6`，
M224 才出现明显下降，因此这里只报告实际有限序列，不宣称单调收敛。

步长 `.002/64` 使用 65 个已接受节点、769 次 RHS；半步长版本为 130
节点、1549 次 RHS。浮点端点余量和步长吻合仍不是连续区间认证。

## 3. 与原 prefix 的接合仍缺失

增模时初始值严格由零补给出，故 F 值相同；但新有限 RHS 与其二阶导数
改变。在 8192 角上，相对原 M112 节点 jets 的最大变化是：

| 初始 jet 变化 | M160 | M224 |
|---|---:|---:|
| `max|ΔF_s|` | 1.03026337870e−6 | 4.63017741253e−5 |
| `max|ΔF_ss|` | .000864621983941 | .0141877211295 |

这些量不能当作零。当前短 IVP 不能直接作为与原 prefix 已完成 C² 接合的
延伸，也不作为接受的完整 BVP 父。输出显式标注这一边界。
