# 强核心 late-boost 前缀的圆柱图与近点对检查

2026-11-10，geometric_amplification。

**结论范围。** 已保存的强核心入口与 late-boost 段，在下面明确的共同两 jet 插值重建及采样网格上，具有正的圆柱投影角导数、正 Jacobian 和沿固定方位角的正高度导数。对原点的支撑量已经为负，因此旧星形条件不能直接用于此片；[R9](../results/R9-cylindrical-graph-global-embedding.md) 给出适合此片的条件嵌入路线。本记录仍是有两个边界圆的前缀数值检查，不是闭图、连续域嵌入证书或 reach 证书。

## 输入与实际重建对象

入口是 `alternative-hermite-k045-v025-s065-m64.json`，其核心参数为 $A=.38$，Hermite 速度参数 $k_0=.45,V=.25,S=.65$。late-boost 文件 `alternative-late-boost-025to065-m96.json` 接续 $s\in[.65,.85]$，将末速度提高至 $.65$。后者只保存晚段，不能把它单独当作含核心的整个前缀。本计算沿 `input` 链递归读取两段，并核对祖先 SHA256：

| 输入 | SHA256 |
|---|---|
| Hermite 入口 M64 | `6d3ef805cb86aa901e51dc936af3027f4cdb89866caae7bcfc23239361443be6` |
| late-boost M96 | `3d8ebf127aa956aaeee9b304aea842e1982940157a3a824366e6832d5f461ceb` |

每个保存节点的 Fourier 位置系数包含竖直均值。径向一、二阶 jet 由该段原 Fourier 截断的有限 ODE 重算；随后将两段提升到共同 M96，并在各保存区间上作五次 Hermite 两 jet 插值。$s=.65$ 处左右原始位置、径向一阶和二阶 jet 的最大样本差分别为

$$
0,\qquad 1.4211410\times10^{-11},\qquad
2.7340387\times10^{-9}.
$$

重建在该节点采用右段两 jet 作为共同值，故所得插值对象是 $C^2$ 的。这是一项显式记录的微小共同 jet 修正；插值对象不是一次新求解的有限 ODE 轨迹。原入口、晚段保存节点的度量样本残差分别约 $1.2342\times10^{-11}$、$2.2145\times10^{-11}$；本次密采样插值残差为 $2.3867\times10^{-9}$。

镜像按照 [R6](../results/R6-mirror-seam-nonzero-acceleration.md) 的带符号 $s$ 规则产生下半部，保持真实高度均值。在相位对比中，旋转核心的长轴点是实际像上的候选见证；本次仅报告其到原片点云的最近距离，不将点云最近距离误作连续曲面的距离下界。

## 圆柱投影检查

实现使用核心初始法向角 $\phi$。原度量材料角满足

$$
\frac{d\theta_0}{d\phi}=\rho_0(\phi)
=1-3A\cos2\phi+\frac{15A}{10\sqrt2}\cos4\phi>0.
$$

因此 $\beta_{\theta_0}=\beta_\phi/\rho_0$，$J_{\theta_0}=J_\phi/\rho_0$；两种角坐标下的符号相同。计算量为

$$
\beta_s=\frac{x y_s-y x_s}{R^2},\quad
\beta_\phi=\frac{x y_\phi-y x_\phi}{R^2},\quad
J_\phi=\beta_\phi z_s-\beta_s z_\phi,\quad
\left.\partial_s Z\right|_\beta=J_\phi/\beta_\phi.
$$

网格合并全部保存节点和 401 点均匀径向网格，得到 476 个不同径向样本，每圈 1024 点。只合并相差不超过 $64\epsilon\max(1,S)$ 的浮点重复值；最小真实网格间隔为 $.000125$。此前不合并末位重复值时，差商会把舍入误差除以伪造的 $O(\epsilon)$ 间隔，出现负数；修正后下表中导数及独立差商相互一致。

| 量 | 样本极值 |
|---|---:|
| 最小圆柱半径 $R$ | 0.5931299423 |
| 最小 $\beta_\phi$ | 0.1368447882 |
| 最小 $\beta_{\theta_0}$ | 0.6241796291 |
| 最小 $J_\phi$ | 0.1368447882 |
| 最小 $J_{\theta_0}$ | 0.1470555992 |
| 最小固定 $\beta$ 高度导数 | 0.1221050710 |
| 256 个固定 $\beta$ 上的最小径向高度差商 | 0.1222398681 |
| 最大 $|Z_\beta|$ | 0.1540034733 |
| 每圈样本绕数 | 1，浮点误差不超过 $2.3\times10^{-16}$ |
| 最小对原点支撑量 $F\cdot n$ | −0.5731938450 |

最小固定方位角高度导数和负支撑量都出现在晚段终点的短轴位置，约为 $(0,.9856827447,.6987795484)$。顶边高度的样本范围为 $[.6987795484,.8483629770]$；镜像上下边界在相同方位角的最小样本高度间隔为 $1.3975590968$。

R9 所需的全局条件不是仅有局部 $J>0$：每一圈还须一次绕轴且严格按方位角排序，之后才能对每个固定 $\beta$ 的整个 $s$ 区间积分正的 $\partial_s Z|_\beta$，得到全局单射。这里所有对应样本检查通过，但尚未给有限网格之间的连续界。把上表极值作为候选常数代入 R9 的矩阵范数，得到 $C\approx8.8650404$；这个数同样只是待认证常数，不是已经证明的连续 Lipschitz 常数。

## 曲率、直径与近点对

上半部有二重角对称，再加水平镜像使整张前缀中心对称。因此点云直径可由 $2\max|F|$ 精确得到，而连续曲面直径仍需控制网格之间的半径极值。

| 量 | 样本数值 |
|---|---:|
| 镜像前缀直径 $D$ | 3.2684075047 |
| 最大主曲率绝对值 | 6.1478876807 |
| 曲率半径 $1/K_{\max}$ | 0.1626574934 |
| $(1/K_{\max})/D$ | 0.0497665891 |
| 目标 $.03D$ | 0.0980522251 |
| 旋转核心长轴见证到前缀点云的最近距离 | 0.7600000000 |

近点对检查使用 311 条带符号径向圈、每圈 256 点，总共 79,616 个目标点；选取 41 个径向索引和每圈 64 个角索引，总共 2,624 个源 query。定义参数分离量

$$
d_0^2=(s_2-s_1)^2+(r_0d_{S^1}(\beta_2,\beta_1))^2,
\qquad r_0=.5931299423.
$$

对每个源 query，寻找满足指定 $d_0$ 门槛的最近目标。k 近邻列表触及上限而尚未找到候选的 226 项，已对完整目标云穷举回退，因此以下三列均无未决 query。

| 参数分离门槛 | 最小样本弦长 |
|---|---:|
| $d_0\ge.25$ | 0.2395105358 |
| $d_0\ge.5$ | 0.4773353484 |
| $d_0\ge1$ | 0.9301349203 |

另外对每个 query 枚举弦长不超过 $2(.03D)=.1961044503$ 的全部目标，得到 4,493,804 个非零有序近点对。对两个端点法向都检查

$$
Q(p,q)=\frac{|F(q)-F(p)|^2}{2|n(p)\cdot(F(q)-F(p))|}.
$$

最小样本值为 $.1628370195$，出现在 $s=-.77$ 与 $s=-.78$ 的同短轴附近，弦长 $.0099984287$，属于接近局部曲率极值的点对。没有检查到弦长 $\le.1961044503$ 且 $d_0\ge.25$ 的点对。

这些结果说明此有限网格没有暴露比局部曲率半径更紧的近点瓶颈。源 query 是子集，并非全部连续源点；网格间点对、端帽和跨片点对还未支付。环带边界的法锥还包含普通曲面法向以外的方向。因此，$.16284$ 不能被写成此有边片或未来闭图的 reach 下界。
