# 大核心新前缀到原固定尾的完整 scalar C² 连接及高度预算

已实际构造并检查一条无额外回环的 scalar profile 连接。输入是 geometry 主线 λ=1.2 的固定 415-knot profile 及真实 native M96 末态；本计算没有把非轴末态替换成圆，也没有求解新增段上的 Frenet 方程。它只解决“后续能否在合理轴向尺寸内以完整 C² 背景接口接到现有物理尾”的几何设计问题。

输入终点为 s=0.984、(a,a′,a″)=(1.1644225968293673,0.3699791680048837,−2)。真实输入均值高为 0.9627515186017743，非轴高度范围为 [0.8214554297988764,0.9833045077119383]，故均值不能代替整条空间纬线。

## 连接的定义及 C² 接合

令 φ₀=arcsin(a′₀)，初始角曲率 k₀=−a″₀/cosφ₀=2.15275972133223。先以连续的角曲率 k(s) 接续：一个 cubic smoothstep 从 k₀ 变化到 K，经过平顶，再以 smoothstep 降到零。两个 ramp 的相对宽度均为 0.08。总长度用 ∫k 精确归一，使末端 φ=−arcsin(0.985)。随后沿 a′=−0.985、a″=0 的 coast 到半径 0.35，再接原 K=7.5 的完整 finite bridge，最终到原物理 tail cut 半径 0.3。物理尾的全部参数及 radius/backgroundSlope/backgroundSecond/E/Ep 保持原值；finite bridge 的私有标签明确采用已有 A 的 K=7.5。

连续模型中定义 a(s)=a₀+∫sinφ、z(s)=z₀+∫cosφ，φ′=−k。因此 a′=sinφ、a″=−k cosφ；起点恰好恢复完整 incoming jet，末端 k=0 与 coast 的二阶 jet 相同。连接与 bridge 的所有新增 scalar 及背景 XYZ 的 0/1/2 阶接合都实际检查过，最大浮点差 2.531308496145357e−14。48→80 点 Gauss（在 ramp 边界分段）使全部采样半径/高度的最大变化不超过 5.56e−16。这是明确连续定义加浮点检验，不是 interval quadrature 证书。
