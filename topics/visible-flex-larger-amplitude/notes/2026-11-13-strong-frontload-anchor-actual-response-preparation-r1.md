# frontload 首段 anchor 修复后的生产与补列入口准备

原八列作业在已完成六列后因首段 `a0` 尚未由父 `append` 注入而退出 1。新 hook 只把该时刻的取值改为同一个首段入口 `self.aend`；原 hook 及冻结数学源未改。独立的实际非零 prefix 构造已通过 54 门，来源见本包计划引用的 anchor-fix manifest。

本包新增实际 BVP 入口和 fixed-J 响应入口。三个 source/reverse/AST 准备与一次真实接受包的 metadata 门均有 owned exit 0；准备阶段未启动新 Flow、J、Node 或 BVP。将来补列严格绑定原 q122 的固定 view、完整 raw、真尾和六列恢复包，只算缺失的 frontload/vd 两列。旧匿名 J/QR 已由原 finally 释放，故仅重建必要的一份完整矩阵，不重做六条成功外参数响应。新两列的完整与半步方向、forcing 都将立即保存。

旧六列的半步数组没有保存。保留原真实测量的单列半步门，后续组合不得把缺失数组或未测的八列组合半步差伪装成完整测量。所有方向只能作为局部设计和初猜数据，新候选仍须原完整非线性 H、边界、RMS 和物理审计。当前 M32 真求解继续占用唯一大作业槽，计划文件本身不会启动补列。
