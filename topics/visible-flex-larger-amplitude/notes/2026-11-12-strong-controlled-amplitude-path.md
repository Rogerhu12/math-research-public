# 大幅度主线：随 q 增长控制 c6，而不先在小 q 把 c6 调到零

这是下一批真实延拓的设计安排。所有新候选仍须实际求解；既有有限线性-DN
前缀没有变成闭曲面。父会话已采用的队列为 actual → root tol7 → 本分支
q=.09 → tail M32 同 H。这里只新增轻量代数分析和可执行命令。

## 1. 为什么先控制 c6 漂移，而不先追正 c6

当前成功基点为 angle vu=.32、q=.085、M20/N512：

\[
(c_2,c_4,c_6)=(.085,-.006010407640085654,-.00033755018199025175),
\]

delta=.15764858379009572、LB=.12244806104956663、vp=.8689804963021789。
核心相位支撑差下界约.16924，离约.8的目标差距主要在 q。

已核验的完整线性响应是在**另一成功基点** vu=.35、q=.085、M12/N256
上取得，不能当成当前点的导数：

| 外部方向 | dc6 | d(delta) | d(LB) |
|---|---:|---:|---:|
| actual q4 | .06313713444 | 5.92027300 | −5.93178511 |
| vp | −.001411596067 | −.597142669 | −.339387832 |
| vu | −.001625048423 | .813602488 | −1.115828779 |

等量抬高 c6 时，q4 方向缩短 boost，vp/vu 方向延长 boost；vp 同时增大
delta，vu 同时减小 delta。实际 vu=.34→.32 的 M20 两个成功解给出的
c6 割线为 −.001548279187，方向与旧导数一致，但 delta/LB 的割线已有
明显变化，所以旧矩阵只支持方向选择。

把当前 c6 一次抬到零，若错误地外推旧矩阵，会得到 Δvp≈−.23913 或
Δq4≈+.0053463。前者远超已试的小设计步，后者几乎抹去当前 q4；这些
都不是可信的有限步预测。直接把“c6 越正越好”当目标，会把大量计算
花在小幅 q 上。

优先路线是 q 增大，同时把 c6 保持在当前约 −3.4e−4 的小管道内。
待完整核心的曲率半径或 R7 预算需要时，再逐步抬高 c6 或改变 q4。
这比预先追到 R12 的正 c6 更少规定一个尚不必要的形状变化。

## 2. 存在一条具体的完整核心预算路径

这一步是平面支撑函数代数，不是前缀解的外推。取 vu032 已保存的全部
20 项实际 core 系数。令 q 从原值增加到 .402，q4 保持原线性律（保留
原存储舍入偏移），**所有频率6及以上的系数保持原值**：

\[
c_2(q)=q,\qquad
c_4(q)=c_4(q_0)-\frac{q-q_0}{10\sqrt2},\qquad
c_{2j}(q)=c_{2j}(q_0),\quad j\ge3.
\]

它不是 §14 中按谐波阶数幂律放大的 warm 初猜。用
\(\rho=1-\sum_j(4j^2-1)c_{2j}\cos2j\phi\)，两模部分的全角下界和高模
绝对值和给出

\[
\rho\ge1-\frac{3q}{\sqrt2}
 -15\left|c_4(q_0)+\frac{q_0}{10\sqrt2}\right|
 -\sum_{j\ge3}(4j^2-1)|c_{2j}(q_0)|.
\]

短轴点法向上的相位见证距离为
\(d=2\sum_{j\text{ odd}}c_{2j}\)。严格凸性保证旋转后的对应长轴点与原曲线
在此法向上的距离恰为 d；因此这是核心边界 Hausdorff 距离的下界，不
要求高谐波后的整个相位差仍恰在这个方向达到最大。

`strong_control_path_budget.py` 把原 float64 系数转为精确有理数，利用
可平方检验的 \(1/\sqrt2\) 有理区间计算端点界：

| q=.402 的静态完整20模核心 | 预算 |
|---|---:|
| 全角 rho 严格下界 | >.1216561145752399 |
| 浮点临界点求得的 rho_min，仅辅助显示 | .1322962951 |
| 指定轴向相位见证 d | .8032910944284353… |
| 按距离给出的未来直径预算 5d | 4.016455472142177… |
| k0 d rho(短轴) 的有理上界，k0=.45 | <.9479328009079470 |
| rho下界 − .03×(5d) | >.0011624504109747 |

这些不是网格采样证书。核心 rho 的简单下界沿路径递减，正的 d 与短轴
rho 沿路径递增，因此这些端点不等式控制整个**平面核心路径**。
它说明当前 c6 和已保存高模本身没有迫使我们先改成正 c6 才能获得约.8
的核心见证。

但真实 BVP 会重新求频率8以上的自由核心系数；它们未必保持这条路径。
此外 D≤5d 是未来整曲面的预算，并没有实测或证明完整 D、遮挡、reach、
尾和帽。尤其上述简单 rho 余量只有约.00116，不能浪费在未计的高模
漂移或连续误差上。实际求解后要重新计算完整 core 的 rho 和 R7 积，
不能拿这个静态表直接验收前缀。

R12 的正 c6 候选 (.4065,−.0278,+.00082) 仍保留为较大曲率半径余量的
后续目标；不在 q=.085 阶段先支付它的全部控制变化。

### C. 用新响应选择后续 q 步长

设在最新成功点重新得到
\(a_q=\partial c_6/\partial q\)、
\(a_b=\partial c_6/\partial q_4\)、
\(a_v=\partial c_6/\partial v_p\)，并令
\(b'(q)=-1/(10\sqrt2)\)。同图三控制的局部预测为

\[
\Delta v_p\approx
\frac{\Delta c_6^\star-(a_q+b'a_b)\Delta q}{a_v}.
\]

delta/LB 和全部自由核心系数按同一完整 Jacobian 响应线性组合，不能只
计算上式而忽略其余方向。旧响应文件没有 actual_q1 这一行；当前工具
已支持它，但尚未实算。因此此处没有填写虚构的 dq 响应。

取得最新响应后，q=.09→.10 是可审阅的下一候选；若控制增量超出刚验证
的局部尺度，则减到 .095。Δvp≈.02、Δvu≈.01、delta/LB约10%只可作为
初始信赖范围的工程判断，不是数学门槛。接受依然由完整非线性 BVP 和
实际几何决定。不能反复只靠减小 q 步长掩盖一个逐渐耗尽 vp 范围的方向；
若累计控制消耗明显，就刷新响应并改变物理形状方向。

## 4. q4 的角色和明确备选

q4 是有用的控制方向，但旧响应显示它为抬 c6 而缩短 LB，对当前仍紧的
boost 曲率不利。它更适合在接近强核心时调整完整 rho 分布，而非在小 q
用来把 c6 一次抬到零。

若 vp 方向的最新响应很弱、三控制条件恶化，已有
`strong_free_q4_bvp.py` 可固定 q1/c6、放开实际 q4，并仍只解 delta/LB。
从原成功 q=.09 双控制包作这个对照，实际比较所得 q4、完整 core 与
boost 几何；不从失败包起步，也不因 c6 达标就忽略其他模式。

当前 vu=.34→.32 的真实成功结果也保留为改变物理形状的有效方向。若
以后要把 vu 或一个 vp/vu 组合用作第三未知，须另设明确接口并验证真
Jacobian；现有 same-chart triple 的第三未知仍严格是 vp。
