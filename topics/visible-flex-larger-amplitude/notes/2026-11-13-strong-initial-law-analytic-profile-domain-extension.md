## 理想初段

把原配置中的二进制浮点常数解释为精确有理数。令 n 为固定次数、V 为 vu、k 为入口加速度、δ 为径向增量、λ 为初段前置权重。当前 n=22，0≤λ≤1。物理 provider 的理想长度 S 是

    B k S² + A V S − δ = 0,
    A = (1−λ)/2 + λ(n−1)/(n+1),
    B = (1−λ)/12 + λ/[n(n+1)].

A、B、k、δ、V 均严格正，所以多项式在 S≥0 严格递增且有唯一正根。新消费者用 96 次精确有理二分保存完整根夹。这里并不把 Python 的平方根舍入值当作精确根。

先把三次速度控制点 [0,kS/3,V,V] 用精确二项式公式升到 n 次；再与 [0,kS/n,V,…,V] 作权重 λ 的凸组合。每一控制点可写成 a_j+b_j S。消费者在整个有理 S 根夹上检查每一个相邻差非负。Bernstein 基函数的非负性和单位和随即给出 0≤v≤V；物理加速度控制点为 n(c_{j+1}−c_j)/S，逐项根夹给完整上界。两端的速度与加速度分别是 (0,k) 与 (V,0)。控制点总和还逐项核成

    S sum(c_j)/(n+1) = A V S + B k S² = δ.

因此理想初段半径由 1 单调到 1+δ。输出保存全部控制点的有理仿射系数，以及速度的归一化 u 导数和物理 s 导数 0 至 4 阶界。这里的速度多项式次数为 22、半径次数为 23；报告中原 angle-phase 的“四次”项只指其余显式角相位片，不能解释成新初段也是四次。
