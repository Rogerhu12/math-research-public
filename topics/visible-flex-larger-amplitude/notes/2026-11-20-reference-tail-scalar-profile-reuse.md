## 1. 可以分开的三层对象

同一准确 FullHold 标量问题给 $a(s)$ 与

$$I(s)=\int_s^S\cos\alpha(v)\,dv.$$

在 R674 的准确解析 piece $P=[\ell,r]$，取准确符号中心 $c=(\ell+r)/2$。
端点仍是原来的 $\alpha S+\beta$，不能将浮点 carrier 或 cell 编号当成数学身份。

依赖分为三层：

| 层 | 可保存的严格对象 | 数学输入 |
|---|---|---|
| 锚 | $a(c),I(c)$ 的向外盒 | 原标量定义、准确符号点 c |
| 共用 Taylor jet | A/J 的 0、1、2 阶 Bernstein 多项式与各阶余项 | 上一层、准确 piece、实际解析段、degree、向外核 |
| 仿射 profile | f/h/k/z 的 0、1、2 阶控制点及余项 | 上一层、lambda、准确 eta 两端、chi 宽度、S/R；z 还依赖准确 H |

第一、二层与 q、core 角函数、H、M、lambda 和 eta 无关。
第三层 f/h/k 与 q、core、M 无关；但 z 必须包含当前准确 H，因为

$$z=Hh+k=(1-\lambda)H\chi-\lambda\eta(I-H)$$

是在取界之前完成的真实相消。不能把不同 H 的旧 z 控制点当成当前场的 z。
H 改变时，A/J 仍可复用，重新形成仿射 profile 即可。

## 2. 直接复用为什么仍严格

假设先前一次公开计算已经给出同一准确输入的区间对象 $B$，且证明它包围所声明函数或余项。
后一次计算仅在完整数学输入相等时直接读取 B 的原有端点，则它仍包围同一个对象；后续已有向外基本运算仍然有效。
这不要求前后候选 q 相同，因为 q 从未进入 B 的定义。

完整输入键至少包括：

- 原标量输入 SHA、FullHold/integer/Hold 与 R657/R674 计算源身份、实际区间算术源；
- 准确 S/R 盒、实际解析段和两个准确符号端点；
- Taylor degree；
- 对最终 profile，追加 lambda、eta 两个符号端点、chi 宽度、old-chi-active 分支与准确 H。

保存的原报告、原节点报告、原 bundle/model SHA、所用 oracle 参数作为生产来源保留。
某个较粗 oracle 得到的盒仍然是严格盒；将它用于后续不自动获得更窄 oracle 的精度。
如果要求后续配置的逐字同计算结果，oracle panels、锚来源与所有舍入配置也要纳入键；如果只要求继续严格，旧盒可保留，但必须记录实际使用了哪个已付盒。

缓存输入必须以实际文件 SHA 显式传入，文件内保存完整键、生产源和无损端点。
缺失、键不匹配、身份不匹配时调用原完整核，不把“无缓存”计作科学成功。
raw cache 只留本 job 工作目录，不入 Git、Release 或分块转运。

## 3. 同一 Taylor jet 的 0/1/2 阶仍不可分开伪造

设 n 阶共用 Taylor 多项式为 A、J，R674 已给

$$|a^{(j)}-A^{(j)}|,\ |I^{(j)}-J^{(j)}|
\le \varepsilon_j={B_n\,R_P^{n+1-j}\over(n+1-j)!},\qquad j=0,1,2.$$

缓存应将这个共用 jet 与三个已经证明的余项一起保存。
导数多项式仍由同一 power 系数解析形成，然后转 Bernstein；不能对含共同 a(c)/I(c) 区间的 Bernstein 控制点作差分来声称得到新的紧导数界。

profile 的标量误差仍按

$$e_j=\lambda\sum_{i=0}^j{j\choose i}\|\eta^{(i)}\|_{\infty,P}\varepsilon_{j-i}$$

支付。角向六 jet 的完整 Laurent/Taylor 费用、实际 q 三 jet、core 变化与归一形算子照常在当前场计算。
复用标量多项式并不准许删除高角模或将 $(a,I)$ 当成准确多项式。

## 4. 径向精化时哪些键还能命中

R676 可以改变 cell 编号、原胞数量和 M，同时保留同一个准确标量问题。
若新 piece 的实际符号端点与旧 piece 相同，其 A/J 仍是同一数学对象；把生产 node SHA 作为来源，而不把旧 cell 编号作为当前坐标。
M 补零与 core 改变也不改变这一标量身份。

需要避免旧 R657 legacy 路径的一个差别：在 eta 尚未激活的旧段，`Scalar.approximation` 可以从当前 node/mid 列表选择不同的旧锚。
那里如果要复用具体 Taylor 对象，必须另外绑定实际锚；最小实现可以完全不缓存这条旧段分支，先只缓存新解析 tail。
这保留了当前 f122 旧段行为，并直接针对新增 oracle 成本。

如果子 piece 比旧 piece 更小，**仅限制旧多项式并不能自动把余项中的半径改小**。
直接限制时仍付旧统一余项。

一个合法但未实现的进一步方案是：在新中心 $c'$ 计算旧 A/J 多项式的向外值，并加旧 C0 余项，得到 $a(c'),I(c')$ 的新锚盒；然后由准确 alpha 的新中心 Taylor jet 重建新的 A/J，并用新 piece 半径证明新余项。
此时旧 C0 锚不确定性仍保留在常数项中，不能丢弃；导数 jet 的常数项消失只来自准确解析微分，不来自“误差变小”的假设。
所以该方案可能让导数余项变紧而 C0 锚盒仍较宽，需要按实际数据选择，不能预告它优于一次新整数 oracle 查询。

## 5. first 到 curvature、metric 的复用边界

同一准确 piece、同一 H 的 first 和 curvature 构造使用相同 f/h/k/z 的 0/1/2 阶 profile；first 只消费其中一部分。
角向 Q 和保留 Laurent 低模数改变，不改变这些径向标量控制点。
因此二者在相同 piece 上可以无损复用全套 profile；metric 使用同一 A 时也可复用其 target-a 多项式与已付余项。

但完整六 jet、Gram 与曲率仍要使用当前 q/core 重新构造。下面不是标量缓存可继承的对象：

- 完整有限 Fourier 系数与 core 的 rho、rho-prime、解析 $e_r(\Theta)$ 乘子；
- 当前场 X/V/T/AA/VT/EE；
- E、法向平方、支持、直径、见证距离、主曲率与全部比例；
- 任意求解父的接受状态或已有证书标签。

f122 已允许曲率消费 **同 actual bundle/node/model 的完整 first 报告** 来复用 E/法向平方下界。那是另一条已经明确验证同一场的接口，不能与这里跨 q 的纯标量复用混为一谈。

## 6. 可说明的成本与尚无的数据

如果某组 P 个解析 piece 都访问径向 levels 1、2、4、8、16，字面上共有

$$P(1+2+4+8+16)=31P$$

次对应中心/profile 请求。第二个消费者访问完全相同的这些 piece 时，可以复用已付条目；实际自适应 pending 集合不同则只能按真实键交集计数。
这只是调用数关系，不是时间预测。

本轮没有做缓存性能试验，也没有测量 a/I 锚、角变换或形算子分别占用多少时间。
FullHold 对象的初始化与源码/定义检查仍须进行；当前设计不跳过它们。
大部分原胞也可能不在新 tail 的 eta 支撑内，因此不能把全场成本都算作可以消除的新增标量成本。

后续若实际采用独立缓存 wrapper，它必须给新的 source SHA 和执行层身份，报告原 f122 kernel SHA；不能把新 wrapper 报告冒成 f122 原字节的输出。
当前 R675 与新几何合并器只绑定已刊 f122，没有因此自动支持新的缓存生产源。
