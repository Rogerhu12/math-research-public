# q098/M28：实际接受后的物理尺寸与振幅预算

## 本条结论及其范围

原实际非线性 BVP 已正式 `exit 0`，最终审计不是待补状态。完整结果和资源见 [2026-11-13-strong-q098-accepted-recovery-manifest.json](2026-11-13-strong-q098-accepted-recovery-manifest.json)。本条只评估这个新的 q098 设计点。它与 q096 的物理剖面不同，不能把两者之间误差的变化叫作同一 `g` 的加密收敛。

在完整 28 模核上，轴向支撑函数差为 **0.19512909318712157**；对当前中央对称候选前缀，采样尺寸 `S = 2 max ||X||` 为 **3.925501732144566**，比值为 **0.049708064472186425**。这仍只约为目标 `0.2` 的四分之一。若尺寸保持不变，所需 gap 为 `0.78510034642891324`，还差 `0.58997125324179167`，约需把当前 gap 增至 `4.02349200524` 倍。这里没有把参数 q 本身当成几何幅度。

`S` 来自全 3387×768 共同网格，完整均值使用原 1360 角及 Gauss 6。对于真正中央对称的连续前缀，其直径等于 `2 sup ||X||`，但这里仍只采到了有限网格；尚未接上的完整无限尾和闭合面也不在此尺寸证明中。核支撑差尚不是全闭曲面的 held 下界。由此本条不宣称达到 README 完成标准。
