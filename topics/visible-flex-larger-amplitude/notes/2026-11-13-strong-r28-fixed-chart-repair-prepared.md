# R28 到当前固定 g 保存包的精确消费接口（准备态）

本条复用已有 [R28](../results/R28-exact-quintic-seam-repair.md)，不另立普适修复定理。新入口是 `computations/strong_r28_fixed_chart_repair.py`。源码尚未在本地 Python 执行；没有读取或推测尚未完成物理后处理的 M28 系数，没有产生新的曲面数值。

## 1. 与既有 R28 完全相同的对象

输入必须是经过原 actual/full-H 验收的 fixed 物理包。复用 `strong_sameg_continuous_finite_field.load_field` 的完整门：物理与原始 t 网格、全部六个五次系数、所有 Fourier 状态行、各 gzip 块 SHA/尺寸/布局、fixed raw 及原角参考。所有浮点节点和系数都解释为其精确二进制有理数。

内部节点的目标仍为原左右两侧 0、1、2 阶 jet 的精确平均，外端目标仍为原单侧 jet。没有换成单侧修复，也不改变 R28 的 Bernstein 常数或角权。

每个物理区间上，程序按 R28 公式 (2.1) 实际生成**有符号精确有理系数**，逐段输出给惰性接口：

`repaired_intervals(field)`

每一项含原多项式、修正多项式、修复后多项式及三阶误差上界。系数按物理 $s-s_i$ 的升幂排列，不是归一化区间坐标系数，也不再舍入为 binary64。

程序用实际完整输入验证：

- 每个状态分量的六个端点条件都是精确有理等式；
- 每个相邻区间共享同一值、一次导数、二次导数；
- 两个外端的全部两阶 jet 与原单侧多项式严格相同。

这里保留的是**原保存多项式的精确单侧外端 jet**，不能把它换称原 PDE 或尾部的精确边界解。原有限端口偏差及完整 Cartesian seam 仍单独支付。

## 2. 新增加的消费输出

仍逐段使用 R28 (3.1)，不把不同区间的局部长度换成一个不安全的平均值。输出包括：

1. 全部状态分量的 0、1、2 阶修复界及最大值位置。
2. $E_{00},E_{10},E_{01},E_{20},E_{11},E_{02}$ 的完整 Cartesian Fourier 界。
3. 同一角权对径向一次误差的 $E_{12}$ 界，供已发布的完整高度均值混合 AD 消费器使用。
4. 原精确 q096 角图传递矩阵的六项物理两阶误差，不将计算角当材料角。
5. 原精确接缝跳量、全部端点等式计数、按原区间顺序累积的完整有理系数流和界流 SHA。

角图证书固定为：

`notes/2026-11-12-strong-q096-fixed-chart-transport-exact.json`

SHA256 为 `da4709e9bfdc6330e440c8a69a556ddd760ffd364bb05fa45a4caf28eff4e618`。必须实际匹配物理总长、两个参考系数、频率与完整过渡范围；不能将它借给新的 metric/profile。

旧 R28 使用的安全角权为：径向 mean 行权重 1，径向/切向频率 $m$ 的一次权重 $m+1$，高度频率 $m$ 的一次权重 $m$；二次权重取其平方。本入口保留这些原界，未以新的较小权重替代。

## 3. 明确未支付的部分

修复改变有限场的表达式，一般也改变诱导度量。程序只声明规定的背景 g 和角图没有改变；**不声明诱导度量保持不变**。已接受原数值包不被改写，旧物理误差门不自动传给修复后的映射。

高度 mean 仍须由同一完整速度和平均泛函处理。若要在修复后重建精确 mean，应把这里的 $E_{01},E_{02},E_{11},E_{12}$ 及有符号区间交给已有 mean 同伦消费器，实际核正性和全盒覆盖，再将 $A_0,A_1,A_2$ 加到物理 position、s、ss 行。此处不把它们置零。

同样，若共同背景本身是有未付误差的浮点分段公式，它仍需要独立的连续参考与误差界。本入口没有证明精确等距、无限尾匹配、完整闭面或 reach，也不把两个有限分辨率之间的差称作到真实解的误差。

## 4. 实际执行顺序

环境恢复后，先完成原 M28 全尾审计及 0-Newton 物理后处理。随后分别对已接受的 fixed24 包和真正完成的 M28 物理包执行本入口；不能把旧 q0775 的 R28 数值挪给这两个输入。

M24 命令（题目目录为 cwd）：

```text
python computations/strong_r28_fixed_chart_repair.py \
  --input notes/2026-11-12-strong-q096-sameg-m28-local-recovery6-r1-fixed24.json.gz \
  --chart-certificate notes/2026-11-12-strong-q096-fixed-chart-transport-exact.json \
  --out notes/2026-11-13-strong-q096-fixed24-R28-chart-r1.json.gz
```

M28 使用实际成功 summary 所指向的物理主包，另取全新输出名。本工具不接受 raw-only 状态作物理包。

依赖为原 Python/NumPy 与 python-flint；没有 Flow、RHS、Newton、Node 或真实尾求解。预期是单次低内存有理消费，不应与唯一大计算重复启动。当前仅已完成文本/来源核对，Python AST、实际端点计数、运行资源和新数值都保持 **尚未执行**。
