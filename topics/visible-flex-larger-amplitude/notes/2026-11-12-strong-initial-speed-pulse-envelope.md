# 初段速度 pulse：完整背景前缀包络与曲率界

## 范围与物理身份

本笔记继续 `2026-11-12-strong-initial-speed-pulse-budget.md` 的新轮廓。
参考是已接受的 q095 actual M24 解
`2026-11-12-root-q095-design-fixed-actual-m24-tol7-frozen-r1.json.gz`。
这里只用其冻结物理轮廓和 cut 数据，不评价非轴对称解的场。

新 pulse 保持第一段的初始半径、初始零斜率、初始加速度
`k0=.45`、总半径增加 `delta`、末速度 `V=.32` 和末加速度零。
第一段长度由

\[
 k_0 S_b^2/12+(V/2+16b/35)S_b=\delta
\]

确定，速度是

\[
 v_b(t)=Vt^2(3-2t)+k_0S_bt(1-t)^2+64bt^3(1-t)^3.
\]

这改变物理度量。其后原 boost、first turn、下降、loop 和 bridge
的半径曲线与速度完全保留；只把它们的经向坐标和平面以上高度
分别平移第一段长度、第一段高度的变化。
本条有限设计没有重新固定实际核心系数，没有解新的 prefix 或尾，
也没有声称实际挠曲曲面继承这个背景直径或曲率。

## 完整有边背景的包络筛选

`strong_initial_speed_pulse_envelope.py` 加载原 provider，逐段评价原
半径、速度和背景高度。新第一段用上述显式多项式。
每段 1025 个参数样本，批量 16；包括 terminal bridge。
baseline 的总物理长度与接受包的长度逐值相等。
该作业正式 exit 0，16.072 秒，峰 64024 KiB；
没有 Flow、RHS、Jac、BVP 或 Node。

每个最大包络样本都在第二个 loop turn，不在最高点。
因此不能只用两倍高度替代这项包络检查。
经线为单位速度，`||(r,z)||` 对弧长 1-Lipschitz；本样本的

这只支付样本之间的距离，不支付原数值积分的区间误差。

尾部与帽仍需另行支付。若其半径不超过 rCut、在 cut 以上的
背景高度增加不超过 B，则相应圆柱包络可用
`2 sqrt(rCut²+(heightCut+B)²)`；本次没有计算或假设 B。

## 前缀及 bridge 背景曲率严格小于 8

第一段的五个 b 已由先前精确有理 Bernstein 证书覆盖。
以下给其余原段一个独立、较松的连续界，不用曲率样本。
所有参数按接受 JSON 的二进制浮点值视为精确实常数；
下面展示的小数只供阅读，完整有理数在
`2026-11-12-strong-initial-speed-pulse-background-bounds-r1.json`。

写原 flat-turn ramp 比例为 e=.08，loop 半径 r=.35，
速度 vl=.985，曲率参数 K=7.5。
对轴对称单位速度经线，主曲率为

\[
 |\kappa_s|=|\phi'(s)|,
 \qquad |\kappa_\theta|=\cos\phi(s)/r(s)\le 1/r(s).
\]

原角速度 ramp 在 0 与 1 之间，故每个 turn 的经向曲率
不超过其 K。精确有理交错 Taylor 界给出
`asin(vl)<1.4`、`asin(vp)<1.05`、`acos(vl)<.18`、
`acos(vd)<.21`、`acos(vl)>.1`。
`sin` 用七次下界，`cos` 用四次上界或二次下界；参数均在
交错项递减的范围。脚本逐项验证严格正裕量。

1. **boost。** `asin(V)>V`，故其曲率小于
   `(1.05-V)/(LB(1-e)) < 6.374 < 8`。它的半径单调增加，且大于 1。
2. **first turn 与下降。** 两个端点角均在 `(-pi/2,pi/2)`。
   turn 长度小于 `pi/(6.75(1-e))`；用 `pi<22/7`，其半径严格大于
   `0.4939038417`。后续 sync 长度小于 `.21/(2(1-e)) < .114131`，
   所以其前 coast 的目标半径小于 `.35+.114131`，严格低于
   first-turn 末半径；coast 长度为正。sync 与下降 coast 半径均不小于 .35。
3. **loop。** 从 `-asin(vl)` 转到 `asin(vl)` 的相位关于中点反对称，
   总径向位移为零。中点前的径向减少不超过半个 turn 长度，故
   `r(s) > .35-1.4/(7.5(1-e)) > .1471014492 > 1/8`。
   反向 turn 的内部半径只增后减，最小值在端点。
   两段 loop coast 的长度由 `loop_ratio>1` 保证为正。
4. **bridge。** 令保存的 cut 斜率为 w，二阶径向图导数为 `w'<0`，
   fraction 为 f=.1。原 first bridge turn 的两个角均严格为负，
   并且向内转；`(1-f)atan(w)<(1-f)w<.1<acos(vl)`。
   其长度小于 `.18/(7.5(1-e)) < .026087`。
   brake 长度为
   `2f atan(w)(1+w²)^(3/2)/(-w')`，严格小于
   `2f w(1+w²)^2/(-w') < .008682`。
   两者之和小于 `r-rCut=.05`，其间 coast 长度为正，
   整个 bridge 单调向内且半径不小于 rCut>.3-1e-15。
   brake 的经向曲率不超过 `(-w')/(1+w²)^(3/2)<-w'<1.867<8`。

所有其余 turn 控制为 7.5、6.75、2，均小于 8。
全部背景半径严格大于 `0.1471014492 > 1/8`；
所以其纬向曲率也严格小于 8。结合第一段 Bernstein 证书，
**五个所列新轮廓的整个轴对称背景 prefix+bridge 都满足
`|kappa_i|<8`**。这条连续曲率结论不使用表中的数值峰。
精确有理辅助作业正式 exit 0，0.992 秒，11776 KiB，18 项检查全通过。

## 对后续实际延拓的用途

b=.5 的背景包络样本比 baseline 小约 .910，第一段 k0 不变，
因此它是比单独改变 `vu` 或 k0 更有幅度预算潜力的物理控制。
这仍不能说明固定实际核心后会保留全部收益；
`delta/LB/vp` 的实际响应可能补回高度，也可能改变高核心模和曲率峰。
下一步应把 b 作为新的真实 profile 外控制，保持原角图和完整核心定义，
计算原完整实际 Jacobian 对 b 的响应，再选小步真实分支。
所有原 RMS、full-H nonlinear tail、完整 Jacobian、物理 BC、度量和几何门继续保留。
