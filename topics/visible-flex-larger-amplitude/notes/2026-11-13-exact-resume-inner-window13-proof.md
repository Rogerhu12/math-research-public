## 2. 实际 DQ 核及共同材料的合法性

固定 `C=C_S+Lambda d` 的完整 46 个正 pair 帽来自已认证的
`aux-modal-physical-transfer-r1.json.gz`，SHA
`0816e8e7d62bb5df1df58848dfe8ab1c9a3699210f5df9b9da7e5e31e6a18d93`。

实际 DQ 表由 geometry_audit 的独立 producer 生成，primary SHA
`bb4c7036f45d23a33cfe7f8dbeb4ccb142ffab22c91b62b0162de9c628dc9772`。
每胞元保存 2 个材料的 `13 x 15` 表；15 个输入块为低 2..92、上述 13
窗，以及完整无限高块。表项给每个输入块**一份共同 strong pair 质量**
到输出窗 weak 源质量的上界，没有再乘输入模数。

对中心频率 `k <= 92`、扰动频率 `n >= 2`，两个正系数为

```
beta_s(k,n)   = 5*k*n / (4*(1+k)*(1+n)),
beta_ell(k,n) = max(1,5*k/(4*B0),5*n/(4*B0),
                       (5*k*n+1)/(4*B0^2)) / ((1+k)*(1+n)).
```

和频、差频按真实支持保留；差频另付
`exp(-2*min(k,n)*tau_outer_lower)`。原角导数已经在这些系数中付清。
各源胞元 `B0 >= 120`，因而逐项有 `beta_ell <= beta_s`：四个分子
分别不超过 `5*k*n/4`。所以 **s 的同一逐模正卷积同时支配两材料**。
这是把逐窗 DQ 源放入原共同材料 Green 的依据；不是从两个材料的总
质量上界凭空推出逐模共同支配。程序取 `max(DQ_s,DQ_ell)` 至少保留了
该合法的 s 支配量；独立审计又核全部保存的 `K_s >= K_ell`。

单位要区分相对源与物理 κ 源。R106 的相对 x 源材料是
`s*(V'/w)^2`、`|ell|*(V'/w)^2`；乘回 `w` 后，实际 Green 所用物理
材料是 `s*V'^2/w`、`|ell|*V'^2/w`。原 high Green 以及本次两材料
端点列均使用后者。无额外 r、w、频率或 pair 因子可省略。

## 3. 完整源、共享质量与有限代入

记低误差帽为 `L_n`，13 窗帽为 `r_nw`，原 near/rest 共同帽为
`R_ng`，完整无限帽为 `H`。每步同时保持

```
q_ng <= min(R_ng, sum_{w in g} r_nw),
t_n = L_n + q_n,near + q_n,rest + H.
```

对任何非负列，使用 `0 <= x_w <= r_nw`、`sum x_w <= q_ng` 的支持
函数。它由按准确 dyadic 权重降序的 greedy 分配给出；程序的中途剩余
质量只向上舍入，并再与 `max(weight)*mass` 及 `sum(weight*cap)`
两个上界相交。独立 Fraction 程序直接用有理数重算该 support。

固定 C 的完整源直接读取此前 Laurent producer 的所有 213 胞元、
全部 322 个高多项式 pair（94..736）以及**完整逆的共享尾**。原 source
保留分子零模至乘完完整逆之后才投影，所以没有遗漏 mean 或逆。

完整非线性使用 `N=Q+T` 的已证分解。设 `a_n = sup(V'/w)`、
`C_n` 为同一固定中心的共同 strong 帽，则未知 e 的完整剩余源由

```
Q(e)       <= (23/18) t_n^2,
T(C+e)-T(C) <= 270*a_n*(C_n+t_n)*(C_n*t_n+t_n^2/2)
```

控制。所有非零频率均包含在这些共同余项内；没有用低阶支持删掉完整
T。每胞元、每步核 `a_n*(C_n+t_n) < 1/128` 及原误差域
`t_n+Lambda_n < 2^-30`。

逐窗口源由完整 reference 源、实际 DQ 表、上述两个完整余项组成。
用原 R42 near/rest 正三角核乘以 `S=257/256`，保留所有 213 源胞元，
并保留原辅助 far 源及 `4*Theta*F_n*|e_z|` 的完整 far 反馈，其中
`Theta=16705/16384`。原 near/rest 核对该整带每个频率都成立，因而
限制到子窗合法，不需重算 Green。

每步只执行

```
r_new = min(r_old, complete_source_Green_image).
```

已存在的同一场满足初始旧帽；由逐步归纳，它也满足每次新帽。低、far、
无限坐标仍使用已有完整证书。此法无循环存在性假设，也没有通过换域
或把未知量置零得到改进。

## 4. 真端点读出与共享余项

cell12 的全部原面板、原 τ、原 frame jump、μ 和真实 w 转换已经由
前一 mixed endpoint 包支付。本条只消费该包的严格正列。94 和 96
分别使用旧 `[94,96]` 上有效的同一列，保守且覆盖准确；其他窗沿用
相同的原列。

每窗初值是本次得到的**真 cell13 同一窗帽**，乘已经支付 frame 与
条带的 canonical/physical 初值列。cell12 的源按实际两材料分别付：

```
K_s,w * (reference_s,w + DQ_s,w + square + Tdifference)
 + K_ell,w * (reference_ell,w + DQ_ell,w + square + Tdifference).
```

每窗所得端点界还与旧完整头和本窗 whole-cell 点读出界相交。
计算共同 near/rest 质量时，不能给每窗一份共同余量。因此：

* 初值按 cell13 各窗帽与该带共同质量计算 support；
* reference 的多项式逐窗加权，完整逆尾对每材料仅乘该带最大列一次，
  并与原完整带源帽乘最大列的上界相交；
* DQ 先把输出窗的加权正列聚合，再对同一份输入帽与共同质量取 support；
* 完整 square 和 Tdifference 仅乘 `max_w(K_s,w+K_ell,w)` 一次。

共同结果再与各窗已证界之和、原共同头和共同 whole-cell 点读出界相交。
所有这些量都是同一场的真上界，故取 min 合法。

实际 near 总预算为：初值约 `4.3004e-67`、完整 reference 约
`3.9022e-69`、DQ 约 `4.3727e-64`、完整共享 square/T 约 `3.2661e-76`。
94 与 96 的差别来自真实频谱支持，不是从舍入的整窗总值中相减。
