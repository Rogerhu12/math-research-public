## 5. 137 入口缺陷的最小明确修正

137 外层实际命令含 `--wall-guard-seconds ... --command python helper --owner-child ...`。旧代码的 `if '--owner-child' in sys.argv` 错把命令尾识别为自身入口。140 用：

```python
entry = sys.argv[1] if len(sys.argv) > 1 else None
if entry == "--wall-guard-seconds":
    return source_scope("owner")["wall_guard_main"]()
if entry == "--owner-child":
    sys.argv.pop(1)
    return source_scope("owner")["main"]()
```

另外两个入口 `--budget-read`、`--fresh-child` 也只认首位置。这是参数解析修复，没有执行本地 fixture 或把它当数学验收门。
