# 真实 .995 / 向内 .997：冻结 Frenet Jacobian 与移动框架左 Schur 对照

日期：2026-11-17。维护：`parallel-geometry-amplification`。

**状态：浮点数值证据。未改变已接受场、原方程或终端边界。这里没有严格谱包围、完整尾 DN、闭面、全相位 reach 或完成标准声明。**

主结论是：裸坐标 Jacobian 的正谱不能直接解释为法向增长支；加入实际移动
法切框架的连接项后，两处都出现可分的 109 维快速增长子空间，足以明确
定义一组新的有限终端行。其改善程度仍须用真正 BVP 对照确认。

## 2. 能否按实部取 109 行

对 `A.T` 做实 Schur 分解并排序，选实部大于阈值的完整实块。
若 `Q₁` 是所选列，则取 `L=Q₁.T`。它满足

\[
L A=T_{11}^{\mathsf T}L,
\qquad LL^{\mathsf T}=I.
\]

这两处均有一个不切断共轭对的阈值，恰好选出 109 行。

| 所选最快 109 维的读数 | 真 .995 | 新向内 .997 |
|---|---:|---:|
| 实部阈值 | .4105220681 | .4709794487 |
| 阈值上下相邻实部之差 | .0164425819 | .0598605302 |
| `||L A−T₁₁ᵀL||₂ / ||A||₂` | 2.236e−15 | 3.130e−15 |
| `cond₂(L)` | 1 + 3.0e−15 | 1 + 2.2e−15 |
| LAPACK 子空间 `sep` 估计 | 1.514995e−7 | 2.419797e−6 |
| `sep / ||A||₂` | 4.317e−13 | 5.922e−12 |
| 斜谱投影 `||P||₂` | 3979.940 | 1566.153 |
| 与同一实际端点主符号行空间的最大夹角 | 82.7083° | 88.5104° |
| 上述夹角的均方根 | 11.3749° | 15.2145° |

主符号比较对象是现有 `continue.projector` 在**同一个实际末端场**重建的
109 行，不是 JSON 中更早端点保存的行。其原始行矩阵条件数分别约
2136.64、5811.99。

`cond₂(L)≈1` 来自 Schur 正交基；它不说明整个分离 BVP 条件良好。
为单独检查谱分拆的敏感性，在排序后 Schur 坐标中求

\[
T_{11}X-XT_{22}=-T_{12}.
\]

对应斜谱投影为
`[[I,−X],[0,0]]`，故 `||P||₂=sqrt(1+||X||₂²)`。
表中的数值据此计算，Sylvester 方程相对残差小于 `1.5e−17`。
`sep` 是 LAPACK `dtrsen` 的估计，不是严格分离下界。

更关键的是：取走 109 维之后仍分别留下 **169、177 个**
`Re λ>1e−6` 的方向。它们的行空间 Fourier 模能量也不集中在前 3 模。
因此这项选择不能解释成“保留 K3 的 3 个低模，同时消除其余增长支”。
因此不直接采用这一**裸 A** 的最快 109 维选择。

## 3. 移动实际法切框架与连接项

从同一个节点的完整有限 RHS 定义实际 `V,dV,Acc`，并取

\[
e_\phi=d/|d|,\quad n=(V\times d)/|V\times d|,\quad
e_s=e_\phi\times n.
\]

对每个原系数基方向 `δF`，定义有限方阵

\[
T\,\delta y=P_M(\delta F\cdot e_s,
                  \delta F\cdot e_\phi,\delta F\cdot n).
\]

这里使用原 `q.project` 的 cos/sin/cos 系数约定和同一 N=2048 网格，
没有把有限乘积投影当作无限维正交坐标转换。`T_s` 由 `dV,Acc` 对上式
解析微分：单位向量导数均用 `(I−u uᵀ)v_s/|v|`，然后对同一系数基投影。
实际使用的移动有限矩阵为

\[
B=(T A+T_s)T^{-1}.
\]

求逆乘积通过线性求解完成。采用 `cross` 法向及其一致导数，没有混用反向
法向的手算符号。

`B` 中还有大量接近 `a′/a` 的慢正谱方向，所以仍不能只用实部正负划分
112 维。强取最快 112 维时，其最后切口分别只有
`.3155652−.2989816`、`.3161227−.2994530`；最快 109 维的上述切口更清楚。
这不证明所剔除/保留的方向与全无限维低模完全一致。

设 `L_B` 为 `B.T` 排序 Schur 的 109 行，回到原系数取
`L_y=L_B T`。当前点上检查

\[
L_y A+L_B T_s=S L_y,\quad S=L_B B L_B^{\mathsf T}.
\]

归一化残差分别为 `6.28e−16`、`5.93e−16`。
这只是当前节点的协变关系；把 `L_y` 冻结作边界条件之后，没有由此证明
真实尾流形或未来各节点仍满足同一行空间。

`T_s` 还用 `y(s±h)=y±h y′+.5h²y″` 及真正 scalar evaluator 的
中心差分独立核对。h 为 `1e−6`、`5e−7` 时，相对 Frobenius 误差分别为
`.995: 2.38e−9, 7.83e−10`；`.997: 2.58e−8, 6.63e−9`。
代数变换 `BT=TA+T_s` 的相对残差小于 `7.8e−16`。

这些数值支持下一步**只更换终端行定义**的真实比较试验；它们不提前保证
解的误差更小、稳定延伸到平盘或满足全局几何门槛。

## 4. 导数一致性与解释边界

对每份输入，固定随机种子 `20261117` 取 5 个单位方向。
完整矩阵乘积 `A v` 与原 `q.jvp`、步长 `1e−24` 的复步 `q.rhs`
分别核对，全部相对误差小于 `3.63e−16`；高度常量列严格为零。
实 Schur 重构相对 Frobenius 误差小于 `8.3e−15`。
这排除了把转置、不同 scalar 或另一套 RHS 混入本次诊断的解释。

冻结的全 Frenet 坐标 Jacobian 是当前有限采样 ODE 的精确导数对象；
其正谱不自动等于随径向参数移动的等距切空间中的法向椭圆增长支。
第 3 节已把实际法切坐标及连接纳入当前有限投影，但没有进一步证明完整
等距约束消元或全尾稳定子空间，也没有据此声称现有主符号边界准确。

此前检索到的非轴对称主符号实现
`computations/geometry_20261114_normal_terminal_projector.py`
确实已含实际 `n_s,n_φ`；
`computations/geometry_20261114_full_dn_boundary.py` 的完整链式装配则要求
真实 tail map。两者都不能直接被本次冻结矩阵 Schur 选择认作 exact tail DN。
