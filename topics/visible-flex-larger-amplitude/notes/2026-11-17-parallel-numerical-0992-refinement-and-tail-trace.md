## 1. 明确的同源边值问题与加密

scalar 继续使用 `.99` 的原 exact-rational 末 jet 接定角曲率圆弧；原点、参数与区间均不变，不在每一步重接圆弧。固定 core 前三模，其余 core 系数由完整两点 BVP 求出。终端主符号矩阵来自实际 `.991` 解，常系数搬到 `.992`，目标为同一参考的二阶 Taylor 值。

`parallel_20261117_continue.py` 新增零时长精化、零填充角模提升以及指定原边界参考。M96 精化逐字重建原 `.991` 参考的相同端点行；M112 在同一实际参考曲线上重算更高分辨率的同一公式。后继输出还保存完整端点矩阵和目标，使同 M 的后续径向精化可以冻结这些行。所有核心状态、ODE 行与分离边界都保留，没有只解某些选中的高频块。

不同求解的自由 core 会略变，因此不是固定物理角 rho 的同一近似场。依 [R240](../results/R240-canonical-material-metric-and-refinement.md) 的材料弧长归一，每个 core 的周长固定为 2π，公共目标可写成同一 `ds²+a(s)² dϑ²`。这不能自动替代完整闭族的固定几何收敛；本文只比较这些有限前缀的真实误差。

## 3. 同一个真实端口的材料角数据

新 `parallel_20261117_prefix_tail_trace.py` 直接读取完整 M112 状态和已保存径向 RHS。设 core 物理法向角为 φ，则

\[
\rho(\phi)=1+\sum_j(1-(2j)^2)c_j\cos(2j\phi),\qquad
\vartheta=\phi+\sum_j\frac{1-(2j)^2}{2j}c_j\sin(2j\phi).
\]

在等距材料角节点上作单调求逆，再读真实高度 `h=F_z`。在 `0<a'<1` 的 cut，使用

\[
r=a,\quad w=\frac{\sqrt{1-a'^2}}{a'},\quad
w_r=-\frac{a''}{a'^3\sqrt{1-a'^2}},\quad
P=\frac{h_\vartheta}{rw},\quad K=\frac{h_s}{a'w}-1.
\]

这里不是以椭圆或只保留一个高度模式替代原端口。8192个材料角点得到求逆残差最大 `2.6645352591e-15`。实际浅端背景为

| 量 | 值 |
|---|---:|
| r | 1.167318285443017 |
| a′ | .3539250923788041 |
| a″ | −2.0134197052329856 |
| w | 2.642575483767545 |
| w_r | 48.558078940023854 |
| mean h | .9196724087226285 |
| mean K | −.09208764312352026 |

完整变换后 sampled `max|P|=.0600841367503`、`max|K|=.348373478317`，R626 正分支余量 `min S=.974789906588`、`min D=.0330190092777`、`min L=.380282597655`、`min(1+K)=.651626521683`、`min N=.391826865787`。无相减连接均值的采样值约 `1.15563516e-10`。

**物理角 M112 不等于材料角 M112。** 将这份实际数据投影到112个材料偶模后，采样均值变成 `2.67658464e-6`，离散 Fourier 未保留部分的 ℓ¹ 和为

|---|---:|
| P | 4.70628948595e-5 |
| K | 8.30317182245e-5 |
| h | 2.14567933406e-7 |

这些数字不是无限谱尾的严格上界。后续必须提高材料角分辨率，或把这个误差实际纳入尾接合；不能把同名112当作无损转换。有限 tail 还需要匹配真实非均值斜率及一个均值条件，不能仅指定 P 后把任意 deep Robin 解称为与该前缀闭合。
