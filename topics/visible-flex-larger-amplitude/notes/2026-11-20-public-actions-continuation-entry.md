代理仍不直接修改 Git 索引或远端。

## 同一临时场的后继工作

后继队列由 root 更新；每35秒仅检查该路径提交，变化时实际同步，固定该步骤源码提交，
以 argv 启动（无 shell 展开）。`{repo}` 是新的固定源码树，`{work}` 是既有研究临时目录。
每个 id 只尝试一次，失败、未启动、已返回分别登记。默认20000秒仅停止接纳新步骤，
已经启动的子进程观察到自然返回；workflow 的350分钟硬上限不是课题完成或本会话停止理由。
本次初始队列仅含已登记 seed2026112007 的原32变量/28不等式问题对提前释放算法的必要检查，
不增加新fixture，不把独立小问题通过当作真实闭曲面成功。实际新父返回后继续加入同父完整方向与连续几何。

后继可明确删除仅该步新生成、已退出进程不再使用的 row cache；父文件、声明输出、状态、日志、
预先存在的路径和符号链接均不删，删除对象与字节数写入紧凑来源记录。

或显式 workflow_dispatch 启动；后继队列及普通阶段结论提交不触发重复 job。

`a26af69be951a213d495a4c3e4e4022e16d87065`；Python3.12.14、NumPy2.3.5、SciPy1.17.0、单BLAS。
只用本公开仓库 Actions 的临时 `GITHUB_TOKEN` 发布，用户PAT没有进入源码、请求、日志或提交。

源码已作静态语法/接口检查，没有本地科学执行。旧本地事实及地点纠正保留原记录。
此入口既不补造历史 run ID，也不把旧结论重复运算描述为新的证明；输入重建仅为获得公开执行中的实际父材料。

执行身份与是否已运行以正文各项状态为准，未执行准备源不冒称已有数值结果。临时数组沿原输入链再生；纯位置替代输入保计算语义，不冒称原raw报告的路径或逐字SHA。
