这里 `v_B` 是原 point 读出的实际 Cartesian 径向速度，`a_B` 是同一原 point 上按原 GW 规则重建的加速度。`V_AC` 是只用 A、C 的 v/a 构造的三次速度多项式。

| --- | ---: | ---: |
| `V_AC(B) − v_B` | `1.1189341714090105e-8` | `4.71542866650996e-9` |

第三行没有使用任何 GW 加速度来构造插值，所以提供了不同的数据组合；它仍只是三点多项式的导数，不是原连续 point 速度的真导数。它比两端三次速度导数更接近 B 的 GW 加速度，支持增加实际径向信息有用；这还不能证明 GW 公式的连续准确性。

尤其第二行的 z 差已达 `4.43e-4`。GW 分支只另行完成水平二阶；其竖直二阶仍取原 height point jet。因此现象不能只归入水平 rr 规则。

## 中间位置消去的积分检查

令每段三次速度的积分为 I，并按 [R245](../results/R245-hermite-compatibility-and-integrated-velocity.md) 定义 E。则纯代数有

\[
I_{AB}+I_{BC}-I_{AC}=E_{AC}-E_{AB}-E_{BC}.
\]

右侧的 d_B 精确消去，两个端点位置也消去。实际结果为：

| 量 | 1024 角最大范数 |
| --- | ---: |
| `E_AC` | `3.824032896590792e-13` |
| `E_AB` | `3.5972245324394305e-15` |
| `E_BC` | `7.582146519058563e-15` |
| `I_AB + I_BC − I_AC` | `3.712239352553341e-13` |
| 上式两侧浮点差 | `2.025920446147138e-28` |

新增真实中间速度/加速度后，积分发生与原 E_AC 同量级的变化，而较短分段的兼容缺陷显著较小。这里无需把小的节点位置差当成噪声；真实径向分辨率和插值阶数本来就是影响因素。仍须保留“GW 加速度是否等于连续原点速度导数”这个独立问题。
