## What the observer reads and preserves

`ObservedResidual.evaluate` invokes the original
`CompleteResidual.evaluate` exactly once. Original exceptions propagate
as before. After it returns, the observer reads the original `middle`
and `fm` arrays and takes precisely the indices whose original midpoint
RHS is nonfinite. These are the same rows counted by the original
`midpoint_domain_failures` field.

For each observed bad row, the added report gives its interval index,
actual `problem.mid` station, endpoints and fraction `0.5`. It records
the actual middle-state and RHS identities, finite-input status and
nonfinite component indices. If the original middle input itself is
nonfinite, the observer reports that separately and does not evaluate an
angular field from it.

For a finite original middle input, the observer copies the row and uses
the existing `angular_values` helper only. That helper calls the original
`q.jet` and scalar-jet readout to evaluate the original normal-expression
beta squared on all2048 physical angles. Its report contains the complete
grid identity, minimum and worst angle, finite/negative/zero counts,
actual scalar jets and controls, and curve curvature at the reported
minimum. The cross-product reformulation is not substituted into any
original domain decision.

No extra whole-flow or Jacobian evaluation occurs. The original middle,
RHS, collocation residual, residual vector, finite flags, merit and
acceptance predicates are not changed. The added report includes
before/after residual-vector byte identities and the original finite
flag comparison. All subsequent observer, hashing and export exceptions
are caught and recorded as diagnostic failures; they do not make a
scientifically valid trial fail. Exceptions raised by the original
evaluation itself are not swallowed.

Each bad midpoint additionally writes a small NPZ under
`midpoint-observer/evaluate-XXXX-midpoint-XXXXX.npz`. It contains the
original copied middle state, the original nonfinite RHS bytes, and the
complete beta-squared grid when evaluated. The JSON report binds each
file's SHA256 and every array's shape, dtype and original C-order byte
hash. Nonfinite original bytes remain in NPZ rather than being replaced
by JSON nulls. File names use the monotone original evaluation call
counter; an existing diagnostic file is never overwritten. Export
failure is also diagnostic only.

The observer is attached to every evaluation performed by the original
warm driver, including actual line-search evaluations and calls with
`require_rms=True`. It reads their returned collocation midpoints only;
it does not re-evaluate or change the original RMS-query checks. It does
not infer which unobserved midpoint failed in request27. It only records
actual returns in the new run. All original trial and query reports
remain available alongside the added observation.
