# Complete accurate normal and continuous-geometry fees for the fixed Fejér N4096 and M320 fields

## 1. Outcome and actual scope

This package supplies seven complete runtime sources, two complete text construction programs and four complete execution plans. It binds exactly the two independently published fixed-Fejér refinements: the N4096 angular observer family and the M320 current-frequency family. It retains the existing exact-reference, exponential, complete 32-stage normal, full-circle, radial, physical-sixjet, relative-Gram, curvature, support and R717 diameter formulas.

The common family binder is an explicit two-entry source registry. It is not a general schema exception. Each entry names the complete actual driver, complete original reader, normal, base, packet, refinement binding and layout source, with distinct schemas and full current dimensions. The entire original 128-role driver registry must match its exact canonical identity, and every actual source is re-read. Every complete path/SHA pair of the earlier 110-role fixed-Fejér family must remain present as current or historical source identity.

The package is prepared for the actual run 13 N4096 direction, run 46028002241/1, and run 14 M320 direction, run 46028184571/1. These are execution locations, not fee results.

Before publication, the root publisher read the complete run 13 volume containing actual steps 1–4 (30,067 bytes, Git blob 9de98344e8605dfd4dcda66c2759d1472bdaf7c7). Its reference step returned 0; its N4096 scientific step returned 1 and its pure step also returned 1. No complete scientific report was returned. The declared command JSON is not a field snapshot. The actual exception is not inferred here. Run 14's complete reference step returned 0 (16,602-byte volume, Git blob be5daabc639905ebc87078d67f9ea38b882cffe2); no complete M320 field report is assumed. Consequently, the N4096 plans below are complete source-specific pending plans, not a statement that the failed entry produced a fee input. A future repaired scientific source requires a separate exact whole-source fee adaptation; this two-family binder will not silently accept it. No complete scientific report, full point, immutable packet, normal root enclosure, geometric bound or certificate has been assumed to exist. All future scientific report, snapshot, current model and actual target output identities remain null in the plans until a genuine report is read. The recipe is fixed in advance; its mathematical identity is not substituted for an actual target-definition identity or a whole-file SHA.

The source-only work performed here consists of V8 text construction, full-byte SHA calculations and forward/reverse reconstruction of exact text. No Python interpreter, AST, compilation, scientific import, numerical sample, working field, Jacobian, root or quadrature was executed. The text construction programs are not queue prerequisites or independent solver gates.
