# Fixed Fejer target: complete exact-affine J923 to J1845 continuation

This package supplies a complete radial refinement of the actual fixed Fejer input family. It adds a current J1845 SO3 representation while freezing the reference J923 primitive, all 160 fixed material-chart coefficients, the complete scalar law and exact affine node definitions, the supported reference seed, M160 and N2048. It includes the complete source bodies, three source reproducers, one complete parameter reproducer, three executable science/pure plans, and a lossless shared source table.

This is a source and parameter delivery. It contains no newly evaluated field, returned J1845 report, selected normal root, accepted direction, metric value, geometry certificate or convergence claim. Scientific execution belongs exclusively to the public Actions runner. The original J923 parent source is fixed; its eventual scientific report and final checkpoint are not manufactured from input preparation or progress metadata. The independent mode can begin at the original frozen reference point without waiting for that report.

The underlying exact-affine and shared-quintic refinement is the already documented R674/R676 construction. The chart is the already documented R717 binary64-dyadic Fejer recipe. This delivery applies those constructions to the actual Fejer source family and carries the complete current history, source, physical-field and parameter contracts. It does not register another refinement theorem.

## 3. Exact material coordinates and working mesh words

Write each original exact radial node as

$$
X_i=A_iS+B_i,
$$

where the ordered pair consists of the coefficient of the accurate scalar length S followed by the constant. The order is not $A_i+B_iS$. A fine node is either the identical original node or the exact affine midpoint of two adjacent nodes:

$$
\widetilde X_{2i}=X_i,\qquad
\widetilde X_{2i+1}=\tfrac12(X_i+X_{i+1}).
$$

The 923 original working node words are copied to the even locations of the 1,845-word current carrier. A computed floating midpoint is only the working carrier of the exact affine point. It does not redefine the exact node and is not assumed to be exactly the real midpoint in binary64.

The reference J923 mesh and its complete symbolic node definitions remain frozen. A current fine-cell query is mapped to the original reference cell by exact affine arithmetic, preserving its complete coefficient pair. The implementation does not round a derived original-cell coordinate and pass it off as the same exact material point. If an exact comparison or an affine-domain relation is unavailable, the original complete failure is retained.

The exact-affine reference helper evaluates the same fixed supported reference field at the requested exact point. It retains the original endpoint/core/cap meanings, support boundaries, scalar branch definitions, mean root and angle-jet dependencies. New queries do not replace the frozen reference with a current fine field or a copied parent final.

This distinction is used consistently by the fine mesh, the complete observation generator, scalar target construction, history mapping and the pure reader. Equal counts or equal nominal J values alone are never used as evidence of equal physical coordinates.

## 4. Every current variable and the full quintic restriction

The SO3 channel order remains the actual x/y/z order with 161, 161 and 160 channels, respectively. There are 482 channels in total. The construction does not reinterpret these as an obsolete R/T/Z layout.

Each original node carries a value, first radial derivative and second radial derivative in every channel. All three original jets are copied, word for word, to the corresponding even fine node. Each new midpoint receives the complete three-jet evaluation of the original cell's shared quintic. All midpoint coefficients remain free variables in the refined problem; they are not tied or eliminated after initial injection.

The cap/core support, normal controls, gamma and endpoint definitions do not create additional hidden zero rows. The first three core coefficients remain fixed, the other 157 core coefficients remain free, and H remains free.

The complete coordinate sizes are

$$
n_{\rm old}=482(3\cdot923-3)+157+1=1,333,370,
$$

$$
n_{\rm new}=482(3\cdot1845-3)+157+1=2,666,582.
$$

In exact polynomial arithmetic, restricting a quintic to its two half cells preserves the same function and its derivatives. The actual midpoint word construction uses declared working width carriers and floating arithmetic. Its rounding is explicitly not claimed to have been enclosed.
