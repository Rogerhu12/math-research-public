## 2. 尺寸含义和基准

令 S 为共同固定原点下整个保存前缀采样场的 `max(2*norm(X))`。它不是水平 2r，也不是已经认证的整闭面直径 D。本文仅把 S 用作数值设计预算；后续需要完整连续空间覆盖、同一坐标规范及闭合各段，才能支付真正 D 与 held/reach。

本轮基准为

- κ_sample = 8.383679679468635；
- S_sample = 3.908756832366815；κ_sample S_sample = 32.76976522749786；
- |height|_sample = 1.9261534018210071；水平 r_max,sample = 1.3451921056598604；
- 全 28 模的 core 轴向相位差 = 0.19112888349703164，除以 S 为 0.04889761417603971。

现有真实物理 quintic 内点审计的更高 κ_sample = **8.383911512431759**（`2026-11-13-strong-m28-interior-jet-audit.json`）继续有效，不被这里较小的 cubic 网格值覆盖。两者都仍是数值样本。
