# 三重对称强核心的短筛查

2026-11-10，geometric_amplification。**仅核心几何筛查，未构造闭图。**

若二模尾匹配难，可以取

$$\rho(\phi)=r+(1-r)\sin^{2N}(3\phi/2)/\mu_N,
\qquad\mu_N=\binom{2N}{N}/4^N.$$

对应支撑函数是 $h=1+\sum_{j=1}^N c_j\cos(3j\phi)$，其中

$$c_j=\frac{2(1-r)(-1)^j\binom{2N}{N-j}}
{\binom{2N}{N}(1-9j^2)}.$$

凸性严格由 $\rho\ge r$ 给出。旋转 $\pi/3$ 的轴见证差为
$d=2\sum_{j\text{奇}}c_j$；它是完整核心 Hausdorff 的下界。
核心直径可由 $\max_\phi[h(\phi)+h(\phi+\pi)]$ 计算；下表对这个有限三角多项式用 65,536 个等距角采样，直径列不是严格连续上界。

所以这条轴见证路线在 $N=16,32$ 才留下少量完整直径余量，而且大的 $\rho_{max}$ 会压低最小曲率、收紧早期 Frenet 速度。现有 flat17 的完整 $D\approx3.787$ 不能直接使用这些见证过 .2；必须另得非常短的实际过渡。这个结论不排除别的相位见证或别的三重对称核心。
