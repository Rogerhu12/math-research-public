# 从实际闭组装生成全空间 reach 覆盖预算

2026-11-14，geometry，AI 辅助。**方法推导已证明；具体数值预算由公开仓库 Actions 执行，不以脚本存在代替返回结果。**

源码 `computations/geometry_20261114_continuous_cover_budget.py` 消费已经生成的闭族网格、plan、assembly、background 和接受前缀。它比有限法向点对筛查多做一步：给样本周围的整个材料参数块分配路径半径，再按 R37 的短路径或空间分离门覆盖点对。

## 1. 先消去全部相位

把四个固定弱标记高度设为零，所得未标记闭面记为 $S$。两个完整平帽关于轴旋转不变，所以整个未标记族的像准确为 $R_\alpha S$。其几何只需静态检查一次；材料角重参数化不改变这个像集等式。随后由 R24 对固定的四个小标记付出统一的定量损失。这条全相位消元不依赖时间采样。

## 2. 实际材料块的路径半径

参考度量在前缀为 $ds^2+a(s)^2d\theta^2$，在尾为 $(1+w(r)^2)dr^2+r^2d\theta^2$。提供数值包络 $|w|\le W$、$|da/d\ell|\le L_a$，以及实际诱导度量相对于参考度量的算子误差 $\eta$。于是参考路径长度乘 $\sqrt{1+\eta}$ 给实际路径上界。默认参数为 $W=.4,L_a=1,\eta=10^{-6}$；它们不是由脚本自动推断的严格区间界，脚本另核已保存样本是否与它们相容。

用真实显示网格选定径向、角向中心；径向 Voronoi 块按已计长的经线坐标划分。若第 $i$ 块的径向半宽上界为 $b_i$，中心参考纬圈半径为 $a_i$，角半宽为 $\Delta\theta$，则
$$h_i=\sqrt{1+\eta}\bigl(b_i+(a_i+L_a b_i)\Delta\theta\bigr)$$
给块内每点到其中心的路径长度上界。中心坐标另有误差 $\epsilon_x$ 时，位置球半径取 $e_i=h_i+\epsilon_x$。两个未标记平帽分别用一整个圆盘覆盖，中心取帽心、路径半径取 $r_c$，避免密集极点三角形制造海量无意义点对。

给每对中心用同角经线加端点中较小纬圈的圆弧构造路径；也比较绕任一极点的路径。加上 $h_i+h_j$ 后，若总长严格小于 $\pi/K$，整个块对由 R37 支付。否则尝试
$$|p_i-p_j|-e_i-e_j\ge2\tau_0.$$
所有同块点对也检查 $2h_i<\pi/K$。程序用空间树省略已由距离自动支付的远块，不省略任何未过门的近块；输出尚未覆盖的实际径向、角向块及其差额，供细化同一个有限场的查询网格。

## 3. 直径上界不用全局最大的网距

若整闭面的半径最大点属于第 $i$ 个块，R37 §8 的测地线极值论证逐块给
$$\max|F|\le |p_i|+\epsilon_x+\tfrac12K h_i^2.$$
因此可对各块右端取最大，而不把一个离最大半径区很远的大网距施加到所有点。两个未标记帽另用准确几何式 $\sqrt{H^2+r_c^2}$ 控制。未标记直径上界取所得半径上界的两倍；加入幅度不超过 $A$ 的标记后，再加 $2A$。

这对当前 A 很重要：$K=8.35$ 时，仅局部曲率要求就限制 $D\le1/(.03K)\approx3.992016$，已保存的点云直径约 $3.977459$。一阶全局 $2h$ 损耗会吃掉余量，逐块二阶估计则集中控制实际接近半径极值的区域。

## 4. 标记预算自动与实际块覆盖衔接

程序从实际活动块的位置球得到活动部分水平半径下界，再与标记支撑最大水平半径、帽边界和两帽间距比较，得到 R24 所需的支撑分离候选 $d_0$。标记函数给出高度、梯度、Hessian 上界 $A,G,K_b$。

令 $\tau=.03D_+$。由 R24，只需未标记面满足 reach $\ge\tau_0$，且
$$\frac1{\tau_0}+\frac{2G}{d_0}+\frac{4A}{d_0^2}
\le\frac{(1-2A/d_0)^2}{\tau}.$$
程序由此解出需要的 $\tau_0$，用这个稍大的半径执行全块覆盖，并检查 $K\tau_0\le1$、$2A<d_0$ 和 $K_b\le1/\tau$。因此不会把弱标记的损失忘记在最后一步。

## 5. 执行及证据范围

```bash
python computations/geometry_20261114_continuous_cover_budget.py \
  --directory CLOSED_OUTPUT --checkpoint ACCEPTED_PREFIX.json.gz \
  --source-topic PINNED_SOURCE_TOPIC --port ORIGINAL_PORT.json \
  --radial-stride 2 --angular-stride 1 --out OUTPUT/coverage.json
```

同一场可从步长2改为1，或生成更密显示角网格后再次执行；这不会改变度量、场参数、尾或相位区间。接受新大核后必须换用其自己的完整闭组装数据与真实曲率预算。

`numerical_cover_budget_passed` 只表明在给出的数值包络下所有覆盖不等式通过；输出同时保留这些输入和样本，便于比较余量及加密。它不声称已有严格区间曲率证明或精确存在性。实际场的 $C^2$ 装配、嵌入和参考度量误差包络仍分别记录；这些严谨性差距可以按课题 README 第7条说明，不另设“必须全部机器区间认证”完成门。本程序也不替代大幅度 $\delta_{\rm hold}\ge.2D$ 的要求。
