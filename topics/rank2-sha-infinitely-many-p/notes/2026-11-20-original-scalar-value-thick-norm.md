# 循环门未通过时的同一实际标量值范数

2026-11-20。短补件；完整证明与独立 helper 的增量已保存，不改变当前运行的基础工具、上层或 CI。

继续同一个原完整 \(R=k[\xi]\) 自由代数 \(A\)、真实单位行 \(u\)、
完整理想 \(I\) 及首一行列式 \(d=\det H_I\)。始终
\(\deg d=\dim_k(A/I)\)，原 \(k=\mathbf F_{r^2}\) 和 \(\omega\) 保持不变。

## 1. 同一 HNF 给一个较弱而准确的值门

仍取已完整认证的 \(307\times306\) 原矩阵与变换

\[
M=\binom{u}{H_I},\qquad
UM=\binom{K}{0},\qquad
\operatorname{row}_R K=Ru+I.
\tag{1}
\]

上一补件已通过全变换返回及全部原行反向余式付清这个全行模。
当 \(K\ne I_{306}\) 时，单位不生成整个商；本补件不改变此判断。

对这次需要范数的实际原值 \(h\in A\)，只作同一 \(K\) 的完整
多项式行除法，得到唯一标准余式

\[
h=qK+r.
\tag{2}
\]

所有 \(306\) 个坐标均返回。\(r\ne0\) 就明确 miss，保原全部
\(\pi\)-层回退，尚不判断 \(h\) 是否为商中的单位。

若 \(r=0\)，令 \(U_0\) 为原 \(U\) 的前 \(306\) 行，则

\[
(c_0,b)=qU_0,\qquad
\boxed{h=c_0u+bH_I.}
\tag{3}
\]

因此令 \(c=c_0\bmod d\) 后，实际核 \(du\in I\) 和
\(h-cu\in I\)，得

\[
\boxed{m_h=m_c\quad\text{作用在同一个完整 }A/I\text{ 上}.}
\tag{4}
\]

这由 \(I\) 是 \(A\)-理想得到，保全商，不是只在 \(Ru+I\) 上的相等。
程序没有额外求 HNF，没有做分式域除法，也没有挑任意一个局部 lift。

## 2. 全行列式的标量范数恒等式

有限挠 \(R\)-模的 Smith 分解在理论上给

\[
A/I\simeq\bigoplus_{j=1}^{306}R/(d_j),\qquad
d_j\text{ 首一},\quad\prod_jd_j=d.
\tag{5}
\]

这里可有 \(d_j=1\)，不要求只有一个非平凡因子；算法不计算 (5)。
由 (4)，每一项上的算子都是标量 \(c\) 乘法，所以

\[
\boxed{
N_{(A/I)/k}(h)
=\prod_j\operatorname{Res}(d_j,c)
=\operatorname{Res}(d,c).
}
\tag{6}
\]

这只使用同一原完整 \(R\)-模的乘法行列式。它没有宣称
\(A/I\simeq R/(d)\) 为代数，也没有更换底参数或生成元。
全部重复因子及其总 \(k\)-长度在 \(d\) 中完整保留。

在非空商中，\(h\) 为单位当且仅当 \(\gcd(c,d)=1\)：
由 (5) 这等价于 \(m_c\) 在每项可逆，再由 (4) 等价于 \(m_h\)
可逆；有限交换代数中乘法算子可逆恰等价于该元素为单位。
所以 value hit 分支严格核完整 gcd 及非零 resultant，结果留在原 \(k\)。
非单位错误不被吞成 miss。常数 \(a\) 的范数仍为 \(a^{\deg d}\)，
程序保持该返回；空商仍由旧单独分支返回 \(1\)。

取不同的合法 \(c\) 不影响结果：两个差乘原单位在 \(I\) 中，
故其标量作用在整个原商上相同，(6) 的行列式因此相同。
不必把最小标量消去多项式误认成完整 \(d\)。
