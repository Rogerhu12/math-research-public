# 原完整306维环的直接向量乘积

状态：已证明的精确算法与未执行的实现候选。[完整源码补丁](../scripts/original-affine-direct-vector.patch)独立保存，尚未应用到稳定适配器，也未触发重复公开运行。本地只做源码/AST与可应用性检查，没有数学执行。已有实际正规化的原表、两图和全部46971个基乘积证书是本算法的输入。

## 1. 具体目标与保持的对象

稳定适配器目前用 `vector(y)*multiplication_matrix(x)` 求单个乘积。即使消费者只要306个结果坐标，它也先建立含306²个多项式坐标的整个算子。

本候选直接读相同原表计算乘积向量。`multiplication_matrix`、`multiplication_matrix_with_certificate` 的代码及所有完整系数门不改；理想运算仍可按需构造全算子。原 `product_blocks`、`product_pair_positions`、`certificate` 与原 context 的对象身份保持，完整基权与两个图表的基也不变。`constant_extension(field)` 仍只使用调用者给出的原域。

新 `multiply(x,y,infinity=False)` 调用 `multiply_with_certificate`，返回的向量仍在同一个原多项式环上、同一个306有序基中。无Laurent近似、无截断误差、无新函数域。

## 2. 从完整原表到直接公式

记有限图的原基为 $b_i$，权为 $d_i\le4$。已有完整表给出每个 $i\le j$ 的恒等式

$$
b_i b_j=\sum_{(k,e)\in\mathcal B_m}
T^{(m)}_{(i,j),(k,e)}\,t^e b_k,
\qquad m=d_i+d_j,
$$

其中

$$
\mathcal B_m=\{(k,e):0\le e\le m-d_k\},
\qquad T^{(m)}_{(i,j),(k,e)}\in\mathbf F_p.
$$

所有 $m$ 的行一共46971条，每条是先前实际完整全局窗口认证过的原基乘积。适配器逐条核对 `(i,j)->(m,row)` 的真实映射、无重复/遗漏及全部 recipe 列。

给定多项式向量 $x=(x_i)$、$y=(y_i)$，置

$$
C_{ii}=x_i y_i,\qquad
C_{ij}=x_i y_j+x_j y_i\quad(i<j).
$$

因为原环交换，直接有

$$
xy=\sum_{i\le j}C_{ij}\,b_i b_j.
\tag{1}
$$

式(1)是全部有序项的准确重组，不要求 $x=y$。实现只在两个完整306坐标多项式向量逐项相等时，使用

$$
C_{ii}=x_i^2,\qquad C_{ij}=2x_i x_j\quad(i<j)
$$

的省乘式；不以摘要、范数或有限取值判断相等。严格零输入坐标可以省略相应有序项；计算后整个 $C_{ij}$ 若严格为零，也可以省略其原表行。没有按某个系数、随机值或短前缀筛行。

将 $C_{ij}$ 的全部多项式系数按次数组成矩阵 $G_m$，则

$$
G_m T^{(m)}
\tag{2}
$$

的第 $q$ 行、第 $(k,e)$ 列就是次数 $q$ 的成对系数在该原 recipe 列上的总和。把它加到第 $k$ 个结果坐标的次数 $q+e$，恰得(1)。这是原 `y*Mx` 的逐系数等式。

## 3. 第二图表与原二次常数

无穷图使用同一个原加权基 $c_i=t^{-d_i}b_i$、参数 $s=t^{-1}$。直接代入原表给

$$
c_i c_j=\sum_{(k,e)\in\mathcal B_m}
T^{(m)}_{(i,j),(k,e)}\,s^{m-d_k-e}c_k.
\tag{3}
$$

指数非负由原 recipe 条件保证。实现使用稳定适配器已经核完的同一 `plans[(m,infinity)]`，每个原列在有限图散射到 $q+e$，在另一图散射到 $q+m-d_k-e$；全部原 recipe 列恰消费一次。没有再造反转表或丢低权列。

令调用者的原二次域为 $k$，$\gamma=k.\mathrm{gen}()$。程序从同一个实际域拆出并回验

$$
\gamma^2=u+v\gamma,\qquad u,v\in\mathbf F_p.
$$

对 $A=A_0+A_1\gamma$、$B=B_0+B_1\gamma$，其中各分量是完整 $\mathbf F_p[q]$ 多项式，使用

$$
P_{00}=A_0B_0,\quad P_{11}=A_1B_1,\quad
P_{01}=(A_0+A_1)(B_0+B_1)-P_{00}-P_{11},
$$

$$
AB=(P_{00}+uP_{11})+(P_{01}+vP_{11})\gamma.
\tag{4}
$$

这是三次原素域多项式乘法的准确恒等式。输入每个实际系数的拆分都回验 $a_0+a_1\gamma=a$；$\gamma^2$ 的实际坐标也回验。整个原结构表都在素域，所以(2)的两个分量独立作 native Fp 乘法。最后结果重新组合到调用者的同一域，所有系数再拆回逐项比较。式(4)不假设 $\gamma$ 是 omega，也不替换或重选原 omega。

## 4. 分块不是截断

默认每批最多128个原 pair 行，每个次数块最多32行。

对同一个权 $m$，一批非零 $C_{ij}$ 的每个原素域分量都是准确的完整多项式；批长 $L$ 取该批所有真实非零分量的最高次数加一。次数块依次覆盖 $0,\ldots,L-1$。每块都包含所选 pair 的完整该段系数，native 乘以**同一原表所选行**，并消费全部原 recipe 列。严格全零块被省略时，也先实际核矩阵为零。高于准确多项式次数的零填充是代数事实，不是把未知幂级数尾补零。

定义

$$
W_x=\max_{x_i\ne0}(\deg x_i+d_i),\quad
W_y=\max_{y_i\ne0}(\deg y_i+d_i),\quad W=W_x+W_y.
$$

每一项 $C_{ij}$ 满足 $\deg C_{ij}+m\le W$，故两图的第 $k$ 个乘积坐标次数都不超过 $W-d_k$。实现实际核每个 pair 分量的这个界；散射若遇到越过全局缓存界的位置，必须实际核该行全零，不能直接丢弃；最终每个非零结果坐标再核精细界 $W-d_k$。

零向量先被完整系数分组识别为空支集，不产生任何 pair。输出仍是同一306维模块的准确零向量。

## 5. 全系数返回与证明范围

最终只建立306个调用者域上的结果坐标多项式。稳定的 `row_polynomials_and_return` 未改：它把所有结果多项式的全部系数独立拆回素域，重建整个矩阵，再与完整累加器逐项比较。这覆盖每一个输出坐标、每一个被证明可能非零的次数、原二次域的两个分量。

正确性的依据是：原全表已证、(1)的全部有序项重组、(2)的准确线性收缩、(3)的原加权图变换和(4)的实际域乘法恒等式，加上完整来源/系数返回。它不依赖抽样。

作为额外 API 兼容门，初始化时复用稳定适配器原本已实际构造且与旧 API 完整相等的 unit 与两坐标算子，不再另造算子。直接算法的 unit 平方、两坐标乘全306坐标向量、两坐标平方分别与该原算子乘积核全部306坐标。两个图表、每次原常数扩张都做此完整比较；它们不代替对任意后续输入的上述证明。

## 6. 可核的内存边界与成本限制

记 $n=306$，$f=[k:\mathbf F_p]\in\{1,2\}$，$B=128$ 为 pair 批大小，$A=32$ 为次数块高，$R_m=|\mathcal B_m|$。因 $m\le8$，原完整基给 $R_m\le1890$。

每次 native 收缩的数值载荷界为：

| 对象 | 素域元素个数上界 |
|---|---:|
| 从原表复制的所选行 | $B R_m\le241920$ |
| 一份输入次数块 | $A B\le4096$ |
| 一份完整收缩输出块 | $A R_m\le60480$ |
| 一份加零列输出块 | $A(R_m+1)\le60512$ |
| 当前散射块 | $A n\le9792$ |
| 全部结果分量累加器 | $f(W+1)n$ |

这些数值矩阵只在当前批/块中使用，不建立 pair selector 的持久缓存。实现记录实际峰值元素个数及每批保留的完整 pair 多项式系数数目。

原输入的分量矩阵与多项式、批内 pair 多项式、最终结果回拆会产生额外线性载荷。若 $D_x,D_y$ 是两个输入的最大坐标次数，则新增载荷的量级为

$$
O\bigl(f n(D_x+D_y+2)+fB(D_x+D_y+1)
+BR_{\max}+A(B+R_{\max}+n)+fn(W+1)\bigr).
$$

原已存的完整乘法表、原有最多64 MiB selector 计费缓存、Sage/Python 对象及 native 乘法实现的内部工作区不计入上述新增载荷；本表不是进程 RSS 的硬上限。组装/替换矩阵时可能短暂保留前后两份同量级块，仍不形成306²个结果多项式的完整算子。

**确定的改进**是普通向量乘积不再分配完整306×306的多项式算子，不再构造/返回它的306²个坐标；最终结果只有306个坐标。对于全坐标、较高次数的输入，去除了原算子可达 $O(n^2W_x)$ 的多项式系数载荷，改为上述线性输出载荷与定长 native 块。稀疏输入还只处理真正有至少一个非零有序项的 pair；其数目不超过 $\min(n_xn_y,46971)$。

这不证明每个输入的运行时间都下降。native 收缩涉及完整 pair 系数的次数，$D_y$ 很大时它与旧单算子路径的乘加分布不同；对非常低次数稀疏输入，批复制/返回的固定开销也可能占主导。平方时准确省去对称重复的输入多项式乘法，但实际总时间和峰值仍需公开 Actions 回执。候选不会自行启动重复 run。

## 7. API 与回执兼容

旧函数入口新增两个带默认值的可选参数：`vector_pair_batch_size=128`、`vector_degree_block_size=32`；旧调用不需改变。

完整矩阵 API 和 `last_coefficient_contraction` 的语义保持为矩阵算子。新 `multiply_with_certificate` 返回 `(vector,receipt)`，新 `last_direct_product` 返回最近一条直接乘积回执。两个新 API 同时位于顶层、原 `constant_extension` 返回值和每张 `chart` 中。

`coefficient_contraction_summary` 保留全部旧算子字段，另列 direct 调用次数、原 pair 多项式乘法次数、native 收缩次数、全部输出系数检查数和按调用顺序的完整 receipt SHA-256 流。不会把直接乘积冒记成已经造过完整矩阵。

每条 direct 回执绑定原完整乘法表签名、原域及图、两个输入的完整分量、实际原 pair/row 顺序、全部 native 收缩、完整 recipe 散射及最终所有结果系数。大表仍留内存，代码不保存可重算数据。
