## 4. reach 证明完整覆盖参数边界

这是本稿最需要独立核查的部分。本审没有引用无边闭面 R10。

从柱弯公式可知 $\|D^2G_\lambda\|\le K=4B/(e\ell)$。
用变量 $t=\ell/(s-a)\ge1$，相关函数为 $t^2e^{1-t}$，
导数符号由 $t(2-t)$ 决定，最大值是 $4/e$；此计算另由本审符号核验。

若空间点 z 有两个不同最近点 $p=G(x),q=G(y)$，
参数盘的凸性允许从 x 沿 $y-x$ 方向取一侧导数。最近点条件给

$$
(z-p)\cdot DG(x)(y-x)\le0.
$$

即使 x 在参数边界，这个不等式仍成立；不需要把 $z-p$ 当成只垂直曲面的向量。
Taylor余项与全域弦长下界继而给

$$
(z-p)\cdot(q-p)
\le \frac{dK}{2}|y-x|^2
\le\frac{dK}{2c^2}|q-p|^2,
$$

其中 $d=|z-p|$。两最近点等距又给左边等于 $|q-p|^2/2$，
于是 $d\ge c^2/K$。空间弦长转换的因子确为 $c^2$；作者没有漏掉一个 c。
紧性保证最近点存在，因此这直接证明包含边界的整个像集合的 reach 下界。
该论证不自动适用于挖去内盘后的环域，作者已明确排除此推论。
