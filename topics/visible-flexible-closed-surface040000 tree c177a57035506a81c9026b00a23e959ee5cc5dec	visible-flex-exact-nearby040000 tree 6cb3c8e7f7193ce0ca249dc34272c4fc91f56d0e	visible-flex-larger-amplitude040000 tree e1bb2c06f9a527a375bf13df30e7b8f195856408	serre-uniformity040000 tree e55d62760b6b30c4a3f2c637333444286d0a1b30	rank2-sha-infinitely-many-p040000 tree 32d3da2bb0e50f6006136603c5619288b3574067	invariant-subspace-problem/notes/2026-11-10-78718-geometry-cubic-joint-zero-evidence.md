## 2. 与极点翻号区分

在 n=4 共振支上，s=−0.005 时 C4≈+1.32098558、n=8 归一残差≈1.35993；
s=−0.006 时 C4≈−0.60653747、n=8 归一残差≈1.36778。求根沿该负 bump
小区间进行，实际每个评估点的 n=8 残差均保持约 1.36。

相反，从 s=0 到 s=+0.005 的一次翻号伴随 n=8 归一残差翻号，
所以没有将它称为三阶零的证据。当前记录不严格排除负区间内未采到的
倍频共振；若要证明参数存在，必须给完整区间或隐函数控制。
