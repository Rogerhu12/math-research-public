## 1. 固定目标与归一化

已逐式核目标 $g=ds^2+a^2(\eta ds+\rho d\psi)^2$。在 $a,\rho>0$ 时，$b_1=(1,-\eta/\rho)$ 与 $b_2=(0,1/(a\rho))$ 对这个目标正交归一：代入后分别给范数平方1、1和交叉0。把坐标残差矩阵 $\left(\begin{smallmatrix}E_r&F_r\\F_r&G_r\end{smallmatrix}\right)$ 左右乘这一标架，恰好得到§2全部三式。再通分得到 $N_E,N_F$ 版本，没有遗漏一个 $a$ 或 $\rho$。

关键范围正确：归一化使用固定解析目标的 $a,e,e_s$；不能换成实际图半径，不能对供应器的值余项求导。整个操作仅改善同一图的上界，不改变方程或实际误差。

## 2. 点值系数盒与 Bernstein 变换

§3最需审查的是系数可以随径向位置选择的问题。对任意固定位置 $u_*$，用供应器允许的系数向量表示其真实值；卷积和相减给出的系数向量属于逐项向外形成的盒。对这一向量的形式多项式，幂基到 Bernstein 的恒等式在 $u_*$ 成立。基函数非负且和为1，因而该值属于所有允许 Bernstein 系数的统一凸包。这个论证先固定点、再使用对所有系数向量有效的代数恒等式，不要求同一系数向量在不同 $u_*$ 同时代表目标。其量词合法。

对同一个固定 $u_*$，目标供应量都不依赖角变量；因此由它们构成的真实 Fourier 系数也不依赖角变量。后续角 Taylor 没有对一个任意随角变化的误差函数直接求导。原余项若以点值盒形式进入计算，则必须随所有系数运算保留；该稿明确要求保留而没有遗失。

径向子区间用精确有理仿射换元；对二元情形，两个 Bernstein 基的张量积同样非负、和为1。点值系数盒的论证逐点保持有效。

## 3. 第一档和第二档

第一档先对已相消的每个真实 Fourier 系数作径向包围，再乘以其角弧上的完整三角范围。极值须纳入，不能只包端点；该稿指定已审有理三角程序并要求按精确弧端点覆盖。虽然独立区间会损失相关性，但乘加包围仍有效。正分母门必须在除法前检查。

第二档对每个频率使用有限实 Taylor 定理。所有阶正弦/余弦导数绝对值不超过1，所以 $|R_j|\le|j\delta|^{p+1}/(p+1)!$ 对闭弧全体成立。把系数的统一绝对上界 $C_j,D_j$ 乘入并求和正好给稿中 $\mathcal R_P$，无需假设渐近收敛。各频率有限项先相加再转二元 Bernstein，不等于把余项互相抵消；稿中保留对余项的绝对和。对 $\rho,\eta,N_E,N_F$ 适用同一有限 Fourier 论证，删除频率时完整范数必须加入余项的要求也正确。

对每盒实对称矩阵，选任一特征向量中绝对值最大分量，从特征方程立即得特征值的绝对值不超过该行绝对和。故 $\max(U_{11}+U_{12},U_{12}+U_{22})$ 是算子范数上界；最后求和仍必须向外舍入。
