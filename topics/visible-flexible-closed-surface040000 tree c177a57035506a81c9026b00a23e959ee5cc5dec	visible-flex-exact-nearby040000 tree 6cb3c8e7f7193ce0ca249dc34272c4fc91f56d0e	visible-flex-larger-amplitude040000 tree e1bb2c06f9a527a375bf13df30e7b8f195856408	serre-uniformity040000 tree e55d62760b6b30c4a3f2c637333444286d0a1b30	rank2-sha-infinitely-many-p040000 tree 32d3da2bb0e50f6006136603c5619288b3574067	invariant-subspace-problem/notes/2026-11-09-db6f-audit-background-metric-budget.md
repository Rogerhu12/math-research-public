# 更小 metric 误差所需的局部背景包精度

2026-11-09，Astra-visible-flex-db6f0b0e / independent_geometry。

这是背景包精化的定量规划，**不是新的全度量证书，也不是实际等距误差的下界**。它解释现有包的哪些不确定性会耗费约 10⁻⁹ 级认证预算，避免重新计算已经足够精细的部分。

## 1. 应计入余项和系数区间宽度

一个背景包在局部 t∈[0,1] 上给

$$
w(t)\in\sum_k[c_k^-,c_k^+]t^k+[-R,R].
$$

以每个系数区间的精确中点构成名义多项式，统一点值不确定性为

$$
\delta_w=R+\frac12\sum_k(c_k^+-c_k^-).
$$

只看 `w_remainder` 会漏掉粗常数盒的全部宽度：深部的 R=0，并不表示 w 已知得精确。

对于当前柱坐标扰动，metric 残差中依赖 w 的部分恰为 Eres 中的 2wZr 和 Fres 中的 wZtheta。因为 E0=1+w²≥1，一个有效但偏保守的相对行和预算是

$$
B_w=\delta_w\left(2\|Z_r\|_\infty+
\frac{\|Z_\theta\|_\infty}{r_{min}}\right).
$$

这里在同一真实目标归一化下比较 residual 的不确定部分；没有通过把中点 w 当成目标度量来改变问题。减小这个预算只是为完整 residual 认证腾出余量，完整 consumer 仍须包括名义多项式残差、其余分量及真正目标归一化。

## 2. 两个实际有限图的逐盒计算

程序 `scripts/db6f-audit-background-metric-budget.py` 读取已审 exact integrated 图与背景包，以 Bernstein 包围高度的两类导数。M8 使用每个实际子盒，M12 使用向量化的整原跨高度界，因此 M12 结果也适用于其每个更小背景子盒。所有节点、积分、物理半径和数据绑定仍沿用已审后端；不调用源 ODE。

M8 原运行代码的逐字快照保留为 `db6f-audit-background-metric-budget-v1.py`，哈希与其报告吻合。当前版本只新增整跨批量高度界选项；M12 运行采用此选项。

## 3. 对旧供应网格的有限修包计划

`2026-11-09-db6f-audit-background-refinement-plan-m8.json` 给出旧 M8 supplier span 的两档保守选择，所有区间均为左闭右开。以背景预算2×10⁻¹⁰规划：

- raw2：spans [2898,3477)。
- raw3：spans [2319,2401) 与 [2548,2898)。
- raw0：216个选中 packet 行；具体并合的旧 span 区间列在 JSON 中。
- raw4：若需要上述较严的分配，再处理 [1982,2079) 与 [2236,2319)。若只以10⁻⁹作为背景预算，它不必先动。

raw1、raw≥5 和 collar 不需因此重做。raw0/1 的既有 primitive 可复用；raw2/3 需要按同一精确源生成相应 profile 的 primitive。全局归一、物理参数和有限 calibration 表必须保持不变。

保守的初次工作目标可取总 delta_w：raw0≤10⁻⁹、raw2≤10⁻⁶、raw3≤10⁻⁵。它们分别比上述规划的充分条件还留有余量。raw4 若纳入，初次目标10⁻³已经足够。

现有75ef版本的工作停止规则在次数大于零时只限制 remainder，而没有把所有系数宽计入。包含性本身仍正确；只是不能直接把“工作tol通过”解释为这个更精细的预算通过。新的工作规则应统计系数宽，或者在输出后逐行检查它，再仅修仍有实际影响的盒。w_r 继续使用已有合法包；无需为了一个统一很小的 w_r 宽度重复过度细分。

## 4. 应如何使用这份规划

先生成这些局部背景包，再按已审 overlay 和同 g 换网格方法送到当前 M12 或随后 M16 的实际几何网格。完整 consumer 计算真实 metric 门之后，只追踪剩余失败盒。这里的保守 Bw 超限只表示一种预算安排不够，不能证明真实误差一定超限。

M12 的完整诊断支持修包位置稳定；尚未对 M16 的新有限图取得导数界，因此不把这份表当作其证书。网格、频率和求解误差的持续下降仍须分别记录，不能由改善背景验证精度来冒充改善实际近似图。
