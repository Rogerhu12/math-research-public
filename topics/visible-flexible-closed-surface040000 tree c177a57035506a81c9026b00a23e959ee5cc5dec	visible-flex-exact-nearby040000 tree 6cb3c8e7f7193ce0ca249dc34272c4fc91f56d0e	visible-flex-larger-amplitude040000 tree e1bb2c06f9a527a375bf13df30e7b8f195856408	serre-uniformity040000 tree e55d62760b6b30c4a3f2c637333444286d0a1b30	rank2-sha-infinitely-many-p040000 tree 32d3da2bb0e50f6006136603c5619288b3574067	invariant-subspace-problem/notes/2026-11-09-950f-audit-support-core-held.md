   $d_\phi(\gamma\cdot u(t))=\rho\sin(t-\phi)$ 正确。
   $\rho>0$ 使每个法向有唯一支持点；这给单射及严格凸性，曲率
   为 $1/\rho$，周长精确为 $2\pi$。

3. $|\sin(jx)|\le j|\sin x|$ 给出的导数主项控制包含两个 $j$
   因子，原文条件 $c_1>\sum_{j\ge2}j^2|c_j|$ 正确。

   法向处得到实际最大/最小半径。精确差为 $2\sum_{j\text{奇}}c_j$。

   的支持差给出，对其余曲面由 $|z|\ge\ell$ 给出，所以单向
   距离已足以证明 Hausdorff 下界 $\min(\Delta,\ell)$。
