## 1. 作者原文的适用条件与符号

所引定理用于 \(C^3\) 嵌入、定向、严格负高斯曲率曲面上的闭渐近曲线。
交叉按投影方向高度区分上支与下支，符号为上支投影切向叉乘下支切向
再与投影方向点乘的符号。取
\[
 n^\perp=n\times T,\qquad
 \tau_g=(n^\perp)'\cdot n,
\]
原定理确为
\[
 \operatorname{Lk}(\Gamma,n)
 =\operatorname{Cr}(\Gamma_e)
  +\frac12\#\{e\cdot n=0\}\operatorname{sgn}\tau_g.
 \tag{A}
\]
它不要求 Gauss 映射全局单射，不要求普通空间曲率处处非零。
作者原文讨论 Gauss 映射单射的其它问题，不能移作本定理的附加假设。
原文的 Darboux 标架处理曲率零点，不借不存在的 Frenet 商式。
本文第 2—6 节逐一支付本例的几何、一般位置和横截零点条件。

原文采用的第二形式符号与常用 \(F_{ij}\cdot n\) 约定可能相反；
这不改变“渐近”即该方向第二形式为零，也不改变 K。
这里直接使用其 \(\tau_g=(n\times T)'\cdot n\) 定义计算符号，
不从另一个第二形式符号约定猜测正负。

## 2. 真实负曲率条带与测地扭率为正

已审种子给解析闭嵌入曲线和全周期正定向正交标架
\[
 \gamma'=T,\quad d'=\alpha T-N,\quad
 T'=-\alpha d,\quad N'=d,\qquad N=-B.
\]
沿曲线 d 与 T 单位正交。定义实际直纹图
\[
 F(r,u)=\gamma(u)+rd(u).
\]
在 r=0 微分秩为二，局部平面投影给单射图。
紧致性给统一浸入宽度；若任何宽度都发生两点同像，可取两列 r 趋于 0
的同像点，其极限落在嵌入曲线的同一材料点，违反该点附近的局部图单射。
因此存在统一正宽，使双侧开条带成为解析嵌入。

逐项有
\[
 F_r=d,\qquad F_u=(1+r\alpha)T-rN,
\quad g=dr^2+a_g^2du^2,\quad
 a_g^2=(1+r\alpha)^2+r^2.
\]
该平方和从不为零。L=0，混合第二形式为 \(-1/a_g\)，故
\[
 K=-1/a_g^4<0.
\]
在 r=0，法向为 \(d\times T=N=-B\)，
\(F_{uu}\cdot N=T'\cdot N=0\)，所以曲线确为该实际曲面的闭渐近曲线。
可选双侧开带使曲线位于曲面内部；无须等待任何未来封帽存在。

按作者定义，
\[
 n^\perp=N\times T=-d,\qquad
 (n^\perp)'=-d'=-\alpha T+N.
\]
因此
\[
 \boxed{\tau_g=1.}
\]
它不是标架系统中 \(\beta=d'\cdot N=-1\) 本身，而是其相反数。
这是本计算的一个关键符号。
即使 \(\alpha=0\)、普通空间曲率为零，d、T、N 仍解析正交，以上计算
照常成立。原定理所需的正则性和非零测地扭率均已真实支付。

## 5. 法向 x 分量的全部四个简单零点

法向满足 \(n_x=-\rho\cos\vartheta\)，\(\rho>0\)。
只需计数 \(\cos\vartheta=0\)，但 theta 不单调，必须把其局部最大值
的位置与范围支付。

在第一闭四分区，
\[
 \vartheta'=2+\frac{13}{3}\cos2t,\qquad
 \vartheta''=-\frac{26}{3}\sin2t<0
 \quad(0<t<\pi/2).
\]
导数从 \(19/3\) 严格降到 \(-7/3\)，所以有且只有一个临界点
\[
 2t_*=\arccos(-6/13).
\]
theta 先增后减，其端值为 0 和 pi。
因末端导数严格负，最大值严格大于 pi。

在该临界点，
\[
 \vartheta(t_*)=\arccos(-6/13)+\frac{\sqrt{133}}6.
\]
\(-6/13>-1/2\) 且 arccos 严格递减，故第一项小于 \(2\pi/3\)；
\(133<144\) 给第二项小于 2。再由 \(\pi>12/5\)，
\[
 \pi<\vartheta(t_*)<
 \frac{2\pi}{3}+2<\frac{3\pi}{2}.
\]
这里只需粗的严格圆周率界；已审 Machin 证书甚至给 \(\pi>3\)。

因此增加段只穿过一次 theta=pi/2；
下降段的值域在 \([\pi,\vartheta(t_*)]\)，没有任何余弦零点。
最大值又小于 \(3\pi/2\)，排除了该零点和所有更高的余弦零点。
第一开四分弧恰有一个零点，位于严格增加段，所以 theta' 非零。

对第二四分弧使用
\[
 \vartheta(\pi-t)=2\pi-\vartheta(t).
\]
它恰对应一次 theta=3pi/2；由对称微分或上一个根的 theta' 非零，
该零点也简单。
再由
\(\vartheta(t+\pi)=\vartheta(t)+2\pi\)，后半圈复制这两个零点。
四分端点的 theta 依次为 0、pi、2pi、3pi，余弦均非零。

最后在任何已数出的根上，
\[
 (n_x)_t
 =-\rho'\cos\vartheta+\rho\sin\vartheta\,\vartheta'
 =\rho\sin\vartheta\,\vartheta'\ne0.

\[

## 6. 固定的特殊方向为何能使用“随机方向”表述的定理

原定理以随机方向陈述，原文证明处理投影正则和相应横截计数。
本例已经逐项证明所需条件，不能因为 e_x 是刻意选定就否定适用性。
还可完全独立地用稳定性消除对此措辞的疑问：

投影切向范数在紧材料圈上有正下界，故小扰动方向后仍正则。
唯一双点的两条投影切向线性独立；以两个材料参数为未知量，
投影重合方程的二维导数可逆，隐函数定理给该双点的唯一持续。
高度差和交叉行列式严格正，所以其上下顺序和正符号保持。

参数对空间中，离开对角线与该双点对小邻域的部分紧，
原投影差不为零，故有正下界并排除新的远端双点。
对角线附近，由正则投影曲线的有限个单调局部图，可统一排除不同近参数
相交。由此小方向扰动不会产生额外交叉或三重点。

四个法向零点都是简单的，隐函数定理使每个各持续一个零点；
其余紧参数区域上的法向分量有非零下界，排除了新根。
所以在 e_x 的某个开方向邻域内，交叉数仍为 1，零点数仍为 4。
该开邻域包含定理所说的随机一般位置方向；链接数本来不依赖观察方向。
因此即使把“随机”严格按几乎处处解释，同样得到 e_x 所给的精确整数。

代入 (A)、第 2 节和第 4—5 节，最终为
\[
 \operatorname{Lk}(\gamma,N)
 =1+\frac12\cdot4\cdot1=3.
\]
这里所有三个符号输入均已独立支付，没有把正负约定隐藏在绝对值中。

## 7. 分离曲线的法向自连结必须为零

现在考虑本题允许的闭嵌入定向曲面 S，至少具有本题的 \(C^2\) 正则性，
包含这条固定曲线，并且沿曲线的单位法向为 N。
此处不要求 S 全局负曲率或解析：链接数已经由前述实际解析局部条带
计算，只取决于曲线和法向场。

若 gamma 在 S 的所在连通分量中分离，则其中一侧的闭包 Sigma 是
紧致定向曲面，其唯一边界是 gamma。
S 是闭嵌入 \(C^2\) 曲面，紧致性和法向局部坐标给统一正宽的管状邻域。
因此对充分小正 epsilon，
\[
 \gamma_\epsilon=\gamma+\epsilon N
\]
与整个 S 不相交，尤其与 Sigma 不相交。

选 Sigma 的方向使其边界方向与 gamma 一致。
链接数的曲面相交数定义于是给
\[
 \operatorname{Lk}(\gamma,\gamma_\epsilon)
 =\Sigma\cdot\gamma_\epsilon=0,
\]
与刚计算的 3 矛盾。
若选择另一侧或相反曲面方向，零仍是零，不可能靠取向解决这个矛盾。

这个证明不要求 Sigma 是圆盘：只要 gamma 是它唯一的边界就成立。
因此它排除该固定法向作为任意分离侧的单独封帽边界，而不只是排除某个
特定轴对称圆盘。相反，若是非分离曲线，切开曲面产生两个边界副本，
上面“以 gamma 为唯一边界的 Sigma”步骤不存在，不能沿用矛盾。

## 8. 改法向符号、同一切平面场与拓扑范围

把 N 整体改为 -N 不改变此自连结数。
一个直接证明是使用法平面中的全局单位向量族
\[
 V_\theta=\cos\theta\,N+\sin\theta\,d,\qquad0\le\theta\le\pi.
\]
d、N 始终单位正交并垂直于 T，故 \(V_\theta\) 从不为零。
紧致嵌入曲线的法管邻域允许一次选定足够小 epsilon，使所有
\(\gamma+\epsilon V_\theta\) 都与原曲线不交，且是连续同伦的推移。
因此两个端点推移的链接数相同。

若只固定切平面场而不固定法向定向，则闭曲面法向沿连通 gamma 只能
连续地取 N 或 -N 中的一种，不能在中途任意换号。
所以第 7 节的分离限制确实约束该固定切平面场，不依赖朝向选择。
