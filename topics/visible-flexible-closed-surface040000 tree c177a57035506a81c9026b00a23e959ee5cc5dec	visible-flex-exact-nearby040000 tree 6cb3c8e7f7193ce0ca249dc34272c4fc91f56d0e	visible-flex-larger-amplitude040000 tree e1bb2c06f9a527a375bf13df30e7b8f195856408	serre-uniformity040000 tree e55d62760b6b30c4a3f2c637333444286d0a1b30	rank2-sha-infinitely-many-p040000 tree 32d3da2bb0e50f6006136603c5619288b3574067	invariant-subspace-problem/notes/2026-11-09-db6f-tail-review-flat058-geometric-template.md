## 3. 全角与全半径的两点核门

帽—平环的全角论证继续从 $|p\times q|^2/|p-q|^2$ 出发。把 $u=\cos\theta$ 作为变量，分子凹、分母正仿射，故在整个 $[-1,1]$ 上由两个端点比值下界。这是连续全角论证，不是有限采样。

与圆柱稿不同，现在 $c$ 可在 $[c_-,c_+]$ 变化。两端分子的正下界使用

$$
C_-=c_-V_{lo}-zR_{hi}>0,\qquad
C_+=zR_{lo}+c_-V_{lo}.
$$

负向分母的水平距离上界是 $R_{hi}-c_-$，正向分母则是 $R_{hi}+c_+$。这些取端方向依赖已核 $R_{lo}>c_+$；竖直项则由 $V_{lo}>z$ 得正确上界。作者式(10)完整覆盖所有半径，而不是误用某一中间圆周。
