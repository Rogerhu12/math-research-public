## 3. 独立连续几何验证器的数学定义

脚本：`../scripts/db6f-audit-continuous-hermite.py`。
它不导入原求解器或原几何评估器，只读取 gzip 中的共享节点二阶 jet、节点和逐段平均高度增量。

每个保存的 binary64 常数按精确二进有理数解释。平均高度节点值定义为保存增量的精确有限和；脚本以 `Fraction` 累加后向外转成 binary64 区间。每段的准确长度是两个保存节点的精确差，不是另行舍入后的差；所有运算包围这个准确值。

对一个长度 $h$ 的段，令两端值、一阶导、二阶导为 $(Y_0,D_0,Q_0)$、$(Y_1,D_1,Q_1)$，$\tau=(s-s_0)/h$。脚本使用唯一满足这六个条件的五次 Hermite 多项式。各段共享同一节点 jet，故定义的有限图在每个内部节点精确为 $C^2$；计算机打印的拼缝小误差不参与这个结论。

径向值与前两阶导数的每个多项式被改写为 Bernstein 基；其全段值域包含于控制系数的区间凸包。可选径向细分只细分相同多项式，不改变图。

角向图写在正交旋转柱坐标架中：
$$X=R e_r+T e_\theta+Z e_z,$$
其中 $R,Z$ 为有限 $3j$ 余弦多项式，$T$ 为有限 $3j$ 正弦多项式。角导数包含坐标架的导数：
$$X_\psi=(R_\psi-T)e_r+(R+T_\psi)e_\theta+Z_\psi e_z,$$
$$X_{\psi\psi}=(R_{\psi\psi}-2T_\psi-R)e_r+
(2R_\psi+T_{\psi\psi}-T)e_\theta+Z_{\psi\psi}e_z.$$
这避免依赖原 adaptive chart 的链式实现；曲率和支撑本来就不依赖参数图。

三角函数区间不调用未经误差控制的 `sin/cos`。先以 Machin 恒等式及 arctangent 交错级数给出 $\pi$ 的有理上下界，再将相位按 $2\pi$ 减到 $[-\pi,\pi]$，用有理 Taylor 多项式和 Lagrange 余项控制两端值，并检查区间中是否含正负极值。由此包围整个角区间。

所有基本浮点加、减、乘、除、平方根后用 `nextafter` 向外扩一个可表示数；数组全部为 binary64，点积逐项进行，无隐藏的 BLAS 归约。输入必须有限，除数区间不能含零。实现所依赖的是通常的 IEEE754 binary64 算术和平方根正确舍入；这是一项明确的数值后端假设，不是符号化证明助理输出。

## 4. 连续曲率与支撑

脚本计算实际参数图的第一、第二基本形式，并取
$$n={X_\psi\times X_s\over |X_\psi\times X_s|},\quad
T=\frac{LG-2MF+NE}{EG-F^2},\quad
J=\frac{LN-M^2}{EG-F^2}.$$
分母用叉积范数平方的区间包围，避免差平方的无谓消去。主曲率绝对值由
$$\max|\kappa_i|=\frac{|T|+\sqrt{T^2-4J}}2$$
控制。浸入性的连续证书是叉积范数区间下界严格为正。

同时包围 $X\cdot n$ 和 $|X|$。旋转柱坐标架正交且定向一致，因此坐标内的点积和叉积正是欧氏运算。它只给所表示有限前缀的连续界；只有另行完成整个球面的拼接、尾帽认证，才能应用 R10。

## 5. 直接半周期见证

在入口 $\psi=0$，实际有限图的半径 $R$ 是保存径向系数的准确有限和；入口平面条件通过按位零检查。取
$$p=(R/2,\sqrt3R/2,0).$$
该点是入口材料点旋转半个三重周期后的像。脚本在整个三重周期计算 Fourier 几何，再将固定 $p$ 相对坐标分别置于三个 $2\pi/3$ 扇区，覆盖全圆而非只覆盖一个扇区。由每个格上的距离区间给 $d(p,\text{前缀})$ 的连续下界。

镜像下半图与 $p$ 关于 $z=0$ 对称，故有同一下界。尾和帽仍须另查；若使用中央直柱，该柱也须另查。直接见证不需要法向管达到 $5\%D$，因此比法向射线下界适用于更长的设计。
