# 已认证 M8 连续图的闭网格接口设计

作者：`/root/independent_geometry`，2026-11-09。状态：**具体设计与接口草稿，网格文件尚未生成，新增网格验证引理待独审。** 本任务只提供 G7 的可视离散近似，不改变 R17/R18 的证明图；G5 仍继续。

## 1. 冻结输入与三个时刻

基础对象选择 `2026-11-09-db6f-root-flat17-common-cut-m8s32.json` 指定的精确公共接缝图，以及它绑定的 M8 显式尾、R6 collar、精确桥根和背景定义。所有文件和源码以 hash 绑定；不从新的 M12 图借端迹或高度。

导出 $t=0,1/4,1/2$，相位为 $\alpha=2\pi t/3$，即 $0,\pi/6,\pi/3$。活动环带用

$$F_\alpha(u,\theta)=R_\alpha F_0(u,\theta-\alpha).$$

角节点取固定材料角 $\theta_j=2\pi j/N$，不把保存的辅助角 $\psi$ 当作材料角。前缀评价必须解

$$\psi-e(u)\sin(3\psi)/3=\theta_j-\alpha.$$

其中 $e(u)$ 按已审 exact-clamped-spline 的有理定义计算，再乘规定的五次截止和 $8q_{\rm ref}$。使用有括区间的 Newton/二分；报告最大数值反解残差。其输入 $\Theta_\psi>0$ 来自原已审构造，数值程序仍检查所有采样层 $|e|<1$。

## 2. 实际空间块

前缀读取已审 common-cut 的区间多项式定义，评价其数值代表，而不是重新拟合曲线。若柱坐标系数给 $R,T,Z$，平面坐标为 $(R+iT)e^{i\psi}$；最后再乘 $e^{i\alpha}$。

尾和 collar 的全部扰动通过已审 IntegratedTail/流式定义评价。上尾高度采用

$$z=H_c+\int_r^c w(\rho)\,d\rho-V_z(r,\theta-\alpha),$$

平面坐标为

$$e^{i\alpha}\bigl(r e^{i(\theta-\alpha)}+V_h(r,\theta-\alpha)\bigr).$$

这里对 **整个** $V_z$ 取负号。$H_c$ 从同一公共接缝定义取得；在数值评价中也可用“前缀精确均值的数值代表加尾端 $V_z$ 的均值代表”表达同一 gauge。下方活动带再整体作 $z\mapsto-z$ 镜像。

R6 使用原 cuff 与有限尾内端的同一两 jet 五次定义。核心、cut、cuff 都只保留一套共享顶点索引；先记录两侧独立数值评价的差，再按其已知的精确共同端迹使用一个代表值。若差超过记录的数值工作阈值，程序拒绝导出，而不默默拼接不一致的块。

## 3. 背景高度数值辅助接口

`tail_theory` 并行准备独立 JS helper，输入 M8 manifest、冻结的 160 项 source calibration、紧 alpha 区间及小型 radii JSON。它核查表中所有二进常数和原 `calibrationSteps=512`，使用已夹区间内原数值 alpha 代表，返回 $\int_r^c w$ 的数值采样及局部反解/求积诊断。

其 source `entry.integrate(x_0,x_1)` 的第 4、5 槽（从零计数）分别为 $\int wA$、$\int wB$；相对高度由第 4 槽加 alpha 倍第 5 槽给出。采用 cut 向内累计，避免引入任意绝对高度偏移。

这些高度值只用于网格采样，报告明确其数值求积和深尾截断范围。连续图的严格高度、metric、reach 和非全等结论继续引用原证明；本导出器不会把数值高度列升级为新的严格高度证书。

## 4. 固定帽和标记

上下 cuff 圆盘全部固定。**只有上帽加原 R16 的三个凸起，下帽保持平坦**。上帽三个中心为 $a e^{2\pi ij/3}$，$a=2/25$，半径 $b=3/100$，高度

$$h(\rho)=\frac1{2000}\max\{1-\rho^2/b^2,0\}^{3}.$$

它们位于半径 $.11$ 内；实际 cuff 半径大于 $.14$，所以 cuff 邻域仍是固定平环。全部帽顶点先生成一次，各时刻直接复制，报告对三个文件的固定顶点作逐位一致检查。

## 5. 网格组织与文件预算

使用共享环列和两个单独极点，按以下顺序走完整经向链：下极点、下帽、下 collar、下尾、倒序下前缀、唯一核心环、上前缀、上尾、上 collar、上帽、上极点。角索引取模 $N$，不另存重复的 $2\pi$ 一列。

初始工作设置为 $N=144$、前缀约 128 个均匀采样间隔并加入少量已知切换位置、尾约 64 个半径间隔并加入有限单元边界、collar 4 个间隔、帽若干包含凸起中心及边缘半径的环。这里只选择采样点，不改变或再插值底层连续图。近于浮点表示重合的采样点可合并，记录合并阈值；不改变原 Hermite 节点。

普通相邻环用两三角形拼每个四边形，两极用扇形。下至上经向与角向约定使外向面积为 $F_\theta\times F_s$；所有面采用同一一致方向。

输出 binary little-endian PLY，顶点为 float64，面为 uint8 计数加三个 int32 索引。若有 $V$ 个顶点，则球面三角网格 $F=2V-4$，主体约 $50V$ 字节。导出前按实际环数核算原始文件严格小于 5 MB；大于 1 MB 的文件只保存确定性 gzip 版本。三个时刻保留相同顶点编号和面表。

## 6. 独立的离散拓扑与方向检查

输出后的独立验证器重新读取 PLY 字节，并检查有限坐标、合法索引、无重复面、所有无向边恰出现两次且方向相反、整个面图连通、每个顶点 link 为一个环、Euler 特征数为 2。

每个浮点顶点按文件中精确二进值解释。以向外区间运算检查各三角形 $a,b,c$ 满足

$$\det(a,b,c)>0,\qquad a\cdot b>0,\quad b\cdot c>0,\quad c\cdot a>0.$$

这些条件同时排除退化面、确定朝外方向，并使径向投影在每个小三角形内部保持正向。它们是待实际运行的门，草稿没有假定网格已经通过。

## 7. 可选的完整 PL 嵌入核查引理

在上一节的闭合有向流形条件下，径向投影 $x\mapsto x/|x|$ 在各面内部和各边邻域局部保向。顶点的邻域可放进以其径向为中心的一个半球图；相邻邻点的正行列式使其 link 是有正绕数的角扇，因此顶点局部度为正整数。

每个三角形的径向有向球面积是

$$\Omega=2\arctan q,\qquad
q=\frac{\det(a,b,c)}{|a||b||c|+(a\cdot b)|c|+(b\cdot c)|a|+(c\cdot a)|b|}>0.$$

对 $q\ge0$，有 $q-q^3/3\le\arctan q\le q$。区间求每个面上下界，再把二进端点用 Fraction 精确求和。若总面积的包围 $[L,U]$ 满足

$$L>44/7,\qquad U<18,$$

则 $2\pi<\sum\Omega<6\pi$。总面积等于 $4\pi$ 倍全局整数度，所以度为 1。所有局部度均正，故没有分支或多个原像；径向投影为同胚，PL 曲面本身嵌入。

这为数值输出提供完整的离散无自交门，避免只以“闭合边表”代替几何嵌入。引理和实现须由 root 独审；如实际区间门未过，只能调整可视采样密度后重新验证，不能给单个坏面任意翻转来掩盖问题。
