# 好看的可弯曲闭曲面：按直径算的大幅度弯曲

> 2026-11-09 作者修订：完成标准中的形状变化量由对刚体运动取商的 $\delta$ 改为握持下的 $\delta_{\rm hold}$；原 $\delta$（现记 $\delta_{\rm E}$）的 $0.05\,D$ 改为更强目标。

## 问题

`topics/continuous-flexibility-swarm` 的 R520 证明了存在可连续等距弯曲的 $C^2$ 闭嵌入曲面，但振幅极小。本题要找一个做成实物后拿在手里明显能看出在弯曲的闭曲面：握持的部分不动，其余部分相对它运动。变化量和曲面的光滑程度都相对**整个曲面的直径**衡量。

**问题：** 找出闭曲面 $M$、度量 $g$ 和连续的一族嵌入 $F_t:M\to\mathbb R^3$（$t\in[0,1]$），满足下文全部条件。弯曲的机制不限。

## 完成标准

记 $D=\operatorname{diam}F_0(M)$。**握持区** $H\subset M$ 是一个闭子集，内部非空，$\operatorname{diam}F_0(H)\ge 0.2\,D$（可以由几个不相连的部分组成），并且对每个 $t$ 都有 $F_t|_H=F_0|_H$。握持下的变化量定义为
$$
\delta_{\rm hold}=\max_{t\in[0,1]}\ d_H\bigl(F_t(M),\,F_0(M)\bigr),
$$
其中 $d_H$ 为 Hausdorff 距离，**不做任何刚体对齐**。它度量的是握持区不动时，看到的像变化了多少，材料点沿曲面的滑动不计入。

另记对刚体运动取商的形状变化量
$$
\delta_{\rm E}=\max_{t\in[0,1]}\ \min_{A\in\mathrm{E}(3)} d_H\bigl(A\,F_t(M),\,F_0(M)\bigr),
$$
$\mathrm{E}(3)$ 为欧氏刚体运动群（含反射）。它只用于下文的非平凡性和更强目标。

**完成：** 给出满足以下全部条件的解，由可复现的脚本生成：

1. $M$ 是连通闭曲面；对每个 $t$，$F_t$ 是 $C^2$ 嵌入，$t\mapsto F_t$ 在 $C^2$ 拓扑下连续。
2. 存在满足上述要求的握持区 $H$，使 $\delta_{\rm hold}\ge 0.05\,D$；并且 $\delta_{\rm E}>0$（族不是整体刚体运动，且严格证明或由带误差估计的计算确认）。
3. 对每个 $t$，$F_t(M)$ 的 reach（法向单射半径）不小于 $0.03\,D$。这同时要求各点主曲率半径不小于 $0.03\,D$，以及曲面不同部分之间不过分贴近。
4. 全部 $F_t$ 对同一个度量 $g$ 等距：诱导度量相对 $g$ 的最大相对误差不超过 $10^{-6}$，在整个曲面和全部 $t$ 上计算。
5. **必须是某个精确解的近似。** 同一个几何（度量、参数、$t$ 的范围都不变）在网格、频率和 $t$ 的加密下，等距误差持续下降，直到机器精度或求解容差。若误差来自构造本身的固有缺陷，只靠层数、尺度比等渐近参数压小，则缺陷再小也只算中间结果。
6. 嵌入性和 reach 在全部 $t$ 上检查，不只检查端点。
7. 提供若干个 $t$ 的网格文件（例如 STL，单个文件小于 5 MB），并如实说明数值解与严格存在性之间的差距。

**更强的目标（作者希望达到）：** $\delta_{\rm hold}\ge 0.2\,D$；$\delta_{\rm E}\ge 0.05\,D$；或者严格证明存在满足上述比例的精确解。达到完成标准后请继续推进，并报告能达到的最大 $\delta_{\rm hold}/D$、$\delta_{\rm E}/D$ 和 reach$/D$。

以下只算中间进展：带边曲面片或环带（未闭合）；$\delta_{\rm hold}<0.05\,D$ 或 reach $<0.03\,D$ 的解，不论比例按环宽或其他长度算有多大；只有 $C^1$、带折痕或带奇点的曲面；某些时刻不嵌入的族；只有两个端点而没有连续族；误差未随加密趋零的近似解；任何不可能性或障碍结果。
