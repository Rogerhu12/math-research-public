# R301 实际返回层的三通道短轴修形

**数值证据；未取得连续 reach 证书。**

取[首个 2400 维真实位置](2026-11-28-2ecf-r301-first-2400-actual-xyz-and-missed-normal.md)，独立近对显示固定开发段上的点约为 (.01004, −.76411, .44066)，对应活动层的点约为 (.01451, −.62030, .31654)。正 y 侧也有对应的狭窄区。保持同一正径向度量、R293 整帽、领高及 .032 左右的真实重裁平环，将活动层沿这两处实测弦的分离方向移动。

修正只有三个非零的角通道。以 d=.006，有 ΔY=−.75dB(x)sin(u)，ΔZ=−.325dB(x)+.325dB(x)cos(2u)。B 用 22 个活动五次 B 样条，原计算区间为 [x_cut,x_end]，归一结点为 (.5t+.5t²)，t=j/23，j=0,…,23。两端按五次夹紧，去掉两端各三个控制点后，对其余各控制点的 Greville 横坐标 g_i 取系数 exp(−.5((g_i−.453)/.1)²)。用相同真实物理钟求 s 导数，全部空间端口及其二 jets 一致。该脉冲在完整 M2 笛卡尔 15 通道的基中表达，余通道的系数精确为零。
