# inverse-Q 的深尾归一化、耦合目标与多段接合

2026-11-12，metric_closure。接 R127；原六件闭组及其中源码没有改动。

## 1. 未改深尾的准确缩放引理

固定一个内端 a，设 a 以下的物理背景 g 完全未改。给定与原先相同的内侧
允许线性方向（例如同一有限 far 条件所选的一维解空间）。令 Hold 是该方向
中的一个非零 m2 解，且 Hold(a)≠0。任何同方向的新解 Hnew 都满足

\[
H_{new}(r)=sH_{old}(r),\qquad
s=\frac{H_{new}(a)}{H_{old}(a)}
\]

于全部未改深尾。

**证明。** 两个允许初态属于同一一维线性子空间。选定 s 后，Hnew−sHold
在 a 处的高度和物理径向一导都为零。它满足同一线性二阶方程
Hrr=−(wr/w)(Hr−4H/r)，由初值唯一性恒为零。
若 Hold(a)=0，可改用非零径向一导或 canonical 状态坐标归一；并不需要
排除该背景。

R127 的三个线性 II 分量和 Γ 都是同一 H 的线性泛函，所以各处和全域上确切有

\[
B_{II,new}=|s|B_{II,old},\qquad |\Gamma_{new}|=|s||\Gamma_{old}|.
\tag{1}
\]

把新 cut 高度归一为1，写 γ=|Hnew(a)|。若 CII、CΓ 是原未改深尾中
以 |Hold(a)| 归一的全域上界，则新整条尾的上界为

\[
\max\{B_{II,bridge},\gamma C_{II}\},\qquad
\max\{G_{bridge},\gamma C_\Gamma\}.
\tag{2}
\]

**数据范围不能省略。** 目前 geometry 的
`2026-11-12-fd2d-tail-inner-loads-wc01-n512-01.json`
（SHA256 `7e3be548e901a3c406967d7c82a855bde17c22e4e98148c04775faf61659e423`）
来自完整有限轨迹上的采样最大值。它们是相应连续上确界的下界，并不是
已经证明的连续上界。用它们构造 (2) 是设计筛查；换成已支付的连续上界后，
(2) 才给连续证书。

R127 多项式参考解在内端规定 J=0。原实际 bounded line 在有限浮点校准后
可能只有很小而非严格为零的 J/H；这时不能直接宣布该参考多项式就是新全尾
解。消费者必须将新背景接到同一真实内侧允许线并重算新 γ。对 raw0/.65/.1
的实际全160计算，geometry 已得到 γ=.0959542734163，确认了此例的预测，
但这不是其它候选免算的依据。

## 4. 两段 inverse-Q 的准确接合规则

设 [a,c]、[c,b] 上各有 R127 未校准的准确构造，背景在 c 具有同一 w 和 w_r。
将第一段 H1 在其外端归一为1，其内端为 −γ1；第二段 H2 在 b 归一为1，
在 c 为 −γ2。定义

\[
H(r)=\begin{cases}-\gamma_2H_1(r),&a\le r\le c,\\
H_2(r),&c\le r\le b.
\end{cases}
\]

两段均有 J(c)=0、Hrr(c)=0。因此在 c 位置值均为 −γ2，物理一导均为
−4γ2/c，物理二导均为0。这给准确 C² 的 H，且各段同一线性方程在接点连续。
背景由同 w,w_r 也准确 C² 接合。总向内高度比为 γ1γ2；第一段的 II、Γ
负荷在外端归一中须乘 γ2，第二段不乘。于是总设计负荷应取

\[
\max\{\gamma_2B_1,B_2,\gamma_1\gamma_2 C_{II}\},
\quad
\max\{\gamma_2G_1,G_2,\gamma_1\gamma_2 C_\Gamma\}.
\tag{4}
\]

证明已包含全部界面两 jet，不依赖第三阶径向正则性。若各段另作 S5 校准，
它们仍定义准确的新背景及端口，但原 H 的准确方程要按 R127 的缺陷式重新支付；
最直接的实际方案是对新背景重新计算整条 bounded line。当前尚未把一个两段
优化参数包冒充成已经闭合的强尾。
