## 3. 退出 rim 的有限线性 range 诊断

另名脚本 `fd2d-gc-coast-cell-range-screen.py` 对这个末态只做固定参数的两个局部单元诊断，`50494 / ce49fb → 4cd371` 真正退出 0，耗时 3.743563 秒。没有求第二个 BVP、更新输入场或添加新验收门槛。

固定实际 g、central/tail/δ 以及 reference 后，每个 Codazzi 单元均值对该单元两端共 94 个 correction 系数是仿射的。保留与 D2 高角补余共 128 行。诊断将两端的全部 94 个 state 系数放开，故比真实相邻单元/边界/曲率约束宽松。按列范数缩放后以三个 SVD cutoff 求数值最小残差，再用完整实际公式回代。

出口 cell 71 `[.8281800958020702,.8675434451024153]` 原完整均值峰 8.21357；即使用 2.13e7 大小的系数改动，cutoff 1e−10 的回代峰仍 6.09514。cutoff 1e−14 需要约 1.14e11 的系数改动，回代峰仍约 5.38934，formal κ 已达 3.11e11，显然不是有效几何初猜。病态方向的回代误差同时实际保留，未把 SVD 输出当精确证明。

另加由 sampled 分量界 `|n|,|m|,|l|≤1/.136` 推出的宽松 Fourier 系数盒；这个盒仍远弱于真正的谱曲率约束。凸 BVLS 的实测一阶 optimality 为约 1.12e−12，完整回代的高角均值峰仍 7.92974、L2 为 2.25836；即使这个宽松拟合的 formal κ 仍约 81.59。入口 cell 63 的同类宽盒拟合高角峰仅约 .01853，二者差异鲜明。

这些是**固定 p、固定当前角图与有限行空间的数值 range 诊断**，不是严格不可解证明，也不排除外设计、改变角图、丰富 lifting 或提高适当空间阶数。它们说明出口 `w′` 乘 reference 高模的强迫是实际表示困难；继续原初猜的 Newton 或笼统只加径向节点没有已见依据。下一步比较已有自然 ruling 标签下同一局部范围，再据实选择表示改动。
