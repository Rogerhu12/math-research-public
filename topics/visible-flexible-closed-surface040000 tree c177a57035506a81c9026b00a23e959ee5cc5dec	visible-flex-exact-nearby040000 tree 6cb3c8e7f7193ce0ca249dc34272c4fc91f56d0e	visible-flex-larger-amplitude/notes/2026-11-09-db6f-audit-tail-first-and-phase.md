## 2. 算法与有限 C² 映射审查

令 $G=V_r$。四次 $G$ 的系数由 $G(0),G(1),G'(0),G'(1),G(1/2)$ 唯一确定。把脚本的五个幂系数代入这五个条件，均逐项满足；直接积分得到

$$\int_0^1G(t)dt=\frac7{30}(u_0+u_1)+\frac8{15}u_m+\frac1{60}(v_0-v_1).$$

因此脚本从最深端的精确二进制 $V$ 开始逐跨积分，确实定义一个全局 C² 的有限 Fourier 映射。后续储存的位置列未作为独立插值约束。向外舍入逐跨累加包含该精确积分定义的常数项；不能把读取器中的近似 long-double 累加值换作这些精确常数项，而认证脚本没有这样做。

幂系数到 Bernstein 系数的公式使用精确有理数包围。对每个跨度、同一 Bernstein 基底，先对模式取绝对值和再对控制点取最大是有效的：每个基函数非负且和为一。平面复 Fourier 和与高度余弦和的角导数均由 $|m|^k$ 给界。零频在零阶按权重一处理，没有漏项。

## 3. 一个可用的加强：整个尾块的水平投影嵌入

这些同一份一阶界还直接推出整个有限尾及圆领的水平投影为一个嵌入环域。对每个 $r$，$|V_h|<r$ 保证同伦 $re^{i\theta}+tV_h$ 不经过原点，因此极角绕数为一。极角导数严格为正，故存在唯一的全局极坐标表示

$$X_h(r,\theta(r,\beta))=R(r,\beta)e^{i\beta}.$$

由坐标变换的行列式恒等式，

$$\left.\partial_rR\right|_\beta
=\frac{J}{R\,\partial_\theta\beta}>0.$$

于是每条固定极角射线上，截面半径严格随材料半径递增，各截面严格嵌套，整个水平映射单射且局部正则。紧环域上的连续单射是嵌入；因此对应空间尾块也嵌入。该结论与背景高度无关，可为尾块的竖直图积分提供坐标。它并不排除该尾块与另一个尚未组装的前缀或帽相交。

## 4. 全相位组装的条件论证

审读 `notes/2026-11-09-db6f-all-phase-assembly.md`，本次冻结 SHA256 为 `04b8a375639b88d8e4e050ce352f43766431a8b69ff02e06b9e0eca39ca08468`。§1–4 的条件推导 **PASS**，其输入条件仍须逐项认证。

角向材料坐标必须使用 $\Theta(s,\psi')=\Theta(s,\psi)-\alpha$ 的唯一解。$\Theta_\psi>0$ 及其 C² 正则性给反函数和组合的 C² 正则性；不能以 $\psi-\alpha$ 替代。$e'(0)=0$ 足以使 C² 的 $e$ 偶反射为 C²，出口 $e=e'=e''=0$ 保证物理图接口到二阶一致。

在活动带上，$F_\alpha=R_\alpha F_0\circ\tau_\alpha$ 且 $\tau_\alpha$ 是旋转目标度量的等距变换，所以相对 metric 算子误差的全域 supremum 不随相位改变。这里 $\tau_\alpha$ 和拉回恒等式限于活动环带。标记帽的 metric 未必轴对称，不应把 $\tau_\alpha$ 解释为整个标记球面的等距变换；帽误差恒为零，逐块取 supremum 就得到同一全域结论。

角平移在 C² 一致范数中连续只需要紧域上二阶导数的一致连续性，不需三阶空间导数。接口 jet 在旋转重标下不变，才可与固定帽作真正 C² 组装。

所有相位的支持、曲率、球包络均逐块由刚体旋转保持。完整球面正支持与实际曲率统一界给 R10 的嵌入及 reach。该论证不能从前缀局部界推出完整图的同一结论。

held 见证需实际参数区间包含见证旋转角；本候选使用 $\alpha=\pi/3$。完整相位公式对全部 $\alpha$ 成立，最终发布的 $t\mapsto\alpha(t)$ 应明确覆盖该角。固定帽给握持集合；R16 的三阶体积矩论证另外负责严格非全等，held 与体积矩不可互相替代。
